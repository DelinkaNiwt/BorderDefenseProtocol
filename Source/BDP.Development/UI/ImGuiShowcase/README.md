# ImGui（即时界面库）能力展示

这是仅限 RimWorld 1.7 的临时开发展示，和 BDP 业务没有关联。它使用游戏自带的 `Brutal.ImGui.dll` 原生控件与绘制接口，不打包第三方运行库，不注册服务或添加补丁，不读取人物、地图或存档。

## 打开方式

1. 同步整个模组项目到游戏使用的模组目录，确保 `1.7/Development/Assemblies/BDP.Development.dll` 和 `1.7/Development/Languages` 一起更新，然后重启游戏。
2. 开启原版开发者模式，进入游戏，打开调试动作菜单。
3. 搜索 `ImGui`，或在 `BDP` 分类找到“打开 ImGui（即时界面库）能力展示”。
4. 用顶部原生控件调色、调透明度/线宽，切换动画和抗锯齿；向下滚动浏览六个分区。第五区可按住鼠标拖动画布。

原版外壳负责关闭、拖动、暂停地图及输入遮挡；内部窗口和控件是原生 ImGui。展示复用游戏的原生帧和中文字体，不创建/切换游戏上下文，不另调用 `NewFrame` 或 `Render`（开始/提交帧）。其坐标从原版界面转换为物理像素，并只乘一次界面缩放。

游戏兼容层派发 Unity 风格事件，并不会自动向原生 ImGui 输入队列投递鼠标。`ImGuiShowcaseInput.cs` 在本窗口输入事件阶段转交位置、按键和滚轮；已接管事件会被消费，避免外壳重复拖动。拖出窗口仍能释放鼠标，关闭或失去输入权时清理本窗口接管的按键。所有逻辑仍在本目录，没有全局输入补丁；当前展示以鼠标操作为主，未建立通用键盘输入桥。

六个分区包括颜色/透明混合/渐变、基本形状/凹多边形/贝塞尔曲线、抗锯齿左右对照、假数据雷达/折线/虚线/柱状图、局部裁切/鼠标交互、动态仪表/轨道/波形。它不是“调用一个接口就自动生成任意图表”的通用业务库。

## 完整移除

以下路径均相对模组根目录：

1. 删除 `Source/BDP.Development/UI/ImGuiShowcase` 整个目录（含本说明及专属构建引用）。
2. 删除 `1.7/Development/Languages/ChineseSimplified (简体中文)/Keyed/ImGuiShowcase.xml`。
3. 删除 `Source/BDP.Development/BDP.Development.csproj` 中唯一的 `ImGuiShowcase.props` 导入。该导入已有存在性判断，目录删除后也不会因缺失导入阻止构建。
4. 重新构建 1.7 Development 并同步，重启游戏。仅删源码不会从已经编译的程序集里删除入口。

也可按既有发布流程整体移除 Development 运行内容。正式图表的 1.7 颜色适配位于 Core，不依赖本展示，删除展示不会撤销该修正。

- 两版本 Core、Content、Development 均编译通过，开发边界检查通过；1.6 产物中没有展示类型。1.6 图表开始/结束方法与基线反编译内容哈希一致。

- 独立进程调用真实原生库执行展示内容，在 1 倍、1.5 倍缩放及三种透明度下检查绘制数据、颜色、局部裁切命令和列表状态恢复，全部通过。26 个语言键均核对完整。
- 临时验证工程位于工作区 `tmp/bdp-chart-entry-regression` 和 `tmp/bdp-imgui-showcase-probe`，未加入模组运行内容。

- 新增 `tmp/bdp-imgui-input-probe`，直接编译实际窗口与输入源码，使用真实兼容事件和原生控件：旧窗口点击回归失败；修正后在 1 倍/1.5 倍缩放下通过按钮、滑块拖动、滚轮、滚动条拖动、事件消费、窗口外释放及关闭清理检查。只用最小替身提供原版外壳、输入权和坐标环境，没有操作正在运行的游戏。
- 本次修正的 1.7 构建及开发边界检查通过；1.6 未改动、未重新构建。尚未验证修正后的真实游戏鼠标响应，需同步重启后再检查控件、滚动、弹出选色器和窗口关闭/重开。独立原生帧验证不能替代这些游戏内项目。
