日期：2026-10-17。目标版本：1.6、1.7，已由用户明确确认。

以上伤害为投射物基础伤害。左轮等构型可能施加伤害倍率；不是任意成品、任何攻击轮次的总伤害。

### 必须先确认的语义

1. 卵之冠“非致命部位”是否指现有策略的“非要害”，还是要求排除移除后可能立即死亡的父部位？现有分类检查本部位的能力来源标签和核心标记，不递归检查其下属关键部位，不能承诺绝不致死。没有非要害候选时，现有策略会回退原版随机。
2. 用户已明确：部位选择必须由独立模块负责，崩解内部再次选择属于职责冗余，应删除；不采用直接配置崩解内部选择策略的方案。当前部位模块与崩解模块都在命中效果计划阶段收集贡献，接收同样的输入；前者选出的部位只写入汇总计划，后者读取不到并自行提前选择。应修正统一命中部位结果进入后续效果执行的缺口，不建立两个业务模块相互调用、直接传递或识别的专用关系。风刃主伤害与额外伤害已有统一部位结果消费路径，部位减益效果目前缺少对应接入。
3. 猎犬“最多1个”理解为允许0或1个中转锚点；不强制每次选锚点。黄蜂同步该限制。毒蛇和战斧仍保留8个锚点及已有自动绕障，不随猎犬收紧。
4. 现有高角射击保留。手动路线和高角同时适用时，必须明确先遵守路线，再由追踪接管；不能因最终目标不可视而无条件绕过手动路线。现有操作台间接攻击许可仍须检查，增加路线不应无条件放开全部不可视攻击。
5. 六项之外只报告精度问题，尚未获得顺带修正风刃、姿态判定等逻辑的授权。

## 二、精度如何生效

### 定义值不是最终命中率

四档精度分别是贴身、近、中、远的武器系数。原版按3、12、25、40格节点插值；40格之后使用远距值，不按各武器射程重新分档。

例如小行星在30.9格的武器系数约38.2%，不是远距字段20%；毒蛇在30.9格约39.0%。朱鹮在40格以上使用90%，仍会受到射手精度随距离衰减等因素影响。

普通射击链首先调用原版射击报告。标准瞄准值包含射手能力与距离、武器系数、天气、烟雾及适用的光照修正；对实体目标再计体型，掩体另行判定。射手能力不是只乘一次，而包含每格精度的距离次方。

BDP已经有仅限触发体的精度来源补丁：读取当前动作的四档字段，而不是误读触发体物品的默认100%属性。双侧发射还会暂时使用各发所属动作的四档精度；不应把双持直接理解为精度平均。

需要注意：BDP普通发射的首次偏射掷骰使用“忽略目标姿态”的瞄准值。原版报告仍含姿态信息，但不能把报告估计值直接当作BDP最终全过程概率。终端原版碰撞、目标移动、沿途实体、护盾与模块仍会影响结果。

## 三、会改变实际精度的逻辑

1. **路线段散布。** 毒蛇与战斧基础中间续段半径0.625、最终续段半径0.30格。按标准瞄准质量q缩放：半径＝基础半径×(1－0.75q)。q为1时仍保留0.15625／0.075格，q为0.5时为0.390625／0.1875格。这是半径上界，不是固定偏离量；狭窄路径的安全检查还会最多四次折半，或退回名义落点。
2. **路线精度的几何基准。** 初始射击报告使用射手到最终目标的距离，非绕行总长度；掩体来自最后锚点到最终目标的进攻方向。合理绕行能改变掩体方向，但不免除初始精度掷骰。掩体截获、强制偏射不允许继续原定路线；普通随机偏射允许保留偏移继续路线。
3. **追踪可以追回偏射。** 追踪模块在命中窗口内允许恢复原版命中类别过滤掉的目标；所以猎犬、黄蜂、卵之冠最终命中概率不能直接套初始瞄准值。追踪不是自动寻路；墙、屋顶和高角规则应分开看。
4. **地面搜索。** 弱追踪允许到地面后在3格内搜索可见目标，强追踪为5格；这属于搜敌锁定，不是用户要禁用的自动绕障路线。当前追踪模块会开放地面选点，因此部分功能的静态目标参数注释与最终操作能力并不完全一致。是否保留地面锁敌不在本轮六项需求中另作变更。
5. **高角射击。** 猎犬与黄蜂在适用许可下对不可视最终目标改用越顶投射物；屋顶限制仍在，高角不会提高四档系数，但会改变障碍碰撞机会。追加手动路线必须避免该模式与锚点约束互相抵消。
6. **部位策略不是瞄准精度。** 要害模块只作用于有效的单体直接命中，范围爆炸不使用它指定逐目标部位。现有要害候选根据意识、供血、呼吸、过滤、代谢来源和核心分类，再加权选择，不能等同于固定打头。
7. **铅弹增强。** 追加减益保持基础瞄准系数，但速度乘0.5，绕过已注册拦截器及伤害盾，并取消真实伤害、改附减益。因此对移动目标和带盾目标的效果命中会变化。爆炸型仍按范围目标施加减益，不能当作直接子弹命中。
8. **齐射与双持。** 各发独立解析，不能把四发或五发当成单发精度四倍或五倍；也不宜直接假设全部独立同分布，因为目标移动、掩体、追踪与同一轮几何共同作用。

## 四、问题分类与最小实施建议

| 事项 | 分类 | 本轮处理 |
|---|---|---|
| 六项数值平衡 | 新需求 | 待用户确认后修改共享定义 |
| 朱鹮缺要害模块 | 当前实现事实，非版本差异 | 按需求追加现有模块 |
| 卵之冠单加部位模块不影响崩解部位 | 实现错误：职责冗余与效果链消费统一部位结果的缺口 | 独立部位模块负责选择，删除崩解内部选择；效果执行消费统一结果，不增加业务模块之间的专用传递 |
| 路线和追踪同时提交飞行方向 | 新组合的实现约束 | 不能只排列定义；必须明确路线未完成时谁负责、何时交接追踪 |
| 战斧投射物参数未完全跟随母本 | 当前定义事实 | 本轮改为所需母本字段关系；删除速度140对应的过时注释 |
| 风刃声明80%却没有原版精度掷骰 | 实现不一致 | 只记录，不纳入本轮六项修改；是否调整需单独确认 |
| 普通首次掷骰忽略姿态 | 当前实现事实；是否需要纠正待确认 | 只记录，不扩展修复 |

推荐方案：数值和关系尽量在共享定义层处理，复用已有路线、追踪、部位策略；只有现有模块组合不能满足玩家行为的衔接点做必要源码改动。另一方案是增加专用模块及独立算法，但会增加维护量，没有必要优先采用。

后续实施验证重点：卵之冠同一部位第三次精确触发；非致命分类及无候选回退；猎犬／黄蜂0锚点、1锚点、拒绝第2锚点与禁自动路由；先路线后追踪；高角／屋顶／操作台许可；组合参数跟随；朱鹮直接命中后的部位覆盖。两版本分别构建与记录结果，游戏内行为用最小诊断和实测确认。
