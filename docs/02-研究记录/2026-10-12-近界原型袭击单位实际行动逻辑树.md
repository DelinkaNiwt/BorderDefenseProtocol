# 近界原型袭击单位的实际行动逻辑树

研究日期：2026-10-12。对象：近界宙域常规袭击中的近界民战斗员，装备近界原型触发体。本文把原版决策、BDP 攻击接入、持续任务和资源规则合并后解释，不把它们当作互不影响的两套系统。

后续根因分析已补充：[近界原型袭击远近战异常根因分析](C:/NiwtDatas/Projects/RimworldModStudio/模组工程/BorderDefenseProtocol/docs/02-研究记录/2026-10-12-近界原型袭击远近战异常根因分析.md)。原先将旧远程会话冲突概括为“入口暂缓”不够准确：它会清空原版攻击能力查询，使正常战斗分支不给任务；普通冷却结束也没有保证释放旧会话。另需区分走向敌人的任务与真正近战任务，不能把贴脸不动直接判断为短剑拒绝出刀。

## 依据与边界

- 原版依据：本机 RimWorld（边缘世界）1.6.4871 rev591 的真实游戏程序集，由 DecompilerServer（程序集源码查询服务）读取。
- BDP 依据：当前工作区源码、定义与实际安装的程序集。工作区和游戏安装目录的 BDP.Core.dll（核心程序集）、BDP.Content.dll（内容程序集）SHA256（文件校验值）分别一致；并反编译核实安装版的自动近战任务替换及设置继承。
- 原版职责树依据：RimSearcher（运行时定义查询工具）导出的 AssaultColony（进攻殖民地）职责。该职责中作战的索敌半径是 65 格、保留半径 72 格，不是父类默认的 56／65 格。
- 当前定义数据库查不到 BDP 派系，说明其导出快照不足以代表最新 BDP；BDP 配置采用工作区，并与安装目录核对。不能把旧数据库当成最新模组运行状态。
- 现有 Player.log（游戏日志）可佐证弹丸续射、短剑持续砍墙与卸装中断等路径。本次没有操作游戏逐分支复测；条件树是代码合并结果，日志只证明其中实际出现的路径，也不代表运行中的进程必然已经重新载入磁盘上最新的程序集。
- 普通袭击与皇室任务追兵共用攻击接入，但队伍退出规则不同，见文末。其他模组额外改变决策的分支不冒充 BDP 自身逻辑。

## 先认识这个单位

它是原版人类，不是另写了一棵思考树的新种族。生成时，BDP 只对近界派系成员补齐触粒子腺体、装备固定原型，并通过正式入口激活战斗体。

战斗体启动后，主槽一号的小兵短剑、副槽一号的小兵弹丸和特殊槽的小兵护盾分别激活。短剑与弹丸类型不同，不满足双持统一攻击的条件，因而没有“枪剑同时打一轮”的合成攻击。

```text
近界原型的可用战斗能力
├─ 默认远程主攻击：副槽小兵弹丸
├─ 默认近战主攻击：主槽小兵短剑
└─ 被动防护：特殊槽小兵护盾
```

**主槽不等于所有情况下优先出手。** 原版询问通用攻击行为时，BDP 优先提供弹丸；原版已经决定进行近战、询问近战起手时，BDP 才提供短剑。

## 合并后的总逻辑树

以下“依次尝试”都是前一项无法给出可执行任务，才进入下一项；不是同时做，也不是每个游戏刻从根节点全部重跑。已有任务会继续执行，任务结束、到期复查、常驻安全检查或外部事件才会推动重新决策。

```text
近界袭击生成
├─ 生成人类战斗员 → 补腺体 → 固定装备近界原型 → 激活战斗体
│  ├─ 成功：发布短剑、弹丸和护盾的当前可用结果
│  └─ 失败：记录初始化错误，不能假设三种能力已经生效
├─ 黑洞门持有尚未落地的人物，原版建立袭击队伍
│  └─ 人物分批落地后开始执行；无需等最后一人出门
│     边缘门／空间突袭门改变落点，不改变后续为普通立即进攻
└─ 落地后的行动循环
   ├─ 全局／高优先级状态阻断普通战斗？
   │  ├─ 死亡、离图：结束正常行动
   │  ├─ 倒地、必须卧倒：原版卧倒／爬行等分支
   │  ├─ 着火、危急精神状态、迫近爆炸、缺氧等：相应原版处置
   │  ├─ BDP 战斗体崩解：打断任务、禁用芯片，进入恢复流程
   │  └─ 存在有效的近身反击威胁：进入短剑持续攻击〔C〕
   │     该分支在普通进攻职责之前
   ├─ 队伍目前是否已经切换为撤离／绑架／偷窃／溃逃？
   │  └─ 是：执行对应原版职责，不再进入下面普通进攻清单
   └─ 仍为“进攻殖民地”：按以下顺序尝试
      1. 使用可用的战斗强化药物
      2. 使用可用且允许自动施放的攻击能力
         └─ 此原型不提供主动技能；战斗体短跳也禁止自动施放
      3. 搜索并对付有效敌方威胁〔A〕
         ├─ 成功安排射击／移动／近战任务：执行该任务
         └─ 找不到目标或无法安排攻击站位：继续第 4 项
      4. 就近破坏殖民地建筑／焚烧可破坏植物〔D〕
      5. 尝试破坏较远的殖民地建筑〔D〕
      6. 向可到达的最近有效敌方目标移动
      7. 放宽到可攻击的惰性建筑，继续破坏〔D〕
      8. 仍无任务：尝试为接近目标开路〔E〕
      9. 所有职责分支均无任务：回到人类思考树的后续分支
         └─ 非玩家人物最终可能离图／闲逛／空闲兜底，取决于当时状态
```

高优先级状态也有自身顺序，并非一套统一的抢占器：例如着火和危急精神状态位于近身反击之前；常驻树约每 30 游戏刻进行一次独立检查。这里合并展示它们对战斗主线的影响。

## A：选敌与站位，实际按弹丸来安排

```text
普通进攻的作战分支
├─ 处理旧目标
│  ├─ 已销毁／威胁失效／超保留范围／无法接触到达／过久未接战：丢弃
│  └─ 仍有旧目标：仍可再次选敌、换成新的合适目标
├─ 查询当前有效攻击行为
│  ├─ 弹丸可用：BDP 把弹丸作为原版远程攻击行为返回
│  │  ├─ 装备主攻击属性已桥接到弹丸
│  │  └─ 人物攻击查询后置接入也优先给出弹丸
│  │     例外：旧远程宿主绑定另一个实体时，BDP 清空查询结果
│  │     正常战斗因此失败，且并非冷却结束就一定恢复
│  └─ 无可用弹丸：保留原版返回的当前候选
│     不应直接等同于“BDP 一定自动选择短剑”；要看原版候选池
├─ 在职责规定的 65 格范围寻找有效敌人
│  ├─ 检查敌对关系、威胁有效性、可自动索敌、视线和必要可达性
│  ├─ 有当前可射目标：按原版射击评分筛选，再加权随机选择
│  │  受距离、最近攻击对象、目标是否瞄准自己、掩体、误伤等影响
│  └─ 当前无可射目标：尝试最近且满足条件的目标，以便移动接敌
├─ 没目标／目标心理隐形／没有有效攻击行为：作战分支不给任务
└─ 获得目标后按返回的攻击行为安排
   ├─ 返回近战行为：下原版追击近战任务，真正起手时走〔C〕
   └─ 返回弹丸：
      ├─ 当前位置可射，且有可用掩体站位：停下，进入战斗等待〔B〕
      ├─ 目标不足 5 格且当前位置可射：也可直接进入战斗等待〔B〕
      └─ 否则用弹丸射程寻找射击位置
         ├─ 找到位置就是当前格：进入战斗等待〔B〕
         ├─ 找到别的格：移动过去，之后再决策
         └─ 找不到：本次作战分支失败，转破坏建筑等后续分支
```

这里的“不足 5 格”是原版允许原地战斗等待的站位判断，**不是短剑切换距离**。弹丸射程 25.9 格，索敌半径 65 格；因此会先发现远处目标，再移动到能射击的位置。

旧目标保留半径 72 格也不是保证一直追到 72 格。保留还要求原版接战时限、威胁和可达条件；普通职责的 `chaseTarget=false`（本轮无法重新找到目标时不强行保留追击）。

当前实现还有一条异常边界：生成人物没有固定排除禁止暴力的背景／基因。人物自动远程接入检查了暴力禁用，但装备主攻击属性接入没有同步检查；原版可能先取得弹丸行为并进入射击评分，随后才在真正攻击入口被拒绝。因此禁止暴力的人物不能简化为“完全不会走进索敌逻辑”。此前 Laney（角色名）的禁用射击精度属性报错就发生在这类评分链路；禁用来源仍需人物运行时状态确认。本次只记录这一现存边界，不修改实现。

## B：战斗等待里的实际射击与邻格近战

“战斗等待”包含自动攻击，并不等于站着发呆。进入时及之后约每 4 游戏刻检查一次，忙于瞄准、攻击、冷却时先等待。

```text
战斗等待的攻击检查
├─ 倒地／身体忙碌／正在搬人等门槛未通过：本次不出手
├─ 本格或邻接八格有符合原版条件的活跃敌方人物？
│  └─ 有：优先请求近战 → BDP 短剑接管〔C〕
│     不要求这个邻格敌人就是此前移动站位时选中的目标
└─ 没有邻格近战目标，且允许远程攻击
   ├─ 使用当前有效弹丸行为，从当前位置再次选择射击目标
   ├─ 没有可射目标：继续等待，直到复查／任务更换
   └─ 有可射目标：人物尝试开始攻击
      ├─ 原版身体忙碌／禁止暴力：拒绝
      ├─ BDP 宿主仍属于另一个目标的旧会话：清空攻击查询，本次不出枪
      └─ BDP 弹丸正式起手
         ├─ 目标当前不可命中／视线不合法／会话准备失败：拒绝本枪
         ├─ 通过：准备正式单发计划，进入原版瞄准姿态
         ├─ 基础瞄准 0.3 秒 → 发出一颗原版自动手枪子弹
         └─ 基础冷却 1 秒 → 空闲后再次检查、准备下一枪
```

瞄准、冷却是配置基值，仍经过人物属性和原版调整。每次单发计划只有一颗子弹。没有弹丸追踪模块、绕墙模块或操控台直视许可的预载；小兵弹丸要求直视目标。

站位时选中的“敌人”和原地实际开枪的“敌人”可以不同：战斗等待会重新挑选当前位置能打的目标。当前 BDP 宿主对同目标续射允许复用会话，但对旧目标以外的实体会清空查询结果；普通发射与冷却结束不会保证清掉会话。这是现存接入缺陷，不应解释为正常等待或换弹；它也影响上层战斗派工，并非只让这一枪延迟。

## C：短剑起手后，实际换成 BDP 持续追击任务

短剑的入口来自：近身反击、战斗等待的邻格自动近战、原版明确下发的近战任务、破坏建筑及开路产生的近战任务。

```text
原版请求一次近战起手
├─ 已明确传入某个攻击行为：保留该明确选择，不自动替换
└─ 未明确指定攻击行为：BDP 尝试读取可用近战主结果＝小兵短剑
   ├─ 没有短剑／请求准备或接管失败：回原版近战候选池尝试
   └─ 接管成功：跳过这次原版近战起手
      └─ 把当前任务替换为 BDP 近战持续执行任务
         ├─ 目标固定为此次近战目标
         ├─ 标记为自动任务，保留来源决策节点和思考树
         ├─ 保留原任务剩余复查时间及有关到期条件
         └─ 不清空命令队列，不按玩家强制攻击处理

BDP 近战持续任务的循环
├─ 目标离图／不存在／心理隐形：结束
├─ 芯片、装备、投影版本或正式会话失效：打断
├─ 正在瞄准／攻击轮次／身体冷却：等待原版动作结束
├─ 不再贴身接触：寻路追到目标旁边，仍使用短剑
├─ 目标人物倒地，且未要求杀死倒地目标：结束
├─ 贴身且可攻击：选择本轮短剑招式，发起一刀
│  ├─ 柄部钝击：基础威力 9，基础冷却 2 秒
│  ├─ 刃部切割：基础威力 12，基础冷却 1.5 秒
│  └─ 尖端刺击：基础威力 13，基础冷却 2 秒
│     三种工具按原版近战权重语义选择，不是固定三连击
├─ 真正出刀时再检查能否命中目标
│  ├─ 目标已脱离攻击范围／人物不满足出手条件：这次攻击拒绝
│  └─ 合法：调用原版近战命中、闪避与伤害处理
├─ 冷却结束：从同一短剑计划的起点继续下一轮
└─ 原版到期复查／高优先级事件／队伍职责变化／执行失败
   └─ 按相应规则更换或结束任务，再由上层决定下一步
```

这颗短剑是约 1.42 格的贴身武器，驱动层使用原版接触可达判断。刀光显示尺寸不等于命中距离；已接入的刀光剑影兼容也让 BDP 正式近战保留自身距离。

**进入持续近战之后，执行器不会每刀比较弹丸与短剑，也不会因为目标退到 3 格就自行切成弹丸。** 它会先追击，直到原版重新决策或其他结束条件出现。因此相同距离下，一个刚进入战斗的人可能射击，一个已经进入短剑任务的人可能继续追砍。

BDP 并没有完整复制原任务的全部语义。当前只继承明确列出的到期与来源设置，近战轮数改由自己的持续计划管理：

| 原版入口 | 原版请求 | BDP 接管后的实际结果 |
|---|---|---|
| 近身反击 | 最多近战一次，200 游戏刻期限，带反击标记 | 变成短剑持续任务；继承剩余期限，但不继承“一次攻击”上限和反击标记，不能解释成必然只砍一刀 |
| 战斗等待邻格攻击 | 在等待任务内尝试一次近战 | 整个等待任务可被替换成短剑持续任务；随后执行器可追击离开的目标 |
| 普通作战近战 | 360～480 游戏刻期限，允许到期重新决策，复查要求附近有敌人 | 继承这些设置，短剑在复查前持续推进 |
| 破坏建筑近战 | 450～500 游戏刻期限，允许到期重新决策，复查要求附近有敌人 | 继承这些设置；无附近敌人时可能长期继续砍同一建筑 |
| 开路近战 | 450～550 游戏刻期限，允许到期重新决策 | 继承设置，继续砍选中的堵路物 |

“期限到了”也不等于到那一刻必定换目标。原版按人物错开的周期检查；设置为重新决策时，还要真正获得可替换的新任务。对于需要附近有敌人的任务，原版 `EnemiesAreNearby(pawn, 25)`（检查约 25 格内的附近敌人）不通过，会跳过到期处理。

## D：为什么明明有弹丸，却会走过去砍墙、砍家具

```text
当前作战分支没有给出可执行任务
├─ 先在附近约 5 格范围随机尝试破坏目标
├─ 再从殖民地建筑中尝试较远的目标
├─ 一般阶段限制惰性建筑；较低优先级阶段放宽
└─ 对一个合法破坏目标生成工作
   ├─ 有专用拆建筑攻击行为，且被抽中：用该行为
   │  └─ 小兵弹丸没有配置为专用建筑破坏器，通常不进入此项
   ├─ 可燃目标且满足原版点火条件：可能点火
   │  └─ 可燃建筑约 35% 的点火抽选；门不会走此建筑点火分支
   └─ 否则下近战破坏任务 → 真正起手时被 BDP 短剑接管
```

“弹丸允许以建筑为目标”与“原版破坏建筑职责愿意用弹丸拆建筑”是两件事。前者只是攻击合法性；后者还看原版是否把它识别为专用建筑破坏行为。当前自动手枪式弹丸不是这类行为，因此任务一旦选择近战拆建筑，BDP 实际执行的是短剑持续砍，不会自动换成射墙。

破坏目标还需可达、未燃烧、允许破坏且有敌对关系；陷阱、明确禁止破坏的建筑等会被排除。近处和远处的选择有随机抽样，不保证选最近、最贵或最薄的墙。

## E：没有正常通路时的开路

```text
普通进攻清单末端的开路尝试
├─ 查找可破坏通路接近的玩家威胁目标；此回退选敌范围约 50 格
├─ 按可穿越可破坏物的规则规划路径，取首个堵路建筑
├─ 堵路物可开采且人物能采矿：采矿
├─ 有专用拆建筑攻击：使用该行为
└─ 其余堵路建筑：下近战开路任务 → BDP 短剑持续攻击
   └─ 目标被别人预约时，可能先到附近等待
```

普通袭击也有这个末端兜底，所以看到砍门、砍墙不能立即断言是专门的工兵袭击。这里与日常破坏建筑不同：目标来自开路路径的首个阻挡物，而不是破坏目标随机选择。

## 防护、资源、受伤与退出是并行约束

### 小兵护盾

护盾被动处理伤害，不要求 AI（人工智能）先执行“举盾”任务，也不会主动规划面向来保证最优格挡。

- 当前耐久上限 120；正面 180 度内，50% 概率抵挡符合条件的伤害。
- 默认处理允许拦截的远程与爆炸伤害；当前小兵护盾未开启近战伤害格挡，声明穿盾的伤害也不拦。
- 未破盾每游戏秒自然恢复 12 点；破盾后等待 600 游戏刻，即标准速度约 10 秒恢复。
- 该盾不使用光魂举盾的远程禁用规则，短剑、弹丸与护盾可同时保持激活。

### 非玩家资源规则

当前近界敌人作为非玩家派系人物，免功能费用、免容量占用，启停无延迟。配置中弹丸每发 2 点、护盾格挡按伤害比例扣费等，对这些敌人的实际功能结算不生效；不会因持续射击或常规护盾扣费而耗尽。

但伤口泄漏仍生效。资源是真实存在的生命资源，不是无敌或完全无限；伤口泄漏耗尽后会触发战斗体崩解。

### 崩解与原身恢复

```text
战斗体受伤
├─ 护盾成功拦截：按盾规则处理，不进入本次普通受伤
└─ 未被拦截：原版伤害进入 BDP 战斗体健康处理
   ├─ 尚可行动：继续当前任务；伤势／资源泄漏继续影响状态
   └─ 倒地／致命身体条件／触粒子见底等触发崩解
      ├─ 立即打断当前任务，禁用芯片战斗能力
      ├─ 约 90 游戏刻崩解表现
      └─ 恢复原身快照、结束战斗体、资源归零、施加短暂虚弱
         ├─ 原身仍能行动：后续由原版身份、队伍与健康状态决定
         └─ 原身仍倒地／死亡／被俘：执行对应原版流程
```

没有发现这套常规袭击 AI 为原身自动重新激活战斗体的决策入口；不能把“恢复原身”写成“继续无限变身”。固定预载也没有紧急脱离芯片，所以不能默认崩解后自动传送逃走。

常规袭击队伍仍按原版处理失能成员。皇室追兵另外暂缓移除正在崩解恢复的成员，不能把该专属保护套到所有近界袭击。

## 队伍为什么会停止进攻

普通立即进攻沿用原版进攻队伍，可受事件参数控制：

- 允许超时退出时，普通进攻约 26000～38000 游戏刻后可能放弃；约标准速度 7.2～10.6 分钟，还要求地图允许退出。
- 允许退出且殖民地损害达到原版随机阈值时，可能认为破坏足够而撤走。这是原版殖民地损害计算，不是该敌人自己的生命百分比。
- 允许绑架／偷窃，且原版对应触发条件满足时，可能改成绑人／拿东西离开；不是附近刚有人倒地或出现贵重物品就必定立刻触发。
- 原版队伍还会额外挂上高优先级的伤亡溃逃。近界派系未单独关闭自动溃逃；原版默认阈值范围为暴力损失人数占队伍累计人数约 40%～70%，每队抽取，不是单兵剩余生命值。
- 派系关系变为不敌对时，有相应离开分支；近界正常配置为永久敌对，所以正常外交中不常出现。

皇室任务的近界民斥候另用 `LordJob_RoyalPursuers`（皇室追兵队伍）：关闭普通超时退出、绑架、偷窃；其继承关系本身并未关闭原版队伍自动伤亡溃逃。这是同款装备下的队伍差异。

## 现有日志已经证明的实际路径

2026-10-12 的游戏日志里，Oahnip（角色名，Human39468）实际使用同一近界原型：

1. 多次通过副槽小兵弹丸的正式远程宿主，对 Mongo（角色名）完成自动起手和同会话续射。
2. 后来进入主槽短剑的自动持续任务，目标为钢铁墙 Wall39007。
3. 在游戏刻 25170、25260、25350 连续三次记录近战命中，墙显示从完整降至 95%、92%、87%；这组样本每刀间隔 90 游戏刻，符合选到 1.5 秒基础冷却工具的路径。
4. 日志的近战轮数上限显示为 2147483647，即持续任务使用的整型最大值，并非只砍一刀。
5. 随后的卸装记录使三侧停用、正式宿主重置、旧攻击任务被中断。日志未说明这次卸装的操作者／原因，不能据此认定为正常战斗死亡或某个故障根因。

这能证实“弹丸远射 → 短剑持续砍墙 → 装备失效时中断”的实际链路。现有片段没有完整记下进入砍墙前的原版决策来源，不能在破坏建筑与末端开路两个入口之间强行二选一。

## 玩家看到的现象如何解释

| 现象 | 合并后的解释 |
|---|---|
| 主槽装短剑，却先用副槽弹丸 | 原版通用攻击查询被 BDP 接成默认远程主结果；主副槽不决定远近优先级 |
| 发现人后先走位，停下才开枪 | 原版用弹丸射程和掩体规则安排位置；战斗等待负责实际自动出枪 |
| 有人贴过来便改砍他 | 战斗等待邻格近战优先，或人类思考树先处理近身反击；不要求是原先目标 |
| 对方跑开仍追砍，没有立即射击 | 已进入 BDP 固定目标的持续近战执行，需等重新决策／结束条件 |
| 明明有枪却砍建筑 | 原版生成近战破坏／开路任务；BDP 把其真实攻击换成短剑 |
| 很久不停止砍同一面墙 | 持续短剑计划不会每刀重新选敌；来源任务还可能在无附近敌人时跳过到期复查 |
| 射击或格挡很久仍未耗空 | 非玩家功能费用豁免；真正的资源压力主要保留伤口泄漏 |
| 看起来持盾却仍会被近战打中 | 小兵盾没有开启近战格挡；正面远程也只有 50% 概率 |
| 人恢复原身却不自动再变身 | 生成时激活与战斗中自动再激活是两回事；当前没有这条常规 AI 决策 |
