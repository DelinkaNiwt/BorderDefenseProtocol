# 清洗执行记录-第九刀

日期：2026-03-25

## 本刀目标

继续做三核心综合重审，明确：

- 什么才是真正对外正式开放面
- 什么只是内部主链或内部兼容接口

这一步主要针对“名字看起来像公开协议，其实只是内部管线用接口”的误导问题。

## 实际改动

### 1. 删除无实际承载价值的 `ITrionState`

处理结果：

- 删除：
  - `Source/BDP/Core/Trion/ITrionState.cs`

裁定：

- `ITrionState` 只是 `ITrionReader + ITrionCommands` 的空合并口
- 当前代码里已经没有真实使用
- 继续保留只会让人误以为 Trion 还存在一套“统一总口”设计

### 2. `CombatBody` 内部主链接口改为内部接口

处理结果：

- `ICombatBodyCoordinator` 改为 `internal`
- `ICombatBodyPhaseState` 改为 `internal`
- `ICombatBodyHost` 改为 `internal`

裁定：

- 这三者是 CombatBody 内部主链拼装接口
- 不是给外部系统依赖的正式开放面
- 继续保留 `public` 会误导后续阅读者

## 结构结果

本刀前：

- 三核心虽然已经有正式 surface
- 但仍残留少量会让人误判为“对外总口”的接口

本刀后：

- 对外正式开放面和内部主链接口分界更清楚
- 讲解时可以直接按 `SurfaceAccess + Reader / Commands / Events` 这一套说
