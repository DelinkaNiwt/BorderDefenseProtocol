# 清洗执行记录-第二十四刀

日期：2026-03-25

## 本刀目标

审 `Semantics / Projectiles / BodyConstraints`，按真实需要裁定谁该保留公开、谁该收口。

## 审查结论

### 1. `Semantics` 不属于空转抽象层

实际职责：

- 在 `Expressions` 里生成攻击语义
- 在 `Verbs` / `Projectiles` 里把语义压进运行时作用域
- 在 `Patches` 里把语义写回伤口来源和爆炸链
- 在 `CombatBody` 阶段变化里承接崩解原因

裁定：

- `Semantics` 是真实跨链协议层
- 不是“未来也许有用”的空抽象
- 这层保留 `public` 合理

### 2. `Projectiles` 现在体量克制，没回膨胀

实际职责：

- `BdpBullet` 只是在伤害落地时压入语义
- `BdpExplosiveProjectile` 只是在引爆边界把语义带进爆炸系统

裁定：

- 这两件东西都贴着 RimWorld 原版入口
- 没有长出弹道系统、命中系统、轨迹系统之类旧 BDP 式膨胀
- 因为 Def / Verb 配置可能直接指到它们，所以继续保留 `public`

### 3. `BodyConstraints` 是内部折算层，不该挂成公开协议

实际职责：

- `PawnBodyConstraintSignalHub` 负责发布身体约束变化
- `TriggerBodyDisableEvaluator` 负责把身体事实折算成 Trigger 禁用结果
- `PawnBodyConstraintChangedArgs`
- `PawnBodyConstraintChangeKind`

这些都只在本模组内部：

- Patch 发信号
- Trigger 主链读版本、做禁用同步

裁定：

- 它们不属于正式外口
- 应统一收成 `internal`

## 本刀实际执行

以下类型改为 `internal`：

- `PawnBodyConstraintSignalHub`
- `TriggerBodyDisableEvaluator`
- `PawnBodyConstraintChangedArgs`
- `PawnBodyConstraintChangeKind`

## 本刀后的全局图

执行前：

```text
伤害后半链
├─ Semantics      [public]
├─ Projectiles    [public]
└─ BodyConstraints [public + internal 混着放]
```

执行后：

```text
伤害后半链
├─ Semantics       [public，跨链真实协议]
├─ Projectiles     [public，Def/Verb 入口宿主]
└─ BodyConstraints [internal，内部身体折算层]
```

## 本刀结果

这刀之后，这三块的口径更稳定了：

- `Semantics` 是真实跨链描述协议，保留
- `Projectiles` 是贴原版入口的最小宿主，保留
- `BodyConstraints` 是内部折算件，收口
