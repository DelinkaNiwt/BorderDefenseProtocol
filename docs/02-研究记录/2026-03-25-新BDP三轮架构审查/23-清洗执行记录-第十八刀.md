# 清洗执行记录-第十八刀

## 本刀目标

处理文件级边界问题，重点是：

- `CompTriggerBody.cs` 过大
- `TriggerFormalSurfaces.cs` 混入内部投影宿主表面
- 新拆文件必须补到逐成员中文注释粒度

## 本刀裁定

### 1. `CompTriggerBody` 必须拆文件

原因：

- 它已经超过“一个 owner 文件直接通读”的舒适范围
- 同时混有：
  - 生命周期
  - 读取逻辑
  - 上下文构建
  - 完整性修复
  - 通知广播

裁定：

- 保留一个总文件作为 owner 主入口
- 其余按职责拆成 partial 文件

### 2. `TriggerProjectionHostSurface` 不该留在 formal surfaces 文件里

原因：

- 它不是正式外口
- 它只服务内部投影链

裁定：

- 从 `Access/Surfaces/TriggerFormalSurfaces.cs` 移出
- 单独放回 `Projection/TriggerProjectionHostSurface.cs`

### 3. `TriggerFormalSurfaces` 本体不再继续拆

原因：

- 移走投影宿主后，剩下四个 surface 都属于正式外口
- 规模还在可直读范围内
- 再拆只会更碎

裁定：

- 保持一个文件
- 但补齐成员级中文注释

### 4. `CombatBodyFormalSurfaces` 同样不继续拆

原因：

- 只有 reader / command / event 三个正式表面
- 规模克制
- 拆开收益不大

裁定：

- 保持一个文件
- 补齐成员级中文注释
