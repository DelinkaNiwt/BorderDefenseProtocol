# 清洗执行记录-第二十三刀

日期：2026-03-25

## 本刀目标

回到全局，收紧 `Expressions / Projections / Verbs` 三层的公开边界。

## 本刀裁定

### 1. 这三层不是正式对外开放面

判断：

- 玩家真正会接触的是：
  - `TriggerSurfaceAccess`
  - `TrionSurfaceAccess`
  - `CombatBodySurfaceAccess`
- `Expressions / Projections` 做的是中间加工链：
  - 收集表达
  - 解析表达
  - 投到按钮 / 自动攻击 / 默认表面

它们服务的是内部主链，不是给外部系统直接依赖的正式接口。

裁定：

- `Expressions` 里的运行时接口与实现收为 `internal`
- `Projections` 里的运行时接口与实现收为 `internal`

### 2. 哪些要保留 `public`

判断：

- `BdpExpressionConfig` 需要给 Def ModExtension 使用
- `ExpressionHostKind` 需要给配置字段使用
- `BdpVerb_*` 需要保留可被原版 Verb 配置指到

裁定：

- 这些继续保持 `public`
- 不把“运行时中间链”误讲成“正式外部接口”

## 本刀后的边界图

执行前：

```text
TriggerProjectionService
   -> Expressions (很多 public)
   -> Projections (很多 public)
   -> Verbs (public)
```

执行后：

```text
正式外口
├─ TriggerSurfaceAccess
├─ TrionSurfaceAccess
└─ CombatBodySurfaceAccess

内部中间链
├─ Expressions   [internal]
├─ Projections   [internal]
└─ Verbs         [保留真正需要被 Def 指到的 public 类型]
```

## 本刀结果

这刀之后，上层结构更符合模组体量：

- 对外讲解时，只讲三核心正式外口
- 表达收集、解析、投影这条链，明确属于内部实现
- `Verbs` 只保留 RimWorld 入口确实需要看到的类型

这样不会再把内部中间件讲成模组对外协议。
