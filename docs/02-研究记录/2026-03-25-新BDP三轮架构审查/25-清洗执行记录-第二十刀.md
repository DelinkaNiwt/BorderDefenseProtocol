# 清洗执行记录-第二十刀

日期：2026-03-25

## 本刀目标

复审 `Trigger/External`、`Trigger/Projection`、`Trigger/Access` 三组，确认它们是不是已经进入终态。

## 复审结论

### 1. `Trigger/Access`

判断：

- `Contracts`
- `Surfaces`

这两层已经很清楚。

剩余文件：

- 正式接口
- 正式表面实现
- `TriggerSurfaceAccess`

裁定：

- 到终态
- 不再继续拆

### 2. `Trigger/External`

判断：

- `TriggerEquippedGizmoService`
- `TriggerExternalGizmoContext`
- `TriggerExternalGizmoRegistry`

这三者正好构成一条完整的外部按钮扩展链。

裁定：

- 到终态
- 不再继续拆

### 3. `Trigger/Projection`

判断：

- `ITriggerProjectionHost`
- `TriggerProjectionHostSurface`
- `TriggerProjectionService`
- `TriggerResolvedExpressionCache`

归属已经对，但有一个口径问题：

- `TriggerResolvedExpressionCache` 只是内部缓存桥
- 不属于正式外口
- 也不该看起来像一个公开可依赖类型

裁定：

- 把 `TriggerResolvedExpressionCache` 从 `public` 收口为 `internal`

## 本刀实际执行

- `TriggerResolvedExpressionCache` 改为 `internal sealed`
- 顺手删除同命名空间下多余的 `using BDP.Core.Trigger`

## 本刀后的全局判断

到这一刀为止，`Trigger` 的三条外围链已经比较稳定：

- `Access`
  - 正式外口
- `External`
  - 外部按钮扩展链
- `Projection`
  - 内部投影链

这三组现在职责清楚，公开口径也基本一致。
