# BDP 护盾属性归属调整实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 移除 BDP 护盾规则信息组，让抵挡属性和来源直接属于各自的护盾功能节点，同时保留当前图表和姿态筛选行为。

**Architecture:** 只调整 BDP.Content、内容 Def（定义）、语言包、芯片预设和作者指南；Core（核心）的通用信息模型与组机制保持不变。护盾来源仍从指定表达条目读取原版护盾组件，只将归属从组来源迁到功能来源；现有独立护盾功能实例继续隔离姿态数据。

**Tech Stack:** C# 7.3、RimWorld XML Def、PowerShell 静态契约脚本、旧式 .NET Framework 项目。

---

## 执行边界

- 不修改 `Source/BDP` 下的 Core 模型或通用解析 API。
- 不改近战攻击方式组、机动方式组、护盾 ExtraEffect 子组以及任何护盾运行时数值计算。
- 保留 Light Soul 移动/举盾功能实例及其 `EntryId`；保留能量护盾和自动护盾各自的条目来源。
- 同步修改现有静态契约脚本，不新增测试脚本；本次不运行测试脚本。最后编译 BDP.Content 并检查生产文件的旧标识引用。
- 保留已完成的历史计划与审议记录；只把当前作者指南更新为现行规范。
