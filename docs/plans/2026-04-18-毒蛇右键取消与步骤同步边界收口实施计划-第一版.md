# 毒蛇右键取消与步骤同步边界收口 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改变毒蛇当前玩家手感和现有功能表现的前提下，把 `Preview（预览阶段）` 的右键取消越权收回到正式输入链，并把 `InteractionSession.StepIndex（交互会话步骤号）` 的共享同步责任还给宿主驱动。

**Architecture:** 主模组已经有 `PressedButton（按下按钮）` 输入桥和 `AdvanceDecision（推进裁决）` 正式出口，所以这次不新增协议层能力。修复方式只做两件事：第一，把毒蛇右键取消从 `Preview（预览阶段）` 挪到 `Targeting（目标选择阶段）` 正式输入处理；第二，让毒蛇模块只维护私有状态和 `InputState.StepIndex（输入步骤号）`，由宿主 `TargetingInteractionDriver（目标交互驱动器）` 继续统一同步共享会话状态。

**Tech Stack:** C# / RimWorld / BDP Core / BDP.DevHarness / PowerShell smoke tests / UTF-8

## 不包含在本计划中的内容

- 不重写毒蛇路径业务
- 不新增主模组协议层
- 不改 `Confirm（确认阶段）` 的 `Target / SemanticTarget` 语义
- 不改 `ProjectileInit（投射物初始化）` 和 `Arrival（到达）` 的分段飞行表现

- 毒蛇模块不再在 `Preview（预览阶段）` 直接读原始事件或直接停止 `Targeter（目标器）`
- 毒蛇右键取消仍保持当前玩家可感知表现
- 毒蛇模块不再直接写 `InteractionSession.StepIndex（交互会话步骤号）`
- `TargetingInteractionDriver（目标交互驱动器）` 继续作为共享步骤号同步唯一归口
- 相关烟测与两个工程编译全部通过
