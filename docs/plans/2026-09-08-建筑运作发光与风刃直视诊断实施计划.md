# 建筑运作发光与风刃直视诊断实施计划

> **For Codex：** 按 TDD（测试驱动开发）先写并验证失败测试，再实施最小改动；完成前使用 verification-before-completion 技能进行新鲜构建和测试验证。

**目标：** 让 Trion 中继核心和操作员控制台在实际运作时使用 RimWorld 原版机制提供小范围光照，并为风刃的动态非直视目标许可增加可关闭、限频的 Development 诊断链路。

**架构：** 发光使用原版 `CompGlower`，建筑通过 `IThingGlower` 将实际运作状态作为点灯条件；状态变化时主动刷新原版光照网格。诊断只放在 Development 模块，通过现有日志设施记录许可提供、运行时表达结果、许可接收器和最终目标判定，不改变 Core 或正式战斗规则。

**技术栈：** RimWorld Def/XML、C#、PowerShell smoke test、MSBuild。
