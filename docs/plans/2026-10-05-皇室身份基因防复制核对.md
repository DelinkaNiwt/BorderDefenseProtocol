# 皇室身份基因防复制核对

## 当前结论

用户要求皇室身份不能被玩家随意复制。先核查原版机制，再决定是否更换基因方案；初次核查仅研究，最新定案与实现见下方。

### 最新定案与实施

用户已选择超凡内源基因，允许自然传承，异象复制体保留身份；普通基因提取器候选改写不实施。正式 `BDP_Gene_RoyalBloodline`（皇室血脉）基因定义已加入，仅为它在原版遗传方法的父母两处候选检查放行。其余概率与组合检查沿用原版，不改共享定义字段，不接任务或核心绑定。

编译、真实候选流程、单方与双方原版候选概率、其他基因边界及定义语言检查通过，游戏内加载、提取、生育与存读档待实测。详情见[皇室超凡基因实施计划](C:/NiwtDatas/Projects/RimworldModStudio/模组工程/BorderDefenseProtocol/docs/plans/2026-10-05-皇室超凡基因实施计划.md)。下面保留核对与方案比较过程，未选候选不再作为下一步待选方案。

### 用户补充：允许自然传给后代

用户认可基因方向，并明确希望皇室身份可以自然遗传。因此下面的纯配置候选不能完整满足要求，不能直接作为实施方案。

推荐讨论方向：皇室基因使用非超凡内源基因（`biostatArc = 0`），排除随机基因组生成，保留原版生育遗传；另对皇室基因加入范围限定的提取限制。原版基因定义没有已确认的单条禁止提取配置或可重写的提取准入方法，因此这项限制需要介入原版提取候选筛选，且只影响 BDP 皇室基因，不能阻止皇室成员其他普通基因被正常提取。具体补丁位置与完整准入一致性需实施前核对，不通过删除已产出的基因组遮盖问题。

另一候选是保留超凡属性、为生育增加皇室基因专属遗传例外；它复用原版提取限制，但改动遗传并继续承担超凡属性语义。初步推荐前者；进一步核查具体介入位置后的比较见下方，方案尚待确认，未修改业务代码。

原版单方父母携带时的初始遗传候选概率为 50%，双方携带时为 100%；最终仍受原版遗传组合筛选影响，不能直接承诺最终必定获得。用户目前仅要求可自然传承，未要求必传，不另行确定特殊概率。

用户随后明确：复制体保留皇室身份符合逻辑。异象整人复制沿用原版复制基因行为，不增加剥夺资格逻辑。研究树与核心细则继续搁置。

### 两条方案的实际介入位置

1. 普通内源基因方案：在原版基因提取器针对单条基因的筛选中加入皇室排除。需要保持三处一致：`CanAcceptPawn`（可入舱提取判断）对是否仍有非超凡候选的检查，`Finish`（完成提取）统计可选基因数，以及局部 `SelectionWeight`（随机抽取权重）判断。正常人物和皇室成员其他基因继续使用原版逻辑；只有皇室基因不计入候选，若无其他候选则不允许开始提取。不得通过暂时删除人物基因、临时改写全局定义或删除产出结果实现。
2. 超凡内源基因方案：保留正值 `biostatArc`，原版提取器不动；在 `PregnancyUtility.GetInheritedGenes`（父母遗传基因选择）读取父母内源基因时，仅对 BDP 皇室基因放宽超凡排除条件。父方、母方各一处判断，属于同一个方法。放行后继续进入原版候选概率、组合抽样、前置基因与代谢检查，不在孩子出生后另行强行添加，也不解除其他超凡基因的遗传限制。

已读取遗传方法的实际中间指令，确认父方和母方各自存在一处 `GeneDef.biostatArc` 读取与正值跳过分支，可以作范围限定的指令改写。此方案无需临时改写共享基因定义数据，也无需重写整个遗传方法；实际实施仍须校验两处目标完整匹配。

进一步核对后，若用户接受皇室基因归类为超凡基因，则超凡方案更集中：只介入一个遗传方法，提取器完全沿用原版。普通方案的优势是没有超凡属性语义，代价是提取判断分散在三处。此为设计比较，不代表用户已选定超凡方案。

### 初次核查的纯配置候选及限制

基因方案可以限制原版常规复制渠道，但不存在覆盖所有传播方式的单一禁止复制配置。可行候选为：皇室基因由事件赋予为内源基因，`biostatArc > 0`（按原版超凡基因处理），并设置 `canGenerateInGeneSet = false`（排除随机基因组生成）。这只是候选，不是已批准规格。

| 原版途径 | 实际行为 | 对候选方案的影响 |
| --- | --- | --- |
| 基因提取器 | 从内源和外源基因中选择，但排除正值 `biostatArc` 基因 | 无法常规提取成基因组，进而批量制作胚芽 |
| 基因植入能力 | 整套复制施术者的外源基因，不检查超凡属性 | 皇室基因放在内源位置可避开这条复制途径 |
| 自然生育 | 从父母内源基因中选取，排除正值 `biostatArc` 基因 | 同时失去原版自然生育传承，需要用户另行取舍 |
| 随机基因组生成 | 检查 `canGenerateInGeneSet` | 可排除这条随机生成途径；不代表所有显式任务奖励或其他模组都被禁止 |
| 异象整人复制 | 无差别复制内源和外源基因，不检查上述配置 | 候选配置无法阻止；若也需排除，必须单独明确并处理 BDP 皇室资格规则 |

不能把 `passOnDirectly = false`（直接传递标记）当作通用禁止复制开关：提取器的入场判断只要求人物至少有一条带此标记的基因，实际选取单条基因时不检查该标记。人物还有其他可传递基因时，不能据此阻止皇室基因被提取。仅设置内源位置也不能阻止提取器。

正值 `biostatArc` 是原版超凡基因属性，会影响原版相关处理与显示，不是中性的隐藏防复制标记。初次核查时上述传播边界尚未定案；用户后续已明确要求保留自然血脉传承，其他未定事项见上方补充。没有理由仅因普通提取和胚芽生产就断言必须弃用基因。
