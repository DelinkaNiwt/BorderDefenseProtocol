# 光魂双武器举盾贴近、抬高与南北层级设计

## 目标

只调整光魂举盾的双武器视觉：东西朝向进一步贴近人物，四个朝向整体略微抬高；朝南时盾面绘制在另一把武器之前，朝北时盾面绘制在另一把武器之后。单武器保持现状。

## 参数分工

- `SideBaseX`（侧向基础横移）只控制东西朝向与人物的屏幕横向距离。
- `DefaultOffset.Z`、`NorthZAdjust` 与 `SideBaseZ` 只控制屏幕纵向位置。
- `DefaultAltitudeOffset`（默认绘制高度层）写入 RimWorld 的世界 `Y` 层，只决定遮挡排序，不移动屏幕位置；南向取正值，北向自动取负值。

## 已确认数值

- 东西 `SideBaseX`：`0.28 → 0.12`；保留 `SideDeltaX = 0.04`，最终主手距离为 `0.08`、副手距离为 `0.16`。
- 南北 `DefaultOffset.Z`：`0.18 → 0.23`；`NorthZAdjust`：`0.36 → 0.46`，使南北最终屏幕纵向偏移都为 `+0.23`。
- 东西 `SideBaseZ`：`0.18 → 0.23`。
- 南北 `DefaultAltitudeOffset`：`0.08 → 0.12`，使南向盾层为 `+0.12`、北向盾层为 `-0.12`，分别越过常见双武器的 `+0.10/-0.10` 层级。

## 边界

不修改单武器预设、贴图、角度、镜像、东西主副手前后景、尺寸、受击抖动或 Core（核心层）解析器。实现仅涉及 Content（内容层）XML（可扩展标记语言）与既有配置契约测试。
