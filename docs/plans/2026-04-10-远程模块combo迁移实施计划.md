# 远程模块 Combo 迁移实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让远程模块既能挂在芯片表达条目上，也能挂在 combo 表达条目上，并把 DevHarness 的教学骨架模块从单芯片样例迁移到 `远程芯片 + 齐射芯片` 的 combo 样例。

**Tech Stack:** C# / RimWorld Def XML / PowerShell smoke tests
