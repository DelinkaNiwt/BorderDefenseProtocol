# 风刃·实体刀芯片设计

## 目标

新增正式芯片功能“风刃·实体刀”。它的功能行为、数值、实体刀表达和弧月一致，但作为特殊槽芯片存在，并且不在芯片制造台功能列表中显示。刀刃发光层改用风刃投射物光束拖尾的绿色。

## 已确认事实

- 弧月功能定义位于 `1.6/Content/Defs/ChipFunctionDef/Presets.xml` 的 `BDP_ChipFunction_Kogetsu`。
- 弧月视觉位于 `1.6/Content/Defs/ExpressionDef/Visual.xml` 的 `BDP_Visual_Kogetsu`，由手柄层和刀刃发光叠层组成。
- 风刃专用拖尾定义为 `BDP_TrailPreset_FujinLong`，颜色为 `(0.45, 1.0, 0.55, 0.775)`。
- `ChipFunctionDef.showInManufacturing` 已由制造台列表读取；设置为 `false` 即可隐藏，不需要改制造台代码。
- 特殊槽使用已有 `SlotRegion=Special` 约定。

## 方案

采用 Def 与语言包最小扩展：

1. 在 `ChipFunctionDef/Presets.xml` 新增独立的“风刃·实体刀”功能定义。
2. 复制弧月的职业、分类、标签、费用、工作量、Trion、激活条件、近战工具和表达条目。
3. 将新功能的 `SlotRegion` 改为 `Special`，设置 `showInManufacturing=false`。
4. 在 `ExpressionDef/Visual.xml` 新增独立视觉预设，完整复制弧月的姿态、偏移、角度和贴图路径，仅把刀刃发光层 RGB 改为 `(0.45, 1.0, 0.55)`。
5. 复用 `Things/Trigger/Chip/Kogetsu/kogetsu_handle` 与 `kogetsu_blade`，不新增或改写 PNG。
6. 在简体中文语言包增加芯片名称、说明和表达名称键；代码与 XML 不新增玩家可见中文硬编码。

## 数据流

```text
ChipFunctionDef
  -> 主副槽装载规则
  -> 正式近战表达
  -> 新视觉预设
       -> 弧月手柄 PNG
       -> 弧月刀刃 PNG + 风刃绿色 MoteGlow 颜色

ChipFunctionDef.showInManufacturing=false
  -> 芯片制造台功能列表过滤
```

## 不在本次范围内

- 不修改 Core.dll、制造台 UI 或槽位系统代码。
- 不修改弧月现有 Def、视觉预设或贴图。
- 不把“风刃·实体刀”加入旋空弧月组合。
- 不新增独立实体刀 PNG。
- 不改变风刃投射物、拖尾或现有风刃芯片行为。

## 验收标准

1. Def 加载时新功能和新视觉预设均成功注册，无重复 DefName 或 XML 解析错误。
2. 新芯片显示名称为“风刃·实体刀”，功能表达和近战属性与弧月一致。
3. 新芯片只能进入特殊槽，不能进入主槽或副槽。
4. 芯片制造台的功能列表中不出现“风刃·实体刀”。
5. 装载并激活后，手柄、刀刃形状、姿态、角度和尺寸与弧月一致，刀刃发光颜色为风刃拖尾的绿色。
6. 弧月原有制造、装载和视觉表现不发生变化。

## 验证方式

- 使用 XML 解析检查新增 Def 的结构与引用。
- 构建 BDP Content 项目，确认编译无错误。
- 检查版本控制差异，确认只包含本需求相关文件。
- 进入游戏后用 Development 入口或已有芯片制造台/触发体界面验证制造台隐藏、主副槽装载和视觉颜色。
