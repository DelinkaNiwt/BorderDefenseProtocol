# 双武器静默姿态状态修复设计

## 目标

修复双武器绘制中单侧射击时，未射击侧错误套用静默倒 V 镜像和装饰角的问题；保留整体静默时现有的自然下垂倒 V。

## 根因

当前南北姿态把单条视觉是否命中执行焦点 `IsExecutionActive（当前条目是否执行）` 当成整体是否静默。单侧射击时，另一侧条目为非执行态，于是被强制套用静默镜像；两把武器因此分别使用攻击姿态和静默姿态。

## 设计

- 继续使用现有 `TriggerVisualRuntimeState.HasExecutionState（视觉运行时是否存在整轮执行态）`，不新建状态系统。
- 将 `ForceHandMirrorWhenInactive（非执行侧强制镜像）` 替换为 `HandMirrorOnlyWhenIdle（手侧镜像仅用于整体静默）`，不保留旧字段兼容。
- 开启 `HandMirrorOnlyWhenIdle` 后：
  - 整体静默时，按既有主副侧与南北朝向裁定手侧镜像，并跳过正南北角度门槛，保留倒 V。
  - 任意一侧进入攻击执行时，两侧都禁止手侧镜像，只保留原版瞄准镜像。
- 新增 `DecorativeAngleOnlyWhenIdle（装饰角仅用于整体静默）`：任意一侧进入攻击执行时，两侧的 `DefaultAngle（默认装饰角）` 与 `SubHandAngleOffset（副侧附加角）` 一起归零。
- 仅在中型枪械双武器基准开启这两个选项；其它视觉预设继续使用当前默认行为。

## 数据流

```text
视觉运行时整轮执行态
        │
        ├─ 无执行态：静默镜像 + 6° 装饰角
        │
        └─ 有执行态：禁用手侧镜像 + 0° 装饰角
                       │
                       └─ 两侧继续共享原版 aimAngle（瞄准角）
```

枪口锚点、握持锚点、原版后坐力和实际开火侧判定不改；它们继续跟随最终姿态或各自来源武器。

## 验证

- 回归测试锁定：整体执行态必须参与南北姿态判定，不能再使用单条目的 `IsExecutionActive` 控制静默镜像。
- 配置测试锁定：中型枪械双武器基准开启两个“仅静默”选项，仍保留 6° 静默装饰角。
- 运行视觉定向测试、相关测试集和项目编译。
