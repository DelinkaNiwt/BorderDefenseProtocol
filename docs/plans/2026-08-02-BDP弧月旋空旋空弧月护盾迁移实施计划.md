# BDP 弧月、旋空、旋空弧月与护盾迁移实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已确认的弧月、旋空、旋空弧月和护盾业务及其 Def、运行时代码、资源和正式画像从 DevHarness 迁入主模组 Content，并保持 Core → Content 的严格单向依赖。

**Architecture:** Core 只增加中性的 `ChipTagDef`、芯片画像标签配置、契约快照与校验；Content 提供“武装/能力/防护”三个正式分类、五个正式标签以及四组具体业务。已迁移内容从 DevHarness 移出，剩余候选仍保留原候选分类。

**Tech Stack:** RimWorld 1.6、C# 7.3、XML、PowerShell 冒烟测试、MSBuild、Git。

**实施状态（2026-08-02）：已完成。** 四组业务已迁入主模组 `1.6/Content` 与 `BDP.Content.dll`；Core 已补齐中性标签底层；候选库仅保留未确认内容。专项测试、XML 解析和三个程序集 Release 构建均通过。

**后续纠错（2026-08-02）：** 发现四组正式芯片共同继承的 `BDP_ChipBase` 仍留在 DevHarness，导致主模组解析时找不到父节点。已将这个共用芯片物品基类迁入主模组 `1.6/Content/Defs/Things/Items/Chips/ThingDefs_ChipBase.xml`，并删除候选副本；候选芯片通过其对主模组的依赖继续继承该基类。
