# 追踪弹拦截残差修复实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让追踪模块依据目标预测残差判断追踪是否失效，避免把弹体初始射偏误判为目标逃逸，同时保留移动目标可被有限追踪能力躲过的手感。

**Architecture:** 在 `HomingState` 保存上一段路径的预期目标位置；`HomingModule` 在到达时计算当前目标位置与该预期点的残差，并把残差作为现有丢失判定的前置条件；`HomingPathBuilder` 向调用方返回本段路径实际采用的预测目标点。保持 `HitStage`、Core.dll、命中结果和高角飞行模块不变。

**Tech Stack:** C#、RimWorld 原版弹体时序、PowerShell 静态契约测试、`dotnet build`。
