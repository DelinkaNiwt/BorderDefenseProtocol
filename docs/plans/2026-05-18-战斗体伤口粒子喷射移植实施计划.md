# 战斗体伤口粒子喷射移植实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 战斗体 Active 状态下压制原版伤口贴图，并让仍处于 Trion drain 生命周期内的伤口从原版伤口锚点持续喷射三层 Trion 粒子。

**Architecture:** 伤口 Hediff 仍是原版伤口事实；BDP 只在 Active 期间维护伤口派生运行时。伤口 Trion drain 是喷射生命周期真值：drain 注册时创建/刷新喷射器，drain 注销时停止喷射。读档时必须恢复伤口 drain 记录并重新发布到 Trion 账本，再按这些 active drain 重建喷射器。

**Tech Stack:** RimWorld 1.6、Verse、RimWorld PawnOverlayDrawer/PawnWoundDrawer、Harmony、Fleck、C# 7.3、PowerShell smoke tests。

**Project Constraint:** 按当前项目要求直接在当前工程执行，不创建 worktree。主模组允许承载该系统级业务功能；外部模组以后只通过配置口调整参数。

## 根因修正说明

当前代码读档后会清掉伤口 drain，这是错误行为，不是要适配的边界：

```text
CompTrion.PostExposeData(PostLoadInit) 清空 drainRegistry
CombatBodyWoundRuntime.RestoreAfterLoad() 调 RebuildActiveWounds()
RebuildActiveWounds() 再清空 trionBinding
```

正确语义：

```text
存档前：伤口 A 的 drain 还在，剩余 300 tick 到期，正在喷射
读档后：伤口 A 的 drain 仍恢复，剩余到期 tick 继续生效，喷射器同步恢复
```

实现方式：不把 `CompTrion` 的全局 drainRegistry 当长期唯一存档源；它仍可作为运行时账本。伤口系统必须保存自己的 active wound drain 记录，并在读档恢复 Active 状态时重新注册到 Trion 账本。

**Step 6: Republish saved wound drains after load**

Add:

```csharp
internal int RestoreAfterLoad(Pawn pawn, int currentTick)
{
    EnsureInternalState();
    publishedKeysByHediffLoadId.Clear();

    if (pawn?.health?.hediffSet == null || expiryTickByHediffLoadId.Count == 0)
    {
        return 0;
    }

    expiredHediffLoadIds.Clear();
    foreach (KeyValuePair<int, int> pair in expiryTickByHediffLoadId)
    {
        if (currentTick >= pair.Value)
        {
            expiredHediffLoadIds.Add(pair.Key);
            continue;
        }

        Hediff hediff = FindWoundByLoadId(pawn, pair.Key);
        if (hediff == null || !CombatBodyWoundTrionDrainUtility.TryResolveDrainPerSecond(hediff, out float drainPerSecond))
        {
            expiredHediffLoadIds.Add(pair.Key);
            continue;
        }

        TrionDrainKey key = BuildDrainKey(hediff);
        TrionSurfaceAccess.ResolveCommands(pawn)?.RegisterDrain(key, drainPerSecond);
        publishedKeysByHediffLoadId[pair.Key] = key;
    }

    for (int index = 0; index < expiredHediffLoadIds.Count; index++)
    {
        expiryTickByHediffLoadId.Remove(expiredHediffLoadIds[index]);
    }

    expiredHediffLoadIds.Clear();
    return ResolveNextExpiryTick();
}
```

Add:

```csharp
internal IEnumerable<int> GetActiveHediffLoadIds()
{
    EnsureInternalState();
    return expiryTickByHediffLoadId.Keys;
}
```

Add `FindWoundByLoadId(Pawn pawn, int hediffLoadId)` that scans `pawn.health.hediffSet.hediffs` and returns supported wounds whose `loadID` matches.

```csharp
using BDP.Core.CombatBody.Wounds;
using HarmonyLib;
using RimWorld;
using UnityEngine;
using Verse;

namespace BDP.Patches
{
    /// <summary>
    /// 战斗体 Active 时压制原版伤口覆盖贴图。
    /// 只拦 PawnWoundDrawer，不影响疤痕和灭火泡沫覆盖层。
    /// </summary>
    [HarmonyPatch(typeof(PawnOverlayDrawer), nameof(PawnOverlayDrawer.RenderPawnOverlay))]
    public static class Patch_PawnWoundDrawer_RenderPawnOverlay_CombatBodySuppress
    {
        /// <summary>读取 PawnOverlayDrawer 保护字段 pawn。</summary>
        private static readonly AccessTools.FieldRef<PawnOverlayDrawer, Pawn> pawnAccessor =
            AccessTools.FieldRefAccess<PawnOverlayDrawer, Pawn>("pawn");

        /// <summary>
        /// Active 战斗体只跳过伤口 overlay，其他 overlay 继续走原版。
        /// </summary>
        public static bool Prefix(PawnOverlayDrawer __instance)
        {
            if (!(__instance is PawnWoundDrawer))
            {
                return true;
            }

            Pawn pawn = __instance != null ? pawnAccessor(__instance) : null;
            return !CombatBodyWoundPolicy.IsCombatBodyActive(pawn);
        }
    }
}
```
