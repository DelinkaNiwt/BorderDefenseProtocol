# BDP 武器东西姿态高度设计

## 目标

让 BDP 显式四向武器姿态的 East／West（东／西）共同屏幕高度与 South（南）一致，同时保留双武器既有的前景低、背景高透视分离。

## 根因

RimWorld（边缘世界）原版成年人物的 East／West／South 持械点屏幕纵向均为 `-0.22`。BDP 南北姿态可通过 `DefaultOffset.z + SouthZAdjust` 表达共同纵向偏移，但东西姿态只有 `SideDeltaZ`（前后手纵向差）；解析器按前后手分别使用 `-SideDeltaZ` 与 `+SideDeltaZ`，无法把两侧一起抬高。

`FrontAltitudeOffset / BackAltitudeOffset`（前后景绘制层偏移）写入 Unity（游戏引擎）世界坐标的 `y`，只控制遮挡层，不改变屏幕纵向位置，不能承担共同高度。

## 方案

在中性的 Core（核心层）`ExpressionVisualEastWestPoseConfig`（东西视觉姿态配置）中新增：

```csharp
public float SideBaseZ = 0f;
```

东西姿态最终纵向偏移改为：

```text
finalZ = SideBaseZ + (前景手 ? -SideDeltaZ : SideDeltaZ)
```

默认值为零，因此未显式使用该字段的姿态保持现状。Content（内容层）正式预设按各自已经确认的南向共同偏移显式填写：

| 预设 | SideBaseZ（侧向基础纵向偏移） |
|---|---:|
| 弧月 | `0.05` |
| 光魂灵活盾·单／双 | `0.10` |
| 光魂举盾·单／双 | `0.18` |
| 光魂重刃 | `0.12` |
| 中型远程双武器基准 | `0.03` |

中型远程双武器继续保留 `SideDeltaZ = 0.10`。修正后朝东主手／朝西副手为共同基准减 `0.10`，朝东副手／朝西主手为共同基准加 `0.10`；两把武器的中心与南向一致。

## 边界

- 不修改南北姿态及已经恢复的原版朝北高度差。
- 不修改角度、左右距离、前后景绘制层、贴图、缩放或握持锚点。
- 纯贴图替换单武器继续使用原版姿态，不进入自定义东西高度计算。
- 诊断快照同步公开 `SideBaseZ`，保证新增姿态字段可在现有视觉诊断中核对。

## 验证

- 先新增失败测试，要求 Core 配置、解析器和诊断链完整承载 `SideBaseZ`。
- 配置测试复算所有七个显式姿态，要求东西前后手中心等于南向共同偏移。
- 中型远程双武器额外断言 `±0.10` 前后手分离保持不变且东西镜像。
- 运行南北高度、单武器原版姿态、光魂及中型远程相关回归测试。
