# 光魂举盾有限瞄准旋转设计

## 目标

让光魂举盾注视警戒中的盾牌继续随目标连续移动，并在视觉上保持盾面朝向目标的感觉；同时限制屏幕内的旋转幅度，避免盾牌像枪械一样横躺或大角度斜插。

## 根因

`Patch_PawnRenderUtility_DrawEquipmentAiming_LightSoulGuardWatch`（光魂警戒装备绘制补丁）把目标的连续 `AngleFlat`（平面方向角）写入原版 `DrawEquipmentAiming`（装备瞄准绘制）参数。BDP Core（核心层）的 `VisualPoseResolver`（视觉姿态解析器）随后按原版枪械公式把该角度作为贴图长轴旋转角。光魂盾又使用 `Graphic_Multi`（多朝向贴图）按 Pawn（人物）四向选择宽正面和窄侧面，导致世界方向被同时表达为换图和整面盾牌滚转。

## 设计

1. `drawLoc`（绘制位置）继续使用警戒目标的真实连续角度，盾牌可以连续移动到人物与目标之间。
2. `Graphic_Multi`（多朝向贴图）继续按 Pawn 四向选择宽正面或窄侧面，不新增八方向资源。
3. 在 `ExpressionVisualPresetDef`（表达视觉预设）增加中性字段 `AimRotationLimit`（瞄准旋转限幅），默认 `0`。默认值表示继续使用现有完整原版瞄准旋转，所有既有武器行为不变。
4. 当限幅大于 `0` 时，解析器把当前人物四向对应的原版公开持械角作为旋转基准：非西向使用 `143°`，西向使用 `217°`。目标相对人物四向中心的角度用 `Mathf.DeltaAngle`（最短角差）计算并限制在 `±45°`，再按 `AimRotationLimit / 45°` 缩放。
5. 光魂举盾单持和双武器预设都配置 `AimRotationLimit = 15`。因此每个四向扇区内最多只产生 `±15°` 的自然倾斜，越过扇区时直接切换现有方向贴图和新的四向基准。
6. 该限幅只改变视觉姿态角；盾牌位置、主副手偏移、网格镜像、绘制层、受击冲量和同持其它武器的完整瞄准行为不变。

## 边界

- Core 不判断“盾牌”或光魂业务，只提供通用的预设级旋转限幅。
- 角度限幅不改变 `EquipmentPoseSample.AimAngle`（装备姿态样本中的真实瞄准角），因此位置和诊断仍能看到真实目标方向。
- 带枪口锚点的远程视觉预设不启用该字段；其默认值保持原版角度与枪口一致。

## 验证

- 新增 Core/Content 源码形状与 XML（可扩展标记语言）配置冒烟测试，先验证失败再实现。
- 覆盖北、东、南、西四向基准角、扇区边界和 `±15°` 限幅，以及默认 `0` 的旧行为保持。
- 运行光魂举盾方向、实时瞄准、真实武器边界和视觉解析相关测试。
- Release（发布）构建 BDP.Core.dll 与 BDP.Content.dll，并在游戏内按 8 个方向检查：盾牌位置连续跟随、宽窄贴图切换、最大倾斜不横不斜。
