# 装配台图表数值内移与辅助元素移除设计

## 目标

调整触发器装配台详情区的雷达图和精度曲线：移除截图红框标出的辅助说明与图例；把截图绿框中的实际数值移动到对应图表内部；不改动数据模型、图表边界裁切、曲线插值和卡片整体高度。

## 已确认的现状

- 雷达卡片由 `DrawRadarCard` 绘制，下方数值网格由 `DrawRadarValuesBelow` 绘制，基础值/最终值/变化方向由 `DrawComparisonLegend` 绘制。
- 雷达轴名称由 `DrawRadarAxisLabels` 绘制，当前值和固定上限目前只存在于图形下方数值网格。
- 精度曲线卡片在图表右上角绘制范围提示，在图表下方绘制四组锚点名称/当前值、比较图例和插值说明。
- 精度曲线的四个当前锚点已经在 `DrawAccuracyCard` 中以圆点绘制，可以复用 `AccuracyPoint` 的当前值和现有格式化方法。

## 方案选择

1. 只删除红框元素，保留绿框数据表：实现最小，但不符合“把实际数值直接标注在图中”的要求。
2. 在雷达轴名称处增加当前值，在精度曲线当前锚点处增加当前百分比，然后删除绿框数据表：信息始终可见、与图形对应明确，推荐采用。
3. 只在鼠标悬停时显示图内数值：占用空间最小，但数据不可同时比较，不符合当前静态信息面板风格。

## 详细设计

### 雷达图

- `DrawRadarAxisLabels` 保留轴名称，在同一轴的外侧标注 `FormatAxisValue(axis.Current, axis.IsPercentage)`。
- 轴名称使用现有 `BaseColor`，当前值使用 `AccentColor`；超限当前值使用现有 `WarningColor`。
- 删除 `DrawRadarValuesBelow`、`MeasureRadarValueGridHeight` 以及 `DrawRadarCard` 对它们的调用。
- 删除雷达卡片中的 `DrawComparisonLegend` 调用；雷达几何本身、差异线和超限裁切不变。

### 精度曲线

- 保留四个当前锚点圆点，在每个圆点附近绘制 `FormatPercentValue(point.Current)`。
- 数值默认放在点的上方；靠近图表顶部时放到点的下方，并限制水平位置，避免标签贴出图表视口。
- 删除右上角 `AccuracyRange`、下方锚点名称/数值块、比较图例和 `AccuracyNote`。
- 保留曲线、基础虚线、差异线、坐标轴和距离刻度。

### 语言与测试

- 删除不再使用的雷达图例、精度范围、精度图例和精度插值说明语言键。
- 更新详情渲染契约，禁止旧的下方数值/图例/说明入口，并要求新的雷达轴值和精度锚点值绘制入口存在。
- 运行图表契约、详情/窗口边界测试和 `BDP.Content` Release 构建；图内最终位置需重启游戏截图复核。

## 风险与边界

- 不修改 `RadarAxis`、`AccuracyPoint`、数值计算或超限裁切逻辑。
- 不改变卡片固定高度；本次不处理用户之前暂缓的空位排版。
- 图内标签可能受极端本地化长度影响，但数值本身使用现有格式化逻辑，不新增玩家文案。
