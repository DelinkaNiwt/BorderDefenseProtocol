# 追踪弹模块 Implementation Plan（实施计划）

> **For Claude（给 Claude）:** REQUIRED SUB-SKILL（必需子技能）: Use superpowers:executing-plans（执行计划） to implement this plan task-by-task（按任务逐条执行）.

**Goal（目标）:** 在主模组增加中立的曲线路径宿主能力，并在测试模组落一个可配置、可存读档恢复的追踪弹业务模块。

**Architecture（架构）:** 主模组只新增 `ProjectileFlightPathSnapshot（投射物飞行路径快照）` 一类中立基础设施，把首段与续段路径快照接到 `BdpProjectile（投射物宿主）`。测试模组通过 `ProjectileInit（投射物初始化）` 与 `Arrival（到达）` 两个阶段，按当前目标真实位置规划一段段平滑曲线，不依赖 `PathLatch（路线引导）`。

**Tech Stack（技术栈）:** C#、RimWorld / Verse、XML Def、PowerShell 烟雾测试、`dotnet msbuild`。

**Step 2: 用路径快照替代当前直线段真值**

把当前这三个字段：

必要时可保留旧字段过渡一小步，但最终宿主的真实路径真值应只认快照。

**Step 3: 新增宿主内部辅助方法**

至少补这几个方法：

```csharp

private ProjectileFlightPathSnapshot BuildLinearFlightPathSnapshot(Vector3 start, Vector3 end) { ... }
private float ResolveCurrentFlightProgress() { ... }
private Vector3 ResolveCurrentFlightStartDirection() { ... }
```

**Step 4: 修改 `Launch（发射）`**

`Launch()` 后：

- 如果 `launchPlan.InitialFlightPathSnapshot` 有值，绑定它
- 否则构造线性快照
- 把 `destination` 统一设置为当前快照的 `End`
- 再按当前路径长度重置飞行时长

**Step 5: 修改 `ExactPosition（精确位置）` 与 `ExactRotation（精确朝向）`**

不要再按“起点到终点直线插值”算。

改为：

```csharp
float progress = ResolveCurrentFlightProgress();
Vector3 pos = ProjectileFlightPathUtility.EvaluatePosition(currentFlightPathSnapshot, progress);
Vector3 tangent = ProjectileFlightPathUtility.EvaluateTangent(currentFlightPathSnapshot, progress);
```

`ExactRotation（精确朝向）` 用切线方向。

**Step 6: 修改 `ContinueFlight（续段飞行）`**

续段时：

- 优先用 `arrival.NextFlightPathSnapshot`
- 没有时退回线性快照
- `origin` 的兼容回退方向不要再用“整段弦线方向”
- 要用“新路径起点切线方向”

即：

```csharp
Vector3 startDir = ResolveCurrentFlightStartDirection();
origin = normalizedOrigin - startDir * 6f;
```

**Step 7: 修改 `ResetFlightDurationFromCurrentSegment（按当前段重置时长）`**

不要再按弦长。

改为：

```csharp
float pathLength = currentFlightPathSnapshot != null
    ? Mathf.Max(0.001f, currentFlightPathSnapshot.ApproximateLength)
    : (origin - destination).magnitude;
```

然后用 `pathLength / SpeedTilesPerTick（每 tick 速度）` 算时长。

**Step 8: 修改 `ExposeData（存读档）`**

持久化：

```csharp
currentFlightPathSnapshot
currentFlightPathStartingTicksToImpact
```

并删掉不再作为真实路径真值的旧字段。

**Step 9: 在宿主代码里写延期注释**

在 `BdpProjectile.cs` 路径绑定附近留最简注释：

```csharp
// TODO: 如果后续要做飞行中途实时重建路径，只扩展路径宿主，不允许业务模块直接写 projectile 物理字段。
```

这是必须写入代码的延期事项。
