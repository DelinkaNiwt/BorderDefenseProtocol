# BDP 芯片信息设施第一阶段结构整理 Implementation Plan（实施计划）

> **For Claude（供执行代理）:** REQUIRED SUB-SKILL（必须使用的子技能）: Use superpowers:executing-plans to implement this plan task-by-task（使用 executing-plans 技能逐项执行本计划）。

**Goal（目标）:** 在不改变玩家显示与信息模型内容的前提下，把成品芯片信息模型构建从制造预览界面类抽成 Content（内容程序集）共享设施，并移除装配台借道制造预览获取模型的依赖。

**Architecture（架构）:** 新建 `ManufacturedChipInformationModelBuilder`（成品芯片信息模型构建器），原样迁移当前声明配置、最终配置、描述、武装构型信息和来源链合成逻辑。制造预览与装配台直接调用该构建器；Core（核心程序集）信息模型和所有界面布局保持不变。

**Tech Stack（技术栈）:** RimWorld 1.6、C# 7.3、Verse、现有 `ChipInformationModel`（芯片信息模型）、PowerShell（命令脚本）静态契约测试、MSBuild（微软构建工具）。

**Step 1：建立最小类和公开入口**

类的完整目标实现应为：

```csharp
using System.Collections.Generic;
using BDP.Content.Assembly.ChipManufacturing.Model;
using BDP.Content.Assembly.ChipManufacturing.Resolution;
using BDP.Core.Information;

namespace BDP.Content.Information
{
    /// <summary>
    /// 从一份合法成品组合解析结果构建统一芯片信息模型。
    /// 本类不持有窗口状态，也不负责把模型映射成具体界面。
    /// </summary>
    public static class ManufacturedChipInformationModelBuilder
    {
        /// <summary>构建当前成品的基础值、最终值、描述与来源链模型。</summary>
        public static ChipInformationModel Build(
            ChipCombinationResolution resolution)
        {
            ChipInformationIdentity identity = new ChipInformationIdentity(
                null,
                null,
                null,
                resolution.SourceProfessionKey);
            List<ChipInformationDescription> descriptions =
                CreateDescriptions(resolution);
            List<ChipInformationFactBlock> armamentFormBlocks =
                ChipArmamentFormInformationAdapter.CreateBlocks(resolution.ArmamentForm);
            ChipInformationParseInput declared =
                ChipInformationDefinitionInputAdapter.Create(
                    resolution.DeclaredConfig ?? resolution.ResolvedConfig,
                    identity,
                    ChipInformationRuntimeInputAdapter.CreateStatic(),
                    null,
                    descriptions,
                    armamentFormBlocks);
            if (resolution.ArmamentForm == null || resolution.DeclaredConfig == null)
            {
                return ChipInformationSurfaceAccess.Read(declared);
            }

            ChipInformationParseInput effective =
                ChipInformationDefinitionInputAdapter.Create(
                    resolution.ResolvedConfig,
                    identity);
            ChipInformationParseInput effectiveOverlay =
                ChipInformationInputComposer.ReclassifySources(
                    effective,
                    ChipInformationSourceKind.EffectiveDefinition,
                    ChipInformationContributionKind.Replacement,
                    "armament." + resolution.ArmamentForm.defName);
            ChipInformationParseInput combined =
                ChipInformationInputComposer.Combine(declared, effectiveOverlay);
            return ChipInformationSurfaceAccess.Read(combined);
        }

        /// <summary>读取功能模板与武装构型的已语言化描述。</summary>
        private static List<ChipInformationDescription> CreateDescriptions(
            ChipCombinationResolution resolution)
        {
            List<ChipInformationDescription> result =
                new List<ChipInformationDescription>();
            if (resolution?.FunctionDefs != null)
            {
                for (int index = 0; index < resolution.FunctionDefs.Count; index++)
                {
                    if (resolution.FunctionDefs[index] == null)
                    {
                        continue;
                    }

                    result.Add(new ChipInformationDescription(
                        resolution.FunctionDefs[index].defName,
                        resolution.FunctionDefs[index].ResolvedLabel,
                        resolution.FunctionDefs[index].ResolvedDescription));
                }
            }

            if (resolution?.ArmamentForm != null)
            {
                result.Add(new ChipInformationDescription(
                    resolution.ArmamentForm.defName,
                    resolution.ArmamentForm.ResolvedLabel,
                    resolution.ArmamentForm.ResolvedDescription));
            }

            return result;
        }
    }
}
```

该代码是机械迁移目标，不代表允许顺手改空值策略、来源类型或描述顺序；若实际源码在执行前发生变化，应以届时旧实现为准重新做逐行等价核对。

**Step 2：原样迁移模型构建逻辑**

从 `ChipManufacturingPreviewBuilder`（芯片制造预览构建器）迁移：

- `BuildInformationModel`；
- `CreateDescriptions`。

保持下列顺序不变：

1. 创建身份；
2. 收集功能和武装构型描述；
3. 创建武装构型附加信息块；
4. 创建基础配置输入；
5. 无构型或无基础配置时直接读取；
6. 创建最终配置输入；
7. 重分类为 `EffectiveDefinition`（最终有效定义）与 `Replacement`（替换贡献）；
8. 合成输入；
9. 通过统一读取面返回模型。
