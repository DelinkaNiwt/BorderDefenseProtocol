# 攻击模式与双侧调度 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在新 BDP 中正式引入远程逐发/齐射、近战单击/多击、双侧调度，并保持 `1远 + 1近` 不合成为统一双侧攻击。

**Architecture:** 在表达系统结果上增加 `AttackExecutionStyle`，只声明执行节奏与双侧调度；`VerbHosting` 继续只负责运行时 Verb 宿主；`AttackPlanner / AttackExecution` 负责把执行风格展开为真实时序。默认主攻击继续保持场景决策，不恢复固定字段。

**Tech Stack:** C#, RimWorld Verb/JobDriver 体系, BDP Expression/VerbHosting/AttackExecution 分层

---

- 单侧条目不得声明 `Dual.Schedule`

- 这里先做结构校验

要求：

- 双近 -> `MainThenSub`

**Step 3: 不让 `1远 + 1近` 混入复合推导**

要求：

- 即便主副侧都存在 Primary
- 只保留 `PrimaryRanged` 与 `PrimaryMelee` 并列
- 不生成统一的双侧复合攻击结果
