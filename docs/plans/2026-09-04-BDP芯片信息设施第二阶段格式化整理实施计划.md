**Goal（目标）:** 在不改变制造预览和触发器装配台现有玩家文字的前提下，抽取两者确实相同的基础值格式化逻辑，并把真实的界面策略差异继续留在各自消费者中。

## 二、已确认的当前差异

| 值类型 | 制造预览 | 触发器装配台 | 本阶段处理 |
|---|---|---|---|
| Text（文本） | 原文本 | 原文本 | 共享 |
| Boolean（布尔） | `BDP_Yes/BDP_No` | `BDP_Yes/BDP_No` | 共享 |
| Integer（整数） | 当前区域格式 | 固定不变量格式 | 共享分派，保留格式提供器差异 |
| Number（普通数值） | 当前区域 `0.##` | 固定不变量 `0.##` | 共享分派，保留格式提供器差异 |
| Percentage（百分比） | Verse 比例格式 | 自有归一化与 `0.#%` | 各自保留 |
| Duration（持续时间） | 数值后套字段单位 | 专用秒数语言键 | 各自保留 |
| Enum（枚举） | 把键当语言键翻译 | 已知值专门映射，未知值保留原键 | 各自保留 |
| List（列表） | 只显示数量 | 展开并以顿号连接 | 各自保留 |
| Unknown（未知值） | 空文本或调用前跳过 | 显示装配台未知值语言 | 各自保留 |
| UnitKey（单位键） | 翻译单位并代入值 | 翻译单位并代入值 | 共享 |

### Task 2：新增最小基础格式化器

**Files（文件）:**

- Create（新建）: `Source/BDP.Content/Information/ChipInformationTextFormatter.cs`

**Step 1：实现完整最小类**

```csharp
using System;
using System.Globalization;
using BDP.Core.Information;
using Verse;

namespace BDP.Content.Information
{
    /// <summary>
    /// 统一格式化信息模型中无界面策略差异的基础值。
    /// 百分比、持续时间、枚举、列表和未知值由具体消费者处理。
    /// </summary>
    internal static class ChipInformationTextFormatter
    {
        /// <summary>尝试格式化文本、布尔、整数和普通数值。</summary>
        internal static bool TryFormatScalar(
            ChipInformationValue value,
            ChipInformationValueKind kind,
            out string text,
            IFormatProvider formatProvider = null)
        {
            text = string.Empty;
            if (value == null)
            {
                return false;
            }

            IFormatProvider provider = formatProvider ?? CultureInfo.CurrentCulture;
            switch (kind)
            {
                case ChipInformationValueKind.Text:
                    text = value.Text ?? string.Empty;
                    return true;
                case ChipInformationValueKind.Boolean:
                    text = (value.Boolean ? "BDP_Yes" : "BDP_No").Translate().ToString();
                    return true;
                case ChipInformationValueKind.Integer:
                    text = value.Integer.ToString(provider);
                    return true;
                case ChipInformationValueKind.Number:
                    text = value.Number.ToString("0.##", provider);
                    return true;
                default:
                    return false;
            }
        }

        /// <summary>按字段单位语言键套用已经格式化的值。</summary>
        internal static string ApplyUnit(string unitKey, string text)
        {
            return unitKey.NullOrEmpty()
                ? text
                : unitKey.Translate(text).ToString();
        }
    }
}
```
