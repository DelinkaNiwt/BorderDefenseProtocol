# 铅弹投射物条件减益 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将铅弹模块的投射物速度倍率调整为 50%，并让爆炸型投射物对每个受影响目标只附加 1% 铅块负重严重度。

**Architecture:** 复用现有 Content 远程减益配置、ProjectileInit 速度倍率和 Impact 额外效果参数袋。只在 Content 的 `RangedDebuffConfig` 增加一个爆炸严重度倍率，并由 `RangedDebuffModule` 按当前投射物的爆炸半径选择最终严重度；不修改 Core 阶段契约或 Hediff 执行器。

**Tech Stack:** C#（C#语言）、RimWorld Def/XML（定义/可扩展标记语言）、PowerShell 冒烟测试、Git。
