# BDP 事项09E：实验性战斗日志表现退役实施计划

## 目标

退役临时制作、且当前效果不满意的 BDP 自定义战斗日志表现，让游戏恢复使用原版战斗日志显示。不得改变攻击、命中、伤害、Trion、芯片或战斗体流程。

## 保留范围

- 保留 `BattleLogEntry_RangedFire` 和 `BattleLogEntry_RangedImpact` 的原版日志写入。
- 保留必要的 `weaponDef` 安全适配，避免 BDP 特殊攻击来源向原版日志传递无效定义。
- 保留攻击执行、投射物碰撞和原版日志自身的运行逻辑。

## 退役范围

- 删除 Core 自定义战斗日志快照、记录仓库和中文格式化器。
- 删除 `LogEntry.ToGameStringFromPOV` 的自定义 Harmony 覆盖补丁。
- 删除远程攻击协议、发射计划、投射物计划中的 `BattleLogPresentation` 字段和读档字段。
- 删除开火/命中日志的 BDP 元数据登记调用。
- 删除只验证旧自定义表现的测试，新增退役边界测试。

## 验证标准

1. 退役边界测试确认自定义日志文件和生产代码引用已清理。
2. 原版开火、命中日志对象仍然创建并写入。
3. Core、Content、DevHarness Release 构建成功。
4. Core 零本模组程序集依赖门禁通过。
5. 全量冒烟测试不新增与本次退役相关的失败。

## 执行结果（2026-08-01）

- 退役边界测试按测试先行：删除前失败，删除后通过。
- 三个程序集构建成功，Core 依赖门禁通过。
- 全量冒烟测试286项通过274、失败12；失败集合与退役前基线一致。
- 未来若重新处理战斗日志，须以原版显示为基线重新设计，不在本次退役代码上继续修补。
