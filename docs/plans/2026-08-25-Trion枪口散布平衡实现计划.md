# Trion 枪口散布平衡 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让正式发射点在单发时回到理论中心，在多发时按发射序号保持左右交替，同时保留散布幅度随机性。

**Architecture:** 复用现有 `RangedVerbEmissionPlan.ExpectedEmitCount` 和 `ProjectileInitPlan.EmitSequence`，由 `BdpVerb_Shoot` 在最终发射点解算阶段决定横向侧别。一次正式发射计划只保存首发侧别状态；不增加 XML 字段，不改变枪口锚点、连发数量或组合技解析。

**Tech Stack:** C#（C#语言）、RimWorld Verb/Projectile 发射链、PowerShell 烟测脚本。

### Task 2: 实现单发归零和多发左右交替

**Files:**
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP/Core/Verbs/BdpVerb_Shoot.cs:721,1304-1334`

**Step 1: 取得当前正式计划的发射总数**

在调用散布解算时复用 `emissionCursor.PendingVerbEmissionPlan.ExpectedEmitCount`。当正式计划缺失或数量无效时，按单发回退处理，避免无上下文时错误扩散。

**Step 2: 为每次正式计划确定首发侧别**

在 `BdpVerb_Shoot` 中保存当前正式发射计划的身份和首发侧别：

- 计划身份使用现有 `AttackInstanceId` 与 `ResultId`。
- 计划身份变化或 `EmitSequence == 0` 时重新随机一次首发侧别。
- 后续按 `EmitSequence % 2` 在两侧之间交替。

**Step 3: 修改散布解算**

- 预期总发射数 `<= 1`：返回 `Vector3.zero`。
- 预期总发射数 `> 1`：横向偏移只随机幅度，再由交替侧别决定正负。
- 继续按原有 `ForwardMin..ForwardMax` 随机前向偏移。
- 保留无效目标、无散布配置、零方向的原有零偏移回退。
