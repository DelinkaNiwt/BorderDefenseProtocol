# Dual 宿主适配层执行归属纠偏实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 纠正 dual 远程攻击中“入口结果仍是 dual，但实际已退化成单侧时，运行时宿主仍错误绑定到 DualPrimary 壳”的问题，并把 dual 宿主收口为引擎接口适配层而非业务判定主体。

**Architecture:** 保留 dual 结果作为自动主攻、手动 targeting 与 dual 调度的入口门面；但进入运行时后，`HostResultId` 必须表达“这一动作步实际由谁执行”。dual 宿主自身不再提供独立的业务真值，面向原版引擎的 LOS / legality 判定统一转译为对来源侧结果的聚合判断。单侧存活时执行 ownership 下沉到 surviving side；双侧都存活时，dual 宿主仅作为协调壳继续存在。

**Tech Stack:** C# / RimWorld 1.6 / BDP AttackExecution + VerbHosting / PowerShell smoke tests / `dotnet msbuild`

**Step 1: Write the failing test**

创建 `Source/BDP.Tests/DualRangedAdapterLegalitySmokeTests.ps1`，断言：

```powershell
$formalHostShootText -match 'override bool CanHitTargetFrom'
$formalHostShootText -match 'TryEvaluateDualAdapterLegality'

$formalHostShootText -match 'return base.CanHitTargetFrom\(root, targ\);'
$diagnosticsText -match 'event=dual_ranged_host_los_probe'
```

测试目标：
- dual 壳面对原版 `CanHitTargetFrom` 时，优先做 sides 聚合；
- 非 dual 或无复合引用时，仍回退 `base.CanHitTargetFrom(...)`。

**Step 2: Run test to verify it fails**

Run: `& '.\Source\BDP.Tests\DualRangedAdapterLegalitySmokeTests.ps1'`  
Expected: FAIL，提示当前 dual formal host 仍只做 base LOS 并把 side 聚合仅用于日志。

**Step 3: Write minimal implementation**

在 `BdpVerb_FormalHostShoot.cs` 中把当前“只记日志不改返回值”的实现改成：

```csharp
public override bool CanHitTargetFrom(IntVec3 root, LocalTargetInfo targ)
{
    if (TryEvaluateDualAdapterLegality(root, targ, out bool anySideAllowed, ...))
    {
        return anySideAllowed;
    }

    return base.CanHitTargetFrom(root, targ);
}
```

其中 `TryEvaluateDualAdapterLegality(...)` 只在以下情况下接管：
- 当前 `HostResultId` 对应已发布结果确认为 `CompositeKind.DualWeapon`
- 能解析到 `CompositeExpressionReference`

接管后的规则：
- 只要任一 side 当前允许执行 -> 返回 `true`
- 两侧都不允许 -> 返回 `false`

side 判定沿用现有必要 LOS 语义：
- `RequiresDirectTargetLineOfSight == false` 的侧直接视为 adapter 层可放行
- `RequiresDirectTargetLineOfSight == true` 的侧读取自己的 formal host 壳做 `CanHitTargetFrom(root, targ)`

同时保留现有 `dual_ranged_host_los_probe` 日志，但其含义从“观测 base 是否挡住”改成“记录 adapter 聚合结果与 sides 事实”。
