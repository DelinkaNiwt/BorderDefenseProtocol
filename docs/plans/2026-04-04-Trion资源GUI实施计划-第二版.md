# Trion Gene-Carried GUI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在主工程当前真实 `CombatBodySession / CombatBody / Trigger / Trion` 架构上，为新 BDP 新增一个“只承担基因职责”的 `Gene_TrionGland`，并由它承载 Trion GUI 入口，而不是再把 GUI 直接挂到 `CompTrion`。

**Architecture:** `CompTrion` 继续作为独立 Trion 真值宿主；`CombatBodySessionService` 继续作为跨三系统唯一协调层；新增 `Gene_TrionGland` 只负责基因身份、Trion stat 贡献、Pawn 侧 GUI 入口与最小 stat 刷新协作。Trion 主条核心继续只读 `ITrionReader`，不直接依赖 `CombatBodySession / Trigger / CombatBody`。

**Tech Stack:** C#, RimWorld 1.6 Gene / Stat / Gizmo runtime, Verse / RimWorld defs, PowerShell smoke tests, `dotnet msbuild`
