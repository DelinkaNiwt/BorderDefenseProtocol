# BDP 护盾状态与动作准入实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 实现已确认的共用耐久、穿盾与破盾接口、关闭后冷却及光魂举盾近战规则，以游戏内测试为主要验收。

**Architecture:** Content（正式内容）用一个原版持久 Hediff（健康状态）保存人物各护盾组的耐久比例和恢复完成游戏刻，临时防护宿主只消费它。光魂举盾姿态与盾面防护分开发布，完好条件统一控制防护、盾面及盾击，推进复用既有角色使用条件。Core（中性基础设施）仅开放来源条件子类求值与条件变化刷新入口，不认识任何盾型。

**Tech Stack:** C# 7.3、.NET Framework 4.8、RimWorld 1.6、Harmony（补丁库）、XML（定义文件）。直接使用当前工程与现有分支，不创建工作树。

## 固定规则与边界

- 普通单盾 120、双盾按来源相加为 240，常驻自动盾 120、光魂两种盾姿态共用 240；各类恢复初值 600 游戏刻（10 秒），耐久损耗倍率 1。
- 耐久归属人物的同类防御组，不归属临时姿态或单次表达发布；普通、自动、光魂各自独立。关闭、切换姿态、单双切换、更换同类来源均不刷新剩余比例或恢复时点；当前最大值来自有效来源数量。此版不增加芯片跨人物转移耐久机制。
- 破盾的最后一击：先成功支付能量、清零当次伤害并播放格挡反馈，再扣耐久并转换状态。失败格挡不损耗耐久。
- 已破盾再次强制破盾不延长计时。到期恢复比例为 1；关闭期间用绝对游戏刻结算，无需常驻每帧倒计时。
- 穿盾仅针对这类 BDP 护盾，提供可释放的本次伤害调用范围，近战、远程和爆炸均可使用；与已有包含原版盾的投射物策略互不混淆。
- 举盾保留 0.6 移速与远程武器限制；近战继续使用原版/BDP 正式链。推进不是远程武器攻击，不被举盾限制误禁；破盾由完好条件禁止盾击与推进。
- 不修改无关芯片与原版武器判定；原计划未包含的攻击会话续接已单独获得用户授权，范围见末尾补充。所有新玩家/开发菜单文案放语言包。
