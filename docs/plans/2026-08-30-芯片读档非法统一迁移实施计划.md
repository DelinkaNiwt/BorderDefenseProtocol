# 芯片读档非法统一迁移实施 Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将芯片读档兼容处理从三状态收束为二状态，所有当前无法确认合法的芯片按遗留物规则处理。

**Architecture:** `BDP.Content` 的组合解析器仍负责先解析来源、再校验组合，但来源解析失败统一返回 `Invalid`。读档迁移器只处理 `Valid` 与 `Invalid`：物品统一替换为遗留物，账单统一删除；删除玩家可见的来源缺失保留分支。`BDP.Core` 不改。

**Tech Stack:** C#、RimWorld `GameComponent`/`ThingComp`/`Bill`、PowerShell 冒烟测试、MSBuild、XML 语言包。
