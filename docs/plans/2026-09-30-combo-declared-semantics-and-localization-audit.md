# 组合声明语义展示与翻译审查计划

## 目标

在芯片详情面板的组合关系下，按需展开显示 `ComboDef` 声明的完整功能语义树，初始折叠。继续使用当前信息解析器和功能渲染器，不修改信息模型，也不读取已发布组合运行结果。

## 实施

1. 复制 `ComboDef.Features` 与表达条目作为解析输入；普通远程来源在进入现有功能解析器前按 ComboDef 明确声明的字段过滤，避免空字段假零值参与同层合并。AbilityDef 与 VerbProps 覆盖合并时保留原能力的视线要求。
2. 在组合关系行增加折叠入口；展开后复用现有功能树、属性卡片和图表渲染。
3. 复核最新 `TranslationReport.txt` 中 BDP 缺失项，区分真实玩家可见缺译、中文默认值、已有 Keyed 覆盖项与内部项；补齐组合名称和说明、风刃投射物和拖尾预设名称，以及继承英文通用标签的三种内部粒子效果名称。
4. 编译 Content 项目并检查最终差异；不运行测试。

## 范围

只修改组合关系详情渲染所需的 Content 代码和对应简体中文翻译。报告中的其余中文默认值、已有 Keyed 覆盖项及无效告警不做批量改写。
