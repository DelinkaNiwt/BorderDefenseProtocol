# BDP 远程模块开放面与执行边界重审 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不脱离 RimWorld 原版远程攻击基线的前提下，收缩并纠正 BDP 远程模块系统的作者开放面、状态传递边界与宿主消费边界，使作者可稳定编写业务模块，而主模组继续对具体业务保持无知。

**Architecture:** 本次实施不重造攻击链，不引入额外大层级对象体系，而是以现有 `RangedAttackModuleSession`、`AttackExecutionTargetingSource`、`RangedAttackProtocolService`、`BdpVerb_Shoot`、`BdpProjectile` 为骨架做边界纠偏。核心原则只有三条：前置链会话稳定、确认后执行态一次冻结、宿主消费游标不复制正式计划对象。

**Tech Stack:** RimWorld 1.6 C# / Verse / RimWorld 原版 `Targeter`、`Verb`、`Projectile`、`Bullet` / BDP 主模组 smoke tests / DevHarness 测试模组。
