## 正式配置

多形态块：

```xml
<Modes>
  <li>
    <ModeKey>stable</ModeKey>
    <DisplayLabel>稳定形态</DisplayLabel>
    <GizmoIconTexPath>Things/Trigger/Chip/BDP_TriggerChip</GizmoIconTexPath>
    <ActiveEntryIds>
      <li>shared_ability</li>
      <li>stable_state</li>
    </ActiveEntryIds>
  </li>
  <li>
    <ModeKey>mobile</ModeKey>
    <DisplayLabel>机动形态</DisplayLabel>
    <ActiveEntryIds>
      <li>shared_ability</li>
    </ActiveEntryIds>
  </li>
</Modes>
```

字段规则：

```csharp
public string ModeKey;
public string DisplayLabel;
public string GizmoIconTexPath;
public List<string> ActiveEntryIds;
```

- `DisplayLabel`缺失或空白时，多形态定义无效。
- `GizmoIconTexPath`为空时合法，Content 回退芯片物品图标。
- 单形态芯片不声明 `Modes`，不受显示字段校验影响。

## 正式运行接口

预计对外读取形态：

```csharp
string GetChipModeKey(Thing chip);
IReadOnlyList<ChipModeOptionSnapshot> GetChipModeOptions(Thing chip);
```

预计对外提交命令：

```csharp
bool RequestSwitchChipMode(Thing chip, string targetModeKey);
bool RequestCycleChipMode(Thing chip);
```

`ChipModeOptionSnapshot`只公开：

```csharp
public string ModeKey { get; internal set; }
public string DisplayLabel { get; internal set; }
public string GizmoIconTexPath { get; internal set; }
```

未启用、单形态、定义无效或找不到正式根槽时：

- `GetChipModeKey`返回 `null`。
- `GetChipModeOptions`返回空只读列表。
- 两个命令返回 `false`，不修改真值。

**Step 5：实现原子发布**

指定形态命令流程：

```csharp
string previousModeKey = rootSlot.CurrentModeKey;
if (string.Equals(previousModeKey, targetModeKey, StringComparison.OrdinalIgnoreCase))
{
    return true;
}

rootSlot.SetCurrentModeKey(targetModeKey);
try
{
    if (PublishCombatProjection(ProjectionDirtyReason.ChipModeChanged))
    {
        return true;
    }
}
catch (Exception ex)
{
    // 记录诊断后回滚。
}

rootSlot.SetCurrentModeKey(previousModeKey);
MarkCombatProjectionDirty(ProjectionDirtyReason.ChipModeChanged);
return false;
```

要求：

- 发布失败前旧投影仍是正式结果。
- 回滚后下一次可发布的真值仍是旧形态。
- 诊断包含 Trigger、Pawn、芯片 ThingID、旧形态、新形态和异常或失败原因。
- 成功发布继续复用现有投影换版逻辑，中断已经失效的旧攻击；不另写攻击中断补丁。
