# Trion 立方体阶段贴图细化实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 Trion 立方体构型接入预热主层/发光层切换，并在射击与冷却阶段隐藏完整视觉，同时保持待机视觉不变。

**Architecture:** 扩展 `BDP.Core` 中已有的中性阶段视觉覆盖，使一个动作阶段可以替换主贴图和叠层集合；`BDP.Content` 只在两个 Trion 视觉预设中声明具体资源和阶段策略。未声明阶段叠层时继续回退到预设原有叠层，确保旧视觉行为兼容。

**Tech Stack:** C# 7.3、.NET Framework 4.8、RimWorld Def/XML、PowerShell 冒烟测试、MSBuild。

### Task 2: 实现中性阶段叠层覆盖解析

**Files:**
- Modify: `Source/BDP/Core/Expressions/Config/ExpressionVisualStageOverrideConfig.cs`
- Modify: `Source/BDP/Core/Expressions/Config/ExpressionVisualPresetDef.cs`
- Modify: `Source/BDP/Core/Trigger/Visual/VisualPoseResolver.cs`

**Step 1: Add the minimal Core model field**

在 `ExpressionVisualStageOverrideConfig.cs` 增加 `using System.Collections.Generic;`，并在 `GraphicData` 字段后增加：

```csharp
/// <summary>
/// 当前阶段的可选附加绘制层集合；留空时沿用视觉预设默认叠层。
/// </summary>
public List<ExpressionVisualOverlayLayerConfig> OverlayLayers;
```

该字段不能出现 Trion 名称、贴图路径或阶段业务策略。

**Step 2: Add stage-aware overlay fallback**

在 `ExpressionVisualPresetDef.cs` 增加：

```csharp
/// <summary>
/// 按当前动作阶段解析附加绘制层集合。
/// 阶段显式提供集合时替换默认集合，否则沿用默认叠层。
/// </summary>
public List<ExpressionVisualOverlayLayerConfig> ResolveOverlayLayers(
    WeaponVisualActionStage stage)
{
    ExpressionVisualStageOverrideConfig stageOverride = ResolveStageOverride(stage);
    return stageOverride != null && stageOverride.OverlayLayers != null
        ? stageOverride.OverlayLayers
        : OverlayLayers;
}
```

**Step 3: Feed the resolved stage into overlay rendering**

在 `VisualPoseResolver.cs` 的 `Resolve` 和 `ResolveTextureOnly` 中，把：

```csharp
OverlayPoses = ResolveOverlayPoses(request, calculation),
```

改为传入已经解析出的 `weaponStage`：

```csharp
OverlayPoses = ResolveOverlayPoses(request, calculation, weaponStage),
```

同时把私有方法签名改为接收 `WeaponVisualActionStage weaponStage`，并将：

```csharp
if (overlayPreset.OverlayLayers == null)
```

替换为通过 `overlayPreset.ResolveOverlayLayers(weaponStage)` 得到当前叠层集合，再遍历该集合。其它激活态、位置、角度、材质和绘制顺序逻辑保持不变。
