# 第一阶段修正任务清单：立即结算与事件落实（第一版）

## 目标

修正当前第一阶段实现中已经暴露出的方向性错误：

- 控制操作结果错误依赖时间流动
- Trigger 与 CombatBody 仍以时间状态机为主
- 事件通信尚未真正落地
- 当前测试链存在按钮、激活、自动攻击与 Verb 宿主异常问题

## 本轮任务范围

本轮不追求扩大功能面，只处理这几件事：

1. 立好暂停结算与时间过程分层原则
2. 重做 Trigger 的激活建模
3. 统一表达、按钮、自动攻击读取逻辑快照
4. 落一个最小可用的事件通信骨架
5. 修掉当前测试链已暴露的实际问题
6. 回查 CombatBody，列出下一轮同类修正入口

## 本轮验收方式

### 游戏内验收

在暂停状态下：

1. 装备测试触发体
2. 点击 `测:装主远程`
3. 点击 `测:开主0`
4. 不推进时间，直接看是否出现 `测试远程`
5. 点击 `测:装副近战`
6. 点击 `测:开副0`
7. 不推进时间，直接看是否出现 `测试近战`

### 诊断验收

应能清楚区分：

- 装载成功
- 激活请求
- 激活已提交
- 表达已刷新
- 手动按钮构建数量
- 自动攻击入口是否命中

### 失败判定

以下任一情况都视为本轮未通过：

- 暂停状态下无法完成按钮结算
- 仍需依赖时间流动才出现激活结果
- 查询入口继续承担补救式结算
- 自动攻击入口继续出现空引用
