# 战斗体编辑台与个人服装模板实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 BDP 增加战斗体编辑台，使每个 Pawn（小人）能够保存并选择带实际材料、颜色和风格的个人战斗体服装模板。

**Architecture:** `BDP.Content.dll` 使用存档级 `GameComponent`（全局存档组件）保存按 Pawn 归属的模板、模式和选中项，不再给 Pawn 增加新的 `ThingComp`（组件）。`BDP.Core.dll` 只新增中性的前台外观解析契约和动态服装创建路径；Content 通过注册表提供个人模板，Core 在没有个人有效预设时回退到全局镜像。编辑台建筑、Job、窗口、预览和语言文案全部属于 Content。

**Tech Stack:** RimWorld 1.6、C# 7.3、.NET Framework 4.8、Verse、RimWorld、Unity IMGUI、Harmony、PowerShell 冒烟测试。
