# 许可声明链与动态目标直视放宽设计

## 目标

在不把“操作员控制台”或“风刃”写死进 Core 的前提下，建立可复用的许可声明链：具体表达声明自己愿意接入的许可键，地图侧业务对象动态提供许可，业务接收器解释许可效果。首个效果是：操作员控制台处于运作状态时，已声明该许可的攻击可以不要求施法者直视目标。

## 已确认范围

- 许可机制不属于风刃专属；以后其它攻击也可以声明同一许可键。
- 机制同时覆盖普通 BDP 远程攻击和 Ability 两条施法入口。
- 只有显式声明许可键的表达才参与对应业务判定；未声明的表达保持原行为。
- 当前仅放宽“施法者到目标的直达视线”要求，不改变射程、目标类型、投射物飞行、命中和伤害规则。
- `风刃·实体刀` 不自动获得该许可，除非它自己的表达也显式声明。
- 操作员控制台的运作状态变化必须在攻击运行时即时生效，不能在 Def 加载或静态表达缓存时冻结。
- 无需现在预定义所有许可类型、提供者或效果；Core 只维护中性许可链，不解释业务键名。

## 核心机制

许可键是带命名空间的布尔能力信号，例如 `BDP.OperatorConsole.Active`。它描述“某项地图能力当前有效”，而不是“某个攻击可以无视直视”。

```text
许可提供者
  └─ 发布 Map + Faction + PermissionKey + IsActive
       ↓
地图许可汇总器
  └─ 查询当前键是否由至少一个有效提供者发布
       ↓
表达运行时上下文
  └─ 携带 DeclaredPermissionKeys 和许可读取入口
       ↓
业务接收器
  └─ 检查声明键与当前许可，并解释具体效果
```

### 许可提供者

由提供能力的业务模块定义键常量并实现地图许可提供接口。操作员控制台由 Content 定义 `BDP.OperatorConsole.Active`，其提供者只报告 `IsOperational`，不把控制台的电力、操作员和 Trion 中继核心条件复制到消费者中。

### 许可汇总与查询

Core 按地图和派系汇总提供者。任意一个匹配且有效的提供者即可满足同一键；许可不叠加数值。没有提供者、提供者失效、地图或派系不匹配时，查询结果为 `false`。状态从提供者实时读取，生命周期失效按未授权处理。

### 表达声明

表达配置、契约和运行时结果统一使用 `DeclaredPermissionKeys`。该列表的含义是“此表达主动声明愿意接入哪些许可判定”，不是攻击专属权限清单，也不是发动攻击的必需条件。

XML 形式：

```xml
<DeclaredPermissionKeys>
  <li>BDP.OperatorConsole.Active</li>
</DeclaredPermissionKeys>
```

键的实际含义由提供者和业务接收器共同约定；Core 不建立所有键的中央枚举，也不根据键名自动产生效果。

### 业务解释

Content 中的目标直视许可接收器读取运行时上下文：只有表达声明了控制台键，且当前地图查询到该键有效时，才向攻击目标判定提供“直达视线可放宽”的结果。该结果只影响目标合法性和施法入口所需的直视检查，不改写所有表达的静态 `DirectTargetLineOfSight` 规格。

其它未来接收器可以解释其它键，例如制导站提供远程锁定能力；这些解释互不要求 Core 认识具体业务名称。

## 命名约定

- 表达侧字段：`DeclaredPermissionKeys`
- 运行时上下文字段：`DeclaredPermissionKeys`
- 提供者单键字段：`PermissionKey`
- 地图查询：`HasPermission(...)`
- 操作员控制台键：`BDP.OperatorConsole.Active`

不使用 `AttackPermissionKeys`，避免把未来许可用途限制为攻击；不使用 `RequiredPermissionKeys`，避免误解为缺少许可就必然不能发动。

## 运行时接入点

- 普通 BDP 远程攻击：在现有目标边界和正式 Verb 直视判定中读取许可接收器结果。
- Ability：在 `BdpVerb_AbilityShoot` 的目标检查与预热/施法入口中读取同一结果，保证原版非虚拟的直视检查也能正确放宽。
- 不通过修改全局 `ResolvedVerbSpec.RequiresDirectTargetLineOfSight` 或所有远程 Verb 的默认属性实现，避免污染未声明表达。

## 异常与兼容

- 上下文、地图、派系、读取器或接收器缺失时按许可无效处理，不阻断游戏。
- 未知许可键不会报错，只会查询为无效；这允许提供者和消费者按模块增量接入。
- 当前机制只表示地图/派系范围内的布尔许可。若以后需要数值、等级、Pawn 专属或世界范围许可，应新增相应数据契约，不把复杂状态编码进键名。

## 验证标准

1. 已声明控制台键、控制台运作、目标无直视：普通远程攻击和 Ability 均可进入施法流程。
2. 未声明控制台键：即使控制台运作，原有直视限制仍生效。
3. 已声明但控制台停止运作：直视限制立即恢复。
4. 原本 `DirectTargetLineOfSight=NotRequired` 的表达行为不变。
5. 风刃·实体刀未声明该键时不受影响。
6. 控制台多个实例、读档、离图和派系变化不会留下失效许可。

## 不在本次范围内

- 不建立所有许可键的 Core 中央注册表。
- 不实现除“动态放宽直达视线”之外的具体许可效果。
- 不调整 Trion 资源、状态条、操作员控制台运作条件或其它触发体槽位配置。
- 不处理与本功能无关的腺体装备历史状态迁移。
