## 一、设计目标与已确认边界

玩家通过外部接触认识 BDP，保留检测与首次取得腺体的过程；先获得基础玩法体验，再逐步建立自己的人员、装备和基地支援体系。内容建设以基地防御为重，外出保留基础个人使用，中后期个人装备配装与基地队伍支援并行发展。

体系稳定后的日常参与重心已确认：平时少量维持，主要投入集中在战前筹备和实战。日常研究、生产、补充与休整接入殖民地平常的经营节奏；具体维护频率、交互与数值以后设计。

用户已选择首次实际试用在殖民地前期基本安顿后即可发生，首次物品接触可以更早。检测与首枚腺体的外部入口需支持这一时间位置；具体事件天数与原版技术关联后定。

首名使用者的典型形成方式已选：通过外部接触取得含腺体基因的成品胚芽，玩家自建固定检测仪，检测并选择已有殖民者植入，再用原型体验基础玩法。检测作为殖民地早期的一项 BDP 建设，具体研究归属与合格操作者条件以后安排。这个体验顺序不新增检测完成才允许植入的硬门槛。

用户提出首枚腺体的取得候选：若初次接触采用包含敌对袭击的剧情任务，可从敌人尸体提取成胚芽，交互参考生物科技扩展包提取机控中枢的体验。尸体提取直接形成首用胚芽，需支持此前已定的前期试用位置；具体提取条件、任务与产物规则以后设计。敌对袭击与尸体提取仍为候选，不固定为唯一入口。

后续腺体的常态扩充已确认：从已有腺体的成员通过原版基因提取器取得腺体基因组，再由玩家手动沿用原版制作胚芽，继续培养人员。首次外部胚芽与后续基因组生产分别承担首用和自主扩充，不要求另设一次外部基因组任务。

现成腺体胚芽与原型的获取机会已确定紧密相连：可由同一次接触或顺势延伸的机会取得，让玩家较早完成实际试用。具体取得行动与事件载体以后构思。

核心材料已选择在首次接触中就有机会取得，使试用与正式研究的筹备能够紧密展开。玩家可按已有条件交错推进检测、原型使用与材料分析；具体交付形式留后。皇室成员加入也属于外部接触阶段，采用简化的前期任务入口；若入口采用敌对袭击，人物加入与入门物品取得大概率属于同一事件，具体分合留到剧本设计。核心实际建设和运行继续分别按研究、人物与补充条件推进。

首次接触的情境当前暂采用“被追捕的皇室成员向殖民地求助”。用户对推荐情境作肯定回复，按认可这一候选理解，不扩大为完整任务流程、追捕原因或物品交付规则已确认。追捕原因、人物身世等背景留到具体剧情设计，已撤下本轮关于冲突焦点的追问；当前只讨论会影响玩家行动、阶段衔接或实现范围的事项。

首用连接的物品取得关系：用户明确敌人袭击任务目标达成、任务结束后，皇室成员才正式加入殖民地；任务期间出现或参与不等于已加入，期间身份与操控方式留后。原型作为追兵成品战利品、首枚胚芽从剧情敌人尸体提取仍为候选。用户明确核心材料在这个接触事件中有取得机会，可由追兵、皇室成员或双方携带，具体载体、数量与交付方式保持开放，不在当前选定唯一来源。人物正式加入的时间点不自动决定物品取得时间；取得材料后按已有分析规则开展研究筹备，不新增原型试用前置。

关键外部条件采用自然事件引出首次接触、后续线索支持主动争取的节奏。玩家可依线索争取尚缺的核心材料或皇室成员等条件，并自主决定何时投入建设。物品与人物仍可提前出现、分开或合并取得；具体任务形式、线索载体及失败后的重新取得途径留后。

正式起步的典型成果已确认：核心开始运行且有持续补充办法，殖民地能自制、装配替代原型的普通装备。初期提供少量基础功能，性能、功能选择和重复补充共同体现成长；研究与筹备可以交错推进，芯片制造台与装配台实际运行均需核心许可，后续各研究路线再逐步深化个人装备、人员扩充与基地支援。

普通成长主要依靠殖民地研究与生产：有腺体基因组后沿用原版反复制作胚芽，普通触发体与芯片使用常规材料、由研究解锁。外部发现提供入口、补充和稀有内容。核心材料已确定为所有正式 BDP 研究路线的共同入口；参照原版机械体首领芯片，分析材料取得研究资格并保留实物，之后用于建造核心。各路线仍分层、多线逐步研究，可有多条主研究路线和更多支研究路线。本任务中的“主线、支线”专指研究路线，具体分析条件以后设计。

中期成长以丰富多样为主要方向：逐步增加功能、构型、组合和支援选择，让玩家形成不同处理方法。目前更新换代设计较少，不围绕连续装备换代来组织路线；具体性能与平衡后定。这是现阶段的内容重心，未来可以按实际需要补充进阶内容，原型在正式进入后迅速落后淘汰的已确认定位继续保留。

操作员支援已确定从中期开始发展，与个人配装并行，供玩家按需要投入人员和设施。当前控制台需电力、持续人员操作和运行核心许可，只支持明确接入的武装；具体研究条件与后续兼容内容以后安排。

人物侧紧急脱离已确定从中期成为可取得的可选保障，承接危机准备与失利后重整。现有流程在有效脱离被动与战斗体被动崩解条件下尝试同地图转移，正常执行消费来源芯片；信标提供优先落点，其出现阶段另定，不作为人物侧脱离的必备条件。紧急脱离就是普通芯片，沿已定制造台与装配台通路取得，消费后重新制造并补装；具体研究项目留后，不另设计获取或补给渠道。

跨芯片组合采用已获同意的原则倾向：通常随参与功能的取得、正确装配与使用条件齐备自然可用，形成发现与搭配的回报；个别涉及独立新技术的特殊机制，另行判断研究条件。组合随相关功能的层次分布在不同阶段，具体项目和例外留后。

边境特制触发体已定位为偏后期的进阶品，以更大的预装空间承接丰富功能后的配装需求。芯片装载仍占人物容量；具体研究与取得方式以后安排，这项定位不规定标准型淘汰或人物容量升级。

合理体验与玩家自由优先。小规模、高难度自足及善良温暖的玩法倾向作为作者愿景和平衡参考。长期方向是逐步进入有相应深度的后期内容，具体内容待前中期成形后迭代，终局与原版结局衔接优先度低。

## 二、典型成长阶段

阶段用于组织玩家体验和开发检查。物品、人物及研究可以按实际条件提前、交错出现；据点建立和自主生产的具体先后由设施依赖决定。正式研究和核心建设按实际前置推进，原型试用或指定战斗不额外作为准入条件。

| 阶段 | 玩家体验与阶段成果 | 必须接通的内容 |
|---|---|---|
| **外部接触** | 接触陌生技术，皇室成员在任务达成并结束后正式加入；腺体胚芽与原型的取得机会紧密衔接，核心材料首次接触也有取得机会。若采用敌对袭击，人物加入与入门物品取得倾向由同一事件承接 | 外部取得途径、皇室基因与加入任务；若采用剧情敌人尸体提取入口，配套击杀后线索信件 |
| **早期试用** | 前期基本安顿后，自建检测仪、选择已有殖民者植入腺体，用原型体验基础近战、远程与战斗体，睡眠恢复后再次使用 | 前期检测条件、首用胚芽、预载低性能原型、无核心许可的睡眠恢复 |
| **正式起步** | 分析材料、开展正式研究、建成核心；已加入的皇室成员参与献祭启动。芯片制造与装配投入运行，普通装备替代原型；原版提取基因组、制作胚芽支持人员扩充 | 材料分析与研究准入、皇室成员参与核心操作、核心献祭绑定及补充、普通装备配方、制造与装配许可、原版基因生产条件 |
| **中期拓展** | 研究逐步提供不同功能、构型和组合，个人配装与基地队伍支援并行；操作员支援和人物侧紧急脱离可取得、按需选用 | 现有素材的分层研究与正常取得；信标阶段留到对应内容设计 |
| **后期进阶（后续迭代）** | 保留特制触发体偏后期的位置，其他内容随前中期成形后迭代 | 当前保留方向，不要求补齐具体内容；终局低优先度 |

成熟应用是跨阶段逐渐形成的状态，可以与战术发展和后期内容扩展交织。它不以解锁全部装备、采用全部设施或新增一个统一等级衡量；这一状态的明确也不代表具体后期内容已经设计完成。

## 三、原型的已确认定位与体验提案

用户明确原型是一件近界触发体：**主槽预载一项低性能近战功能，副槽预载一项低性能远程功能，仅用于体验战斗体和触发器的基本作用。** 正式进入内容后，它会很快因性能落后被淘汰；本阶段为短期入门体验。

原型控制方式已确认：固定预载，不开放玩家装卸换配，不显示芯片槽位管理面板。已补原型定义，主槽预载现有弧月、副槽预载现有小行星，不修改其性能或消耗；战斗体启动、两项攻击和能量反馈复用现有机制。专用低性能芯片留到以后；固定双预载试用待游戏内联测，正常取得由外部入口承接。

按这一定位，首个使用循环建议为：

**植入腺体后具备可用能量，必要时先睡眠积累 → 启动战斗体 → 使用预装的基础近战、远程功能 → 感知能量消耗并解除或退出 → 睡眠恢复 → 再次使用。**

当前实现中，已有殖民者运行时新取得腺体，会将当前能量置零；这只是现状，初始量可随平衡调整。睡眠恢复已接通，用户已确认本项游戏内验证通过；它承接需要时的首次能量积累，以及之后的重复使用，与原型的连续体验留到原型工作包联测。

原型到手后的主动启动、解除、能力信息和能量反馈可以提供初步体验，实际战斗作用再由自然遇到的战斗验证。玩家可以暂缓或自行尝试；具体近战、远程功能和退出呈现方式以后安排。

原型最终使用低性能功能是作者已确认的定位，具体数值以后校准；近期预载暂用现有普通弧月和小行星，不在本次压低其性能。原型带有实际可体验的能力，首次使用条件需能在正式核心与芯片制造体系之前取得。

正式发展的第一批成果已确认衔接可实际使用的普通装备：普通触发体、少量基础功能芯片和装配能力按必要前置接通，形成替换原型与自主配置的选择；随后继续分层增加配装和基地支援。具体研究项目与初期功能名单以后安排，玩家自主选择配置。

“预载两项功能”只确定初始内容，不自动确定主副槽总数、后续是否允许换装、芯片继承或与标准装备的兼容。淘汰来自性能落后与正式装备的替代价值，具体机制以后设计。

### 首次试用的最小需求：设计清单

| 环节 | 已有基础与待补内容 |
|---|---|
| **取得物品** | 现成腺体胚芽与原型的获取机会紧密相连，首次接触也有核心材料机会；具体外部获取待补，材料分析可与试用筹备交错推进 |
| **检测与植入** | 固定检测仪和腺体基因已有，成品胚芽植入沿用原版；需让前期设备、合格操作者与可培养对象的条件实际成立。现行操作需另一名智识至少10级的人物，这一门槛仅作现状参考，可重新平衡 |
| **实际使用** | 战斗体与基础触发器机制已有；待补主副槽分别预载低性能近战、远程功能的原型成品，让玩家实际体验两项基本作用 |
| **首次积累与重复恢复** | 新植入腺体的初始量按现行实现为零，后续可调整；已接通无核心许可也可睡眠恢复的渠道，支持必要的首次积累，以及使用后的休整、再次使用 |

这一阶段的可用表现是：玩家能在前期基本安顿后培养已有殖民者，积累能量、使用两项基础功能，并在休整后再次使用。皇室成员加入已归属外部接触，其后参与核心首次运行；人物加入与核心运行不作为首次试用前置。具体事件脚本、功能数值及研究项目留后，玩家提示按第七节的已定范围安排。

## 四、体验转折的校准：提案

### 初次体验到正式建设：已确认阶段成果

正式建设的投入包括研究、材料、皇室人物参与和核心启动。用户已确认正式起步以核心运行并能持续补充、自制装配替代原型的普通装备作为典型成果；核心运行的近期回报包括许可下日常自然恢复、更快的睡眠恢复及相关设施投入运行。设备仍按各自研究、准备与许可条件投入使用，睡眠恢复已单独接通。

研究与设施筹备可以交错推进，芯片制造与装备装配需在核心运行许可有效时进行。少量初期功能承担基本配装，后续研究再深化个人装备、人员扩充与基地支援，具体层次和内容摆放仍待安排。

### 正式起步的最小需求：设计清单

| 环节 | 必要连接与留后事项 |
|---|---|
| **材料分析与研究** | 核心材料可取得、分析后保留实物并获得正式研究资格，随后正常研究，实物用于核心建设；分析者等具体条件与研究项目留后 |
| **皇室参与** | 承接外部接触阶段已加入的皇室殖民者，使其能够承担核心操作者与绑定者身份；皇室基因与加入任务归属外部入口，具体任务内容留后 |
| **首次运行与常态补充** | 核心建成后，皇室操作者可向尚未运行、尚未绑定的核心完成首次献祭并启动绑定；首批合法物品可来自已有原版科技制成品，随后沿常态生产与获取补充；估值和资源数值留后 |
| **普通人员自主扩充** | 从已有腺体成员用原版基因提取器取得基因组，再手动制作胚芽，让玩家可继续培养人员；检查原版提取与制作条件可达，不新增为核心首次运行前置 |
| **普通装备自主取得** | 研究关联、普通触发体与芯片配方、制造和装配条件接通，让玩家用常规材料补充装备并替代原型；芯片制造台与装配台均需核心运行许可，其余设施范围与初期功能名单留后 |

筹备仍分清研究解锁、设施准备和运行许可。首次献祭的物品需能从不依赖核心运行的渠道取得，使核心可以从未运行状态启动；研究准入也不反向依赖核心已运行。用户已确定制造台与装配台均受核心许可影响，并将普通触发体生产并入制造台：核心未运行或停运时，不能在该台制造普通触发体或芯片，也不能装卸、换配已有芯片。因此首次自主装备生产与配装需接通核心运行；停运后的制造、换配与补装需先恢复许可。具体停运时正在进行的操作怎样处理，留到相关功能设计。

### 首次自主制造与装配：连接核对

承接已确认的正式起步成果，玩家操作串为两条准备路径：已有腺体的成员装备空的普通触发体；制造已解锁的少量基础功能芯片，并搬入与装配台有效连接的芯片仓。条件齐备后，该成员使用装配台配置，再按自身资格、容量与能量条件启动使用；之后沿同一通路补充芯片、制造更多装备或调整配装。普通触发体取得与芯片生产可按各自条件并行准备，不将两者写成新的固定任务顺序。固定预装原型到自主配装的转折，体现性能、选择和重复补充的共同成长。

局部源码与定义核对（2026-10-05）：普通标准触发体已接入临时制造配方，并在制造窗口新增“触发体”页；触发体与芯片使用同一个原版账单栈。现有装配台读取连接芯片仓中的芯片，使用者需已装备可配置触发体、满足通电及核心许可等操作条件并退出战斗体状态。制造成品入仓与仓的有效连接是已有操作的必要衔接，芯片仓未因此新增核心许可。两台核心许可均已接通，普通触发体配方沿原版半成品流程运行；当前尚需研究关联与游戏内完整生产装配核对，具体材料与工时仅为占位，研究项目继续搁置。

制造分工已获用户确认：普通触发体也交由现有 BDP 制造台生产，该台负责制造触发体和芯片，装配台负责装卸与配装；普通触发体生产随制造台受已定核心许可约束，不新增专用设施。2026-10-05 已将建筑显示名称改为“触发器制造台”，与“触发器装配台”对应，名称、说明与相关语言包文案同步；原定义和类型标识保持不变。

### 自主生产到战术深化：已确认成长方向，具体摆放仍为提案

自主生产解决重复取得和补充装备的问题。用户明确中期主要体现丰富多样，当前更新换代设计较少；战术深化据此以功能、构型、组合与支援选择的扩展增加处理方法。以下是现有素材的体验例子，具体研究归属和出现次序未定：

一般组合随参与功能自然接通，研究路线之间可以通过搭配形成联系；独立新技术的特殊机制另行判断。玩家可以随着配置尝试逐步发现组合。

当前以已有内容串联中期体验：

```text
可持续运行的核心与自主制造、配装
├─ 取得更多个人功能 → 在攻击、防护、机动、隐匿等处理方式间选择
├─ 参与功能齐备并正确配置 → 使用已有组合，例如旋空弧月、光魂推进
├─ 配置兼容武装 ＋ 控制台持续值守 → 按需要获得基地攻击支援
└─ 制造并装配紧急脱离芯片 → 被动崩解时尝试脱离 → 消费后重新制造、补装
```

图呈现功能之间的关联，不确定各功能的具体解锁时期或要求全部使用。组合仍随参与功能分布在各阶段；中期主要增加个人处理方法、搭配和可选支援。现有控制台在通电、有运行核心许可、有人持续操作时，可支援同地图同派系的多名兼容武装使用者；普通可制造内容中的猎犬、黄蜂组合已有兼容声明。支援提供相应攻击许可，攻击仍由对应武装执行；控制台不检查装备制造来源，外来兼容成品也可按其条件获得支援。

正常入口的接通事项：普通功能沿制造、装配通路取得，组合随参与条件成立，具体研究映射留后；操作员控制台已有正常建筑和工作入口，需安排中期发展关联。紧急脱离当前在制造列表中隐藏，后续按普通芯片接入制造和研究即可，消费后仍沿同一通路制造、补装；这是实现接通事项，不再提出独立获取或补给设计问题。信标阶段继续留后。

用户选择“逐渐形成常用配置，遇到新功能或明确新需求才调整”，同时明确这方面无需过多约定，玩家自由发挥。该选择仅作轻量体验参考，配装方式、调整时机和人员分工由玩家决定；不再细化换配节奏，也不作为频率、固定配置或职业分工的设计要求。后续关注已有内容的正常取得、使用与补充连接。

| 能力变化例子 | 玩家新增加的选择 |
|---|---|
| 普通直射之外，取得追踪或路径控制能力 | 选择不同瞄准与弹道处理方式，按目标和地形尝试合适武装 |
| 正面接敌之外，取得机动、隐匿能力 | 在站位、接近、转移和行动时机上增加选择 |
| 从中期发展操作员控制台，支援明确接入的武装 | 投入人员持续值守、电力与核心许可，为同地图同派系的多名兼容武装使用者提供相应攻击条件，例如猎犬和黄蜂组合的支援 |
| 从中期取得人物侧紧急脱离能力 | 选择投入会被消耗的来源芯片，在战斗体被动崩解时尝试同地图脱离，增加失利后重整的机会 |

配置本身存在这些取舍：特制触发体扩展预装空间，装载芯片仍占人物容量；控制台支援需持续人员操作；紧急脱离会消费来源芯片。这些为玩家提供有理由的配置选择，具体负担和数值以后平衡。

### 战术深化到成熟应用

成熟度来自玩家选用的配置、日常供给和重整办法逐渐配合。小范围专精、个人装备投入较多或支援投入较多，都可以形成自己的成熟体系。

用户明确后期暂无具体想法，前中期尚未做好，可在后续更新迭代时再增加后期内容。当前优先接通首次试用、正式起步和中期拓展，后期保留方向，不要求现在明确相较中期的全部能力增量或取得途径。后续可根据前中期的实际体验再判断需要哪些进阶内容，独立终局仍保持低优先度。

已确认的特制触发体偏后期定位继续保留：扩大预装选择空间，让玩家可以筹备更丰富的配置；实际装载继续受人物容量约束。其研究与正式取得留到具体内容安排。组合随参与功能分布在不同阶段，操作员支援与人物侧紧急脱离从中期开始；信标及其他特殊技术的层次在涉及相应内容时再讨论。

## 五、核心怎样连接发展与经营

### 三类条件

| 条件 | 决定什么 |
|---|---|
| 研究解锁 | 获得哪些设施、配方的建设和制造条件 |
| 设施准备 | 设备、材料、电力、人员及自身常规条件是否齐备 |
| 核心运行许可 | 依赖核心的设施当前能否执行相应生产或支援 |

核心对普通人员装备发展的主要影响，按已确认原则体现为相关设施的运行许可。核心材料作为所有正式 BDP 研究路线的共同入口，与核心建筑建成、核心首次运行分别是不同条件；取得共同入口不代表全部项目同时解锁。研究筹备与核心建立按实际前置交织。

材料参照原版机械体首领芯片：**取得材料 → 分析并保留实物，获得研究资格 → 正常研究相关技术 → 将材料用于建造核心。** 实物建造消耗后研究资格继续保留，具体分析者、时长和研究项目关联以后设计。

当前核心许可已有恢复、操作员控制台、制造台与装配台业务。制造台与装配台许可已接通：核心停运后原版制造任务停止可用，装配台无法装卸、换配芯片；已加入的普通触发体配方同样受许可约束。检测仪和芯片仓保持当前规则，未加入许可限制。其余设施的未来范围仍未统一决定，原版基因设备沿用原版，不由总体许可原则自动推导改造。

### 人物与补充

**核心绑定者是皇室殖民者；献祭操作者可以是她本人，也可以是她的具体契约者。** 绑定、解绑和献祭分别独立处理，不把首次补充写死为自动绑定。皇室成员加入属于外部接触阶段，采用用户提出的简化前期入口：游戏前期，殖民地没有皇室成员殖民者时，可以出现特定任务；任务达成并结束后，该人物正式加入殖民地。敌人袭击任务期间的人物接触不视为正式加入，具体身份与操控方式留后。若入口采用敌对袭击，人物加入与入门物品取得大概率属于同一事件；这是当前倾向，具体分合仍留到剧本设计。人物可以随机，皇室血脉及必要任务要素保持一致；具体任务内容、前期范围与出现节奏留后。

这个入口按殖民地缺少皇室成员的状态提供机会，当前不额外设置取得核心材料、完成原型试用或逐层追寻线索的前置。此前损失有代价、保留后续重获机会的原则继续适用；前期结束后的重获是否复用此任务，留到事件具体设计。

重获条件分别检查人物与物品：皇室已加入但核心材料仍缺或遗失时，需保留有代价的后续取得机会，不能只依赖“无皇室成员”才出现的加入任务。这是此前已接受重获原则的衔接要求，具体途径留到事件设计，不预设新增任务数量或无代价补发。

科技制成品献祭为核心储量补充的已提出方向：由操作者投入合法物品，换取运行资源。首次补充需有可取得的合法物品，常态补充与殖民地技术生产衔接；具体估值与绑定交互规则仍在专门讨论中。

按已确认的轻度日常维持重心，后续设计优先检查补充是否可计划地接入原版生产与工作安排，投入是否与核心的持续收益相称。皇室操作者与献祭设想继续保留，具体频率、资源负担及交互方式待专题设计。

核心储量与人物能量恢复分别判断。地图内玩家角色的睡眠恢复已实现：无许可时默认恢复基准速率的 20%，有许可时默认 120%；清醒且有许可仍为基准速率，两者都无则停止。两种睡眠倍率由内容层 XML 配置，可继续平衡；战斗体冻结独立生效，人物恢复不直接抽取核心储量。

皇室成员心情经日常关系轻微影响核心效果与稳定，是待定设想。实际影响、停机范围与恢复方法以后设计，强度服从合理体验和开放玩法。

## 六、常态循环与跨阶段事件

### 常态循环

**日常研究制造 → 按人员和需要准备装备、安排可选支援 → 应对原版危机 → 休整恢复、补充损耗、调整配置 → 再次准备。**

这个循环以少量日常维持为基础，主要体验投入集中在战前筹备与实战。后续检查建议：生产、恢复和核心补充融入平常的工作安排；配装选择围绕新功能、打法调整与当前危机展开；操作员持续人员操作的既有要求作为选用支援时的投入单独衡量。具体便利功能和交互以后按实际缺口决定。

成长表现为这个循环中能力的变化：少数人基本使用，转为能重复取得资格和普通装备，再增加战术与支援选择，最后将配装、后勤和重整结合。循环是体验组织参考，日常活动和危机发生时机沿用原版节奏。

基地防御是重点，外出以个人装备和自身续航为基础。临时战斗地图可依靠实际睡眠恢复；无地图角色沿用原有基准恢复例外，本次不修改旅行机制，外出实际恢复时序仍待游戏核验。现有同地图控制台支援与脱离落点不能直接当作跨地图支援或返回殖民地。

### 跨阶段内容

- **黑触发器**：殖民者在危机中濒危或死亡时，以生命力为代价形成独特、稀有、强力的触发器；跨阶段承接人物命运与力量传承，出现与否不决定普通体系是否成熟。
- **外部人物与发现**：承接关键入口、补充与稀有内容；自然事件引出首次接触，后续线索支持主动争取尚缺关键条件，具体形式和数量按实际职责安排。
- **损失与重新进入**：错过入口、失去关键人物或物品，有代价但保留后续重新取得条件的机会；具体途径以后设计。

### 事件的衔接职责：提案

先按成长线需要整理职责，再由作者构思具体载体和剧本：

| 职责 | 需要支持的体验与条件 |
|---|---|
| **入门接触** | 提供皇室成员加入，以及紧密衔接的成品腺体胚芽与原型取得机会；核心材料首次接触也有取得机会，引出研究筹备。前期缺少皇室成员时可出现加入任务；若采用敌对袭击，人物加入与入门物品取得倾向由同一事件承接，敌人尸体提取成胚芽为候选；具体载体留后 |
| **正式建设条件** | 已加入的皇室成员参与核心启动，其他尚缺条件由相应取得机会支持 |
| **后续补充与发现** | 承接外部补充与稀有内容，普通人员与装备的常态扩充仍以已确认的殖民地研究、生产为基础 |

这些是事件需要承担的职责，不对应固定数量或唯一剧情顺序；同一事件可以承担多项职责。错过或损失关键条件后的重新取得，是各途径共同需要考虑的恢复要求。黑触发器另按跨阶段人物危机处理。首次试用条件紧密衔接，核心材料首次接触即可有取得机会，皇室加入同属外部接触；敌对袭击入口倾向整合人物加入与入门物品取得。入口的高层安排可到此收束，具体奖励、行动形式与事件脚本留后。

### 接通顺序：提案

按现有实现与已选方向，近期串起外部接触、首次试用、正式起步和中期拓展，后期列为后续迭代方向。下表用于检查已有基础与连接缺口，不将本范围全部计划内容作为必须补齐的清单；具体研究项目继续搁置：

| 建议次序 | 最低可玩表现 | 已有基础 | 尚需接通或继续设计 |
|---|---|---|---|
| **首次试用（含外部接触）** | 外部接触提供皇室加入与入门物品机会；培养已有殖民者，用原型体验基础近战、远程功能，并能休整后再次使用 | 检测仪、腺体基因、战斗体与基础触发器功能、睡眠恢复 | 皇室基因与加入任务、外来胚芽与原型及核心材料的取得机会、预装低性能原型；尸体提取候选配套击杀后提示信件 |
| **正式起步** | 已加入的皇室成员参与核心首次启动与补充，能自行取得并装配普通装备替代原型；从已有腺体成员提取基因组并制作胚芽，继续培养人员 | 核心建筑与许可门控、制造和装配设施，原版基因提取与制作体系 | 核心材料分析准入、皇室成员的核心操作、献祭和绑定、原版基因提取与胚芽制作条件、普通触发体配方及研究关联、芯片制造台与装配台核心许可；其余设施名单留后 |
| **中期拓展** | 取得不同功能后可改变处理方法、尝试搭配；操作员支援和人物侧紧急脱离成为能正常取得、按需选用的内容 | 多种功能、跨芯片组合、操作员控制台、紧急脱离与信标流程 | 分层研究与正常取得；信标阶段仍待定，不要求玩家使用全部内容 |
| **后期进阶（后续迭代）** | 保留发展位置与特制触发体的已定方向 | 特制触发体扩大预装空间的规格 | 正式来源和其他后期内容在前中期成形后逐步设计，当前不要求补齐 |

开发接通顺序建议为：

1. 先接通外部接触中的皇室加入与物品取得机会，完成原型重复使用的体验，核对首次使用条件实际可达；人物加入不另设为原型使用前置。
2. 再接通材料分析与研究、已加入皇室成员参与核心启动和补充、自主装备制造装配；同时安排首次基因组与原版胚芽制作通路，支持后续人员扩充。
3. 在可持续取得、使用与补充的基础上，分层接入已有的不同打法、组合及中期支援保障。具体功能名单由研究设计承接，不为本轮新增固定数量或必用配置。

玩家实际推进仍按各自条件交错，材料分析与核心筹备可以在试用期间开展；原型使用不作为正式研究准入。首次成品胚芽提供个人资格，后续从已有腺体成员沿原版提取基因组提供重复培养能力，沿原版制作胚芽；这是已经选定的连接，不另设基因组获取任务，也不将其设为核心启动前置。

首次腺体基因组的典型来源已选择沿用原版基因提取器，从已具有腺体的成员取得。真实原版程序集已确认外源腺体基因可进入提取候选，仍遵循原版设施、人物和随机抽取条件，不保证首次或每次提取都得到腺体；当前不另定概率或专用活体提取机制。首次外部接触中的尸体提取成胚芽另为候选，尚待设计，不代表原版基因提取器已支持该尸体流程。

### 前中期依赖复核：设计层面

按已确定的结构，当前未发现循环依赖：

- 首次试用由外部胚芽、原型、可自建的检测仪与无核心许可的睡眠恢复支撑，皇室加入和核心运行不作为试用前置。
- 核心材料先分析、取得研究资格，再按研究建设；皇室任务按已有入口提供加入机会。皇室参与核心绑定与首次补充，两个动作逻辑独立；首批供物可从原版科技生产取得，具体操作安排见核心专题实施计划。
- 后续人员扩充由已有腺体成员提供原版提取候选，再沿用胚芽制作；随机提取可能带来等待，不形成互相依赖。

上述睡眠恢复与制造、装配许可已实现；外部入口、材料分析、皇室任务、献祭绑定仍需实现，是已定连接的接通工作。研究项目具体映射时，核对检测仪与材料分析条件，避免把分析设为检测前置后，又要求先完成检测才能分析；当前未添加此类要求。

制造台的许可边界已获用户确认并接通：需要核心运行才能生产；普通触发体已确定并入同一台，生产同样受许可影响。研究、备料和建设可按自身前置筹备，实际制造与装配需许可有效；不保留未运行时先制造芯片备货的候选。制造、装配许可的编译与隔离验证通过，游戏内中断、恢复及物品状态仍待核对。芯片仓的独立存取条件留到设施设计，操作员控制台的核心许可已经存在。

| 优先作用 | 检查项 |
|---|---|
| **闭合首次使用** | 接触机会、检测、首枚腺体、实际可用的原型与睡眠恢复相连；首次条件不循环依赖未建成的正式体系 |
| **闭合正式运行与生产** | 核心材料、皇室加入、献祭与绑定、首次启动、触发体配方、设施许可与常态补充相连；首次腺体基因组和原版胚芽制作支持人员重复培养 |
| **安排渐进成长** | 作者的研究路线映射到新增能力与体验回报；制造、装备和支援来源能在正常发展中取得 |
| **检查成熟体验** | 特制触发体的预装空间、人物容量、现有组合、操作员和紧急脱离的收益，能否与人员时间和经营负担相称 |
| **检查日常负担** | 稳定后平时少量维持，主要投入在筹备与实战；核对核心补充、制造、休整和支援操作是否符合这一重心 |
| **后期迭代** | 前中期成形后，根据实际体验逐步增加后期能力、选择与取得途径；当前保留方向和已有定位 |
| **远期终局** | 独立终局与原版结局衔接保持低优先度 |

当前正式制造配置每枚选择一项功能模板，模板自身可包含多种形态或能力，跨芯片组合已有；特制触发体增加预装槽位，全部装载仍占人物容量；操作员支援只服务明确接入的武装；信标本身不等于人物已取得脱离能力。安排研究和阶段回报时须保持这些实际边界。

整体框架现按五段整理：外部接触 → 早期试用 → 正式起步 → 中期拓展 → 后期进阶。用户认为大方向没有明显问题；成熟应用是其中逐渐形成的状态，稳定后的轻度日常维持与筹备、实战重心已确认。入口高层安排现已收拢，后续按阶段缺口规划工作，先闭合首次试用，再接通正式起步与中期拓展；后期具体内容在以后更新迭代中增加，研究项目和事件剧本分别留到相关内容的具体设计。

本稿已按用户整体审阅意见校正皇室加入的阶段归属，作为当前前中期内容建设的设计依据；其余方向用户暂未发现明显问题，具体内容仍可调整。当前范围明确为从外部接触到中期拓展，重点串联已实现内容，按已定连接补齐正常取得、使用与发展的断点，不要求填满全部计划。研究树和剧情背景继续搁置，后期留待迭代。本轮仅整理设计文档，未修改模组实现。
