# 投射物高角视觉轨迹实施计划

> 设计记录：`docs/plans/2026-09-12-投射物高角视觉轨迹设计.md`
>
> 本计划只覆盖 BDP.Core 的通用高角视觉能力，不添加具体武器内容，也不接入真实高角物理移动。

## 目标

让 BDP 投射物可以通过 Def 的可选扩展绘制出 Eccentric Tech 风格的连续高角轨迹，同时保证没有该扩展的现有投射物完全沿用当前低角绘制、飞行、碰撞和命中逻辑。

## 执行顺序

### 1. 先建立失败测试

新增 `Source/BDP.Tests/ProjectileVisualArcUtilitySmokeTests.ps1`，检查：

- 高角扩展类及其 XML 字段存在；
- 默认曲线与 Eccentric Tech 所需的 `Sine`、`EaseInCubic` 公式存在；
- 视觉取样包含基础高度、额外抛物高度与 RimWorld `z` 轴叠加；
- `BdpProjectile` 只在高角扩展启用时进入特殊绘制分支；
- `ExactPosition` 的现有平面位置公式没有被高角视觉配置替换；
- Core 仍未引用 BDP.Content 或 BDP.Development 命名空间。

运行该测试，确认实现前失败。

### 2. 实现 Def 配置模型与通用取样工具

新增 `Source/BDP/Core/Projectiles/Visual/ProjectileVisualArcExtension.cs`：

- 继承 `DefModExtension`；
- 暴露 `arcHeight`、`startHeight`、`endHeight`、`positionCurve`、`heightCurve`、`arcCurve`；
- 不配置扩展时不参与任何路径。

新增 `Source/BDP/Core/Projectiles/Visual/ProjectileVisualArcUtility.cs`：

- 使用现有 `ProjectileFlightPathSnapshot` 作为水平路径输入；
- 支持 `Linear`、`Sine`、`EaseInQuad`、`EaseOutQuad`、`EaseInOutQuad`、`EaseInCubic`、`EaseOutCubic`；
- 未识别曲线名回退 `Linear`；
- 输出基础位置、视觉位置、绘制高度与视觉切线；
- 高度只叠加到 RimWorld 地图的 `z` 轴，保留 `def.Altitude` 的原版绘制层高度。

### 3. 接入 BDP 投射物绘制

修改 `Source/BDP/Core/Projectiles/BdpProjectile.cs`：

- 新增高角 Def 扩展解析；
- 无有效高角配置时直接调用原版 `DrawAt`；
- 有效高角配置时复用原版材质、图形类、自转与组件后绘制，只替换投射物绘制位置和视觉朝向；
- 为高角绘制补充与高度相关的地面阴影；
- 保持 `ExactPosition`、`ExactRotation` 的现有主线语义不变；
- 让视觉附加件飞行样本在高角配置下跟随高角视觉位置，未配置时保持现有平面样本。

### 4. 验证与收束

依次运行：

1. 新增高角视觉冒烟测试；
2. 相关现有投射物视觉冒烟测试；
3. `dotnet msbuild Source/BDP/BDP.csproj -p:Configuration=Debug -t:Build -v:minimal`；
4. `Source/Build/Verify-BdpCoreIsolation.ps1` 对 Core 的程序集隔离检查；
5. `git diff --check` 与最终工作区检查。

只保留实现高角视觉能力所需的修改，不添加示例武器、冷发射阶段或 Development 调试业务。
