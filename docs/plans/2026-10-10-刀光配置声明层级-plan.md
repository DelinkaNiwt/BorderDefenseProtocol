# 刀光配置声明层级修正

用户已明确要求按攻击声明层级配置：形态公共近战只列形态，姿态追加的近战才列姿态。当前目录按完整生效状态展开，导致公共盾击在光魂两个姿态重复；仅删名称会留下两套隐藏配置，因此需同时修正目录身份与运行时匹配。

1. 用现有真实程序集夹具确认：公共盾击两姿态同一配置项；姿态自己的近战单列；同姿态混合两种攻击时各自匹配；构型仍优先。
2. 兼容目录从正式解释后的有效近战条目出发，按形态/姿态的 ActiveEntryIds（启用条目表）确定声明归属，合并继承项。记录有效状态到攻击条目的配置映射，不靠工具图像或伤害类型猜归属。
3. 运行时复用已有结果标识与来源芯片标识识别单侧声明：核心 ExpressionSourceCollector.BuildMaterialId 构造 chip.ThingID + ":" + declaration.Id，SingleSideExpressionBuilder 原样保留该标识。仅移除已核对的芯片前缀，完整保留声明键；非此格式或混合状态无法唯一匹配时沿用真实工具自动分类。无需修改核心接口。
4. 仅构建工作区兼容程序集与符号，运行行为与边界检查，更新验收与倒序日志并提交。不迁移旧姿态覆盖，不部署游戏。

完成：旧产物确认公共盾击仍按姿态重复配置；修正后 20 组真实行为检查全部通过，包含公共/姿态混合攻击、构型优先、带冒号声明键、未启用/不存在姿态、无法唯一归属拒绝猜测。独立只读审查及兼容程序集边界、故障隔离、背包页检查通过。兼容程序集构建零警告零错误，工作区正式产物复验通过。游戏内应看到光魂大盾合并为一个形态项，需要在新项重新设置旧手动类型；姿态尺寸仍按实际视觉读取。
