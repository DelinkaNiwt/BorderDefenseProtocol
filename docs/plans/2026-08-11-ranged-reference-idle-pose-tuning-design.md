# 远程武器基准图静默双持姿态调试设计

## 目标

在朝南、非瞄准的双武器状态下，让两把长枪的握持位置更靠外、更靠上，并用轻微的副手角度差打破完全平行的僵硬感。单武器继续保持原版默认姿态。

## 当前表现

- 握持点作为姿态原点的换算已正确生效。
- 主副手握持点当前位于原版绘制基准左右各 `0.12` 格，画面上仍略靠里、靠下。
- 两把武器角度完全相同，重叠后容易看成一把加宽的武器。

## 方案比较

- 保守：偏移改为 `(0.15, 0, 0.04)`，副手角度差 `4` 度；变化可能不够明显。
- 均衡：偏移改为 `(0.16, 0, 0.06)`，副手角度差 `6` 度；能改善高度和轮廓，又不形成明显 V 字或 X 字。
- 明显：偏移改为 `(0.18, 0, 0.08)`，副手角度差 `8` 度；长枪轮廓可能过度张开。

采用均衡方案。

## 数据设计

只修改双武器专用预设 `BDP_Visual_RangedWeaponReference_Dual`：

```xml
<SouthNorthPose>
  <DefaultOffset>(0.16, 0, 0.06)</DefaultOffset>
  <SubHandAngleOffset>6</SubHandAngleOffset>
</SouthNorthPose>
```

- X 从 `0.12` 增加到 `0.16`，主副手分别向外移动 `0.04` 格。
- Z 从 `0` 增加到 `0.06`，朝南时两个握持点一起向画面上方移动。
- 主手不增加装饰角；副手围绕其握持点外张 `6` 度。
- 不修改 `GripOffset`、枪口配置、贴图和单武器基础预设。

## 本轮边界

本轮用于快速观察静默姿态，只修改 XML（可扩展标记语言）数据，不扩建状态感知设施。现有 `SubHandAngleOffset` 在瞄准时也会继续生效；待静默姿态定型后，再单独设计“执行态装饰角归零”。

## 验证

- 烟雾测试锁定双武器偏移和副手角度差，并继续确认单武器没有姿态配置。
- 解析 `Visual.xml`，执行 `git diff --check`。
- 游戏内继续使用同一张参考贴图和朝南静默状态截图对比。
