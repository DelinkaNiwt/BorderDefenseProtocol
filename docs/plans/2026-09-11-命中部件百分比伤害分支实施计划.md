# 命中部件百分比伤害分支实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为通用远程额外伤害模块增加“实际命中部件最大生命值百分比”模式，并让额外伤害复用原版主伤害确定的命中部件。

**Architecture:** Core 只增加中性伤害量延迟解析口，并在主伤害结果中读取 `DamageResult.LastHitPart`；Content 实现命中部件生命值百分比解析器。保留现有固定伤害、部件总和百分比和显式命中部件继承行为，模块之间不互相引用。

**Tech Stack:** C#、RimWorld 1.6 原版 `DamageWorker.DamageResult`、XML Def、PowerShell 烟测、MSBuild。
