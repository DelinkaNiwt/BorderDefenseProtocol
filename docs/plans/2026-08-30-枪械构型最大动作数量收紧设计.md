# 枪械构型最大动作数量收紧设计

## 设计状态

- 日期：2026-08-30
- 状态：已确认，按最小范围实施
- 目标：将 BDP 四种可见枪械构型允许的最大芯片功能模板数量从 2 收紧为 1。

## 范围

只修改以下四个可见枪械构型 Def 的 `maxFunctionCount` 数值：

- 左轮手枪
- 突击步枪
- 冲锋枪
- 霰弹枪

射手的隐藏 Trion 立方体构型已经是 1，不修改。

## 不变项

- 不修改 `ChipCombinationRecord` 存档字段。
- 不修改组合解析器、组合合法性判断或芯片读档迁移流程。
- 不增加双动作芯片的自动降级兼容逻辑。
- 不修改其它武装构型、枪械参数、成本、工作量和文案。

## 旧存档预期

成品芯片和半成品只保存功能模板名与枪械构型名，读档时按当前 Def 重新解析。旧存档中包含两个功能模板的枪械构型记录，在新 Def 下会因功能数量超过 1 而变为非法组合。

现有 `GameComponent_ChipManufacturingMigration` 会扫描这些非法实体：成品或半成品替换为 `BDP_InvalidChipRemnant`（芯片遗留物），非法制造账单删除，并发送现有汇总信。该迁移行为本次保持不变。

## 验证

1. XML 解析并确认四个可见枪械构型均为 1，隐藏 Trion 立方体仍为 1。
2. 运行武装构型定义冒烟测试与冲锋枪冒烟测试。
3. 运行芯片组合解析、持久化和非法芯片迁移相关冒烟测试，确认没有误改兼容链。
4. 编译正式程序集。
