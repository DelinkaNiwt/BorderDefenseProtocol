# Trion Resource GUI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不破坏 Trion / CombatBody / Trigger 边界的前提下，为 `CompTrion` 落地一套“主条独立、右上扩展位可插拔”的 Trion 资源 GUI。

**Architecture:** 核心主条只依赖 `CompTrion` 自己的正式读口，核心显示逻辑完全基于 `Cur / Max / Allocated / Reserved / Available / Frozen / RecoveryPerDay / TotalDrainPerDay`。右上角扩展位通过宿主无关的 Trion GUI 扩展注册表收口；扩展 provider 只能读正式 surface，不能摸内部对象，也不能反向改写 Trion 真值。

**Tech Stack:** RimWorld 1.6 C# / Verse Gizmo & Widgets / PowerShell smoke tests / `dotnet msbuild`

**Step 3: Write minimal implementation**

`Gizmo_TrionStatus` 直接吃 `Thing ownerThing` + `ITrionReader trion`，不要读其它系统。

核心骨架按这个结构落：

```csharp
internal sealed class Gizmo_TrionStatus : Gizmo
{
    private readonly Thing ownerThing;
    private readonly ITrionReader trion;

    public override float GetWidth(float maxWidth)
    {
        return Mathf.Min(maxWidth, 240f);
    }

    public override GizmoResult GizmoOnGUI(Vector2 topLeft, float maxWidth, GizmoRenderParms parms)
    {
        Rect rect = new Rect(topLeft.x, topLeft.y, GetWidth(maxWidth), 75f);
        Rect topRow = new Rect(rect.x + 8f, rect.y + 6f, rect.width - 16f, 18f);
        Rect barRect = new Rect(rect.x + 8f, rect.y + 28f, rect.width - 16f, 18f);
        DrawTopRow(topRow);
        DrawBar(barRect);
        return new GizmoResult(GizmoState.Clear);
    }
}
```

主逻辑要求：

- `Allocated <= 0f`：按未正式锁定显示
- `Allocated > 0f`：按已正式锁定显示
- `Cur / Max` 决定条总填充
- 未正式锁定分隔线位置：`Mathf.Clamp01((Cur - Reserved) / Max)`
- 已正式锁定分隔线位置：`Mathf.Clamp01(Allocated / Max)`
- 恢复文字：`恢复 {RecoveryPerDay:F0}/天`
- 消耗文字：`消耗 {(TotalDrainPerDay / 1000f):F0}/秒`
