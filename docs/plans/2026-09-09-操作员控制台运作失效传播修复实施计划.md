# 操作员控制台运作失效传播修复实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让操作员控制台在 Trion 中继核心停止、控制台断电或操作员失效时立即停止值守工作并撤销下游地图许可，同时保留强制运作覆盖。

**Architecture:** 保留 `CompOperatorConsole.IsOperational` 作为唯一运作真值，继续由它组合强制运作、电力、操作员心跳和 Trion 上游许可。仅在操作员控制台的持续值守 Toil（工作阶段）中补充统一状态复查；非强制运作且状态失效时结束工作，由现有结束回调清除操作员心跳。地图许可提供器不新增条件，也不复制前置逻辑。

**Tech Stack:** C#、RimWorld `JobDriver`/`Toil`、BDP Core 地图许可接口、PowerShell 文本烟测、dotnet Release 构建。
