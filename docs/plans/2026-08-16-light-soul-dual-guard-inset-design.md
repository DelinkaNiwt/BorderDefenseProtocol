# 光魂双武器举盾贴身位置设计

## 目标

只调整光魂大盾在双武器绘制中的横向位置，使南、北、东、西四个朝向都与单持盾一样贴近人物，并允许盾面遮挡人物。单武器表现保持不变。

## 当前原因

双武器举盾预设为了给另一把武器让出空间，单独扩大了横向距离：南北向使用 `0.30`，东西向使用 `0.44`；单持对应值分别为 `0.12` 和 `0.28`。这两处额外外移正是双持盾面离人物过远的来源。

## 调整规则

- 双武器南北向 `DefaultOffset.X`（默认横向偏移）由 `0.30` 改为 `0.12`。
- 双武器东西向 `SideBaseX`（侧向基础横移）由 `0.44` 改为 `0.28`。
- 保留东西向 `SideDeltaX = 0.04`（主副手位置差），因此主手仍比副手更贴近人物。
- 不改变角度、高度、尺寸、方向贴图、水平镜像、前后景或受击抖动。
- 不改变单武器举盾预设。

南北朝向继续由既有手位镜像规则派生左右位置，东西朝向继续由人物朝向、主副手位置差和镜像规则派生四种结果。无需增加逐朝向字段或修改通用绘制代码。

## 验证

配置测试固定双持与单持的两项位置基准一致，同时保留东西主副手 `0.04` 的位置差。随后运行光魂举盾相关测试、构建正式程序集，并检查最终差异只包含本次 XML（可扩展标记语言）数值与说明。
