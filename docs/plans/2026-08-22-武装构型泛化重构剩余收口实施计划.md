# 武装构型泛化重构剩余收口 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完成武装构型泛化重构的剩余收口，并增加只对指定动作有效的临时攻击手型验证样本。

**Architecture:** 在现有单一 `ChipArmamentFormDef`（武装构型定义）和统一覆盖块上增加可选动作白名单。白名单为空表示不限制动作；非空时，所选动作必须全部属于白名单，制造台与解析器共用同一兼容判断。构型仍在动作合并完成后只应用一次，不引入按多形态逐条覆盖的第二套机制。同步明确不做旧存档字段迁移，补齐定义校验、隐藏 Trion 默认型运行时测试和发布前检查。

**Tech Stack:** C# 7.3、.NET Framework 4.8、RimWorld 1.6 Def/XML、PowerShell 冒烟测试、Windows PowerShell 程序集反射测试、dotnet msbuild。
