# BDP 芯片制造窗口视觉层级重做 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 保留芯片制造三栏业务，修复预览翻译和队列裁切，并把窗口重排为紧凑、清晰、轻分组的原版风格界面。

**Architecture:** 窗口只负责总尺寸、平面页签和三栏分配；左、中、右面板各自按内容测量高度。预览与队列不保存新的业务状态，只把现有模型按动态文本高度绘制。

**Tech Stack:** RimWorld 1.6 `Window`、Unity IMGUI、Verse `Widgets`、C# 7.3、PowerShell 冒烟测试、MSBuild。
