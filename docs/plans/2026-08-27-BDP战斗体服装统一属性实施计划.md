# BDP 战斗体服装统一属性实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让所有战斗体前台服装在 `MirrorOriginal` 与 `Preset` 两条路径下统一满足锁脱、无品质、无耐久的硬需求。

**Architecture:** Core 增加只描述“战斗体前台服装实例身份”的中性运行时登记，并用已有持久化 Thing ID 在读档后重建。Content 在公共激活边界提供正式规则：统一去品质、屏蔽耐久损伤并隐藏耐久显示；不修改共享 `ThingDef`，不把规则下放给预设。

**Tech Stack:** C# 7.3、.NET Framework 4.8、RimWorld 1.6、Harmony、PowerShell smoke tests（冒烟测试）。
