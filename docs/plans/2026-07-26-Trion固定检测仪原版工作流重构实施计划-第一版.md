# Trion 固定检测仪原版工作流重构实施计划（第一版）

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**目标：** 将固定 Trion 检测仪改成原版生物科技扫描仪式流程：建筑按钮选择受检者，受检者自行入舱或被搬入，高智识研究员自动操作，操作进度持久化并显示进度条；便携检测仪保持现状。

**实现基线：** 固定检测仪继承原版 `Building_Enterable`（可进入建筑），复用原版 `EnterBuilding`（进入建筑）和 `CarryToBuilding`（搬运至建筑）工作。建筑持有唯一受检者、累计工作量和取消/完成状态；独立研究类 `WorkGiver`（工作分配器）只负责寻找待操作的检测仪。操作工作每个游戏刻按 `ResearchSpeed`（研究速度）增加工作量，基准总量为 7,500。

**技术栈：** RimWorld 1.6、C# 7.3、XML Def（定义）、PowerShell 冒烟测试、MSBuild。
