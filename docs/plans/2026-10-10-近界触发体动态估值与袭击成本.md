# 近界触发体动态估值与袭击成本实施计划

> **Codex 执行要求：** 按任务逐项实施本计划；实现后检查差异并提交。

**目标：** 让所有 BDP 触发体按实际装载芯片动态计价，避免原版财富重复统计，并使近界民战斗员以 80 点战力和匹配的武器预算参与袭击。

**架构：** Core 只增加按 ThingWithComps 获取触发体正式读取口的通用访问方法。Content 组件通过该读取口从正式槽位读取已装芯片，按实体去重后为市场价值提供加值；Content 还仅对 CompTriggerBody 子容器增加原版财富筛选排除，并更新近界 PawnKindDef、袭击预算曲线和简体中文称谓。

**技术栈：** C#、Harmony、RimWorld Def XML、DefInjected 简体中文语言文件。
