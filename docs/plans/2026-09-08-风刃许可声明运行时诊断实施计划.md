# 风刃许可声明运行时诊断 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不改变风刃许可判断的前提下，记录 `BDP.OperatorConsole.Active` 从芯片表达来源声明到 Ability 结果发布之间的实际值。

**Architecture:** Core 在两个数据边界通过现有中性 `BdpDiagnostics` 输出限频诊断；Development 继续作为可插拔日志接收端，不被 Core 引用。第一处观察芯片表达条目翻译出的来源声明，第二处观察正式 Ability 结果进入 Pawn 绑定表前的最终快照。诊断记录实际 `AbilityDefName`，不在 Core 硬编码具体业务 DefName。现有直视许可访问日志保留，用三处结果 ID 对照定位字段丢失层。

**Tech Stack:** C#（C#语言）、RimWorld 1.6、PowerShell smoke test（PowerShell 烟测）、`dotnet build`（.NET 构建）。
