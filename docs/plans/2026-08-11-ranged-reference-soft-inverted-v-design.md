# 远程武器基准图柔和倒 V 静默姿态设计

## 目标

继续调试朝南、非瞄准状态的双武器参考姿态：握持点比上一轮更高、更外，两把长枪的枪口分别朝外，形成不完全对称的柔和倒 V 轮廓。单武器继续保持原版默认姿态。

## 当前判断

- 上一轮 `(0.16, 0, 0.06)` 已证明握持点外移、上移方向正确，但幅度仍不足。
- 主手 `0` 度、副手 `6` 度只形成同向错位，两把枪的画面重心仍偏向一侧。
- 完全对称且角度较大的倒 V 虽然辨识强，但容易像徽标或固定炮架，并让长枪尾部向身体中央聚拢。

## 采用方案

采用不完全对称的柔和倒 V：

```xml
<SouthNorthPose>
  <DefaultOffset>(0.20, 0, 0.12)</DefaultOffset>
  <DefaultAngle>-8</DefaultAngle>
  <SubHandAngleOffset>20</SubHandAngleOffset>
</SouthNorthPose>
```

- “上一轮偏移量的两倍”按相对初始值的累计改变量解释：X 从初始 `0.12` 增加到 `0.20`，Z 从初始 `0` 增加到 `0.12`。
- 主手装饰角为 `-8` 度。
- 副手最终装饰角为 `-8 + 20 = 12` 度。
- 主手更稳，副手张角略大，以避免完全对称的僵硬感。
- 握持点作为姿态原点，武器围绕各自握持点旋转。

## 边界

- 只修改 `BDP_Visual_RangedWeaponReference_Dual`。
- 不修改单武器基础预设、贴图内 `GripOffset`、枪口数据、东西朝向和程序集源码。
- 本轮仍只观察静默姿态。现有装饰角在瞄准时也会暂时生效；执行态归零另行设计。
- 枪口诊断点按瞄准角解析，不随静默装饰角完全旋转；角度增大后可能暂时离开贴图边缘，这不在本轮改动范围内。

## 验证

- 烟雾测试锁定三个南北姿态字段及单武器边界。
- 解析 `Visual.xml` 并执行格式检查。
- 游戏内继续用朝南静默状态观察握持点高度、双枪尾部交叠和枪口分离程度。
