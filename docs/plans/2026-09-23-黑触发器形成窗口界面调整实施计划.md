# 黑触发器形成窗口界面调整实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 调整黑触发器形成窗口的资料展示、默认传承人和侧重简介布局，不改变形成业务逻辑。

**Architecture:** 保留现有 `BlackTriggerFormationEvent`（形成事件）和选择状态；窗口左栏直接绘制完整冻结资料，右栏为侧重增加同行显示器；世界服务在事件创建时写入现有 `None` 哨兵值，窗口校验为旧事件补默认值。

**Tech Stack:** RimWorld 1.6、C# 7.3、Verse UI、中文语言包、PowerShell 烟测、MSBuild。

---

### Task 1：先更新回归测试

**Files:**

- Modify: `Source/BDP.Tests/BlackTriggerPresentationRegressionSmokeTests.ps1`
- Modify: `Source/BDP.Tests/BlackTriggerChoiceLetterSmokeTests.ps1`（必要时）

**Steps:**

1. 增加对完整资料单区绘制、侧重同行绘制和默认 `None` 初始化的断言。
2. 删除“必须存在底栏红色状态区域”的旧断言，改为确认窗口不再包含该绘制区域。
3. 运行测试确认修改前按预期失败。

### Task 2：调整窗口绘制

**Files:**

- Modify: `Source/BDP.Content/Trigger/Black/Formation/Presentation/Window_BlackTriggerFormationDecision.cs`

**Steps:**

1. 左栏取消匹配/其它技能分组，统一绘制全部技能和记录。
2. 侧重选项改为名称和摘要同行显示，不再拼接匹配依据。
3. 继承特性选项只绘制名称，不绘制描述正文。
4. 移除底栏未决红色状态绘制，但保留确认按钮禁用校验。
5. 打开旧事件时把空传承人选择迁移为 `None`。
