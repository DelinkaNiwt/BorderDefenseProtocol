# 炸裂弹内置爆炸投射物改造设计

## 目标

把美特拉当前由 `BDP_AreaExplosionModule`（范围爆炸模块）提供的固定爆炸行为，迁移到一个专用的 BDP 原生投射物 Def（定义）中，使游戏内爆炸伤害、半径、护甲穿透和 BDP 远程执行链保持等效，同时移除美特拉对爆炸模块的依赖。

## 命名

- 玩家可见投射物名称：`炸裂弹`。
- 投射物 Def 标识名：`BDP_Projectile_Explosive`。
- `Meteora`（美特拉）只保留为攻击动作和芯片语义，不进入投射物标识名。

## 当前基线

美特拉当前使用 `BDP_Projectile_Normal`，并挂载 `BDP_AreaExplosionModule`。模块参数为：

- 爆炸半径：`2.9`。
- 伤害类型：`Bomb`。
- 伤害量：`0`，回退当前投射物伤害；当前普通弹为 `52`。
- 护甲穿透：`-1`，回退当前投射物护甲穿透；当前普通弹为 `0.10`。
- 抑制基线单体命中：`true`。

## 方案

新增 `BDP_Projectile_Explosive`，继续使用 `BDP.Core.Projectiles.BdpProjectile`，设置 `Bomb`、`52`、`0.10`、`2.9` 和普通弹的 `120` 速度。`ImpactStageService`（命中阶段服务）会读取投射物 Def 的爆炸半径，生成基线 `AreaEffectPlan`（范围效果计划），再由 `BdpProjectile` 调用原版 `GenExplosion.DoExplosion`（爆炸执行接口）。

美特拉的 `defaultProjectile`（默认投射物）改为 `BDP_Projectile_Explosive`，移除 `BDP_AreaExplosionModule`。不修改共享的 `BDP_Projectile_Normal`，避免小行星等其它动作被连带改成爆炸攻击。

瞄准预览回到原版投射物范围预览。其半径从投射物 Def 的 `explosionRadius`（爆炸半径）读取，实际爆炸覆盖与原版爆炸结算保持同一半径口径；不再使用爆炸模块提供的逐格预览。

## 验证

1. 先修改并运行美特拉边界烟雾测试，确认旧规则按预期失败。
2. 修改投射物 Def 与美特拉动作引用后，验证新投射物名称、标识名、`BdpProjectile` 类型、爆炸参数和无爆炸模块依赖。
3. 运行 XML 解析、边界烟雾测试、Core 隔离门禁和构建检查。
4. 游戏内确认：美特拉发射炸裂弹；命中 Pawn（人形单位）、建筑和地面时在落点爆炸；不额外造成普通弹单体直击；爆炸仍可沿 BDP 语义与护盾策略运行。

## 不在本次范围

- 不改 `BdpProjectile` 继承关系。
- 不支持延迟爆炸或 `explosionEffect`（爆炸特效器）完整迁移。
- 不重做逐格爆炸预览基础设施。
