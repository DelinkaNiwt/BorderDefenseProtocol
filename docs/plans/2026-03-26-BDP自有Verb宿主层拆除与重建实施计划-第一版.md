# BDP 自有 Verb 宿主层拆除与重建 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 彻底删除现有“表达结果 -> 原版装备挂接点映射”宿主链，让模组先进入诚实缺陷状态，再在干净地基上建立 BDP 自有 Verb 宿主层，并逐步恢复手动攻击、自动攻击、双武器和组合技。

**Architecture:** 本计划不做温和迁移，不保留 fallback、兼容桥或过渡宿主。实施分为两大段：先拆除旧宿主映射链，把 Trigger、Expressions、AttackExecution 的边界重新拉直；再新增 `VerbHosting` 正式运行时层，用固定宿主入口、宿主构造规格、宿主持有器、宿主工厂、宿主时钟统一承接运行时宿主问题。

**Tech Stack:** RimWorld 1.6 C# Mod, Verse/RimWorld `Verb / JobDriver / Projectile / Targeter / Gizmo`, Harmony, `dotnet msbuild`, DevHarness XML Def。

## 本计划的正式边界

### 边界 1：先拆旧宿主映射链

必须整体拆掉：

- `Expressions` 内当前 Verb 宿主同步 / 解析链
- `AttackExecution` 内对旧宿主链的依赖
- 手动 targeting 对旧宿主解析的依赖
- 自动攻击桥对旧宿主解析的依赖

拆完后允许：

- 表达仍成立
- 攻击执行入口仍在
- 手动和自动攻击暂时失效

### 边界 2：新宿主层单独建目录

新增正式运行时层目录：

- `Source/BDP/Core/VerbHosting/`

不把新宿主层塞回：

- `CompTriggerBody`
- `Expressions/Projection`
- `AttackExecution`

### 边界 3：Trigger 只负责来源事实，不持有宿主

- `Trigger` 只负责装载、激活、切换和来源事实
- 不持有 `Verb` 宿主池
- 不缓存运行时宿主实例
- 不创建组合技宿主
- 不驱动宿主 tick

### 边界 4：Expressions 不再拥有运行时 Verb 宿主职责

- `Expressions` 只负责正式结果
- 只保留构造宿主规格所需事实
- 不再负责“同步成真实 Verb 宿主”

### 边界 5：AttackExecution 只消费新宿主层

- `AttackExecution` 只从新宿主层读取宿主实例
- 不再按 `ResultId` 反向借原版装备环境
- 未命中新宿主时直接诚实失败

## 完成标准

本计划完成时，必须同时满足：

- 现有旧宿主映射链已整体删除
- 模组不存在 fallback / 兼容桥 / 过渡宿主
- `Source/BDP/Core/VerbHosting/` 已建立正式对象骨架
- 手动攻击从宿主层取宿主，不再临时按结果解析旧宿主
- 自动攻击从宿主层取主入口，不再临时按结果解析旧宿主
- 双武器 / 组合技宿主进入固定宿主入口体系
- `Trigger` 不持有运行时宿主
- `Expressions` 不持有运行时宿主
- `AttackExecution` 不创建运行时宿主
- 主模组可编译
- DevHarness 至少补到新宿主层最小验收口
