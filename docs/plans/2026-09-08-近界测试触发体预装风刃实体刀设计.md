# 近界测试触发体预装风刃·实体刀设计

## 目标

让 `BDP_TriggerBody_NeighborTest` 首次生成时，在特殊槽 4 预装一枚 `BDP_ChipFunction_FujinEntityBlade` 动态芯片，并同步修正触发体说明。

## 最小方案

- 复用现有 `fixedLoadout` 固定装载机制。
- 在 `Trigger.xml` 追加特殊槽 4，`chipDef` 使用 `BDP_Chip_Custom`，`initializationKey` 使用 `BDP_ChipFunction_FujinEntityBlade`。
- 更新 Def 回退说明与简体中文语言包说明。
- 扩展现有 `TriggerBodyVariantsDefinitionSmokeTests.ps1`，将近界测试触发体固定装载从 3 枚校验为 4 枚，并校验特殊槽 4。
- 不修改芯片功能数值、不修改 Core/Content C#，保留当前工作区已有的 `Presets.xml` 未提交调整。

## 验收

特殊槽 1～4 依次为自动护盾、紧急脱离、风刃、风刃·实体刀；XML、固定装载测试和构建全部通过。
