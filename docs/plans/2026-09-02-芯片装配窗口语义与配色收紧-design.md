# 芯片装配窗口语义与配色收紧设计

## 目标

收紧触发器装配台界面的显示语义和视觉一致性：右栏底色统一，芯片名称去除重复产品前缀，左栏资源条改为累计预占用语义，并让当前常规槽位内容在不滚动时完整显示。

## 已确认事实

- 右栏面板外层调用 `Widgets.DrawMenuSection`，产生了与 BDP 深青色卡片不一致的原版灰色底。
- 芯片名称在多个界面位置直接读取 `LabelShortCap` 或 `LabelCap`，底层产品标签由语言包中的 `BDP_ChipManufacturing_ProductLabel` 生成“触发器芯片:”前缀。
- 左栏资源条使用 `preview.Cur` 作为右上数值和填充比例，语义是当前 Trion，而用户要求显示累计预占用。
- 资源条下方的预占用/可用两行文字属于重复信息；删除后可收紧左栏资源卡片高度。

## 方案比较

1. 在每个绘制点分别截断名称：改动直观，但容易遗漏中栏、右栏、左栏或 Tooltip（提示框）中的某一个显示点。
2. 修改 Thing/Def（物品/定义）的底层名称：可以一次影响多个位置，但会污染真实数据，并可能影响其他界面、日志和存档显示。
3. 增加界面显示层统一名称方法：只在触发器装配窗口消费时去除前缀，并由所有界面显示点复用。该方案边界最清晰，采用此方案。

## 设计

### 右栏底色

在 `Panel_ChipDetail` 中用与左栏/中栏相同的深青色面板底和边框色绘制详情外框，替换 `Widgets.DrawMenuSection` 的默认灰色底。详情内容卡片和现有滚动区域保持不变。

### 芯片名称

新增窗口层的 `ChipDisplayNameFormatter`（芯片显示名称格式化器），从现有 `BDP_ChipManufacturing_ProductLabel` 语言键生成当前语言前缀并仅移除名称开头的该前缀。库存卡片、库存 Tooltip、左栏槽位、左栏 Tooltip、右栏详情标题统一调用它；当名称不带前缀时原样返回。

### Trion 资源条

- 标题语言键改为“芯片预占用”。
- 右上数字使用 `PreviewReserved / Max`。
- 轨道始终绘制完整宽度：先绘制低亮度剩余容量段，再绘制高亮度累计预占用段，使用细分界线强化比例；不再绘制“当前 Trion”或下方“当前预占用/可用”文字。
- 资源卡片高度从 82 缩至只容纳标题、完整轨道和必要内边距的尺寸，以释放左栏垂直空间。

### 左栏布局

保留现有滚动兜底以支持未来异常多槽位，但使用收紧后的资源卡片高度；当前常规主/副手和特殊槽位组合应在左栏视口内完整显示，不改变槽位布局、拖拽命中或预览计算。

## 数据流与边界

不修改 `Thing`、Def、芯片快照或 `TriggerAssemblyPreviewSnapshot`。资源条只改变消费字段：从 `Cur` 切换到既有的 `PreviewReserved`。名称只改变 UI（用户界面）输出，不改变芯片对象的真实标签。

## 验证

- 契约测试检查右栏不再调用 `Widgets.DrawMenuSection`，名称显示点统一调用格式化器，资源条使用 `PreviewReserved` 且不绘制旧的两行摘要。
- 运行全部现有 PowerShell（PowerShell）冒烟/边界测试。
- 构建 `BDP.Content` Release（发布配置），运行 `git diff --check`。
- 最后进入游戏检查右栏底色、各处芯片名称、资源条分段比例和左栏是否无需滚动。
