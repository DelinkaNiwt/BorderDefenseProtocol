# 组合技发射根点复用最终视觉位设计

## 目标

修复组合技攻击阶段子弹从小人身体中心发射的问题，使子弹发射根点与该阶段实际绘制的武器最终位姿一致。

## 已确认事实

- `PawnRenderUtility.DrawEquipmentAiming` 已经按当前阶段消费组合技视觉绑定，并构造组合技临时视觉条目。
- 发射根点解析仍按 `sourceResultId` 查普通常驻视觉条目，没有消费组合技阶段绑定。
- 发射根点解析失败时，`BdpVerb_Shoot` 明确回退到 `Pawn.DrawPos`，因此会从小人身体中心发射。
- 原版装备绘制点 `EquipmentPoseSample.DrawLoc` 不是 `Pawn.DrawPos`；组合技的武器绘制位本身没有被定义为身体中心。

## 设计选择

新增 Core 内部通用的有效视觉条目解析器，输入当前视觉投影、来源常驻条目、动作阶段和运行时状态，输出当前阶段真正使用的：

- 有效视觉条目；
- 有效视觉预设；
- 有效图层覆盖预设。

绘制入口和发射根点入口共同消费该解析结果。组合技命中时使用与绘制入口相同的临时组合技条目和组合技视觉预设；未命中时保留原有单武器、双武器和待命逻辑。

## 时序边界

- `Idle`（待命）阶段不消费组合技攻击视觉绑定。
- `Warmup`（预热）、`Firing`（射击）、`Cooldown`（冷却）阶段才允许组合技绑定覆盖当前绘制条目。
- 组合技预设缺失、归属来源不匹配或视觉解析失败时，继续走现有普通条目和现有 `Pawn.DrawPos` 兜底，不改变攻击语义。

## 验证

- 新增回归冒烟测试，确认绘制入口与发射根点入口都使用共享有效视觉条目解析器。
- 运行组合技视觉、武器阶段、枪口锚点和构建检查。
- 需要用户在游戏内重新实测组合技，确认子弹和枪口闪光均跟随武器最终绘制位。
