# 炸裂弹内置爆炸投射物改造 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将美特拉的固定范围爆炸从 `BDP_AreaExplosionModule`（范围爆炸模块）迁移到专用的 `BDP_Projectile_Explosive`（炸裂弹投射物 Def 定义）上，使游戏内继续得到相同的爆炸半径、伤害、护甲穿透和弹道表现，同时让玩家看到的子弹名称为“炸裂弹”。

**Architecture:** 保留 `BdpProjectile : RimWorld.Bullet`（BDP 投射物仍继承原版普通子弹），新增一个专用投射物 Def。原版 `Projectile_Explosive` 的爆炸字段由 BDP 的投射物生命周期读取，并通过现有 BDP 基线范围效果路径执行；美特拉不再挂载业务范围爆炸模块。共享的 `BDP_Projectile_Normal` 不改变，避免影响其他动作。

**Tech Stack:** RimWorld 1.6 XML Def（定义配置）、PowerShell 边界烟测（轻量配置测试）、BDP Content/测试项目、MSBuild（构建工具）。

### Task 2: 新增专用炸裂弹投射物 Def

**Files:**
- Modify: `1.6/Content/Defs/ThingDef/Projectiles/Projectiles.xml`

**Step 1: 新增 Def**

在现有 BDP 普通子弹 Def 附近新增 `BDP_Projectile_Explosive`，保持 `BdpProjectile` 类和现有短亮薄荷色拖尾。配置：

- `damageDef`: `Bomb`
- `damageAmountBase`: `52`
- `armorPenetrationBase`: `0.10`
- `speed`: `120`
- `explosionRadius`: `2.9`

Def 中只放基础/英文回退标签，中文玩家显示名放入语言包，避免新增文案硬编码在业务配置中。

**Step 2: 保留结果等效边界**

不新增 `explosionDelay`、`explosionEffect` 或额外 C# 类；当前范围爆炸模块没有配置这些参数，本次只迁移已经存在的爆炸参数。

在中文 `DefInjected/ThingDef` 语言包中添加 `BDP_Projectile_Explosive.label`，值为 `炸裂弹`。不把 `Meteora` 用作子弹的玩家显示名；`Meteora` 只保留为动作/芯片的内部语义标识。
