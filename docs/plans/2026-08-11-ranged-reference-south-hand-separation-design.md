# 远程武器基准图南向主副手分离设计

## 目标

让基准参考武器在“双武器绘制”下呈现两个可辨认的握持点，同时保证单武器继续完全服从原版手持姿态。

## 方案比较与选择

- 选择：保留无姿态配置的基础预设，新增双武器专用复合预设，并只在复合预设中配置 `SouthNorthPose.DefaultOffset.x = 0.12`。突击步枪枪壳分别声明 `visualPresetDefName` 与 `compositeVisualPresetDefName`；现有视觉关系解析会让单武器使用前者、双武器使用后者。
- 不选：直接修改基础预设。`SouthNorthPose` 会令该预设成为显式姿态，单武器可能从原版贴图替换路径升级为完整姿态路径，违反单武器保持原版的边界。
- 不选：新增 Core（核心）双持判断字段或硬编码武器数量。现有复合视觉预设已经承担相同职责，无需扩建架构。
- 不选：分别修改主副侧 `GripOffset`。握持点描述的是贴图内部同一个真实位置，不应承担整枪排布职责。

## 影响范围与验证

- 基础预设 `BDP_Visual_RangedWeaponReference` 继续不声明任何姿态，单武器保持原版位置、角度和镜像。
- 双武器专用预设 `BDP_Visual_RangedWeaponReference_Dual` 复用同一贴图、握持点和枪口，只显式写入 `DefaultOffset`；现有解算器自动形成主侧 `+0.12`、副侧 `-0.12`，总间距 `0.24` 格。
- 突击步枪枪壳把普通视觉指向基础预设，把复合视觉指向双武器预设。
- 用烟雾测试同时锁定单武器默认姿态、双武器偏移和枪壳双重映射；该调整只涉及 XML（可扩展标记语言），不需要重新编译程序集。
