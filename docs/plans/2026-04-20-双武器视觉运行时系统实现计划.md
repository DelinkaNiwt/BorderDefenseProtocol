# 双武器视觉运行时系统实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在新 BDP 正式主链内落地双武器视觉渲染与枪口锚点系统，使静态视觉投影、动态执行态和发射原点共基准运行，不再依赖旧版混合式 `WeaponDraw（武器绘制）` 架构。

**Architecture:** 保留 `TriggerRuntimeCoordinator（触发体运行时协调器）` 作为静态投影唯一 owner（所有者），新增 `TriggerVisualRuntimeState（视觉运行时动态状态）` 保存动态执行态与装备姿态样本，再由 `VisualPoseResolver（视觉姿态解析器）` 统一解算手持贴图与枪口锚点。绘制补丁只读正式投影与视觉动态态；发射链在 `ProjectileInitPlan（投射物初始化计划）` 阶段写入 `AbsoluteOriginWorld（绝对发射原点）`。

**Tech Stack:** C# 7.3、RimWorld 1.6、Harmony、PowerShell 结构性烟雾测试。
