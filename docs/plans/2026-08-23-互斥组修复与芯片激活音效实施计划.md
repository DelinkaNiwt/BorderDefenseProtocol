# 互斥组修复与芯片激活音效实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复制造成品芯片运行时丢失激活互斥组的问题，并在 Core 中提供与具体芯片业务无关的激活前摇、持续和完成音效生命周期。

**Architecture:** 互斥组沿现有 `ChipLoadoutConfig → ChipLoadoutContract` 投影链修复，不改变 Trigger 的互斥判定规则。音效声明作为装载配置的可选通用块，经过静态 Def 与动态成品两条配置路径进入运行时契约；由 Trigger owner 的运行时协调流程维护 `SoundDef` 的 one-shot 与 `Sustainer` 生命周期。

**Tech Stack:** RimWorld 1.6、C# 7.3、Verse.Sound、PowerShell 冒烟测试、MSBuild。
