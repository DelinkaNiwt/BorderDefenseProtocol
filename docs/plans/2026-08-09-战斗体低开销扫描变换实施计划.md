# 战斗体低开销扫描变换实施计划

> **For Codex（给 Codex）：REQUIRED SUB-SKILL（必需子技能）：使用 `superpowers:executing-plans` 按任务逐项执行本计划。**

**Goal（目标）：** 在不延迟战斗体玩法状态、不使用粒子群和完整角色双重渲染的前提下，实现生成时头到脚、解除时脚到头的双层扫描光，并让退场衣物随扫描边界逐段消失。

**Architecture（架构）：** Core.dll（核心程序集）新增中性的战斗体变换表现提供器注册表，在宿主衣物变换前发送进入/离开通知。Content.dll（内容程序集）捕获仍穿在身上的退场衣物图形，创建一个短命 Mote（特效实体），在真实换装完成后用裁切网格绘制尚未扫掉的退场衣物，并叠加细白核心光和青绿色柔光。

**Tech Stack（技术栈）：** C# 7.3、.NET Framework 4.8、RimWorld 1.6 `PawnCombatBodyBridge` / `ApparelGraphicRecordGetter` / `MoteAttached` / `Graphics.DrawMesh`、Unity `Mesh` / `Material`、XML（可扩展标记语言）Def、PowerShell 烟雾测试、`dotnet msbuild`。

**Step 3：实现提供器**

`Begin(Pawn, direction)` 检查 Pawn（角色）、地图、镜头范围；捕获退场衣物；创建现有 Mote Def（特效定义）；直接向 Content 自己的 `Mote_CombatBodyScan` 配置方向和记录；附着并生成。Core 不再提供 Mote 配置接口。

**Step 4：重写 Mote 绘制**

每帧：

1. 计算方向、进度与扫描世界坐标。
2. 为每件退场衣物计算局部裁切值。
3. 从静态网格缓存取 Mesh（网格）。
4. 使用捕获 Graphic（图形）的当前朝向 Material（材质）绘制退场部分。
5. 最后绘制白色细核心和青绿色柔光。

头部衣物使用原版 `BaseHeadOffsetAt`，身体衣物使用 Pawn（角色）中心，背包应用捕获的原版偏移与缩放。删除整块尾迹代码、快闪和粒子调用。
