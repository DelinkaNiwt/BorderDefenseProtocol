# 组合技发射根点复用最终视觉位 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让组合技攻击阶段的子弹发射根点复用当前组合技武器视觉的最终条目和位姿，消除身体中心回退造成的错位。

**Architecture:** 在 `BDP.Core.Trigger.Visual` 内新增共享的有效视觉条目解析器。现有绘制补丁和发射根点解析器都先通过它把普通来源条目转换为当前阶段条目，再交给同一个 `VisualPoseResolver` 计算最终绘制位和枪口锚点。待命及主侧、副侧、双持路径保持原样。

**Tech Stack:** C#、RimWorld 1.6、PowerShell 冒烟测试、Release `dotnet msbuild`。

---

### Task 1: 建立回归测试

**Files:**
- Create: `Source/BDP.Tests/ComboAttackVisualLaunchOriginSmokeTests.ps1`

测试确认：

- 共享解析器存在并生成组合技临时条目；
- 绘制入口消费共享解析器；
- 发射根点入口消费共享解析器；
- 旧的 `Pawn.DrawPos` 只保留为视觉解析失败后的兜底，不再作为组合技正常路径的根点。

先运行测试，旧版本应因共享解析器不存在而失败。

### Task 2: 实现共享有效视觉条目解析

**Files:**
- Create: `Source/BDP/Core/Trigger/Visual/TriggerVisualEffectiveEntryResolver.cs`
- Modify: `Source/BDP/Patches/Patch_PawnRenderUtility_DrawEquipmentAiming_BdpVisual.cs`

保留现有阶段匹配规则，将绘制补丁中的组合技绑定匹配、临时条目构造和预设选择迁移到共享解析器。普通条目解析和待命行为不变。

### Task 3: 接入发射根点解析

**Files:**
- Modify: `Source/BDP/Core/Trigger/Visual/TriggerVisualLaunchOriginResolver.cs`

发射根点解析在找到来源常驻条目并解析动作阶段后，使用共享有效视觉条目和预设构造 `VisualPoseRequest`。组合技正常命中时，最终枪口锚点来自组合技预设位姿；失败时保留既有诊断与 `Pawn.DrawPos` 回退。
