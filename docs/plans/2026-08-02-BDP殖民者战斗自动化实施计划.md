# BDP 殖民者战斗自动化实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal（目标）:** 为玩家自由非奴隶殖民者增加四项默认关闭、个人独立、可被全局策略覆盖的战斗自动化，并通过 Trion（资源）复合 Gizmo（游戏指令面板）的两个区域右键菜单控制。

**Architecture（架构）:** `BDP.Core.dll`（核心程序集）只增加中性的 Trion 分区右键菜单扩展口和战斗体完整激活事件；`BDP.Content.dll`（内容程序集）拥有个人配置、全局设置、征召补丁、自动化执行器和具体界面。所有自动操作继续调用现有 CombatBody（战斗体）与 Trigger（触发器）正式接口，不复制条件、不轮询、不重试。

**Tech Stack（技术环境）:** RimWorld 1.6（边缘世界1.6）、C# 7.3（C#语言7.3）、Harmony（方法补丁框架）、Verse/Unity IMGUI（游戏与即时界面）、PowerShell（自动检查）、XML（可扩展标记语言）、Git（版本控制）

## 最终验收

实施者在声称完成前必须逐项确认：

- 四项默认关闭且分别可配置。
- 修改设置只影响下一次事件。
- 征召与战斗体激活失败均静默且不重试。
- 取消征召走主动解除，不走崩解。
- 芯片只在完整激活事件后处理一次。
- 两个右键区域没有重复或第三个个人菜单。
- 全局强制不破坏个人保存值。
- 新殖民者默认与批量覆盖只在服从个人时出现或生效。
- 批量范围包含地图、商队和旅行运输中的自由非借住殖民者，并排除奴隶等约定对象。
- Core 不出现具体自动化业务类型或 Content 依赖。
- 专项检查、构建、隔离门禁、XML 解析和全量回归无新增失败。
- 游戏内实测未完成时明确标为“待测”，不得把静态检查写成游戏实测通过。
