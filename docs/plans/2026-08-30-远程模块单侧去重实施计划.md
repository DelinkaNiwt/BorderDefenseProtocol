# 远程模块单侧去重实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让同一单侧远程表达内的同一种模块只创建并执行一个运行时实例，同时保留双持主、副两侧各自的一份模块。

**Architecture:** 在 Core 的 `RangedAttackModuleResolver.ResolveSlots` 解析挂载列表时，以 `moduleDef.defName` 建立本次单侧会话的已解析集合。首次成功初始化的挂载保留原始 `MountIndex（挂载索引）`，后续重复项跳过；不改变正式表达结果列表，因此不会移动已有挂载索引或破坏双侧来源上下文映射。

**Tech Stack:** C#（C#语言）、RimWorld/Verse（边缘世界原版运行时）、PowerShell smoke tests（PowerShell 烟测）。

### Task 2: 实现 Core 运行时单侧去重

**Files:**
- Modify: `Source/BDP/Core/AttackExecution/RangedModules/Runtime/RangedAttackModuleResolver.cs:19-71`

**Step 1: Add the local seen set**

在 `ResolveSlots` 创建 `HashSet<string>`，使用 `StringComparer.Ordinal`，作用域只覆盖本次解析会话。

**Step 2: Skip repeated module definitions**

在当前挂载通过空值、启用状态和运行时类型检查后，读取 `mount.moduleDef.defName`。如果该键已经成功解析，直接继续下一项。

**Step 3: Mark only successful instances**

保留现有反射创建、初始化和异常隔离逻辑；仅在 `slots.Add` 完成后登记模块键。这样首次初始化失败时，后续同定义挂载仍可尝试。
