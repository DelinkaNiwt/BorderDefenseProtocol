# 触发体制造页与普通配方实施计划

日期：2026-10-05。

Status: Implemented

**目标**：按用户明确提出的新增选项卡要求，在现有制造窗口列出可制造触发体，并接通普通标准触发体的临时配方。制造台改名为“触发器制造台”。

**实现方式**：顶部总览之后增加“触发体”页，复用现有三栏布局，左栏为产品列表、中栏为物品说明、右栏为材料、数量与共用队列。触发体使用原版配方及半成品账单；队列只把通用控制从芯片账单扩大到生产账单，芯片组合载入仍只作用于芯片。保留原版核心许可、电力、搬料、制作、存读档行为。

**技术基础**：内容层 C#、原版 RecipeDef（配方定义）与 BillStack（账单栈）、简体中文语言包。原版真实程序集已核实 MakeNewBill 扩展方法按半成品配置创建账单，IngredientCount 提供材料数量算法；运行时定义数据库已确认 UnfinishedWeapon（未完成武器）可复用。

## 范围与边界

- 页面名单读取制造台 AllRecipes（全部配方），按产物带触发体组件以及配方当前解锁状态筛选。
- 当前只挂接普通标准触发体配方，产出空触发体；原型、特制和黑触发器不增加普通配方。
- 临时配方：钢铁 20、工业零部件 1，工作量 500。数值仅为可运行的占位，可在 XML 调整，不确定研究前置。
- 缺材料或无核心时仍可安排账单；实际制作由已有原版接口准入约束。触发体与芯片混排在一个真实队列中，支持改数量、暂停、重排、删除。
- 普通触发体没有芯片组合草稿，“载入组合”只对芯片账单开放。开发模式立即完成仍专用于芯片，本轮不扩大调试业务。
- 保留既有类名、定义标识和存档身份，不为显示名称变更重构模块。

## 实施顺序

1. 新增普通触发体配方与简体中文配方文案，挂到当前制造台；同步建筑名称、说明及窗口入口文案。
2. 新增独立触发体制造面板，接入顶部导航与三栏主体；读取原版配方，按原版材料数量算法展示成本，创建有限次数原版账单。
3. 将已有队列显示及通用操作扩大到生产账单，保留芯片专用载入逻辑，避免隐藏触发体任务或产生另一套队列。
4. 编译、检查 XML 引用与语言键、运行相关界面和队列验证，核对混合队列操作与半成品账单类型；实际界面尺寸、制作、核心停运和存读档留游戏内核对。
5. 同步接通清单和工作日志，按本项精确路径提交，不纳入无关改动。

## 执行结果

以上五项已实现。编译及核心依赖隔离、配方与语言检查、既有制造窗口结构、总览、队列及语言检查通过。使用真实编译组件与原版账单栈，验证了混合账单收集、跨类别重排、越界拒绝及独立暂停恢复；普通触发体仍使用原版生产及半成品账单。
