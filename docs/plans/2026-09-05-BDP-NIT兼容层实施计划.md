# BDP NIT 兼容层实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 新增独立的 `BDP.Compatibility.dll`，在检测到支持的 Nice Inventory Tab（漂亮物品栏页，NIT）时安全接入 BDP 当前自动攻击属性，同时在 NIT 缺失、版本不兼容或运行异常时保持 BDP 和 NIT 原逻辑可用。

**Architecture:** 把当前自动攻击的最终属性抽成 Core 可读取的中性快照；原版信息面板继续把快照转换成 `StatDrawEntry`（原版信息条目），新的 Compatibility 程序集把快照转换成 NIT 的显示字段。Compatibility 只依赖 Core，不编译引用 NIT，通过运行时发现和动态 Harmony（运行时补丁）安装 NIT 适配器。

**Tech Stack:** C# 7.3、.NET Framework 4.8、RimWorld 1.6、Verse/RimWorld、Harmony、PowerShell smoke tests（冒烟测试）、`dotnet msbuild`。

### Task 4: 实现 NIT 可选发现和动态补丁

**Files:**
- Create: `Source/BDP.Compatibility/NiceInventoryTab/NiceInventoryTabAdapter.cs`
- Create: `Source/BDP.Compatibility/NiceInventoryTab/NiceInventoryTabDiscovery.cs`
- Create: `Source/BDP.Compatibility/NiceInventoryTab/NiceInventoryTabPatches.cs`
- Create: `Source/BDP.Compatibility/NiceInventoryTab/NiceInventoryTabProjectionAdapter.cs`
- Create: `Source/BDP.Tests/NiceInventoryTabCompatibilitySmokeTests.ps1`

**Step 1: Write the failing test**

测试静态安全边界：

- NIT 包名使用 `Andromeda.NiceInventoryTab`。
- NIT 类型通过运行时发现，不进入 C# 参数和工程引用。
- 缺少程序集、类型、方法或参数签名时返回禁用状态。
- 普通物品不进入 BDP 投影。
- BDP 快照缺失时保留 NIT 原返回值。
- 适配器只安装自己的 Harmony ID，不执行全局取消补丁。

**Step 2: Run test to verify it fails**

```powershell
pwsh -NoProfile -File .\Source\BDP.Tests\NiceInventoryTabCompatibilitySmokeTests.ps1
```

Expected: FAIL，因为 NIT 适配器尚不存在。

**Step 3: Write minimal implementation**

实现以下边界：

1. `NiceInventoryTabDiscovery`：检查运行模组包名、已加载程序集、程序集版本和目标方法签名。
2. `NiceInventoryTabAdapter`：所有必需目标确认后才动态安装补丁；未确认版本不安装。
3. 数据补丁：在 NIT 装备数据刷新边界读取 BDP 当前小人自动攻击快照，映射 NIT 已有数值字段。
4. 类型补丁：在 NIT 远程/近战显示分支边界使用快照模式，不改触发体 `ThingDef`。
5. 失败回退：目标不是 BDP 触发体、没有有效表达、投影异常或 NIT 调用异常时，保持 NIT 原逻辑。
6. 防递归：适配器直接读取 Core 快照，不调用 `SpecialDisplayStats`。
7. 多击近战：使用 BDP 快照中的攻击次数、连击间隔和完整周期 DPS，不读取触发体占位工具。

如果当前 NIT 版本的私有字段无法安全覆盖，适配器宁可只安装数据读取补丁并关闭类型补丁，也不复制 NIT 整套绘制界面。

运行同一 PowerShell 测试，Expected: PASS。
