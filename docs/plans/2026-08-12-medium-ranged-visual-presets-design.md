# BDP 中型远程枪械标准视觉预设设计

## 目标

将已经通过游戏内观察的突击步枪与霰弹枪视觉参数提炼成正式、可继承的中型枪械标准。具体武器默认只填写自身贴图，姿态、缩放、握持点和枪口点由标准预设提供。

## 分层

### 中型枪械单武器基准

- `DrawScale（绘制缩放） = 1`
- `GripOffset（握持点局部偏移） = (0, 0, -0.1953125)`
- `MuzzleOffset（枪口局部偏移） = (0, 0, 0.48828125)`
- `IsRangedWeapon（远程武器标识） = true`
- 不声明自定义姿态，继续进入 `ReplaceTextureOnly（仅替换贴图）` 路径，因此握持点只是贴图规格数据，不参与单武器定位。

### 中型枪械双武器基准

继承单武器基准，并补充：

- 南北偏移 `(0.24, 0, 0.03)`
- 南北装饰角 `6` 度
- 静默状态强制手侧镜像
- 东西共同偏移 `0.04`
- 东西前后手横向差 `0.03`
- 东西景深差 `0.10`
- 前景／背景绘制层差 `+0.05 / -0.05`
- `UseAsPoseOrigin（使用握持点作为姿态原点） = true`

### 具体武器预设

突击步枪和霰弹枪各保留单武器与双武器两个具体 `Def（定义）`。这些条目继承对应抽象基准，只声明 `defName（定义名）`、显示标签和自己的 `GraphicData（主贴图）`。

## 边界

- 不包含贴图资源本身，也不修改枪口闪光尺寸。
- 不把业务审美数值写入 `Core.dll（核心程序集）`；全部使用 RimWorld 原版 XML 继承完成。
- 不修改正在进行中的动作阶段视觉设施。
- 继承后解析出的最终行为和现有突击步枪／霰弹枪表现保持一致。
