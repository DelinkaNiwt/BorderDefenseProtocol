# 芯片详情档案式布局 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将右栏芯片详情中的介绍与规格合并为一张紧凑的档案式信息卡，完整利用已解析的描述、Profile.Tags、激活条件和最终表达消耗数据。

**Architecture:** 保留 `Panel_ChipDetail` 的标题、滚动和选择职责，只收紧 `ChipInformationDetailRenderer` 的玩家向概览布局。概览采用外框加分隔线，不再绘制“芯片介绍/芯片规格”两个独立板块，也不显示槽位区域、槽位占用、常驻占用、激活成本或旧通道标签；表达通道、图表和上下文区域继续由现有白名单布局负责。

**Tech Stack:** RimWorld 1.6 C#、Verse `Widgets`/`DefDatabase`、现有 `ChipInformationModel`、PowerShell 静态契约测试、`dotnet msbuild`。
