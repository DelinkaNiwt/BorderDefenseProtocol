# Trion 潜在容量与检测系统实施计划（第一版）

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在主模组内为所有人形 Pawn（角色）建立永久潜在 Trion 容量，以正式腺体基因解锁精确容量与使用资格，并提供固定式、一次性便携式双人检测流程。

**Architecture:** 不增加新 Comp（组件），潜在容量与检测记录直接归属现有 `CompTrion`。概率、档位与设备参数由 Def（定义）承载；基因通过原版 Stat（属性）体系把潜在容量投影为实际容量；两种检测设备共用资格检查与结果提交服务，只在工作入口和设备消耗上分流。

**Tech Stack:** RimWorld 1.6、Biotech（生物科技）、C# 7.3、Verse/RimWorld Job（工作）与 Stat（属性）体系、XML（可扩展标记语言）、PowerShell（命令行脚本）烟测、`dotnet build`（.NET 编译）。

```csharp
public int Generate(TrionPotentialDistributionDef def)
{
    float roll = Rand.Value;
    if (roll < def.jackpotChance)
    {
        return def.maximumCapacity;
    }

    if (roll < def.jackpotChance + def.exceptionalChance)
    {
        return GenerateBiasedRange(4000, 4900, def.quantizationUnit);
    }

    if (roll < def.jackpotChance + def.exceptionalChance + def.geniusChance)
    {
        return GenerateBiasedRange(3000, 3900, def.quantizationUnit);
    }

    return GenerateCoreCapacity(def);
}
```

普通主体先抽样、后量化；超出 `100～2900` 时重新抽取，不把越界值夹到边界。稀有区间使用向下部倾斜的抽样，并在代码旁注释其玩家体验目的。

```csharp
public TrionAssessmentResult TryCommit(Pawn operatorPawn, Pawn subject)
{
    TrionAssessmentResult eligibility = CanAssess(operatorPawn, subject);
    if (!eligibility.Succeeded)
    {
        return eligibility;
    }

    ITrionCommands commands = TrionSurfaceAccess.ResolveCommands(subject);
    if (commands == null || !commands.TryMarkPotentialAssessed())
    {
        return TrionAssessmentResult.Fail("Trion 检测记录提交失败。");
    }

    TrionAssessmentBandDef band = resolver.Resolve(commands.PotentialCapacity);
    return TrionAssessmentResult.Success(band);
}
```

