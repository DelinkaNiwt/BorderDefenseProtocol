# 语义上下文接入计划（第一版）

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让当前 BDP 主链能把攻击行为名传到伤口来源名，第一轮只覆盖近战直伤、远程投射物直伤、投射物爆炸三条链。

**Architecture:** 第一轮优先用 BDP 自定义 `Verb`、`Projectile` 子类做语义承载宿主。只在原版最终伤口写入点没有正式扩展口时，才允许使用一个最小 patch 接线。

**Tech Stack:** C#, RimWorld Mod, DefModExtension, 原版 `Verb/Projectile/DamageWorker_AddInjury`, Harmony 仅作最后候选接线
