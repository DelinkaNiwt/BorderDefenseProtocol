# 光魂运行时问题修复设计

## 问题

1. 光魂成品名与重刃手动攻击按钮仍显示英文。
2. 姿态切换已写入槽位真值，但正式投影快照漏掉姿态键，导致大盾始终按默认灵活姿态发布。

## 设计

- 为动作预设和表达条目提供可选 Keyed（键值语言包）键；已填写语言键时解析当前语言文本，旧内容未填写时沿用原显示名。
- 光魂成品名和重刃攻击入口改用显式语言键，避免依赖当前未生效的自定义 DefInjected（定义注入翻译）嵌套路径。
- 克隆投影槽位时同时复制当前形态键和当前姿态键，使姿态对应的 Hediff（健康状态）及其全部效果进入同一次正式发布。

## 边界

- 不调整光魂伤害、格挡概率、角度、移动速度、禁止攻击规则及切换时序。
- 不修改其他芯片；新增语言键字段为空时保持既有行为。
