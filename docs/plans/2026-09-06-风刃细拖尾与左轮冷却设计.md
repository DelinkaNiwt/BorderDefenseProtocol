# 风刃细拖尾与左轮冷却设计

## 目标

为风刃建立独立的光束拖尾预设，在保持当前亮薄荷绿长拖尾外观参数基本一致的前提下，将光束宽度减半；同时将左轮手枪武装构型的远程冷却时间调整为 2 秒。

## 现状

- 风刃投射物当前引用通用预设 `BDP_TrailPreset_BrightMintLong`。
- 通用长拖尾的 `trailWidth` 为 `0.1105`。
- 左轮手枪武装构型 `BDP_ArmamentForm_Revolver` 的 `overrides.defaultCooldownTime` 当前为 `1.5`。

## 方案

1. 在 Content 层 `BeamTrailDef/Presets.xml` 新增 `BDP_TrailPreset_FujinLong`。
2. 新预设复制 `BDP_TrailPreset_BrightMintLong` 的贴图、颜色、寿命、透明度、淡出、偏移和调试配置，仅将 `trailWidth` 设置为 `0.05525`。
3. 将风刃投射物的拖尾扩展改为引用 `BDP_TrailPreset_FujinLong`，不改变通用预设，避免影响其他投射物。
4. 将左轮手枪的 `defaultCooldownTime` 改为 `2.0`，不改变其射程、伤害倍率、预热、连射和其他字段。

## 边界

- 不增加运行时代码字段，不改变 Core 或拖尾绘制逻辑。
- 不修改其他投射物、武装构型或视觉资源。
- 通过现有 PowerShell 冒烟测试锁定预设引用、预设参数复制关系、宽度减半和左轮冷却值。
