# 表达系统公开读取面收口 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在主模组里补一套公开、只读、四通道统一的表达读取面，并提供对应的 live 宿主解析口。

**Architecture:** 公开层只负责读，不承担计算与同步。内部投影继续由现有表达系统生成，公开层只把已发布投影转成不可变快照，再按通道解析 live 宿主。

**Tech Stack:** RimWorld 1.6 Mod、C#、现有 BDP 主模组、PowerShell 编译验证
