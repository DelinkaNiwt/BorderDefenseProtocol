# 攻击上下文主干重构实施计划-第一版

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把攻击链路里分散的上下文、确认快照、模块私有快照、临时共享状态，重构成一条统一的 `AttackContext（攻击上下文） -> AttackContextSnapshot（攻击上下文快照）` 主干，并删除旧碎片通路。

**Architecture:** 主模组只提供统一上下文的创建、传递、冻结、存读档与读取入口；模块自己写入节点、自己读取节点、自己把节点解析成正式阶段贡献。所有旧碎片上下文对象不做兼容双轨，直接迁移或删除。重构后，前半段只传 `AttackContext`，后半段只读 `AttackContextSnapshot`。

**Tech Stack:** RimWorld 1.6、C#、Verse / RimWorld API、PowerShell smoke tests、UTF-8 中文文档。

---

## 总原则

- 不为任何具体业务设计字段。
- 不新增复杂总线、事件系统、注册中心。
- 不保留旧通路与新主干长期并存。
- 不让投射物后半段继续依赖运行时会话。
- 不改变阶段贡献边界，只改变跨阶段信息主干。
- 坏现有功能就算重构失败，不能靠兼容补丁掩盖。
