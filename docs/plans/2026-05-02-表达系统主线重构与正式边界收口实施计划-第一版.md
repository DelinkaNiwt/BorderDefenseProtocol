# 表达系统主线重构与正式边界收口 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 清理表达系统主线的正式边界，收回 `RuntimePayload` 到内部材料层，修正 combo 内部取材路径与 `CombatBodyEmergencyEscape` 的复合来源消费，并让烟测、DevHarness、文档重新对齐同一套架构事实。

**Architecture:** 保留当前统一芯片条目解释器，不给 combo 另开第二套 parser。实现上把 `RuntimePayload` 从 `FormalExpressionResult` 和 `BdpFormalVerbBindingState` 收回，只在 `ExpressionSourceMaterial` 保留；combo 复合构建改为直接读取内部来源材料；下游继续只读 `FormalExpressionResult + CompositeExpressionReference + TriggerCombatProjectionState` 这组正式面。

**Tech Stack:** RimWorld 1.6 Mod、C#、XML Def、PowerShell 烟测、BDP 主模组与 DevHarness
