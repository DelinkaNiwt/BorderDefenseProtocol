# 光魂大盾复用真实双武器设计

## 目标

撤回为“非武器手持视觉”新增的通用表达设施。光魂大盾改用现有近战武器表达取得真实武器身份，从而自然进入既有双武器关系、主副手姿态和绘制链。

## 设计结论

1. Core（核心层）恢复到 `25c7ab2a` 后既有的武器视觉判定，不保留 `ParticipatesInHandheldVisualRelation`（参与手持视觉关系）或第二套手持来源计数。
2. 光魂每种盾姿态仍保留原 `Hediff`（健康状态）表达，继续负责抵挡、减速、禁攻和受击回弹。
3. 大盾形态公共激活一条真实 `PrimaryVerb`（主攻击行为）近战表达，使用 5 点 `Blunt`（钝伤）`Tool`（攻击工具）。该表达只提供武器身份与攻击能力，不重复声明盾面视觉；两种姿态不复制武器条目。
4. 盾面视觉继续挂在原 `Hediff` 结果上，保证既有抵挡回弹仍按原结果标识命中。
5. 盾面 `Hediff` 视觉使用既有 `CompositeVisualPresetDefName`（复合视觉预设名称）能力，在双武器关系下切换到光魂专用双持预设。双持预设只调整盾面向手侧外移，保持举盾贴图竖直；不修改通用姿态解析器。
6. 灵活、举盾两个姿态共用一条无视觉武器表达；二者各有一个复合视觉预设，因为贴图、尺寸和角度不同，不能共用视觉参数。

## 数据流

```text
光魂盾姿态
  ├─ Hediff 表达：防御机制 + 盾面视觉 + 抵挡回弹
  └─ Melee Verb 表达：5 点钝伤 + 真实武器身份
                         │
                         └─ 与另一枚枪械芯片形成既有 DualWeapon 关系
                                              │
                                              ├─ 枪切换现有双持预设
                                              └─ 盾切换光魂双持预设
```

## 边界

- 不新增 Core 字段、计数器、绘制入口或通用回退规则。
- 不把防御逻辑迁入武器；盾击表达仅承担真实近战武器职责。
- 不修改双枪、其它武器、普通能量盾或原版装备绘制。
- 举盾姿态现有 `Violent`（暴力工作）禁用继续生效，因此举盾时盾击会服从既有禁攻约束。

## 验证

- 测试必须确认旧通用字段和手持来源计数已移除。
- 大盾形态必须公共激活唯一 5 点钝伤武器表达，两种姿态只切换各自 `Hediff`。
- 盾击武器不得重复绘制盾面；盾面视觉仍由原 `Hediff` 结果提供。
- 两个盾面视觉必须声明复合预设，举盾复合预设继续保持竖直。
- Core Release（核心程序集发布）编译和既有双武器、光魂格挡反馈回归必须通过。
