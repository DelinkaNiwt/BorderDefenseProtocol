# RimWorld 武器预览贴图设计

## 目标

根据 `C:/NiwtDatas/Projects/RimworldModStudio/日志/QQ20260518-145300.png` 中的武器身份，生成一张 512×512 的 RimWorld 原版风格预览图。结果只用于当前对话展示，不放入模组项目贴图目录。

## 输入与身份锚点

- 图片角色：Image 1 为物体身份参考，不作为风格或背景参考。
- 主体：单件长轴科幻步枪，枪口朝右，后部组件在左。
- 必须保留：横向长枪身、上方凸起组件、中央深色枪管/导轨、下方握把、下挂弹匣，以及红黑主体关系。
- 不继承：截图中的 UI 背景、环境反射、青色外描边、文字、界面元素和摄影透视。

## 视觉方案

- 视角：稳定的正侧视轮廓；不显示另一侧、枪身顶部或底部厚度，不使用动态倾斜和强透视。
- 风格：RimWorld 原版二维手绘装备贴图；深灰至近黑外轮廓，较弱内部线，低饱和大色块，硬边明暗。
- 细节预算：按逻辑 128×128 设计，再清晰放大到 512×512；优先保证缩略图下的剪影识别。
- 结构密度：约 2–6 个主要结构块；不添加无身份作用的机械细节、灯条、装甲分面或附件。
- 颜色：暗红/砖红主体、深灰至近黑功能结构，最多保留少量浅色功能强调；不使用大范围发光。
- 构图：单件完整武器居中，四周留白稳定。

## 输出与验收

- 输出：512×512 PNG，纯白背景。
- 禁止：阴影、地面、底座、人物、手、文字、水印、粒子、大范围光晕和复杂 3D 渲染。
- 验收：第一眼先读到外形轮廓；128×128 与 64×64 缩小检查仍可识别；白色四角无阴影或半透明残留。
- 保存策略：生成结果保留在内置图片生成结果位置并在对话中展示，不复制到 `BorderDefenseProtocol` 项目目录。

## 生成流程

1. 将 Image 1 作为物体身份参考提交给内置 `imagegen`。
2. 生成一版，并按轮廓、视角、颜色、背景和禁用项检查。
3. 若需要迭代，只修改一个明确问题，并保持已确认的身份轮廓与构图不变。
