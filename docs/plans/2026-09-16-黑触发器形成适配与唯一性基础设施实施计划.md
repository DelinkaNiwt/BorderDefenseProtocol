# 黑触发器形成、适配与世界唯一基础设施实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal（目标）：** 在不预先决定风刃、卵之冠具体形成路线的前提下，为 BDP 实现可配置、可存档、可诊断的黑触发器形成、玩家选择、世界唯一、适配与绑定基础设施，并提供可读的完整系统目录。

**Architecture（架构）：** `BDP.Content` 承载全部正式业务；`BDP.Core` 不增加黑触发器概念；`BDP.Development` 只调用 Content 的结构化判定结果，提供只读诊断和上帝模式测试入口。死亡入口只做一处带 BDP 准入判断的 `Pawn.Kill` 补丁，形成、候选、唯一性和最终生成分别由小型服务负责。

**Tech Stack（技术栈）：** RimWorld 1.6、Royalty（皇权）、Biotech（生物科技）、C#、Harmony（和声补丁库）、XML（可扩展标记语言）、PowerShell（命令行脚本）、原版 `ChoiceLetter`（选择信件）、`GameComponent`（存档级组件）、`CompBiocodable`（生物编码组件）。

---

## 一、执行边界

- 直接在当前工程执行，不新建分支或 worktree（工作树）。
- 每项任务先写会失败的定向烟雾测试，再做最小实现，再验证并单独提交。
- 只提交本任务明确列出的文件；不得整理工作区中的其它未提交内容。
- 不向 `BDP.Core` 增加黑触发器专用类型、注册表或接口。
- 不在本计划内给风刃、卵之冠填写具体倾向、形成路线、最终意志或适配规则。
- 不把临时测试 `Def`（定义）留在正式 `Content` 或发布包中。
- 若原版 1.6 的真实接口与本计划中的预期不同，先更新本文对应步骤并说明证据，不用 Harmony（和声）补丁掩盖接口误判。

