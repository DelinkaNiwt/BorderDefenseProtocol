# BDP终局统一重构执行核对清单

## 使用方式

- 每进入一个模块施工前，先把对应条目过一遍。
- 每完成一个模块施工后，立刻回填结果。
- 若某条不能满足，必须记录阻塞原因和保留理由，不能口头跳过。

---

## 一、全局红线

### 1. 模块边界

- [x] 不重画 `Expressions / Trigger / CombatBody / AttackExecution / Chips / Trion` 六大边界
- [x] 不把多个核心模块揉成一个大模块

### 2. 允许存在的对象类型

- [x] `Service`
- [x] `State/Model`
- [x] `Policy/Rule`
- [x] `Bridge/Host`
- [x] `Contract`

### 3. 禁止默认存在的对象类型

- [x] `Default*`
- [x] `Surface*`
- [x] `Access*`
- [x] `Formal*`
- [x] `Pipeline*`
- [x] 模块内单实现自用 `I*`

### 4. 真值要求

- [x] Expression 真值装配点明确
- [x] Trigger 状态真值持有点明确
- [x] CombatBody 相位真值持有点明确
- [x] AttackExecution 运行时消费模型明确
