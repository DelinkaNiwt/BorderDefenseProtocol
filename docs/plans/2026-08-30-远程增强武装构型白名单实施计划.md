# 远程增强武装构型白名单 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 BDP 开放式远程模块增强增加通用来源构型白名单，并让“铅弹·改”暂时只对左轮手枪构型生效。

**Architecture:** 在 Core（核心层）的 `RangedModuleAugmentationConfig` 增加中性的 `AllowedSourceVariantKeys` 列表；空列表保持不限制，非空列表要求目标结果的 `SourceVariantKey`（来源变体键）命中。由现有 `ExpressionAugmentationResolver`（表达增强解析器）统一执行构型筛选，并与已有侧别范围判断组合。Content（内容层）只在铅弹·改 Def 中填写 `BDP_GunClass_Revolver`，不把历史 `GunClass` 重命名混入本次任务。

**Tech Stack:** C# 7.3、.NET Framework 4.8、RimWorld 1.6 Def/XML、PowerShell 冒烟测试、`dotnet msbuild`。

---

### Task 2: 实现 Core 构型白名单

**Files:**
- Modify: `Source/BDP/Core/Expressions/Config/RangedModuleAugmentationConfig.cs`
- Modify: `Source/BDP/Core/Expressions/Pipeline/ExpressionAugmentationResolver.cs`

**Step 1: Add minimal configuration**

在配置类加入 `List<string> AllowedSourceVariantKeys`，默认空列表；在 `Clone()` 中复制字符串列表，避免快照共享可变配置。

**Step 2: Add minimal resolver filtering**

在现有 `IsApplicable`（适用性判断）中增加构型条件：

- 空列表返回允许。
- 非空列表只接受 `target.SourceVariantKey` 命中任一键。
- 继续复用已有复合结果来源引用和侧别判断。
- 不引用 `ChipArmamentFormDef` 或任何铅弹标识，保持 Core 中性。
