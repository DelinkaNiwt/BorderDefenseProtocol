# 光魂举盾攻击按钮灰显实施计划

**目标：** 当现有攻击准入规则拒绝某个 BDP 手动攻击时，对应按钮提前灰显并显示同一拒绝原因。

**范围：** RimWorld 1.6、1.7，共享 Core 源码。用户已批准由 Core 通用按钮生成器读取 `AttackAdmissionAccess`，因此任何当前注册规则拒绝的 BDP 手动攻击按钮都会投影为禁用状态。

## Task 1：接入通用攻击准入显示

**文件：** `Source/BDP/Core/Expressions/Projection/DefaultManualEntryGizmoResolver.cs`

在现有 `BuildCommand` 按钮状态判断中保留原版禁止暴力检查，然后调用：

```csharp
AcceptanceReport attackAdmission = AttackAdmissionAccess.Evaluate(pawn, targetingSource.GetVerb);
```

若 `Accepted` 为 false，使用 `command.DisableForUseRequirements(attackAdmission.Reason)` 并跳过 Combo 条件检查；若通过，继续执行当前 Combo 使用条件判断。这样光魂举盾拒绝原因来自既有内容规则，Core 不添加业务判断或新文案。

更新该处已有中文注释，准确说明三个条件的检查顺序。保持改动局限于按钮生成器。
