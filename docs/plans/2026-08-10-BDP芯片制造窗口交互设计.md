# BDP 芯片制造窗口交互设计

## 结论

芯片制造编辑器不再作为 `ITab`（检查页签）显示。玩家选中芯片制造台后，通过底部 Gizmo（命令按钮）打开独立 `Window`（窗口）。

## 交互

- 制造台提供“芯片制造”命令按钮。
- 点击后打开唯一的芯片制造窗口；重复点击不叠加窗口。
- 窗口默认居中并允许拖动。
- 窗口尺寸略小于旧面板，并限制在当前 UI（用户界面）安全范围内。
- 打开窗口期间使用原版窗口暂停机制暂停游戏；关闭后由原版恢复先前时间状态。
- 切走制造台不强制关闭窗口；窗口保留对打开时制造台的引用，建筑失效后禁止提交订单。

## 内容与边界

- 保留既有三栏编辑、预览、材料数量和真实账单队列。
- 移除建筑 Def（定义）上的制造检查页签。
- 将页签绘制逻辑迁入 Content（内容程序集）的专用窗口，不触及 Core（核心程序集）。
- 不增加窗口尺寸记忆、玩家缩放选项或额外入口。

## 验证

- 自动检查入口已由检查页签改为 Gizmo（命令按钮）。
- 自动检查窗口具备居中、可拖动、屏幕尺寸限制与强制暂停属性。
- Release（发布版）编译与既有芯片制造测试全部通过。
- 游戏内复测窗口在当前分辨率和 UI 缩放下完整可见、可拖动且打开时暂停。
