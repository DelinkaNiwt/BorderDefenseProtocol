# 黑触发器形成窗口界面调整设计

## 目标

按截图参考收紧黑触发器形成决策窗口的信息层级，让界面只展示玩家需要阅读和选择的内容，不暴露“本次匹配”过程。

## 调整规则

- 移除侧重卡片中的路线匹配依据明细。
- 移除继承特性说明文本，只保留可选特性名称。
- 移除标题中的“可不指定/可不继承”括号文案和底栏未决红色状态文案。
- “不指定传承人”放在传承人列表第一项，并在事件创建时默认为选中。
- 左栏把全部技能和经历放入同一份“生命印记资料”，不再区分本次匹配资料和其它优势。
- 右栏侧重名称与简介同行显示；传承人详情仍保留原有关系、好感和位置信息。

## 实现边界

只修改 `Window_BlackTriggerFormationDecision` 的绘制和默认选择初始化，以及对应语言文本和回归烟测；不改变形成匹配、权重、候选分配、最终化事务或存档字段语义。默认传承人使用现有 `None` 哨兵值，旧存档打开窗口时空值也迁移为该默认值。

## 验证

- 形成窗口回归烟测确认红框文本和匹配分组不再绘制。
- 确认“不指定传承人”默认选中并位于第一项。
- 确认侧重简介同行绘制，玩家决策仍可正常确认。
- 编译 Content 程序集并运行全部 BlackTrigger 烟测、语言键和 XML 检查。
