# 开发者精确部位移除触发体 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 `Development`（开发内容）中提供一个可由开发菜单直接生成、固定预装精确部位移除芯片的触发体；攻击前用现有形态按钮选择左手、右手等具体部位，直接命中 Pawn（角色）后按预选身份移除该部位。

**Architecture:** `Core.dll`（核心程序集）不改。`Content.dll`（正式内容程序集）只给现有 `RangedDebuffModule`（远程减益模块）补充通用的 `BodyPartDef + OccurrenceIndex`（身体部位定义与完整树出现序号）解析；`Development.dll`（开发程序集）只提供生成入口；全部测试定义位于 `1.6/Development`。芯片使用一个公共射击条目和按形态启用的被动远程增强条目，复用现有形态、远程模块增强、固定装载、Hediff（健康状态）阈值动作和原版 `MissingBodyPart`（部件缺失）机制。

**Tech Stack:** RimWorld 1.6、C#、XML（可扩展标记语言）Def、PowerShell 烟测、MSBuild（微软构建引擎）

---

- 直接在当前工程执行，不建立 worktree（工作树）或新分支。

- 不添加 Harmony（运行时补丁），不修改旧版模组和退役测试模组。
