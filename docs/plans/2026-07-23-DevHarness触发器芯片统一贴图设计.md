# DevHarness 触发器芯片统一贴图设计

## 目标

将新 BDP 伴生测试模组中的 17 个芯片物品统一改用用户提供的芯片图片。只调整物品贴图，不修改游戏内名称、功能或数值。

## 方案

1. 将源图片按原像素复制为 `BDP_TriggerChip.png`，放入 DevHarness 的 1.6 版触发器芯片贴图目录。
2. 将所有直接继承 `BDP_ChipBase` 的芯片物品 `texPath` 统一改为 `Things/Trigger/Chip/BDP_TriggerChip`。
3. 不覆盖弧月手柄等表达视觉贴图，避免芯片物品图标改动影响武器外观。
4. 不修改主模组代码或通用架构。

## 验证

1. 校验目标图片与源图片的 SHA-256（安全散列算法 256 位）一致。
2. 校验全部芯片定义均指向统一路径，数量仍为 17。
3. 解析涉及的 XML（可扩展标记语言）文件，确认格式有效。
4. 运行相关芯片定义烟雾测试。
