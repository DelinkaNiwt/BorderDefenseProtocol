# 双武器姿态与锚点对齐修正设计

## 已确认问题

1. 霰弹枪双武器预设最后一次改为 `(0.24, 0, 0.03)`，突击步枪双武器预设仍保留 `(0.20, 0, 0.12)`，混合双持时两侧握持目标不一致。
2. 握持锚点按最终贴图角度和网格镜像解算，但枪口锚点仍按旧的 `aimAngle`（瞄准角）单独旋转。因此应用 `6` 度装饰角或手侧镜像后，贴图与枪口点会分离，镜像侧甚至落到枪尾方向。

## 修正边界

- 将突击步枪双武器 `DefaultOffset`（默认偏移）同步为 `(0.24, 0, 0.03)`。
- 枪口锚点改用与握持锚点相同的最终贴图局部坐标变换：最终 `DrawAngle`（绘制角度）加最终 `MeshKind`（网格种类）。
- 保留 `MuzzleOffset`（枪口偏移）、副侧显式覆盖和 `ExtraWorldOffset`（额外世界偏移）的既有配置面。
- 不调整岚贴图的握持锚点；它与贴图握把不严格重合仍按此前约定接受。
- 单武器绘制仍走原版姿态替换路径，不引入双武器姿态。

## 验证

- 结构回归断言 `VisualPoseResolver`（视觉姿态解析器）的枪口成员复用唯一的最终贴图局部变换，并拒绝旧瞄准角平行公式；Unity（游戏引擎）四元数内部调用无法由当前 PowerShell 反射载体可靠执行，因此不伪造运行时断言。
- 配置测试断言突击步枪与霰弹枪的双武器偏移一致。
- 构建 Core.dll（核心程序集）并运行现有握持、镜像、枪口、参考视觉回归测试。
