# BDP 芯片信息设施路线 E：正式原版武器投影与信息卡接入实施计划

> **For Claude（供执行代理）:** REQUIRED SUB-SKILL（必须使用的子技能）: Use superpowers:executing-plans to implement this plan task-by-task（使用 executing-plans 技能逐项执行本计划）。

**Goal（目标）：** 让成品芯片在原版物品信息面板中按正规化契约的实际能力显示原版近战/远程统计；普通 BDP 信息通过统一信息模型追加；没有可执行武器表面的芯片不生成武器统计。

**Status（状态）：** 已完成源码接入、边界测试和 Release 编译；游戏内人工调试仍待执行。

## 一、边界与不变量

- Core（核心程序集）只提供中性的临时原版武器表面工厂和原版统计读取适配，不识别制造分类、职业或窗口。
- Content（内容程序集）负责成品芯片信息卡发布，读取统一 `ChipInformationModel`（芯片信息模型）和 `ChipExpressionResolvedContract`（正规化表达契约）。
- `CompManufacturedChip.SpecialDisplayStats()` 只负责接线，不重新解析组合记录。
- 远程/近战能力只由 `ChipExpressionCapabilityResolver`（表达能力解析器）判定；远程增强模块不能单独生成武器条目。
- 原版武器统计通过 `ThingDef.SpecialDisplayStats` 和原版 `StatWorker` 生成，不复制原版公式。
- 临时定义不注册 `DefDatabase`（定义数据库），不生成物品，不进入地图、容器或存档，不做持久缓存。
- 普通 BDP 字段只发布稳定白名单中的可用标量字段；列表、上下文、来源链和诊断保留给 BDP 专用详情界面，避免信息卡膨胀。

## 二、实施任务

### 任务 1：抽取 Core 原版表面设施

- 新增 `VanillaWeaponStatSurface`（原版武器统计表面）。
- 新增 `VanillaWeaponStatSurfaceFactory`（原版武器统计表面工厂），把正规化近战 Tool 或远程 Verb 映射为未注册临时 `ThingDef`。
- 新增中性的原版统计读取适配，集中调用 `SpecialDisplayStats`、`MeleeWeapon_AverageDPS` 和 `MeleeWeapon_AverageArmorPenetration`。
- 将 Development 路线 D 诊断改为复用该设施，删除重复的临时定义构造和原版调用代码。

### 任务 2：新增 Content 信息卡发布器

- 新增 `ManufacturedChipInfoCardPublisher`（成品芯片信息卡发布器）。
- 从成品组件通过中性接口读取当前有效配置；用 `ChipExpressionContractSurfaceAccess` 取得正规化契约。
- 普通说明从 `ManufacturedChipInformationModelBuilder` 取得模型，只发布明确白名单中的标量字段，并使用字段语言键、单位语言键和已有格式化器。
- 对每个可执行远程/近战条目调用 Core 原版表面工厂；原版生成的 `StatDrawEntry`（属性显示条目）原样返回。
- 多条武器表面按稳定契约顺序发布；同一条目不得同时伪造近战和远程表面。

### 任务 3：接入成品组件

- 在 `CompManufacturedChip.SpecialDisplayStats()` 先保留基类条目，再追加发布器结果。
- 无组合记录、解析无效、只有增强模块或没有可执行表面时安全返回，不影响物品信息面板其它条目。
- 所有异常限制在发布器边界内，必要时写 Development 诊断日志；正式面板不显示内部异常文本。

### 任务 4：测试、文档与验收

- 新增 Core/Content 边界测试：依赖方向、能力判定、原版调用入口、无能力不发布、无 DefDatabase 注册。
- 编译 Core、Content、Development Release，并重跑路线 C、D 与信息模型相关测试。
- 更新全局规划和本计划状态，记录新 Agent 工作日志并提交。
- 游戏内人工验收至少覆盖：远程芯片、近战芯片、只有远程增强芯片、普通非武器芯片，以及同芯片同时包含两类表面的组合；人工结果单独记录，不以静态测试替代。

## 三、明确不在本路线实施的事项

- 不处理多形态当前状态的最终策略；默认读取契约当前解析出的主表面，复杂状态留给路线 F。
- 不拆分装配台的大型渲染器；路线 G 只做维护性内部拆分。
- 不增加缓存、Harmony Patch（运行时补丁）或公开外部模组专用接口。
- 不把所有信息模型字段强行压入原版信息卡；详细层级继续由装配台和 BDP 专用详情界面承载。

## 四、完成标准

- 成品芯片原版信息面板能看到原版生成的远程统计或近战平均统计。
- 只有增强声明、没有可执行近战/远程表面的芯片不出现武器统计。
- 普通 BDP 说明与武器原版统计互不冒充，且字段显示来自统一信息模型。
- Core 不依赖 Content/Development；Development 诊断和正式 Content 发布器不再各自复制临时表面构造。
- 临时定义始终未注册，面板关闭后无持久状态残留。
