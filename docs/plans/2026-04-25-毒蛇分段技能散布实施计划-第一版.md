# BDP PathLatch Per-Leg Skill Spread Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make every PathLatch flight leg resample spread like the first leg while scaling continuation spread by the shooter's `Shooting` skill.

**Architecture:** Keep first-leg miss logic in `BdpVerb_Shoot`, but freeze an effective continuation spread radius during `ProjectileInit`. Reuse the existing per-leg snapshot pipeline, switch it from progressive segment scaling to full-radius per-leg resampling, and drive the frozen radius from XML-configurable low/high skill multipliers.

**Tech Stack:** C#, RimWorld `Verse` / `RimWorld`, BDP ranged module runtime, DevHarness XML defs, PowerShell smoke tests.
