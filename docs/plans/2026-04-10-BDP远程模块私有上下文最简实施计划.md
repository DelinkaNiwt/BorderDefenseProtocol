# BDP 远程模块私有上下文最简实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 BDP 远程模块系统补上一套最简、隔离、可冻结、可恢复的模块私有上下文机制。

**Architecture:** 每个模块挂载实例只拥有自己的私有上下文，不做默认共享；主模组只负责创建、顺链路传递、在 `ProjectileInitPlan` 前冻结，并在 `BdpProjectile` 上继续携带与恢复；模块仍然必须通过正式阶段贡献接入主逻辑。

**Tech Stack:** RimWorld 1.6、C#、Verse/RimWorld API、PowerShell smoke tests、`IExposable`、UTF-8 中文文档。

---

## 总原则

- 不设计共享上下文总线。
- 不设计业务专用上下文类型。
- 不增加复杂上下文 key 体系。
- 直接以模块挂载顺序作为上下文槽位身份。
- 主模组只传递与恢复，不解释内容。
- 私有上下文不能替代正式阶段贡献。

## 完成标准

- 每个模块挂载实例拥有自己的私有上下文；
- 私有上下文沿远程攻击链可持续传递；
- `ProjectileInitPlan` 前完成冻结；
- `BdpProjectile` 后半段继续消费冻结上下文；
- 已发射 projectile 的上下文可参与存读档恢复；
- 作者默认只能读写自己的上下文；
- 主模组不包含共享上下文总线和具体业务命名；
- 教学样例展示最小正确用法。
