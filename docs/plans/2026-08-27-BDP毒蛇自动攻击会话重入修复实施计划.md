# BDP 毒蛇自动攻击会话重入修复 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让活动中的 BDP 远程正式宿主拒绝新自动目标重入，并让失效目标在 Trion 扣除与投射物生成前终止发射。

**Architecture:** 保留原版 `Pawn.TryGetAttackVerb`（自动攻击入口）和 `ShotReport`（射击报告）作为基线。BDP 只在自动入口边界表达宿主所有权，在发射前使用通用目标生命周期检查；毒蛇路线和终端掩体计算不改。投射物初始化延后到原版射击报告与终端掩体裁定完成后。

**Tech Stack:** C#、Harmony、RimWorld 1.6、PowerShell smoke tests（烟测）、MSBuild。
