# 信息图比较基准实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让装配台信息图以同一远程芯片功能组合的 Trion 立方体默认构型最终结果作为比较基准。

**Architecture:** 在 `BDP.Content` 增加比较视图模型。成品详情入口复制组合记录并清空显式武装型，调用现有解析器获得默认构型的完整最终信息模型；渲染器通过稳定块/字段键读取这套基准，缺失时回退原始来源链基准。`BDP.Core` 保持不变。

**Tech Stack:** C# 7.3、RimWorld 1.6、Unity IMGUI、PowerShell 冒烟测试、MSBuild。
