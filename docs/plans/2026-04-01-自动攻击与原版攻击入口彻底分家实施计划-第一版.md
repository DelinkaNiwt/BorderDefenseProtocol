# 自动攻击与原版攻击入口彻底分家 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让原版武器声明面回归触发体本体，同时让 BDP 自动远程/自动近战独立读取表达系统默认主攻击并桥接到现有 AttackExecution。

**Architecture:** 本次不重造表达系统、AttackExecution 或手动入口系统。整改的核心只有两步：第一，把 `CompTriggerBody` 从“接管原版武器声明面”的角色上撤下来，让原版本体攻击自然恢复；第二，把两个自动攻击补丁改成读取 `ExpressionService` 已经给出的 `PrimaryRanged` / `PrimaryMelee`，并按类别分别决定“BDP 接管”或“完全回退原版”。

**Tech Stack:** RimWorld 1.6 C#, Verse `CompEquippable` / `VerbTracker` / `Pawn_MeleeVerbs`, Harmony patches, PowerShell smoke tests
