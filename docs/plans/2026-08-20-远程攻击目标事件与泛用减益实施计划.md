# 远程攻击目标事件与泛用减益实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 建立与攻击生产者解耦的通用攻击目标事件派发，让铅弹按每次真实目标判定追加减益，同时独立取消伤害。

**Architecture:** Core 提供通用目标事件模型、额外效果派发和“伤害取消时继续目标解析”策略。直接命中与范围爆炸只是现有目标生产入口；Content 的远程减益模块只订阅通用攻击目标事件并执行 Hediff。

**Tech Stack:** C#（C#语言）、RimWorld 1.6 原版伤害/爆炸入口、Harmony、XML Def、PowerShell 边界烟雾测试。
