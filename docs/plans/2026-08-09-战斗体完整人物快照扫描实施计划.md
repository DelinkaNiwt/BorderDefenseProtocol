# 战斗体完整人物快照扫描 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用换装前后两张原版完整人物最终画面替代逐件衣物重画，并在 10 tick 内沿扫描线互补交接。

**Architecture:** Content.dll 通过 RimWorld 原版 `PawnCacheRenderer` 捕获两张 128×128 完整人物快照，并用小型资源池管理渲染纹理与材质。扫描 Mote 短时替代目标 Pawn 的基础 `RenderPawnAt` 绘制，只绘制两张互补裁切快照和原有扫描光；旧衣物捕获、衣物节点抑制和逐件绘制整体删除。

**Tech Stack:** C# 7.3、RimWorld 1.6 `PawnCacheRenderer` / `PawnRenderer`、Unity `RenderTexture` / `Graphics.DrawMesh`、Harmony（运行时补丁框架）、PowerShell 冒烟测试、dotnet Release（正式）构建。

**执行约束:** 直接在当前 main（主线）执行，不创建 worktree（工作树）或新分支；不修改 `MirrorOriginal`（镜像原身）生成、复制和恢复成员。

```csharp
internal static bool ShouldSuppress(Pawn pawn)
{
    if (pawn == null || (Find.UIRoot != null && Find.UIRoot.HideMotes))
    {
        return false;
    }
    // 仅当前令牌未超时的 Pawn 返回 true。

}
```
