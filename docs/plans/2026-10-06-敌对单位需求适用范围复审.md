# 原“敌对单位”需求的适用范围复审

## 状态

复审后用户已确认并授权修正：资源简化与芯片即时启停按**非玩家派系人物（含无派系）**适用；手动按钮按当前玩家可控资格；自动战斗入口共用；剧情追兵行为仍为任务专属。修正已经实施，见[非玩家派系规则与自动近战修正](2026-10-06-非玩家派系规则与自动近战修正.md)。以下保留复审时的发现与建议，不再把未确认边界视为当前状态。

## 判定维度

1. **当前允许玩家下令**：沿用原版 `Pawn.IsPlayerControlled`（玩家可控）及任务允许征召条件。只用于手动操作权限；不可控不等于不可查看状态，也不等于外部人物。
2. **人物是否需要按玩家经营规则承担资源成本**：建议将外部自动管理人物与玩家需要经营的人物区分。敌人、盟友和中立访客都可能属于前者；玩家殖民者精神失常或离开地图后仍属于后者。具体边界尚待用户回复，不用当前可控资格直接取反决定经济规则。
3. **当前攻击是否自动执行**：可控殖民者也能自动开火、自动近战；自动入口不应依赖手动按钮，更不能被当成玩家强制命令。
4. **具体任务要求**：追兵携带入门物品、入场时处于战斗体、不撤退、崩解后原身继续死战与任务胜利条件，属于具体追兵任务，不能推广为所有不可控单位行为。

## 逐项结论

| 原需求 | 建议适用范围 | 当前实现与偏差 |
|---|---|---|
| 玩家不能操作敌人攻击、变身、模式、姿态、浮空及芯片槽位 | 所有当前玩家不可控人物 | 已改用原版统一控制资格，任务禁止征召也限制同类操作。不是仅敌方。 |
| Trion 容量、余量与容量潜力信息隐藏 | 建议纳入外部自动管理人物的信息规则，不跟随暂时失控变化 | 容量属性及潜力说明仅在当前敌对时隐藏；资源条另要求玩家派系。因此友好外部人物可能没有资源条，却仍可看到容量属性。这是待修正的范围不一致。 |
| 除伤口泄露外全部消耗免除 | 建议用于外部自动管理人物，玩家需要经营的人物保留成本 | 内容提供器只查询当前敌对关系；盟友与访客仍按普通规则扣攻击、启动、维护等费用。若目的为简化游戏自动管理人物，这一范围偏窄。 |
| 能量护盾拦截免耗 | 跟随上述资源成本规则，不另按敌方判断 | 走公共成本入口，架构接入正确，但继承敌对限定的范围问题。方向、概率等拦截条件不放行。 |
| 芯片预占用、战斗体正式占用及相位记录为零 | 跟随上述外部人物资源规则 | 有效金额与阶段账本已一致处理，但提供器仍限定当前敌对。暂时失控时突然改占用会改变战斗体运行条件，因此不宜直接取反当前控制资格。 |
| 芯片启停无等待 | 建议跟随外部自动管理人物规则 | 共同启停解析器已接入，内容规则仍只查询当前敌对；盟友与访客仍等待。 |
| Trion 保持有限真实容量，只因伤口泄露耗尽并崩解 | 简化资源宿主的运行规则；伤口、容量与崩解机制本身共用 | 内部真值未伪造无限值，免耗宿主空血不能重新启动。不是敌方专属的伤口或崩解系统。 |
| 正常使用远程、近战，自动攻击自然调用公共资源接口 | 所有进入自动攻击路径的人物，包含可控殖民者 | 公共攻击入口不限定敌方。近战接管丢失原版到期重新判断，并经玩家下令入口成为强制任务，是公共自动攻击缺陷，不是敌人专属战术问题。 |
| 生成时已处于真实战斗体状态 | 本任务追兵与对应实测对象的初始化要求 | 开发工具已先正式激活再落地图。不能据此让所有外部人物自动变身。 |
| 携带原型、死战不退、崩解后原身继续死战，击败追兵才完成任务 | 指定剧情追兵队伍 | 开发样本用不撤退的普通进攻队伍；正式追兵队伍与任务尚未实现，不能描述成公共非玩家行为。 |

## 额外发现：当前敌对不等于外部敌人身份

读取真实程序集 `RimWorld.GenHostility.HostileTo(Thing, Faction)`（物体当前是否对派系敌对，令牌 `0600D39F`）确认：人物精神状态强制敌对时直接返回敌对；囚犯越狱与奴隶反抗也可返回敌对；玩家作为接待方时普通被接待人物又可能返回非敌对，最后才回退派系外交关系。因此当前提供器还可能让某些玩家人物在敌对精神状态中临时获得免耗、免占用、隐匿容量和免延迟。具体是否发生取决于原版当前精神状态；本轮不是游戏内复现结论。

原版玩家可控殖民者资格另要求人物已落地图且无精神状态。若简单改成 `!IsPlayerControlled`（当前不可控），自己的远行人物也会进入简化资源规则，不能把它当成外部人物身份。

## 后续最小修正建议

- 用户确认资源经营边界后，集中修正现有两个内容提供器的适用判断，并同步它们的名称和注释。核心成本、占用和启停机制已有共同接口，不逐项功能打补丁。
- 容量显示使用单独信息规则，与手动按钮资格分开；不因暂时精神失常隐藏自己人物的已知容量。
- 自动近战重新判断的修复仍是独立主线；适用于自动入口整体，不做敌方专用补丁。
- 追兵任务的死战与物品携带要求继续保留在任务设计中，不通过公共资源规则推定其完成。
