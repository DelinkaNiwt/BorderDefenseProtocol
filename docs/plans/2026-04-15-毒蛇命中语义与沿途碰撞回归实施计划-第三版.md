# 毒蛇命中语义与沿途碰撞全覆盖修复-第三版 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 全量修正毒蛇路径弹的命中语义污染与沿途碰撞回归问题，保证首段锚点只承担导航职责，最终命中语义稳定落在最终目标，同时把 `pawn（小人）`、`wall（墙）`、`door（门）`、`cover（掩体）`、短段续飞、速度与视觉不回退一起纳入同一套实施与验收闭环。

**Architecture:** 当前仓库里已经存在两块半修内容：`BdpVerb_Shoot（宿主射击）` 已拆出 `semanticTarget（语义目标）` / `navigationTarget（导航目标）`，`BdpProjectile（主弹体）` 已有 `ComputeContinuationOrigin（续段兼容起点）`。真正还没完全收口的是 `Aim（瞄准阶段） -> ProjectileInit（投射物初始化阶段）` 的字段契约，以及分支级 `HitFlags（命中类别）`、短段兼容充分性、墙门掩体验收和速度视觉不回退的验证面。第三版在第二版基础上补齐这四块漏项，但仍坚持两条红线：不新增毒蛇专用碰撞系统，不改原版 `vanilla（原版）` 碰撞规则。

**Tech Stack:** C# / RimWorld `Projectile（投射物）` / RimWorld `Verb（攻击宿主）` / BDP `AimStage` / BDP `ProjectileInitStage` / BDP `ArrivalStage` / PowerShell 烟雾测试 / 游戏日志回放 / 原版机制对照
