# 霰弹枪双武器下移外扩试调设计

## 目标

缓解岚参考贴图在朝南静默双持时，枪尾与机匣集中挤在角色下巴附近的视觉拥堵。

## 设计

- 只调整 `BDP_Visual_Shotgun_Dual` 的南北姿态目标位置。
- `DefaultOffset` 从 `(0.20, 0, 0.12)` 改为 `(0.24, 0, 0.03)`，使两把武器略向外并整体降低。
- 握持锚点保持 `(0, 0, -0.1953125)`；本轮不要求贴图握把与可视化锚点重合。
- 保持统一 `6` 度装饰角、非执行态手侧镜像、枪口点和姿态原点逻辑不变。
- 单武器霰弹枪、突击步枪单／双武器配置均不变。

## 验证

- 更新霰弹枪专用视觉测试，明确只允许双武器位置与参考基准不同，其余数据保持一致。
- 解析视觉 XML 并运行相关回归；最终构图由游戏内朝南静默实测确认。
