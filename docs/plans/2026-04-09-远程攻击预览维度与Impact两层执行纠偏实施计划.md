# BDP远程攻击预览维度与Impact两层执行纠偏实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正远程攻击模块协议中 `Preview` 维度过粗与 `Impact` 语义混层的问题，使主骨架能在继续保持业务无知的前提下，正确支持“保留部分原版预览层”和“抑制原版基线命中但继续执行模块计划”。

**Architecture:** `Preview` 从两个总开关升级为多维预览表面，主骨架按维度裁决是否复用原版射程圈、目标高亮、鼠标附着等原版能力。`Impact` 从单层早退执行改为“基线命中层 + 中性计划层”两层模型，`SuppressVanillaImpact` 只作用于基线层，不再阻断 `DamagePlan / AreaEffectPlan / ExtraEffectPlan` 的执行。

**Tech Stack:** C#、RimWorld Mod、BDP `AttackExecution / TargetingProtocol / RangedFlightProtocol / Projectiles / BDP.Tests / BorderDefenseProtocol.DevHarness`
