# 触发器装配台界面调整设计

## 目标

在不改变装配事务和解析数据语义的前提下，修正护盾范围图的几何方向与定位，补充芯片库容量信息，收紧左栏文字和布局，并补齐三栏统一标题。

## 已确认事实

- 护盾范围图由 `ChipInformationDetailRenderer.DrawCoverageVisual` 绘制，当前扇形从正北的 0 度单向扫到目标角度；半透明范围区域与圆心应统一由几何点生成。
- 芯片库当前只从 `IAssemblerFacilityProvider.GetAvailableChips()` 读取有效芯片数量，设施读取口没有暴露连接芯片仓的容量上限。
- 左栏 `Panel_SlotLayout` 的主体内容以滚动视图局部坐标 0 开始，主副槽列以顶部固定偏移 36 开始；列标题下的说明文字和中央操作者文字正是截图中标记的多余元素。
- `Panel_ChipDetail` 当前只绘制面板外框和详情滚动内容，没有像左栏、中栏一样绘制标题栏。

## 设计决策

1. 护盾范围图：使用现有 `ChartGeometryRenderer` 的三角扇填充接口，生成以正北为中心、左右各 `angle / 2` 的弧点；范围数值和范围名称保持在同一个图块中心。这样修正的是扇形几何来源，不是单独移动某个像素元素。
2. 芯片库容量：在 Content 设施读取口增加“所有有效连接芯片仓容量上限”读取方法，由 `CompChipContainer` 暴露自身配置容量，`DefaultAssemblerFacilityProvider` 汇总。中栏标题显示“库存芯片 · 当前 / 上限 枚”。
3. 左栏：主体三个区块使用可视内容宽度的居中偏移；主副槽列按“标题 + 槽位卡片总高度”在舞台内垂直居中；删除主副槽说明、中央“操作者 / 正面”和中栏旧兼容性开关；主副槽标题保留为完整独立标题行。
4. 标题：左栏语言值改为 `01 // ASSEMBLY STATUS` / “装配状态”；右栏新增 `03 // CHIP DETAIL` / “芯片详情”；中栏保持现有 `02 // CHIP DEPOT NETWORK` / “芯片库”。
5. 只改 UI 读取和绘制：不修改芯片定义、解析模型、装配事务或槽位兼容性规则。

## 验收标准

- 120 度护盾图的填充以正北为中线向两侧展开；360 度覆盖为完整圆形，圆心、数值和区域填充不发生相对位移。
- 芯片库右上同时显示当前有效芯片数和所有有效连接仓的容量上限。
- 左栏三块主体以左栏可视区域为基准居中；主副槽卡片组在舞台高度方向居中；标记的冗余文字不再绘制，主手槽/副手槽完整可见。
- 三栏均有同风格编号英文小标题和中文主标题。
- 相关契约测试、Release 构建和差异检查通过。
