# Trion 伤口粒子与空触发体显示修复实施计划

**目标：** 以最小改动消除跨角色伤口粒子串线，并让空芯片战斗体正确显示持续消耗和恢复冻结事实。

**架构：** Core 的表现注册表只负责携带当前 Pawn 生命周期；Content 提供器负责按 Pawn 隔离具体粒子运行时。Trion Gizmo 只读取 `ITrionReader`（Trion 只读接口）已有事实。

**技术：** C#（C# 语言）、Harmony（补丁库）、PowerShell（脚本测试）、RimWorld 1.6。
