# 毒蛇命中语义与沿途碰撞回归 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正新 BDP 毒蛇路径弹的命中语义污染与续段沿途拦截失效，让锚点只负责导航，让原版 `vanilla（原版）` 命中与沿途碰撞重新自然生效。

**Architecture:** 本次只做两层收口。第一层在 `BdpVerb_Shoot（宿主射击）` 把 `semanticTarget（语义目标）` 与 `navigationTarget（导航目标）` 分开，恢复原版 `ShotReport（命中报告）` 与 `ProjectileHitFlags（命中类别）` 的最终目标语义。第二层在 `BdpProjectile（主弹体）` 的续段边界补一个中性兼容起点计算，让分段飞行仍能进入原版沿途拦截有效区；不手写新碰撞规则，不扩写毒蛇专用物理系统。

**Tech Stack:** C# / RimWorld `Projectile（投射物）` / `Verb（攻击宿主）` / BDP `ProjectileInitPlan（投射物初始化计划）` / PowerShell 烟雾测试

### Task 3: 在宿主射击层拆开导航目标与语义目标

**Files:**
- Modify: `Source/BDP/Core/Verbs/BdpVerb_Shoot.cs`
- Verify: `Source/BDP.Tests/ViperPathLatchCollisionParitySmokeTests.ps1`

**Step 1: 写失败断言指向的变量拆分**

在 `TryEmitPlan(ProjectileInitPlan plan)` / `TryLaunchSinglePlan(...)` 相关路径里做最小拆分：

- `semanticTarget（语义目标）`：优先 `plan.CurrentTarget`，回退 `currentTarget`
- `navigationTarget（导航目标）`：优先 `plan.LaunchTarget`，回退 `semanticTarget`

**Step 2: 最小实现**

具体要求：

- 删除或替换 `currentTarget = plan.LaunchTarget`
- `TryFindShootLineFromTo(...)` 使用 `navigationTarget`
- `ShotReport.HitReportFor(...)` 使用 `semanticTarget`
- `Launch(... intendedTarget ...)` 使用 `semanticTarget`
- `Launch(... usedTarget ...)` 的物理导航可继续使用当前发射分支求出的落点

允许的结构示意：

```csharp
LocalTargetInfo semanticTarget = plan.CurrentTarget.IsValid
    ? plan.CurrentTarget
    : currentTarget;
LocalTargetInfo navigationTarget = plan.LaunchTarget.IsValid
    ? plan.LaunchTarget
    : semanticTarget;
```

然后：

```csharp
bool hasLine = TryFindShootLineFromTo(caster.Position, navigationTarget, out resultingLine);
ShotReport shotReport = ShotReport.HitReportFor(caster, this, semanticTarget);
```

**Step 3: 核对命中类别分支**

确保下面三类分支都改成围绕 `semanticTarget`：

- `wild_miss（自然偏射）`
- `cover_miss（掩体偏射）`
- `intended_hit_*（正式命中）`

重点是：

- 不能再让第一锚点决定 `ProjectileHitFlags（命中类别）`

### Task 4: 在主弹体续段边界恢复原版沿途拦截输入

**Files:**
- Modify: `Source/BDP/Core/Projectiles/BdpProjectile.cs`
- Verify: `Source/BDP.Tests/ViperPathLatchBoundarySmokeTests.ps1`
- Verify: `Source/BDP.Tests/ViperPathLatchCollisionParitySmokeTests.ps1`

**Step 1: 把续段起点改成统一 helper**

在 `ContinueFlight(ArrivalRecord arrival)` 附近：

- 去掉直接裸写 `origin = nextOrigin`
- 新增统一 helper，例如：
  - `ComputeContinuationOrigin(...)`
  - `RebaseContinuationSegment(...)`

要求：

- helper 只处理 vanilla 兼容起点计算
- 不引入毒蛇业务词汇

**Step 2: 最小实现**

helper 的职责必须同时满足三点：

1. `exactPosition（当前位置真值）` 不变  
2. `ticksToImpact（到达时间）` 按“当前位置 → 下一段终点”的真实段长计算  
3. `origin（飞行起点）` 沿当前段方向向后退一个有限距离，使 vanilla 沿途拦截进入有效区  

实现意图示意：

```csharp
Vector3 nextOrigin = ExactPosition;
Vector3 adaptedOrigin = ComputeContinuationOrigin(nextOrigin, arrival.NextDestination);
origin = adaptedOrigin;
destination = arrival.NextDestination;
ResetFlightDurationFromCurrentSegment(nextOrigin, arrival.NextDestination);
```

注意：

- 这里的关键不是“把 origin 留在第一次发射点”
- 而是“让当前段方向仍正确，同时不把 vanilla 拦截距离重置成 0”

**Step 3: 保持已有正确项不回退**

必须保留下面已修对的部分：

- 共享高度平面
- `Arrival（到达阶段）` 续段，而不是 `Flight（飞行阶段）` 续段
- 当前正常的折线飞行视觉
