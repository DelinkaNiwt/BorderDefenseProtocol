# BDP 芯片功能树唯一归属设计

## 目标

芯片详情页的完整功能树中，每项功能声明只投影一次。功能仍按信息模型中的表达条目来源展示，不复制或改写芯片配置声明。

## 根因

解析器当前把全部功能声明在无活动条目筛选的状态下解析到根节点，随后又按形态/姿态活动条目投影到上下文。姿态解析还合并形态活动条目，因而形态共有功能会在姿态子节点重复出现。

## 设计

- 形态/姿态活动条目各自拥有唯一上下文范围；结构校验已要求表达条目只能被一个范围引用。
- 对每项顶层功能及其分组、子组、子功能递归收集来源的 `EntryId` / `EntryIds`，映射到条目所属上下文。
- 没有条目来源的声明归芯片根节点；普通无形态树的芯片保持原有根级完整解析行为。
- 一项声明涉及多个上下文时，归到这些上下文最近的共同父节点，并以所涉条目集合解析一次。功能节点保持其分组结构，使不同来源的属性仍能区分。
- 每个功能声明仅由一个目标范围解析；姿态不再继承形态条目做第二次解析。运行时形态/姿态合约继续按原有规则合并活动条目，不改战斗或表达逻辑。
- 不修改 `ChipInformationModel`、`ChipInformationNode` 或芯片预设信息模型；仅调整 Core 的功能投影结果与解析器接线。
- 详情渲染器继续消费统一信息树，不隐藏重复上下文节点；若同一节点属性已被实际绘制的图表完整呈现，则只隐藏重复属性行，模型值仍保留。

## 选择理由

按来源范围决定归属，解决数据投影根因并保留各上下文的层级。绘制时简单隐藏重复节点会任意丢失有效上下文数据，也会继续让模型携带重复语义。

## 验收

- 光魂：盾击只在大盾形态出现；移动护盾只在移动姿态出现；举盾护盾只在举盾姿态出现；重刃攻击只在重刃形态出现。
- 没有形态/姿态树的芯片继续在根节点展示全部功能。
- 一个功能声明覆盖多个子范围时只在最近共同父级出现一次，所涉来源都参与该次解析。
- 雷达图、精度图、距离示意和护盾角度图已完整呈现的属性，不在同一卡片中再重复绘制属性行。
- 现有信息树结构和详情图表渲染规则不变。
