# BDP 芯片制造窗口视觉层级重做设计

## 目标

在不改变芯片制造业务与三栏心流的前提下，把实际窗口调整为简约、干净、紧凑且层级清楚的原版风格界面，并修复预览语言键直出和队列内容裁切。

## 已确认问题

1. 中栏两个固定标题把语言键直接传给 `Widgets.Label`，没有调用 `Translate`，因此显示 `BDP_...` 原始键名。
2. 队列卡片把完整芯片名塞入固定 24 高度单行，整卡又固定为 102 高度；名称恢复完整规范后发生换行遮挡和按钮裁切。
3. 当前只实现了三栏结构，没有实现视觉层级：顶部重按钮、重复边框、统一大行高、大号段标题和固定右栏比例共同造成笨重与拥挤。

## 布局

- 目标窗口由 1180×720 收紧到约 1080×680，继续受当前 UI 屏幕安全边距限制。
- 顶部主分类与职业筛选分别压缩到约 32、28 高度，改为平面页签：只用选中底色和悬浮反馈，不绘制每项厚重按钮框。
- 主体维持左/中/右三栏，宽度约 25% / 50% / 25%，栏间距 8。
- 每栏只保留一个最外层原版菜单区。右栏材料与队列之间用留白和细分隔线分组，不再嵌套两个完整重框。

## 左栏

- 枪壳标题、动作标题使用小号分组标题；条目高度约 30。
- 枪壳区域按实际条目数决定高度，不为不存在的项目保留大片空白。
- 动作列表获得剩余全部高度；选择、禁用、信息卡和交换形态业务保持不变。

## 中栏

- 完整成品名成为唯一中号主标题，并使用英文半角冒号且不加空格，例如 `触发器芯片:毒蛇`。
- 芯片规格、枪壳修正、动作形态均使用小号强调标题；段间距大于字段行距，形成清晰节奏。
- 普通字段和动作指标基础行高压至约 24；长使用条件仍按实际文本高度换行。
- 枪壳修正按两列紧凑排布，减少连续相同箭头造成的清单感。
- 数值与条形图继续同一行，数值位于右侧。

## 右栏

- 材料区按实际材料条目数计算高度，数量和加入任务按钮紧随其后；剩余空间全部交给队列。
- 队列名称按可用宽度计算文本高度，完整显示；正常名称预计最多两行，异常超长名称也不会遮挡后续内容。
- 状态独占一行；数量调整和任务操作分成两排，按钮使用可用宽度等分，不再依赖固定坐标。
- 每张卡片高度由名称、状态和两排按钮共同计算，队列滚动高度由所有实际卡片累加。

## 非目标

- 不改变材料、账单、动作选择、预览字段和制造规则。
- 不制作自定义字体、贴图或脱离原版 IMGUI 的视觉系统。
- 不在本轮处理其它窗口或历史语言欠账。
