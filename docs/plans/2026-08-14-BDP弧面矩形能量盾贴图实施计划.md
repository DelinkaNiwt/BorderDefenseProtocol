# BDP 弧面矩形能量盾贴图实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用 V2 确定性脚本贴图替换当前弧面盾成品，并只接入光魂大盾的举盾姿态进行游戏实测。

**Architecture:** 正式贴图继续使用独立路径 `Effects/Shield/energy_shield_block_curved`，不覆盖六边形通用贴图。仅修改 `BDP_Visual_LightSoulShieldGuard` 的 `texPath`（贴图路径）；灵活姿态、重刃形态和通用格挡 Fleck（轻量粒子）保持原配置。

**Tech Stack:** XML（可扩展标记语言）、PowerShell（命令行脚本）、Python（编程语言）、Pillow（图像处理库）、Git（版本控制）

### Task 4: 修正游戏内竖直角度与朝北高度

**Files:**
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP.Tests/LightSoulChipSmokeTests.ps1`
- Modify: `模组工程/BorderDefenseProtocol/1.6/Content/Defs/ExpressionDef/Visual.xml`
- Test: `模组工程/BorderDefenseProtocol/Source/BDP.Tests/LightSoulChipSmokeTests.ps1`

**Step 1: 先写姿态配置失败断言**

断言举盾视觉使用以下参数：

```powershell
Assert-True ([single]$guardVisual.SouthNorthPose.DefaultAngle -eq 37) '光魂举盾南北姿态必须补偿原版 53° 持械角，使横向源贴图竖直显示。'
Assert-True ([single]$guardVisual.SouthNorthPose.NorthZAdjust -eq [single]0.25) '光魂举盾朝北必须补偿原版持械点与 Z 反转造成的 0.25 格下沉。'
Assert-True ([single]$guardVisual.EastWestPose.DefaultAngle -eq 37) '光魂举盾东西姿态必须保持竖直显示。'
Assert-True ($southFinalAngle -eq 90 -and $northFinalAngle -eq 90 -and $eastFinalAngle -eq 90 -and $westFinalAngle -eq 270) '光魂举盾四向最终角度必须保持屏幕竖直。'
Assert-True ([Math]::Abs($southFinalZ - $northFinalZ) -lt 0.0001) '光魂举盾南北姿态的最终屏幕高度必须一致。'
```

**Step 2: 运行测试并确认失败**

Run:

```powershell

```

Expected: FAIL（失败），首先指出南北姿态仍使用 `DefaultAngle=0`。

**Step 3: 最小修改举盾姿态**

只修改 `BDP_Visual_LightSoulShieldGuard`：

```xml
<SouthNorthPose>
  <DefaultAngle>37</DefaultAngle>
  <NorthZAdjust>0.25</NorthZAdjust>
</SouthNorthPose>
<EastWestPose>
  <DefaultAngle>37</DefaultAngle>
</EastWestPose>
```

不改变贴图、绘制尺寸、横向偏移或高度层参数，不增加渲染代码。

西向按解析器公式先得到 `-90°`，经 `NormalizeAngle`（角度归一化）后返回视觉等价的 `270°`。
