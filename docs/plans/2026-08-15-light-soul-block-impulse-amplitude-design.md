# 光魂护盾受击位移幅度调整设计

## 目标

将光魂灵活盾与举盾姿态成功抵挡后的盾面受击位移幅度降低一半，缓解当前抖动过强的问题。

## 当前行为

两个姿态都通过 Content（内容层）`HediffCompProperties_EnergyShield`（能量护盾健康状态组件配置）声明：

```text
blockVisualImpulseDistance = 0.08
blockVisualImpulseTicks = 8
```

Core（核心层）通用 `ExpressionVisualImpulse`（表达视觉冲量）在首帧应用完整距离，并在半程反向回弹完整距离的 `20%`，最后归零。因此当前首帧位移为 `0.08` 格，半程反向位移为 `0.016` 格。

## 方案

只把光魂两个正式姿态的 `blockVisualImpulseDistance` 从 `0.08` 改为 `0.04`：

- 灵活盾首帧位移：`0.04` 格。
- 举盾首帧位移：`0.04` 格。
- 半程反向位移随同一曲线自然变为 `0.008` 格。
- 持续时间继续为 `8 tick`。
- 回弹比例继续为 `20%`。

## 边界

- 不修改 Core 通用冲量曲线或默认倍率。
- 不影响其它能量护盾或未来使用视觉冲量的内容。
- 不修改抵挡判定、Trion（触力能）消耗、白闪、火花、声音、命中特效位置或盾面静态姿态。

## 验证

先将现有光魂抵挡反馈测试的两个配置期望值和曲线关键帧改为 `0.04 / -0.008`，确认旧配置失败；再修改正式 XML（可扩展标记语言），验证测试转绿并解析正式 XML。
