# 战斗体被动崩解烟雾设计

## 目标

战斗体进入被动崩解并在 90 tick（游戏刻）表现结束后，于原地释放一次与原版烟雾弹相同的烟雾，然后才尝试执行可选的紧急脱离。

主动解除战斗体不释放烟雾。

## 实现边界

- 直接修改 `CombatBodyExitTransaction`（战斗体退出事务），不新增接口、注册表、配置项或内容层接线。
- 烟雾仅位于 `CombatBodySessionExitMode.Collapse`（被动崩解退出模式）分支。
- 调用顺序固定为：

  `移除崩解倒计时 Hediff（健康状态） → 原地释放烟雾 → 尝试紧急脱离 → 其余退出清理`

- 烟雾使用 RimWorld（边缘世界）原版实现：
  - `GenExplosion.DoExplosion`（原版爆炸生成接口）
  - `DamageDefOf.Smoke`（烟雾伤害定义）
  - `GasType.BlindSmoke`（致盲烟雾气体）
  - 半径 `2.0f`
  - 本次调用的初始气体浓度为 `8`；只影响本次崩解烟雾，不修改原版气体定义或全局消散规则
- 原版气体网格没有单格独立的持续时间参数。浓度 `8` 在露天约持续 `1.1～2.1` 秒，在屋顶下约持续 `3.2～4.3` 秒；本功能接受这种原版时序差异，不另加定时清理。
- Pawn（角色）未生成在地图上或地图为空时安全跳过，不阻断后续崩解收尾。

## 验证

- 静态冒烟测试确认烟雾调用只存在于被动崩解分支。
- 静态冒烟测试确认烟雾调用位于紧急脱离调用之前。
- 静态冒烟测试确认半径为 `2.0f`、本次气体浓度为 `8`，且伤害定义与气体类型继续使用原版。
- 运行战斗体相关回归测试与 Release（发布）编译。
- 游戏内复测：有紧急脱离与无紧急脱离时均在原位置生成一次烟雾；主动解除不生成烟雾。
