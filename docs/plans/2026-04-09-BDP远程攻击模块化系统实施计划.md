# BDP远程攻击模块化系统实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 BDP 现有芯片、表达式、攻击执行、投射物协议基础上，落实完整的远程攻击模块化底层框架，并收口到统一投射物宿主。

**Architecture:** 模块挂载正式落在 `ChipExpressionEntryConfig.RangedModules`，沿表达式正式真值进入交互前置链和执行主骨架。系统通过统一模块会话和统一维度裁决器接入现有 `Targeter / ITargetingSource / Verb / Bullet`，无模块时保持原版基线等效行为。

**Tech Stack:** C#、RimWorld Mod、BDP `Expressions / AttackExecution / RangedProtocol / RangedFlightProtocol / Verbs / Projectiles / BDP.Tests`
