# 变色龙自施放动作根因修正设计

## 背景

变色龙能力虽然声明为自身释放，并已关闭范围环、瞄准扇形和远程视线要求，但仍继承原版 `Verb_CastAbility.TryStartCastOn` 的远程施放准备流程。该流程在有前摇时建立射击线并通知 Pawn 瞄准，导致释放期间朝北瞄准。BDP 通用能力 Verb 还会在真正释放时主动添加身体抖动，导致变色龙出现攻击式视觉表现。

## 方案

在 Core 新增通用 `BdpVerb_CastSelfAbility`，继承现有 `BdpVerb_CastAbility`，只改变自施放动作入口：

1. 保留原版 Ability 的按钮、JobDriver、前摇、冷却、效果组件和成本提交。
2. 自身目标校验只接受施法者自身。
3. 保留 `Stance_Warmup` 作为前摇计时与音效承载，但不建立射击线，也不调用 `Notify_WarmingCastAlongLine`。
4. 覆盖抖动入口为空，避免自施放能力产生攻击后坐力视觉。
5. 变色龙只在 AbilityDef 选择该通用 Verb；Core 不引用变色龙名称或业务数值。

## 边界

- 普通远程能力继续使用 `BdpVerb_CastAbility`，保留其现有施放抖动表现。
- `Verb_CastAbilityTouch` 不作为最终方案；它只扩展目标验证和 UI，仍继承原版的 `TryStartCastOn`。
- 不依赖 DLC，不绕开原版 Ability 生命周期，不新增独立能力按钮系统。
