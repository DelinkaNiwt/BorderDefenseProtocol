# 风刃动态刀刃阵列 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让风刃命中特效按目标实际显示宽高动态生成 5～12 道刀刃，覆盖目标贴图范围，同时保持水平接地、前后遮挡和快速错峰刺出。

**Architecture:** 保留 Content 中现有的命中模块、去重和原版 `Effecter` 生命周期入口。把 Effecter 的六个静态喷射子项替换为前后两个自定义 `SubEffecter`，由它们读取 Pawn 目标尺寸、计算总数量和根部横向布局，并创建独立的自定义三角刀刃 Mote；Mote 只负责单道刀刃的网格、延迟、生长和生命周期。

**Tech Stack:** RimWorld 1.6、C# 7.3、.NET Framework 4.8、Verse `Effecter`/`SubEffecter`/`Mote`、XML Def、PowerShell 契约测试。

### Task 2: 增加动态刀刃子特效器

**Files:**

- Create: `Source/BDP.Content/RangedModules/FujinImpact/SubEffecter_FujinImpactBladeBurst.cs`

**Step 1: Implement the minimal code**

- 继承 `Verse.SubEffecter`，在第一次 `SubTrigger` 时从 `TargetInfo` 取得命中 Pawn；后续 `SubEffectTick` 只维护已生成 Mote，不重新计算位置。
- 优先读取 `Pawn.Drawer.renderer.BodyGraphic.drawSize`，乘 `BodyTypeDef.bodyGraphicScale`；读取失败回退 `Pawn.DrawSize`。
- 计算 `bladeCount = Mathf.Clamp(Mathf.CeilToInt(width / 0.32f), 5, 12)`；根部横向位置覆盖 `[-width/2, width/2]`，根部 Z 使用精确命中点减去目标高度的一半。
- 每个索引生成确定性的混合角度，保证中央刀刃经过命中点，少量刀刃向外展开，其余近直上或向中线刺入；索引奇偶拆分到前后 Mote Def。
- 每道刀刃通过 `ThingMaker.MakeThing` 和 `GenSpawn.Spawn` 创建，设置精确位置、宽度、长度、角度、层级、错峰延迟和颜色；把引用存入列表，在 `SubCleanup` 销毁。
- 不使用大量粒子，不把目标 Pawn 作为 Mote 附着目标，确保特效固定在命中瞬间。
