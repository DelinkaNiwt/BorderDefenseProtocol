# BDP 事项 06 按钮状态补正设计

## 一、问题根因

当前玩家可见调试按钮使用 `Prefs.DevMode` 判断。这个值只表示已经开启 RimWorld（边缘世界）的开发者模式，不表示顶部工具栏中的上帝模式已经开启。

因此玩家只开启开发者模式、没有开启上帝模式时，画点诊断和 Trion 数值调节按钮仍会出现。

正确的显示条件应为 `DebugSettings.godMode`。

## 二、调试按钮补正规则

以下五个玩家可见调试按钮统一只在上帝模式开启时显示：

- 画点诊断；
- Trion +50；
- Trion -50；
- Trion MAX；
- Trion 归零。

画点诊断的地图绘制和发射点记录也跟随上帝模式。这样关闭上帝模式后，即使运行期画点开关仍记得上次状态，地图也不会继续绘制或收集隐藏诊断数据。

普通诊断日志仍可继续跟随开发者模式，本项不修改无按钮的日志开关。

## 三、单一战斗体按钮

两个正式按钮合并为一个 `Command_Action`（动作按钮），根据当前相位改变文字和动作：

| 战斗体相位 | 按钮文字 | 显示效果 | 点击结果 |
|---|---|---|---|
| 未开启 | 开启战斗体 | 亮，可点击 | 请求开启 |
| 已开启 | 解除战斗体 | 亮，可点击 | 请求解除 |
| 崩解中 | 战斗体崩解中 | 灰，不可点击 | 无 |
| 冷却中 | 战斗体冷却中 | 灰，不可点击 | 无 |

这里的“亮”表示按钮可以操作，不用选中框表达战斗体是否已开启。角色仍必须同时满足“手持触发体”和“拥有有效 Trion 腺体基因”，按钮才会出现。

## 四、边界

- 不改变战斗体开启、解除、崩解和冷却的正式流程。
- 不新增战斗体状态。
- 不修改 Trion 数值调节动作本身。
- 不修改普通诊断日志开关。
- 不触及事项 07 及后续内容。
