# BDP 芯片制造窗口交互 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将芯片制造界面从不可移动且会越界的检查页签，改为由制造台 Gizmo（命令按钮）打开的自适应暂停窗口。

**Architecture:** `Building_ChipFabricator` 只负责提供原版工作台身份和打开命令；`Window_ChipManufacturing` 持有本轮编辑草稿并复用现有三栏面板。窗口通过 RimWorld（边缘世界）原版 `Window` 属性完成居中、拖动、输入吸收和暂停，不自行管理时间速度。

**Tech Stack:** RimWorld 1.6 `Window`、`Command_Action`、Unity IMGUI（即时模式界面）、PowerShell 冒烟测试、MSBuild。
