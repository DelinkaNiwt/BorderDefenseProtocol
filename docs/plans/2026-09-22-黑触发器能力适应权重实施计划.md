# 黑触发器能力适应权重实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在现有黑触发器特性适应权重之外增加可选的能力适应权重，并在 Anomaly 未加载时安全降级。

**Architecture:** Content（内容程序集）在 DefModExtension 中保存字符串能力声明；死亡前快照保存 Pawn 当前能力 DefName；候选匹配器分别计算特性命中和能力命中，再以 `1 + 3 × 总命中数` 生成稳定候选权重。解析缺失能力只跳过该项，不引入 Anomaly 编译或 About 依赖。

**Tech Stack:** C# 7.3、RimWorld 1.6 Def/XML、PowerShell 冒烟测试、MSBuild。

**Steps:**

3. 在死亡前通过 `pawn.abilities` 冻结人物当前能力，空能力列表保持合法。
4. 在主人物快照中保存和恢复能力列表。
