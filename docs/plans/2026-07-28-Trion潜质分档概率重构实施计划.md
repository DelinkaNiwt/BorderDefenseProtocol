# Trion 潜质分档概率重构实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 Trion 潜在容量改为九档直接权重生成，档内以 100 为单位等概率取值，并让 5000 检测为独立的“略懂(?)”档。

**Architecture:** `TrionPotentialDistributionDef` 用档位列表取代钟形分布参数；`TrionPotentialGenerator` 先按相对权重选档，再用离散整数步长在档内等概率取值。检测系统继续使用独立的 `TrionAssessmentBandDef`，仅把破格上限收紧到 4900并新增5000档。

**Tech Stack:** RimWorld 1.6、C#、Verse Def/XML（可扩展标记语言）、PowerShell 冒烟测试、MSBuild（微软构建工具）

### Task 2: 实现九档权重和档内等概率生成

**Files:**
- Modify: `Source/BDP/Core/Trion/Potential/TrionPotentialDistributionDef.cs`
- Modify: `Source/BDP/Core/Trion/Potential/TrionPotentialGenerator.cs`
- Modify: `1.6/Defs/Trion/Potential/TrionPotentialDistributionDefs.xml`

**Step 1: 定义档位配置对象**

在 `TrionPotentialDistributionDef.cs` 增加逐成员注释的 `TrionPotentialBand`：

```csharp
public sealed class TrionPotentialBand
{
    public int minimumCapacity;
    public int maximumCapacity;
    public float weight;
}
```

`TrionPotentialDistributionDef` 只保留 `minimumCapacity`、`maximumCapacity`、`quantizationUnit` 和 `List<TrionPotentialBand> bands`，删除旧钟形与稀有分支字段。

**Step 2: 改写生成器**

生成器执行：

1. 校验定义、量化单位、档位边界、正权重和有效离散值；
2. 用总权重和一次随机数累加选择档位；
3. 用 `Mathf.CeilToInt`、`Mathf.FloorToInt` 计算档内离散步数；
4. 用 `Rand.RangeInclusive(firstStep, lastStep)` 等概率选取一步；
5. 配置无效时记录 `[BDP.Trion]` 错误并回退1000。

删除 `GenerateCoreCapacity`、`GenerateBiasedRange` 和所有高低值偏斜逻辑。

**Step 3: 写入正式九档配置**

XML（可扩展标记语言）按设计表写入九个带中文条目注释的档位，权重总和100；5000档写为5000～5000、权重1。
