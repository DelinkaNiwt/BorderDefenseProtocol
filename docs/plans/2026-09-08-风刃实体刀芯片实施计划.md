# 风刃·实体刀芯片 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 BDP Content 中新增一个完全复刻弧月属性与表达的“风刃·实体刀”芯片功能，将其限制为主副槽并从芯片制造台隐藏，同时让刀刃发光层使用风刃拖尾的绿色。

**Architecture:** 只新增 Content Def 与简体中文语言包配置，不修改 Core、制造台 UI 或槽位运行时代码。新功能独立复制弧月功能定义；新视觉预设复用弧月两张 PNG 和全部姿态参数，只覆盖刀刃发光层颜色，避免改变弧月原有表现。

**Tech Stack:** RimWorld 1.6 XML Def、BDP Content 程序集、PowerShell 冒烟测试、dotnet build。

---

> 本计划按当前工程直接执行，不创建 branch 或 worktree。XML/语言包属于配置变更，按项目现有 PowerShell 冒烟测试完成红—绿验证；不新增 C# 生产代码。
