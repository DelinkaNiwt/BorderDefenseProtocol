# 光魂举盾最终高度、单持侧视与受击反馈设计

## 目标

1. 灵活盾与举盾的受击视觉位移再次减半。
2. 单举盾朝东呈现双武器朝东主手的最终结果，朝西呈现双武器朝西副手的最终结果；只要求画面一致，不复用双武器手位分支。
3. 补上上次漏掉的单持四向整体抬高。
4. 单持与双武器朝北再额外抬高，尽量避免盾底低于脚部。

## 方案比较

1. 推荐：只调整 Content XML（内容配置）。单持东西向消除主副分支差异，利用原版西向基础镜像得到东原图、西镜像；高度和抖动直接修改业务参数。最短、最直观，不增加 Core（核心层）设施。
2. 新增“按朝向模拟手位”的通用开关。能复用双武器分支，但用户只要求最终表现一致，属于不必要机制。
3. 拆分朝东、朝西专用视觉预设。会增加预设选择和维护成本，不采用。

## 最终参数

### 受击视觉位移

灵活盾与举盾的 `blockVisualImpulseDistance`（受击视觉位移距离）均由 `0.04` 改为 `0.02`。持续时间保持 8 tick，既有 20% 反向回弹曲线不变。

### 单举盾东西向

- `SideBaseX = 0.08`，`SideDeltaX = 0`：无论条目实际在哪一手，东西最终都距离人物 `0.08`。
- `FrontAltitudeOffset = 0.08`，`BackAltitudeOffset = 0.08`：两条分支都使用前景绘制层。
- `HandMirror = false`，`FinalMirrorByHandOnly = false`：不再附加手位镜像，朝东保持原图，朝西只使用原版基础镜像。
- `MainHandAlwaysFront = false` 保持默认语义，但由于位置与绘制层两分支已相同，不再影响最终结果。

因此最终画面为：朝东原图／前景／贴近，朝西水平镜像／前景／贴近，与指定的两个双武器结果一致。

### 屏幕高度

- 单持南北基础 `DefaultOffset.Z` 由 `0.18` 改为 `0.23`。
- 单持东西 `SideBaseZ` 由 `0.18` 改为 `0.23`。
- 单持与双武器 `NorthZAdjust` 均设为 `0.51`。

最终 BDP 额外纵向偏移：南、东、西均为 `+0.23`，北为 `+0.28`。朝北比其它方向额外高 `0.05`；绘制层 `Y`、角度、尺寸、贴图和抖动之外的抵挡反馈不变。

## 验证

配置测试固定两种护盾的 `0.02` 受击位移、单持东西最终真值表、单双持南东西 `0.23` 与朝北 `0.28`。原有“所有预设南北 BDP 偏移必须相等”的测试仅为两个举盾预设声明 `+0.05` 明确例外，其它视觉继续遵守原版等价规则。
