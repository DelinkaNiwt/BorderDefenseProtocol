# 触发器装配台图表几何绘制设计

## 目标

只改善触发器装配台右侧详情中的能力雷达图和精度曲线绘制质量，使图形边缘、线宽、填充和超界裁切更接近专业数据图表；本次不调整卡片高度、空位、文字排版、数值来源或游戏规则含义。

## 已确认的问题

- 当前 `ChipInformationDetailRenderer` 使用 `Widgets.DrawLine`（原版线段绘制接口）逐段绘制全部图形。
- RimWorld 1.6 的 `Widgets.DrawLine` 会把传入线宽放大约三倍，并使用旋转的抗锯齿纹理；当前雷达轮廓、曲线和面积模拟线宽过大。
- 雷达面积使用从中心到顶点的粗线模拟，不是真正的多边形填充。
- 精度曲线的数学数据继续保持原版四个精度节点之间的分段线性插值，不引入非原版的平滑曲线。

## 方案

新增 Content UI 专用的轻量 `ChartGeometryRenderer`，由详情渲染器传入局部坐标和颜色，负责：

1. 以三角扇绘制雷达最终值和声明值的半透明多边形填充。
2. 以窄几何笔刷绘制雷达网格、轴线和数据轮廓，避免使用粗线束模拟面积。
3. 以连续折线几何绘制精度曲线，并保留四个原版关键距离标记。
4. 对雷达超界数据执行视口裁切，保留现有边界警示标记。
5. 只在 `EventType.Repaint`（重绘事件）阶段提交图形，避免布局和输入阶段产生副作用。

绘制器不进入 Core.dll，不读取芯片身份，不改变信息模型；它只属于 Content.dll 的界面实现。若 Unity UI 的几何提交无法安全继承当前 GUI 裁剪状态，则使用同一绘制器的细抗锯齿线段后备路径，保证窗口边界和 UI 缩放稳定。

## 数据流

```text
ChipInformationDetailRenderer
    └─ RadarAxis / AccuracyPoint
         └─ ChartGeometryRenderer
              └─ 当前详情窗口的 GUI 绘制区域
```

数据归一化、职业标尺、超界判定和原版精度插值仍由现有详情渲染器负责。几何绘制器不参与数值计算。

## 约束

- 不修改 `ChipInformationModel`、Core.dll 或战斗逻辑。
- 不修改本地化文案。
- 不处理本轮明确排除的空位、固定卡片高度和文字换行问题。
- 保留现有声明值、成品最终值、增加、减少和超界颜色语义。

## 验证

- 运行图表相关边界冒烟测试和 Content 编译。
- 静态确认雷达面积不再调用中心到顶点的粗线模拟。
- 静态确认图形只在重绘事件提交。
- 进游戏复测三轴近战雷达、五轴远程雷达、精度曲线、超界数据和 UI 缩放。
