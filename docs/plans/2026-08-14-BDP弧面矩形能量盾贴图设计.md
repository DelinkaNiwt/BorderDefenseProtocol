# BDP 弧面矩形能量盾贴图设计

## 目标

- 生成一张 512×512 PNG（便携式网络图形）贴图，透明背景。
- 外形参考用户提供的手持盾牌截图：摆正、居中，整体接近矩形，长边呈柔和弧度，四角略收束。
- 画风参考现有 `energy_shield_block.png`：使用单一青色和程序化透明度层次，不引入随机渐变或噪点。

## 路线比较

1. 确定性脚本绘制（采用）：固定几何轮廓、单一 RGB（红绿蓝）颜色和 Alpha（透明度）层次，输出规整、可重复、无杂质。
2. 图像生成模型：形状容易快速成型，但会产生大量随机颜色、渐变噪声和过实主体，不再采用。
3. 机械分块盾牌：可增加厚重感，但会引入参考图没有的实体结构，偏离能量盾需求。

## 最终画面

- 单独一面盾牌，无人物、握把、文字、标志、投影或场景。
- 盾牌横向摆放并占画布约四分之三，四周保留透明留白。
- 所有可见像素固定使用参考图的 `RGB(0,200,220)` 青色；主体基准透明度为 `90/255`，中部最高 `110/255`，内侧次级边缘为 `130/255`，最亮边为 `240/255`。
- 不增加随机颜色、噪点、扫描线或全不透明像素；只用透明度变化提供轻微厚重感。
- 轮廓保持宽扁的弧面矩形观感，不做六边形、圆盾或尖锐中世纪盾形。

## 输出与验证

- 不覆盖原六边形贴图；脚本版输出为同目录的 `energy_shield_block_curved.png`。
- 首轮游戏实测只把 `BDP_Visual_LightSoulShieldGuard`（光魂大盾举盾姿态视觉）切换到新路径；灵活姿态、重刃形态和通用格挡特效保持原贴图。
- 验证尺寸、透明角、唯一可见 RGB 颜色、最大透明度、贴图路径存在性和姿态引用隔离。

## 游戏实测姿态修订

- 横向源贴图本身已正确居中；斜放来自原版持械绘制角。南、北、东朝向使用 `143°` 瞄准角，绘制时先减去 `90°`，得到 `53°`，因此举盾姿态需要再补偿 `37°` 才能竖直显示。
- 西朝向会翻转绘制平面，同一个 `37°` 补偿会先得到 `-90°`，再由解析器归一化为视觉等价的 `270°`；所以南北和东西姿态统一使用 `DefaultAngle=37`，无需增加专用渲染代码。
- 朝北时，原版持械点为 `-0.11`，同时南北姿态会反转现有 `DefaultOffset.z=0.18`，最终为 `-0.29`；朝南最终为 `-0.04`。仅增加 `NorthZAdjust=0.25`，让南北屏幕高度统一为 `-0.04`。
- 保持贴图、`drawSize`（绘制尺寸）、横向位置和高度层偏移不变；本次只调整 `BDP_Visual_LightSoulShieldGuard` 的三个姿态参数，不修改 Core（核心基础设施）或其他视觉定义。
