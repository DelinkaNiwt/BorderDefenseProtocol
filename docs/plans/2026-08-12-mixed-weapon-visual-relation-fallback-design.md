# 混合武器视觉关系回退设计

## 问题

视觉投影器当前只有在攻击表达层已经生成 `DualWeapon`（双武器）复合结果时，才会启用双武器视觉关系。攻击表达层又要求两枚芯片具有相同身份和相同行为，因此“步枪壳 + 霰弹枪壳”虽然确实存在两枚武器芯片，视觉上仍被误判为 `SingleSide`（单侧）。

这把攻击组合资格错误地当成了视觉关系资格。

## 边界

- 攻击表达、攻击调度和 `DualWeapon` 复合结果生成规则保持不变。
- 单武器仍保持原版基线；一个武器芯片实例不会进入双武器视觉。
- 同一芯片发布多个攻击结果时仍只计为一个武器实例。
- 每把武器仍按自己的 `CompositeVisualPresetDefName`（复合视觉预设名）选取双武器外观；缺失时沿用现有单侧预设回退。

## 决策顺序

视觉投影器按以下顺序确定关系：

1. 可用的 `Combo`（组合）结果显式声明 `VisualPresetDefName`（视觉预设名）或 `CompositeVisualPresetDefName` 时，采用 `Combo` 视觉关系。
2. `Combo` 没有声明视觉时继续向下判断，不截断回退。
3. 存在可用的正式 `DualWeapon` 结果，或实际激活的武器芯片实例数不少于两个时，采用 `DualWeapon` 视觉关系。
4. 只有常驻视觉条目时采用 `SingleSide`；否则为 `None`（无关系）。

这样，混合类型武器不需要在攻击层组成同类双武器，也能各自按双武器规则绘制。

## 验证

新增投影层回归测试，至少覆盖：

- 两个不同芯片实例、没有正式双武器攻击结果时，视觉关系仍为 `DualWeapon`。
- 无视觉声明的 `Combo` 不阻断上述回退。
- 有视觉声明的可用 `Combo` 保持最高优先级。
- 单个武器芯片实例仍为 `SingleSide`。
