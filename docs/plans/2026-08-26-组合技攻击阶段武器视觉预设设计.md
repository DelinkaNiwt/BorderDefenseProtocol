# 组合技攻击阶段武器视觉预设设计

## 目标

补齐双芯片状态下第四个攻击入口“组合技”的武器视觉阶段表现：组合技待命时继续使用现有双武器视觉；组合技进入预热、射击或冷却时，使用组合技定义或武装构型提供的攻击视觉预设；攻击结束或被打断后恢复待命视觉。

本次 Trion 立方体用例把组合技攻击视觉预设引用到现有 `BDP_Visual_TrionCube`。这只是复用同一份视觉预设数据，不把组合技视觉语义定义成单武器视觉。

## 已确认的现有能力

- `WeaponVisualActionStage` 已提供 `Idle`、`Warmup`、`Firing`、`Cooldown` 四个阶段。
- `WeaponVisualStageResolver` 已从原版姿态、正式宿主和 BDP 攻击会话解析阶段。
- `ExpressionVisualPresetDef.StageVisuals` 已支持阶段内贴图、附加层和显隐覆盖。
- 主侧武器、副侧武器和双持攻击已经消费这条阶段绘制链。
- 组合技结果已经有独立 `Combo` 复合结果和来源引用，但目前没有把“组合技攻击阶段视觉预设”传入视觉投影与绘制入口。

## 设计

### 1. 作者配置字段

在通用表现配置中增加 `ComboAttackVisualPresetDefName`（组合技攻击视觉预设名）。该字段只声明组合技攻击阶段的视觉来源，不改变待命视觉来源。

配置入口有两处：

- `ComboDef.Expression.Entries[].Presentation.ComboAttackVisualPresetDefName`：只覆盖指定组合技条目。
- `ChipArmamentFormDef.overrides.comboAttackVisualPresetDefName`：作为当前武装构型组合结果的默认覆盖。

组合技显式条目字段优先于武装构型覆盖；两者都没有时完全保持旧行为。

武装构型字段即使随普通单侧结果传播，也只在当前宿主确实是组合技结果时消费，不能影响主侧、副侧或双持攻击。

### 2. 静态投影

`DefaultVisualProjectionBuilder` 从正式 `Combo` 结果和 `CompositeExpressionReference` 构建组合技攻击视觉绑定：

- `ComboResultId`：当前组合技攻击结果标识；
- `VisualPresetDefName`：组合技攻击阶段视觉预设；
- `OwnerSourceResultId`：沿用主侧来源结果作为本次组合技视觉的绘制归属。

该绑定是视觉投影中的只读运行时数据，不写回芯片、武装构型或存档。

组合技攻击视觉绑定不参与待命 `RelationKind` 判断，因此仅增加该字段不会把待命双武器视觉改成组合技视觉。

### 3. 动态绘制

绘制入口继续调用现有 `WeaponVisualStageResolver`。只有同时满足以下条件时才使用组合技攻击视觉绑定：

1. 当前宿主结果标识匹配组合技绑定的 `ComboResultId`；
2. 当前阶段不是 `Idle`；
3. 当前条目是绑定指定的绘制归属条目；
4. 组合技视觉预设 Def 可解析。

满足条件时，以组合技结果身份构造一次阶段绘制条目，复用来源芯片用于取色和来源追踪；其完整姿态、主贴图、附加层、握持锚点和枪口锚点由指定视觉预设按现有视觉语义解析。其它来源条目不重复绘制该组合技攻击视觉。

预设缺失、绑定不完整或攻击会话不匹配时，回退现有视觉路径，不让武器永久消失。

### 4. Trion 立方体正式内容

在 `BDP_ArmamentForm_TrionCube` 的 `overrides` 中增加：

```xml
<!-- 组合技攻击阶段视觉：当前用例复用 Trion 立方体单侧视觉预设；该字段语义仍属于组合技攻击视觉。 -->
<comboAttackVisualPresetDefName>BDP_Visual_TrionCube</comboAttackVisualPresetDefName>
```

不修改 `visualPresetDefName`、`compositeVisualPresetDefName` 或现有 `StageVisuals`，因此待命、普通单侧攻击和双持攻击保持原样。

## 验证边界

- 配置字段从 ComboDef 和武装构型正确传播到正式 Combo 结果。
- 没有组合技攻击视觉字段时，现有四阶段行为完全不变。
- 组合技待命仍使用双武器视觉。
- 组合技预热、射击、冷却使用指定预设；冷却结束、打断和会话失效后恢复待命视觉。
- 当前 Trion 用例指向 `BDP_Visual_TrionCube`，不改变三条已有攻击入口。
- 两个来源条目不会在组合技阶段重复绘制同一个组合技视觉预设。
