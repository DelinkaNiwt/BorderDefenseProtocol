# 光魂抵挡特效前后景设计

## 目标

让光魂大盾成功抵挡时的白闪、火花、烟尘按攻击来源所在的地图南北深度切换绘制层：北半圆命中位于 Pawn（人物）贴图下方，南半圆及正东、正西命中位于 Pawn 贴图上方。

## 原版根因

原版 `Fleck`（轻量粒子）在绘制时使用 `FleckDef.altitudeLayer`，原版 `Mote`（动态特效）也会用 `ThingDef.altitudeLayer` 重设绘制高度。因此，现有命中坐标和 `Effecter.offset` 中的 Y 值不能控制最终前后景；只调坐标会在绘制阶段失效。

## 方案

- 保留现有攻击方向解析、盾面命中点、声效及原版喷射参数。
- 在 Content（正式业务内容）中为光魂声明前景、后景两套薄特效定义，继续复用原版贴图与着色器。
- 前景特效统一位于 `MoteOverhead`（人物上方粒子层）；后景特效统一位于 `Projectile`（弹体层，低于人物层）。
- 代码按“攻击来源方向的 Z 分量大于零”为北半圆后景；Z 小于或等于零为前景，因此正东、正西稳定归入前景。
- 两个光魂护盾姿态通过 XML（可扩展标记语言）显式开启并引用同一组定义；其它能量护盾不配置时继续使用原有表现。

## 边界

- 不修改 Core.dll（核心架构程序集）。
- 不修改 RimWorld 原版定义。
- 不建立自定义粒子系统，不复制纹理资源。
- 不改变抵挡判定、概率、Trion 扣费、命中半径和盾面抖动。

## 验证

- 纯计算测试覆盖北、南、东、西四个来源方向。
- XML 结构测试确认前后景所有子特效位于统一层，并确认两种姿态均启用配置。
- 编译 Content.dll，并运行既有光魂与护盾冒烟测试。
- 游戏内最终观察北侧火花被人物遮挡、南侧火花覆盖人物，以及两种姿态表现一致。
