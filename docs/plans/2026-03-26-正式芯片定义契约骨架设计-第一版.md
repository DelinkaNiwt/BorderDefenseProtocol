# 正式芯片定义契约骨架设计（第一版）

## 目标

这份设计文档用于把主模组中的芯片上位骨架收口成可直接施工的形状。

这里不再沿用旧的抽象化芯片身份骨架，
而是直接围绕 BDP 中一枚真实芯片必须声明什么来设计。

## 一、设计结论

### 1. 芯片定义层继续保留

`Core/Chips` 作为上位输入层这个方向是对的，
应继续保留。

它负责：

- 统一读取芯片声明
- 统一解释芯片总结构
- 统一做最低合法性校验

### 2. 芯片总结构改为新五块

正式固定为：

- `profile`
- `loadout`
- `expression`
- `trion`
- `extensions`

### 3. 形态留在表达块内部

形态改变的是表达成立方式，
不是芯片本体身份，
所以不单列为芯片并列大块。

### 4. 统一读取口继续保留

主模组内部统一读取入口继续保留：

- `IChipDefinitionReader`

但它吐出的结果对象要改成新骨架。

## 二、目录和职责

目录继续保持：

- `Core/Chips/Config`
- `Core/Chips/Contract`
- `Core/Chips/Validation`
- `Core/Chips/Access`

### 1. `Config`

职责：

- 承载内容作者原始写法

### 2. `Contract`

职责：

- 把作者写法翻译成主模组承认的芯片块结果

### 3. `Validation`

职责：

- 判断芯片结构是否成立
- 输出玩家和开发者都能看懂的错误与警告

### 4. `Access`

职责：

- 向 Trigger、表达系统、未来 Trion 系统提供统一读取入口

## 三、新块具体含义

### 1. `profile`

至少回答：

- 主分类
- 标签

用途：

- 信息模板选择
- 排序
- 分组
- 诊断

明确不再包含：

- `IsFormalChip`
- `ContractVersion`
- `ChipKindKey`

### 2. `loadout`

至少回答：

- 允许装载到哪些侧
- 是否双手锁定
- 互斥标签
- 默认形态入口键

### 3. `expression`

至少回答：

- `Entries`
- `Modes`
- 条目类型
- 条目关系

表达块继续通过 `ChipExpressionContractHandle` 接入，
不在芯片定义层复制表达系统内部全量对象。

### 4. `trion`

至少回答芯片本体级参数：

- 占用
- 激活成本
- 功率要求

条目级使用消耗不放这里，
继续留在表达条目自身的 `trion` 区。

### 5. `extensions`

保留单一总扩展区，
但不再使用：

- `Namespace`
- `Key`
- `Value`

新的扩展结构必须是“有明确用途的命名块”。

## 四、最低合法性校验改成什么

不再校验：

- 你有没有写 `IsFormalChip = true`

改为校验：

- 有没有 `profile`
- `primaryCategory` 是否可识别
- 有没有 `loadout`
- 有没有 `expression`
- 有没有芯片本体级 `trion`
- 表达块是否满足表达系统最低要求

这叫“结构成立”，
不是“自我宣誓成立”。

## 五、统一读取口应回答什么

`IChipDefinitionReader` 继续统一返回：

- 当前 `ThingDef`
- 新总契约结果
- 校验结果

它不回答：

- 当前是否激活
- 当前主攻击是谁
- 当前按钮是什么

## 六、各系统读取边界

### 1. Trigger

读取：

- `loadout`
- 必要时少量 `profile`

### 2. Expressions

读取：

- `expression`

### 3. Trion 系统

读取：

- `trion`
- 必要时少量 `profile`

### 4. 说明与信息系统

读取：

- `profile`
- 正式结果面
- 必要时芯片本体级 `trion`

## 七、当前明确判废的旧设计

以下内容不再作为继续实现依据：

- `Identity`
- `Resource`
- `ChipIdentityConfig`
- `ChipIdentityContract`
- 自证式正式芯片判定
- 泛资源命名
- 通用三元组扩展结构

## 八、当前施工原则

- 先改文档，再改代码
- 先删坏块，再补新块
- 不做新旧兼容双轨
- 统一走 `IChipDefinitionReader`
- 所有新成员逐成员注释
