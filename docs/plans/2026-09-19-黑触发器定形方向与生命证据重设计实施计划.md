# 黑触发器定形方向与生命证据重设计实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal（目标）：** 把现有“侧重／倾向／最终意志”三层原型替换为“经历来源 → 核心功能”的完整定形方向卡，并让人物证据、稳定随机、成品印记和开发者诊断使用同一份结构化数据。

**Architecture（架构）：** `BDP.Content` 在每件黑触发器的现有 `ThingDef` 扩展上声明功能画像和形成路线；死亡前快照读取原版人物记录、技能、关系与健康事实，路线评估后按完整方向分组，并在信件建立时为每张方向稳定暗选一个结果。`BDP.Development` 只读取 Content 的结构化结果，显示玩家界面隐藏的分数、候选池、暗选结果和唯一状态。

**Tech Stack（技术栈）：** RimWorld 1.6、Royalty（皇权）、Biotech（生物科技）、C#、XML、Harmony、原版 `ChoiceLetter`、`ThingComp`、`StatDrawEntry`、`GameComponent`、PowerShell 烟雾测试。

**核心流程：**

```text
评估全部物品的全部路线
-> 同一物品、同一方向只保留最佳路线
-> 按 核心经历+核心功能+有效锚点 分组
-> 用组内最佳路线为方向排序

-> 每张方向保存完整候选池和代表证据
```

4. 候选数量不参与方向分和自然形成概率。
5. 第三张卡必须超过相对强度门槛且方向键不同；不以候选物品不同冒充方向不同。
6. 代表证据只从真正影响该方向的证据中选择二至四条。
7. 加入稳定暗选方法，输入世界标识、角色稳定 ID、事件 ID、方向键和权重列表，输出候选索引。
