# BDP 芯片详情面板设计

## 目标

让芯片制造台预览区与触发器装配台详情区共用同一套玩家向芯片详情布局，直接展示统一信息树中实际存在且已确定要展示的内容，并尽快进入游戏检查实际可读性。

## 已确认事实

- `ChipInformationModel` 已承载芯片根信息、功能、形态/姿态上下文及关系节点。
- 触发器装配台已有原生 `Widgets` 绘制的深青色面板风格，但当前只展示选中的一个上下文，并把通用信息字段整体倾倒出来。
- 制造台另有规格卡、构型修正卡与功能上下文预览，尚未使用装配台同一套详情布局，也没有图表比较模型。
- 因此当前差异是 Content 展示层的差异，不是信息树缺少层次；第一版不改 Core 和信息采集规则。

## 玩家向布局

1. 芯片概览：显示芯片完整名称、实际存在的简介/类别/标签、互斥组名称和激活要求。名称已经包含构型时，不另列构型名称；不显示构型简介。激活要求按实际条件逐条排列，不假定只有一条。
2. 根级功能：按信息树声明顺序展示。
3. 形态与姿态：存在时按信息树父子层级嵌套展示，不改成平铺；默认全部展开。
4. 每项功能内部：统计图表排在该功能内容最前面；其后展示该功能直接拥有的实际属性、语义子组、附属效果和声明的组合关系/结果。关系与结果遵循其实际所属节点，不跨节点解释。

## 统计图表

- 远程攻击：雷达图显示单次伤害、护甲穿透、有效距离、弹速、停止力和理论 RPM；四距离精度使用独立的整行走势图。子弹数量与射击节奏仍以普通属性行显示。远程攻击之外不展示目标类型、视线要求或飞行特征。
- 近战攻击：雷达图显示单次伤害、护甲穿透、理论 APM 和攻击距离；每次命中计为一次攻击。攻击间隔、预热和冷却只供计算使用，不在玩家详情展示。
- 雷达图基准值来自可配对的信息比较模型；沿用旧图中当前值/基准值的绘法、固定标尺、裁切和超限数值颜色，不加溢出标记。雷达与精度图各自独占整行。
- 若绘制图表所需字段不完整，则不绘制不完整图；只展示存在且允许展示的普通属性，不推测缺失值。
- 非远程/近战攻击的有效距离与最小距离在实际拥有这些值的功能下用同心范围环表达。护盾抵挡角度在护盾属性行旁显示有可读尺寸的扇形示意。

## 信息筛选与表达

- 只显示实际存在的值；合法缺项不提示、不预估、不占位。仅非法冲突保留提示。
- 玩家文字优先使用已有本地化标签；遇到无法解析的标签时不暴露内部键名。
- 不展示槽位与占用、目标类型、视线要求、远程飞行特征，以及激活/停用延迟。攻击图中的派生指标不重复以解释性文案复述。
- 字段使用结构化“名称：值”表达；不把数据改写成推测性的战斗描述。
- 移除“无属性”等提示、图表说明脚注和纯解释性提示。

## 实现边界

- 复用 Content 中现有信息树、语义功能渲染器、比较模型和 RimWorld 原生绘制方式。
- 将制造预览接入同一详情渲染入口；保留制造台的成品名称及其当前未完成状态入口，移除并行规格/构型卡片视图。
- 仅在确有必要时增加 Content 内的制造比较模型适配；不为展示改动信息树采集层，也不新增 Core 机制。
- 视觉以触发器装配台现有深青色背景、边框、标题和文字层次为准。游戏实测是最终可读性判断；构建和静态检查不能替代游戏内目视确认。

## 验收要点

- 两处入口显示相同信息结构，制造预览与装配台只因当前/基准数据来源而异。
- 构型名称与简介、内部键、解释性提示、被明确排除的字段均不出现。
- 多条激活要求能完整罗列；功能、形态、姿态父子关系仍清楚；所有层默认展开。
- 远程/近战雷达以及远程精度图分别整行；图表缺少必要当前值时不展示残图；图表仍保留独立基准比较。
- Content 编译通过，相关展示契约检查通过，并由游戏内画面验证或明确记录等待玩家画面反馈。
