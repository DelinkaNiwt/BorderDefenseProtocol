# BDP 芯片信息设施路线 C：能力分类与契约读取面实施计划

> **For Claude（供执行代理）:** REQUIRED SUB-SKILL（必须使用的子技能）: Use superpowers:executing-plans to implement this plan task-by-task（使用 executing-plans 技能逐项执行本计划）。

**Goal（目标）：** 建立不依赖芯片分类、职业或名称的统一武器能力判定，并给 Content（内容程序集）提供只读的正规化表达契约入口，为后续 Development（开发程序集）原版武器投影验证提供稳定事实源。

**Architecture（架构）：** `ChipExpressionContractInterpreter`（表达契约解释器）继续保留内部实现；新增 `ChipExpressionContractSurfaceAccess`（表达契约读取面）只负责调用解释器并返回正规化结果；新增 `ChipExpressionCapabilityResolver`（芯片表达能力解析器）只依据配置或正规化契约中的 Verb（攻击动作）、Tool（近战工具）、Projectile（投射物）和增强模块事实判断能力。制造分类、职业约束和装配选择继续留在 Content。

**Tech Stack（技术栈）：** RimWorld 1.6、C# 7.3、Verse、BDP Core/Content、PowerShell 静态边界冒烟测试。

## 一、已确认的现况与边界

1. 解释器已经负责把形态、姿态、条目顺序、近战 Tool 和远程 VerbProperties（攻击属性）整理为 `ChipExpressionResolvedContract`（已解析表达契约）。
2. `ChipExpressionContractInterpreter`、`IChipExpressionContractInterpreter` 和 `ExpressionContractCache` 都是 Core 内部设施，不直接向 Content 暴露。
3. `IsMeleeEntry`（近战条目判断）在解释器、结构验证器和近战 Tool 构建器中重复出现，三处规则当前都是“显式 Melee 模式或 VerbProperties 标记近战”。
4. `ChipAssemblyDetailModelBuilder.HasRangedWeaponFunction`（装配台远程功能判断）还混有制造分类和装配业务，不能整体搬进 Core；只可替换其中表达模式原子判断。
5. `ExpressionContractCache` 有字段但当前解释路径没有调用 `GetOrAdd`；本路线不启用缓存，避免没有性能证据的状态改变。

## 二、能力判定裁定

### 1. 条目是不是武器候选

- 只有 `PrimaryVerb`（主攻击）和 `SecondaryVerb`（副攻击）属于 Verb 条目。
- Ability（能力）、Hediff（健康状态）和 Passive（被动）不属于独立武器。

### 2. 近战/远程模式

优先级固定为：

1. `WeaponMode`（武器模式）显式值；
2. `VerbProperties.IsMeleeAttack`（原版近战标记）推断近战；
3. 存在 `defaultProjectile`（默认投射物）推断远程；
4. 其余返回 `None`（未知/非武器表面）。

### 3. 可执行表面

- 可执行近战：武器候选 + 解析为近战 + 存在有效 `ResolvedVerbSpec`（正规化攻击规格）和 `Tool`/近战 Tool 表面。
- 可执行远程：武器候选 + 解析为远程 + 存在有效 `ResolvedVerbSpec` 和投射物。
- 远程模块、远程增强附件本身不计为独立武器；没有可执行 Verb 时可识别为 `IsAugmentationOnly`（仅增强）。
- 非法条目（缺少近战 Tool、缺少远程投射物或缺少攻击类型）不算可执行武器。

## 四、明确不在本路线实施的事项

- 不接入原版 `SpecialDisplayStats`（特殊信息条目）或 `StatWorker`（属性计算器）；那是路线 D/E。
- 不把制造分类、职业约束、装配台雷达规则搬进 Core。
- 不拆 `ChipInformationDetailRenderer`（装配台详情渲染器）大文件；那是路线 G。
- 不重写 `ChipInformationModel`（芯片信息模型）或引入万能格式化配置。
- 不启用未被证明需要的表达契约缓存。

## 五、完成标准

- 同一份配置在解释器、验证器和信息适配中使用同一套近战/远程原子判断。
- “只有远程增强附件”的芯片不被解析器认作独立远程武器。
- 非法远程/近战条目不会通过可执行表面判定。
- Content 可以通过只读读取面拿到正规化契约，不接触内部解释器或缓存。
- Core 仍保持中性，不依赖 Content；路线 D/E 的原版信息卡工作可以直接以本路线输出为输入。
