# BDP 触发体芯片控制面板正式化实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将当前活动的 Trion 右侧芯片控制面板迁入 `BDP.Content.dll`，通过具体触发体 Def 的许可扩展决定是否显示，并把玩家文字清理为正式中文。

**Architecture:** Core（核心程序集）继续只提供中性 Trion 面板容器和 Trigger 正式接口，不新增具体触发器类别或界面业务。Content（内容程序集）拥有许可扩展、面板提供器与启动注册；候选触发体只挂载许可扩展，候选程序集不再保留或注册重复面板实现。

**Tech Stack:** C# 7.3、RimWorld/Verse、Unity IMGUI（即时模式界面）、XML（配置文件）、PowerShell（自动检查）、Git（版本控制）
