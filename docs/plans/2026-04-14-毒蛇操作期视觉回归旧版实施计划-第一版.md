# 毒蛇操作期视觉回归旧版实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让新 BDP 的毒蛇在玩家操作阶段完全回到旧 BDP 的表现：保留原版射程圈/目标白圈/鼠标图标，只用白红折线表达路径，只保留锚点计数字，右键直接取消整次瞄准，不再保留绿色格组、右键回退锚点、额外提示等旧版没有的设计。

**Architecture:** 继续使用新 BDP 现有的 `AttackExecutionTargetingSource` + `PreviewRecord` + `PathLatchModule` 分层，不回退整体架构。宿主层只负责保留并补足旧版所需的原版预览维度与文字绘制；毒蛇模块只负责生成旧版等价的折线和计数字真值，不再额外发明格组、回退、即时禁止态等表现。

**Tech Stack:** C# / RimWorld `ITargetingSource` / BDP `PreviewRecord` / `PathLatchModule` / PowerShell 烟雾测试
