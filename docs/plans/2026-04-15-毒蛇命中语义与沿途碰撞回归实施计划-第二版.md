# 毒蛇命中语义与沿途碰撞回归修复-第二版 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把毒蛇首段锚点从正式命中语义里彻底剥离，让它只承担导航职责；同时保留现有续段 `origin（拦截距离基点）` 兼容，让原版 `vanilla（原版）` 沿途拦截重新按原版概率和距离规则自然生效。

**Architecture:** 当前仓库已经有两块半成品修正：`BdpVerb_Shoot（宿主射击）` 已拆出 `semanticTarget（语义目标）` / `navigationTarget（导航目标）`，`BdpProjectile（主弹体）` 已有 `ComputeContinuationOrigin（续段兼容起点）`。真正残留的根因仍在 `Aim（瞄准阶段） -> ProjectileInit（投射物初始化阶段）` 的字段契约：`PathLatchModule（毒蛇路径模块）` 还在借 `Aim.FinalTarget（瞄准最终目标）` 传首段锚点，导致 `ProjectileInitPlan.CurrentTarget（当前正式目标）` 被污染。第二版只补一条中性 `LaunchTarget（发射导航目标）` 覆盖通道，恢复三值分层：`LaunchTarget = 首段锚点`、`AimTarget = 最终目标`、`CurrentTarget = 最终目标`，不新增自定义碰撞系统。

**Tech Stack:** C# / RimWorld `Projectile（投射物）` / RimWorld `Verb（攻击宿主）` / BDP `AimStage` / BDP `ProjectileInitStage` / PowerShell 烟雾测试 / 游戏日志回放
