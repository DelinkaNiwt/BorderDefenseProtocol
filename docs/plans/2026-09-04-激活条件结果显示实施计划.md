# 激活条件结果显示实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将芯片详情中的激活条件条目简化为“条件名：结果”，去掉“可用”和“至少”，并保留等级单位。

**Architecture:** 保留 `PawnRequirementSnapshot.RequiredValueText` 的完整最低要求语义，新增静态条件的 `ResultValueText` 作为详情展示值。结果值沿条件事实、信息字段传递到详情渲染器；渲染器优先显示角色当前值，否则显示定义结果值，不改变激活判定。

**Tech Stack:** C#（C#语言）、RimWorld/Verse UI（边缘世界/Verse界面）、PowerShell 契约测试、MSBuild（微软构建工具）。
