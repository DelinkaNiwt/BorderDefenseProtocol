# 毒蛇路径边界修正 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正新毒蛇的段 LOS 判定与分段飞行边界，让路径模块只改路径，不越权吞掉原版真实碰撞命中。

**Architecture:** 主模组从底层收口投射物阶段边界：只有到达当前规划段终点时才允许继续下一段，真实碰撞仍回落原版命中。测试模组只补毒蛇自己的段合法性接线与必要诊断日志，不在业务层堆补丁。  
`Arrival（到达阶段）` 继续保持中性，只增加“下一段目标”这一条必要事实；毒蛇模块据此传递下一段真值，不改墙、门、命中等既定规则。

**Tech Stack:** C#、PowerShell smoke tests、RimWorld vanilla projectile flow

### Task 2: 自底向上收口主弹体续段边界

**Files:**
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP/Core/Projectiles/BdpProjectile.cs`
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP/Core/Projectiles/RangedFlightProtocol/Arrival/ArrivalContribution.cs`
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP/Core/Projectiles/RangedFlightProtocol/Arrival/ArrivalStageService.cs`
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP/Core/Projectiles/RangedFlightProtocol/Model/ArrivalRecord.cs`

**Step 1: Move arrival arbitration**
- 在 `ImpactSomething` 里接入 `ExecuteArrival` / `ShouldContinueFlight` / `ContinueFlight`。
- `Impact` 只处理真实命中、战斗日志、伤害计划，不再越权决定续段。

**Step 2: Carry next-leg truth**
- 给 `ArrivalContribution` 与 `ArrivalRecord` 增加 `HasNextTarget` / `NextTarget`。
- `ContinueFlight` 优先消费 `NextTarget`，避免续段目标真值丢失。

**Step 3: Preserve vanilla physical rules**
- 续段只发生在“飞到当前段终点”这一种情形。
- 飞行途中撞墙、撞人、被护盾拦截时，仍由原版 `Impact` 正常终结。

**Step 4: Verify**
- 重跑边界 smoke tests。
