# BDP 齐射镜头无关推进实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让已绑定 BDP 发射计划的投射物以逐 tick 频率推进，不再因镜头移出投射物而产生齐射时序错位。

**Architecture:** 复用 RimWorld 原版 `Projectile.UpdateRateTicks`（投射物更新间隔）扩展点，在 BDP 的统一投射物宿主 `BdpProjectile` 上做单点覆盖。已绑定 `launchPlan` 的正式 BDP 投射物返回 1；未绑定计划的兼容路径继续使用原版更新策略。不改齐射编排、飞行协议、碰撞或视觉附加系统。

**Tech Stack:** C# 7.3、RimWorld 1.6、PowerShell 静态烟测、MSBuild。

### Task 2：实现 BDP 投射物逐 tick 更新

**Files:**
- Modify: `Source/BDP/Core/Projectiles/BdpProjectile.cs`，放在 `BindLaunchPlan` 附近的投射物生命周期成员区域。

**Step 1: Write minimal implementation**

添加带中文成员注释的 `public override int UpdateRateTicks` 属性：

```csharp
public override int UpdateRateTicks
{
    get
    {
        return launchPlan != null ? 1 : base.UpdateRateTicks;
    }
}
```

不修改 `Tick()`、`TickInterval()`、`Launch()`、碰撞服务或发射计划模型。
