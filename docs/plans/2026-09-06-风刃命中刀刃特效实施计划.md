# 风刃命中刀刃特效 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为风刃增加一次真实命中只播放一组的脚边能量刀刃动画，并保持伤害、护盾和飞行路线不变。

**Architecture:** 在 `BDP.Content` 增加风刃专用 Impact（命中阶段）模块和额外效果执行器，复用 Core 已有的伤害后效果派发边界。执行器按“攻击实例 + Pawn 标识”短期去重，再在原命中格生成受原版维护的 `Effecter`（特效器）；Effecter 用前后两层共 6 个 `Fleck`（轻量特效实例）完成错峰刀刃动画。

**Tech Stack:** RimWorld 1.6、C# 7.3、.NET Framework 4.8、Verse/RimWorld `EffecterDef` 与 `FleckDef`、PowerShell 契约测试、PNG（便携式网络图形）贴图。

> **修正约束（已获用户确认）：** 斜刺刀刃不得通过旋转整张 Fleck 贴图实现。每个方向变体自身必须带水平接地底边，Effecter 子项不设置 `rotation`；方案 2（水平底座加旋转刀身）不实现，方案 3（自定义 Mote）仅在游戏内确认方案 1 不足时再单独评估。
