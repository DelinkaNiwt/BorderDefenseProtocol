# 远程投射物拖尾颜色覆盖 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让铅弹在不改变拖尾其他参数的前提下，把本发 BDP 投射物产生的拖尾染成灰黑色。

**Architecture:** `RangedDebuffModule` 在 ProjectileInit 阶段提交可选的中性视觉颜色覆盖。Core 将覆盖合并、序列化并传给视觉附加宿主；Content 中的 BeamTrail 提供器消费该覆盖并写入每条拖尾线段。受击闪烁颜色继续使用独立的 Impact（命中结算）路径。

**Tech Stack:** C#（C#语言）、RimWorld 1.6、Harmony（运行时补丁）、XML（可扩展标记语言）、PowerShell 边界烟雾测试。

**Step 1: Extend the provider call**
