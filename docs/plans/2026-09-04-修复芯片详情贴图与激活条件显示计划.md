# 修复芯片详情贴图与激活条件显示实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 恢复芯片详情概览中的芯片贴图，并让激活条件显示各自具体的玩家可读名称。

**Architecture:** 保持芯片定义、制造逻辑和激活判定不变。为中性信息模型补充可选的动态展示名称，解析输入适配器传递 `PawnRequirementSnapshot.Label`，激活条件规则把名称带到最终字段，详情渲染器优先使用该名称；芯片贴图恢复原有 `ThingIcon` 绘制调用。

**Tech Stack:** C#（C#语言）、RimWorld/Verse UI（边缘世界/Verse界面）、PowerShell 契约测试、MSBuild（微软构建工具）。
