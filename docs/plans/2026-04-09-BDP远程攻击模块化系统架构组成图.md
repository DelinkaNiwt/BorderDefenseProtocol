## 2. 阶段与冻结边界图

```text
玩家点击攻击入口
  ↓
ManualEntry
  ↓
Targeting
  ↓
Preview
  ↓
Confirm  ────── 冻结交互输入 + 模块顺序快照
  ↓
AttackRequest
  ↓
Aim
  ↓
Prepare
  ↓
Fire
  ↓
ProjectileInit ─ 冻结 ProjectileInitPlan + 执行链快照
  ↓
Flight
  ↓
Arrival
  ↓
Hit
  ↓
Impact
  ↓
原版能力执行
```

## 3. `Preview` 与 `Impact` 的结构位置

```text
Preview
  ├─ 基线来源：原版 Verb.DrawHighlight / Verb.OnGUI
  ├─ 协议表面：PreviewRecord
  ├─ 维度：RangeRing / TargetHighlight / FieldRadius / MouseAttachment
  └─ 结果：按维度决定保留哪些原版预览表面

Impact
  ├─ 基线来源：BdpProjectile 根据 projectileDef 生成基线命中计划
  ├─ 协议表面：ImpactPlan
  ├─ 基线层：BaselineDirectDamage / BaselineAreaEffect
  ├─ 计划层：DamagePlan / AreaEffectPlan / ExtraEffectPlan
  └─ 结果：SuppressBaselineImpact 只抑制基线层，不抑制计划层
```

## 4. 作者接入视角图

```text
作者写：
  1. BdpRangedAttackModuleDef
  2. IRangedAttackModuleRuntime 实现
  3. ChipExpressionEntryConfig.RangedModules 挂载项

系统做：
  1. 解析表达式条目
  2. 生成 FormalExpressionResult
  3. 建立 RangedAttackModuleSession
  4. 分发到前置链和执行主骨架
  5. 按维度规则合并结果
  6. 交给 BdpProjectile 执行
  7. 落回原版能力
```

## 5. 当前成型后的关键边界

```text
主模组知道：
  - 阶段
  - 记录
  - 计划
  - 维度
  - 顺序
  - 冻结

主模组不知道：
  - 爆炸模块
  - 直伤模块
  - 范围模块
  - 穿透模块
  - 任意具体业务模块

这意味着：
  - 主模组保持业务无知
  - 外接模块仍可利用协议天然接入
  - 无模块时结果回到原版基线
```
