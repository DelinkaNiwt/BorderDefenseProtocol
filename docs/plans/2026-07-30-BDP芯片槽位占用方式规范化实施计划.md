# BDP 芯片槽位占用方式规范化 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把芯片装载侧的 `IsDualWieldBinding（是否双持绑定）`不兼容迁移为必填的 `SlotOccupancy / Single / PairedHands（槽位占用方式/单槽/成对主副槽）`，并修正成对激活时一次性激活费用可能重复结算的问题。

**Architecture:** Core（核心程序集）用中性的 `ChipSlotOccupancy（芯片槽位占用方式）`描述物理占槽；现有根槽、镜像槽、绑定关系和存读档结构继续承担成对占槽运行状态。根槽代表整枚逻辑芯片，镜像槽只占位；容量、激活费、持续费用、正式事件和表达均只由根槽计算一次。

**Tech Stack:** RimWorld 1.6 XML（边缘世界1.6定义文件）、C#（C#语言）、PowerShell（自动检查脚本）、.NET Release（发布）构建、Git（版本控制）

## 正式结构

普通单槽芯片：

```xml
<Loadout>
  <SlotRegion>MainSub</SlotRegion>
  <SlotOccupancy>Single</SlotOccupancy>
</Loadout>
```

成对占据主副同编号槽位的芯片：

```xml
<Loadout>
  <SlotRegion>MainSub</SlotRegion>
  <SlotOccupancy>PairedHands</SlotOccupancy>
</Loadout>
```

枚举：

```csharp
public enum ChipSlotOccupancy
{
    Unspecified = 0,
    Single = 1,
    PairedHands = 2
}
```

合法组合：

```text
MainSub + Single       → 合法
MainSub + PairedHands  → 合法
Special + Single       → 合法
Special + PairedHands  → 定义错误
任意区域 + Unspecified → 定义错误
```

成对占槽结算：

```text
根槽：逻辑芯片、正式事件、费用、表达
镜像槽：只占据对侧同编号槽位，不独立收费或发布表达
```
