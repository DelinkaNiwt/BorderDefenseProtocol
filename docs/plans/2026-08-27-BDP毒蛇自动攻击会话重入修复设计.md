# BDP 毒蛇自动攻击会话重入修复设计

## 目标

修复自动攻击在毒蛇等带路径的远程攻击仍持有上一轮正式宿主会话时，错误复用旧目标、反复扣除 Trion（特里昂）并把失效目标传入原版射击报告的问题。

## 已确认根因

自动远程入口发现正式宿主仍有活动会话时，当前实现仍返回该宿主；续射规划器随后优先读取宿主冻结的模块会话和确认目标快照。因此，新自动目标与旧路径计划发生混用。旧目标脱离地图后，原版 `ShotReport.HitReportFor`（射击报告）在读取屋顶时抛出空引用；异常又阻止原版暖机姿态清理，造成每 tick（游戏刻）重试。

## 设计

1. 自动入口遇到活动 BDP 正式宿主时，明确拦截本次新自动起手，不覆盖、重绑或复用旧宿主；交回空的原版攻击候选，让当前正式会话先完成所有权收尾。
2. 远程发射在提交 Trion 或生成投射物前，确认计划中的语义目标仍有效：格子目标可以继续，实体目标必须仍在当前地图且已生成。无效时关闭本轮宿主会话，不进入原版射击报告。
3. 将投射物生成和初始化移动到 `ShotReport.HitReportFor` 以及终端掩体快照计算之后。射击报告异常或目标失效时，不留下已生成但未调用 `Launch`（发射）的投射物。
4. 不改变毒蛇路径、最后一段路径起点和终端掩体规则；本修复只处理攻击会话所有权和发射前生命周期。

## 验证

- 自动宿主重入回归：活动正式宿主收到不同自动目标时不得返回旧 BDP 宿主。
- 发射原子性回归：射击报告必须先于投射物生成；失效语义目标不得扣除 Trion。
- 运行现有相关烟测、Core/Content Release 构建，并在游戏中复测自动毒蛇连续换目标场景。
