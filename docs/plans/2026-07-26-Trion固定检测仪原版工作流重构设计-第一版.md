# Trion 固定检测仪原版工作流重构设计（第一版）

## 1. 目标

把固定 Trion 检测仪从“玩家先指定操作员，再右键设备选择受检者”的双人命令，重构为接近 Biotech（生物科技）差分扫描仪和裂解扫描仪的建筑主导流程：

1. 玩家通过建筑按钮和 Pawn（角色）菜单指定受检者。
2. 能行动的受检者自行进入建筑；倒地者由殖民者搬入。
3. 受检者就位后，建筑发布高优先级研究类工作。
4. 智识至少 10、允许研究工作的 Pawn 自动前来操作。
5. 建筑保存进度，并以原版进度条提供视觉反馈。
6. 完成后提交准确检测结果并自动释放受检者。

一次性便携检测器本轮保留现状，未来另行设计。

## 2. 原版依据

RimSearcher（原版代码检索器）确认：

- `SubcoreSoftscanner`（差分扫描仪）和 `SubcoreRipscanner`（裂解扫描仪）均由 `Building_SubcoreScanner` 派生。
- `Building_SubcoreScanner` 继承 `Building_Enterable`（可进入建筑），由建筑容纳受检者。
- 原版通过独立 WorkGiver（工作分配器）支持自行进入和搬运进入。
- 原版扫描建筑在建筑侧保存工作状态，并使用进度条效果提供反馈。

本设计只复用“建筑容纳 Pawn、工作系统分配、进度归建筑”的结构，不继承机械核心原料、产物、疾病或致死业务。

## 3. 建筑状态

固定检测仪直接在 `Building_TrionDetector` 保存最小状态，不增加新的业务 Comp（组件）：

- 已预约的受检者；
- 当前容纳的受检者；
- 已完成检测工作量；
- 当前是否处于等待进入、等待操作或操作中。

状态流：

```text
空闲
→ 已选择受检者
→ 等待自行进入或搬运
→ 受检者已容纳
→ 等待合格操作员
→ 操作并累计进度
→ 提交结果
→ 自动弹出并回到空闲
```

建筑被摧毁时复用原版容器释放语义，不能吞掉 Pawn。

## 4. 玩家入口

固定检测仪提供两个原版 Gizmo（按钮）：

- `选择受检者`：打开 Pawn 菜单，只列出玩家可控的殖民者、奴隶和囚犯。
- `取消检测`：仅在已有预约或受检者时显示。

菜单资格继续复用现有检测规则：

- 必须是人形 Pawn；
- 没有有效 Trion 腺体；
- 尚未完成检测；
- 具有有效潜在容量；
- 不能是未受控制的敌对或中立 Pawn。

选择能行动的 Pawn 后，立即给其下发进入工作。倒地 Pawn 不接收自行进入工作，改由搬运 WorkGiver 自动寻找殖民者搬入。

## 5. 工作分配

### 5.1 受检者进入

使用独立 Job（工作）与 WorkGiver：

- 可行动受检者自行走到检测仪并进入容器；
- 倒地受检者由合格搬运者送入；
- 建筑预约变化、目标恢复或失效时，工作安全结束。

### 5.2 操作员工作

检测操作归入 `Research`（研究）工作类型，并通过 `priorityInType`（类型内优先级）排在普通科研之前。

操作员必须：

- 智识等级至少 10；
- 研究工作未禁用；
- 能到达检测仪交互格；
- 建筑已通电；
- 建筑内已有仍符合检测资格的受检者。

玩家不预先指定操作员。任何符合条件且有空的研究员都可以接手。

## 6. 进度与中断

基础总工作量为 7,500 tick（游戏刻）等价工作量，即 `ResearchSpeed`（研究速度）100%时约 3 个游戏小时。

每个操作 tick 的贡献按操作员 `ResearchSpeed` 计算。进度归建筑保存：

- 操作员吃饭、睡觉、换人：保留进度；
- 断电：停止工作，受检者留在建筑内，保留进度；
- 玩家主动取消：弹出受检者，进度清零；
- 建筑被摧毁：安全释放受检者；
- 受检者中途获得有效腺体或被其他设备检测：取消、弹出并清零。

操作期间在建筑上显示原版进度条；无人操作时不推进。

## 7. 完成提交

完成时重新验证：

- 受检者仍符合资格；
- 当前操作员仍满足智识和研究工作条件；
- 建筑仍存在且通电。

成功后：

1. 调用现有 `TrionAssessmentService.TryCommit`（检测提交服务）。
2. 发布准确的模糊档位消息。
3. 信息页开始显示同一档位。
4. 自动弹出受检者。
5. 清空建筑预约与进度。

检测真值与档位解析仍只存在于统一服务，建筑和 JobDriver（工作驱动器）不得复制业务规则。

## 8. 边界

本轮删除固定检测仪的旧右键双人入口和固定仪器专用旧操作 Job 时序。

本轮不修改：

- 一次性便携检测器及其现有右键流程；
- 潜在容量抽样；
- 检测档位；
- 正式腺体基因；
- 腺体获取渠道。

## 9. 验证

自动化验证至少覆盖：

- 固定检测仪只有建筑按钮入口；
- 菜单只列出允许的受检者；
- 可行动者自行进入；
- 倒地者可被搬运进入；
- 操作工作属于研究类型且优先于普通科研；
- 智识 9 不接取，智识 10 可以；
- 研究速度影响推进量；
- 基础总工作量为 7,500；
- 进度归建筑并支持换人续作；
- 断电暂停但不清空；
- 主动取消弹出并清空；
- 完成提交并弹出；
- 资格中途失效时取消；
- 便携检测器现有入口未改变。

游戏内验收重点：

- 建筑按钮与 Pawn 菜单；
- 自行进入及倒地搬运；
- 工作优先级；
- 研究员自动接取与换人；
- 进度条；
- 断电暂停；
- 完成和取消时的安全弹出。
