# Dual Ranged Target And LOS Isolation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正 dual 远程场景下“毒蛇把第一锚点污染给另一侧齐射目标”的问题，并按每侧自身 LOS 语义裁定 dual 是否执行、执行哪一侧。

**Architecture:** 保留“导航目标”和“语义目标”两条真值，不再把 `ConfirmRecord.Target` 既当毒蛇首段导航点又当 dual 另一侧真正目标。先把已确认目标冻结为中性攻击上下文节点，再让 dual 编排和 per-side LOS 剪枝统一读取该节点；毒蛇侧继续在 `ProjectileInit` 覆盖自己的 `LaunchTarget`，但不再污染另一侧的语义目标。

**Tech Stack:** C# / RimWorld 1.6 / BDP AttackExecution + RangedProtocol / PowerShell smoke tests / `dotnet msbuild`

3. 在 `AttackExecutionService.Stages` 新增统一读取：

```csharp
private static LocalTargetInfo ResolveSemanticTarget(AttackExecutionPreparedContext request)
{
    ConfirmedTargetSnapshot confirmed = request?.AttackContextSnapshot?.GetNode(AttackContextKeys.ConfirmedTarget) as ConfirmedTargetSnapshot;
    return confirmed != null && confirmed.SemanticTarget.IsValid
        ? confirmed.SemanticTarget
        : request != null ? request.Target : LocalTargetInfo.Invalid;
}
```

```csharp
LocalTargetInfo dualSemanticTarget = ResolveSemanticTarget(request);
List<AttackExecutionCast> mainCasts = BuildSingleResultCasts(request, mainResult, dualSemanticTarget, true, 0);
List<AttackExecutionCast> subCasts = BuildSingleResultCasts(request, subResult, dualSemanticTarget, false, 0);
```

```csharp
// RangedAttackEntry
public LocalTargetInfo SemanticTarget { get; set; }

// Aim
FinalTarget = entry != null && entry.SemanticTarget.IsValid ? entry.SemanticTarget : entry.Target;

// Fire
emit.SemanticTarget = baselineEmit != null && baselineEmit.SemanticTarget.IsValid ? baselineEmit.SemanticTarget : entry.SemanticTarget;

// ProjectileInit

AimTarget = entry != null && entry.SemanticTarget.IsValid ? entry.SemanticTarget : aim.FinalTarget;
```

这样毒蛇仍可在 `ProjectileInit` 覆盖自己的 `LaunchTarget=第一段`，但另一侧齐射拿到的是 `SemanticTarget=最终目标`。

在 `AttackExecutionService.Stages` 新增 per-side 剪枝：

```csharp
private static bool CanExecuteDualRangedSide(AttackExecutionPreparedContext request, FormalExpressionResult result, LocalTargetInfo semanticTarget)
{
    ResolvedVerbSpec resolvedSpec = result != null ? result.ResolvedVerbSpec : null;
    if (resolvedSpec == null || !resolvedSpec.RequireLineOfSight)
    {
        return true;
    }

    Pawn pawn = request != null ? request.Pawn : null;
    if (pawn == null || !semanticTarget.IsValid)
    {
        return false;
    }

    if (!VerbHostSurfaceAccess.TryGetByResultId(pawn, result.Id, out BdpFormalVerbBinding binding))
    {
        return false;
    }

    Verb verb = binding.ResolveActiveVerb();
    return verb != null && verb.CanHitTargetFrom(pawn.Position, semanticTarget);
}
```

然后在 dual 构建中：

```csharp
bool allowMain = CanExecuteDualRangedSide(request, mainResult, dualSemanticTarget);
bool allowSub = CanExecuteDualRangedSide(request, subResult, dualSemanticTarget);
```

裁定规则：
- `allowMain && allowSub`：双侧都编排
- 仅一侧为 `true`：退化成只编排该侧
- 都为 `false`：返回空 cast，阻止 dual

这正好对应你的三条需求，不需要额外发明 dual 专用业务规则。
