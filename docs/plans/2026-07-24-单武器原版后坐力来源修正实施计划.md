# 单武器原版后坐力来源修正 Implementation Plan（实施计划）

> **For Claude（供执行代理使用）:** REQUIRED SUB-SKILL（必需子技能）: Use `superpowers:executing-plans`（实施计划执行技能）、`superpowers:test-driven-development`（测试驱动开发技能）和 `superpowers:verification-before-completion`（完成前验证技能） to implement this plan task-by-task（逐项执行本计划）。

**Goal（目标）:** 让单枚激活武器芯片使用真实来源正式 `Verb.LastShotTick`（攻击动作最近开火时刻）计算原版后坐力。

**Architecture（实现方式）:** 保留 `ReplaceTextureOnly`（只替换贴图）单武器路径，只把已选 `VisualResidentEntry`（视觉常驻条目）和 `CompTriggerBody`（触发器主体组件）传到姿态绘制方法。按 `entry.ResultId`（条目结果标识）解析 `binding.RangedVerb`（绑定远程攻击动作），直接调用原版 `EquipmentUtility.Recoil`（装备后坐力计算）。

**Tech Stack（技术栈）:** RimWorld 1.6（边缘世界 1.6）、C#（C#语言）、PowerShell（微软命令行脚本）、Git（版本控制工具）。

**Workspace rule（工作区规则）:** 直接在当前工程和 `main`（主）分支执行，不创建 worktree（工作树）或新分支。绘制补丁和单武器测试是已有未提交前置工作；禁止把整段前置实现吸收到本次提交。

```csharp
DrawTextureOnlyReplacement(
    equipment,
    triggerBody,
    entry,
    sourceThing,
    preset,
    graphic,
    sample);
```

方法签名增加：

```csharp
CompTriggerBody triggerBody,
VisualResidentEntry entry,
```

**Step 2：替换错误的原版攻击动作列表读取**

删除：

```csharp
CompEquippable compEquippable = equipment.TryGetComp<CompEquippable>();
if (compEquippable != null && equipment.def != null)
```

改为：

```csharp
if (equipment.def != null
    && triggerBody?.VerbHostManager != null
    && entry != null
    && triggerBody.VerbHostManager.TryGetByResultId(
        entry.ResultId,
        out BdpFormalVerbBinding binding)
    && binding?.RangedVerb != null)
```

原版调用只替换第二个参数：

```csharp
EquipmentUtility.Recoil(
    equipment.def,
    binding.RangedVerb,
    out drawOffset,
    out angleOffset,
    sample.AimAngle);
```
