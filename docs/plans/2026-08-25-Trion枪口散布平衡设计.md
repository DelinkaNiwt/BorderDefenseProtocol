# Trion 枪口散布平衡设计

## 目标

让 Trion 构型的真实发射点以理论中心为基准保持左右平衡，同时保留随机性：最终只有一发时不做任何散布；两发及以上时，首发随机选择左右，后续按发射序号左右交替。

## 已确认根因

`BdpVerb_Shoot.ResolveRandomOriginSpreadOffset` 当前每发独立执行一次横向区间随机。独立随机不携带同次发射的顺序关系，因此多发全部落在理论中心同一侧是允许结果。

## 设计

1. 复用现有正式发射计划的 `ExpectedEmitCount`（预期发射总数）和 `ProjectileInitPlan.EmitSequence`（本次发射序号），不新增 XML 数量字段、不新增统计链。
2. 当最终预期发射数量不大于 1 时，横向和前向发射点偏移都返回零，单发直接从理论中心发射。
3. 当最终预期发射数量大于 1 时，在一次正式发射计划开始时随机决定首发侧别；后续通过 `EmitSequence` 奇偶交替左右。
4. 横向偏移幅度仍按现有配置随机取样，前向偏移继续按现有 `ForwardMin..ForwardMax` 随机取样；只改变横向正负侧的安排。
5. 只修改发射点散布解算和对应烟测，不修改枪口锚点、视觉贴图、连发数量、组合技解析或 XML 配置。

## 验证边界

- 单发：横向、前向偏移均为零。
- 多发：序列中左右侧交替，首发侧别仍随机。
- Trion 当前四连发：四发包含两侧发射点，不会全部挤在同一侧。
- 无散布配置或无效目标：保持原有零偏移回退。
- 现有相关发射、组合构型和视觉烟测继续通过。
