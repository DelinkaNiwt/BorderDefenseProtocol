# 光魂举盾注视警戒连续瞄准视觉设计

## 目标

光魂举盾处于手动或自动注视警戒时，盾牌与同持的另一把武器共同跟随目标方向连续旋转、位移，视觉效果与 RimWorld 原版攻击 Verb 的持械瞄准一致；警戒仍然不攻击、不进入忙碌姿态。

## 现状

注视警戒当前只通过 `FaceTarget` 改变 Pawn 的四向朝向，没有建立原版攻击使用的 `Stance_Busy`。因此 `PawnRenderUtility.DrawEquipmentAiming` 收到的是平时公开持械的固定四向角度和位置，BDP 只能在这四个基准上应用视觉预设。

## 方案

在 BDP 已有的 `DrawEquipmentAiming` 视觉桥接边界解析当前可注视目标。存在有效目标时：

1. 从当前公开持械位置反推出原版人物装备绘制基点。
2. 使用目标相对 Pawn 的方向计算原版连续 `aimAngle`。
3. 按原版攻击绘制公式生成瞄准持械位置。
4. 让宿主装备、单武器替换视觉和双武器全部条目共用该位置与角度；既有预设继续叠加主副手偏移、镜像、角度和图层。

手动警戒读取当前 `BDP_LightSoulGuardWatch` 作业的目标，自动警戒读取 Verb 保存的自动目标。只有目标仍可注视时才覆盖视觉；目标超距、失去视线或失效时恢复普通举盾姿态。

不创建 `Stance_Busy`，不进入攻击施放链，不产生瞄准条、攻击、伤害、后坐力或攻击音效，也不新增存档状态。

## 验证

- 静态测试覆盖手动和自动警戒目标解析，以及渲染桥接对连续角度与原版瞄准位移的应用。
- 运行 LightSoul 与视觉相关冒烟测试。
- Release 构建全部 BDP 程序集，确认 Harmony 签名与程序集依赖正常。
