# BDP 简体中文本地化实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在主模组中建立符合 RimWorld 习惯的简体中文语言包，并把已确认的玩家可见文字改为稳定键调用。

**Architecture:** 语言资源统一放在主模组根目录的 `Languages/ChineseSimplified (简体中文)/`。代码文本进入按玩家功能分类的 `Keyed` 文件，Def 文本进入按实际 Def 类型分类的 `DefInjected` 文件；不按 Core/Content DLL 拆分。开发者日志、内部校验和测试模组具体芯片不纳入本轮。

**Tech Stack:** RimWorld XML language data、C# 原生 `Translate(...)`、PowerShell 静态检查、现有 .NET 构建流程。

- Modify: `模组工程/BorderDefenseProtocol/1.6/Content/Defs/**/*.xml`（同上）

**Steps:**
1. 读取所有 Def 根类型，按 `ThingDef`、`GeneDef`、`HediffDef`、`StatDef`、`JobDef` 等实际类型建立目录。
2. 为每个玩家可见 `label`、`description`、`reportString` 等字段建立 DefInjected 条目。

**Expected:** 中文语言开启时显示值不变；原始 Def 仍可作为未翻译语言的安全回退。
