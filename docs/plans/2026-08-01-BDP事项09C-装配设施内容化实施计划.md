# BDP 事项 09C：装配设施内容化实施计划

> 目标：保持现有玩家功能不变，只调整程序集归属和正式读取边界。

### Task 1：边界失败测试

- 新增 `TriggerAssemblyContentBoundarySmokeTests.ps1`。
- 锁定 Core 无装配业务源码/Def，Content 拥有全部装配源码/Def。
- 锁定 Core 公开芯片只读快照入口，Content 不直接使用 Core 内部芯片读取类型。

### Task 2：建立公开芯片定义快照

- Core 新增 `ChipDefinitionSnapshot` 和 `ChipDefinitionSurfaceAccess`。
- 快照只提供合法性、槽位区域、槽位占用、Trion 容量费用、激活费用、启用/停用延迟和 ThingDef 身份。
- 内部契约与校验对象继续保持 internal（程序集内可见），不把实现类型公开。

### Task 3：迁移装配业务

- 将 `Source/BDP/Core/Assembly/**` 移到 `Source/BDP.Content/Assembly/**`。
- 命名空间改为 `BDP.Content.Assembly`。
- 将 `1.6/Defs/Buildings/Assembly`、`Jobs/Assembly`、`WorkGivers/Assembly` 移到 `1.6/Content/Defs` 对应目录。
- 更新 XML 中 `thingClass`、`driverClass`、`workType` 和 ITab 类型引用。

### Task 4：更新测试、构建和记录

- 更新装配专项测试的源码与 Def 路径及公开快照断言。
- 构建 Core、Content、DevHarness；运行 Core 依赖门禁、装配专项和全量冒烟测试。
- 更新总计划、Agent 日志并提交。

### 执行结果（2026-08-01）

- 事项09C已完成：18个装配台、芯片仓、装配窗口、事务、Job和WorkGiver源码已迁入 `Source/BDP.Content/Assembly`，命名空间统一为 `BDP.Content.Assembly`。
- 装配 Buildings、Jobs、WorkGivers Def 已迁入 `1.6/Content/Defs`，XML中的类型引用已全部指向 `BDP.Content.Assembly`。
- Core 仅新增中性的 `ChipDefinitionSnapshot` 与 `ChipDefinitionSurfaceAccess`，对外提供装配界面所需的合法性、槽位、费用和延迟只读字段。
- Core 原 `Source/BDP/Core/Assembly` 与旧 `1.6/Defs/*/Assembly` 目录已清空，未保留装配业务源码或旧Def路径。
- 装配专项、迁移边界、芯片延迟命名、芯片搬运、装配事务、装载控制模式等相关冒烟测试全部通过。
- Core、Content、DevHarness Release 构建均成功；Core 零本模组程序集依赖门禁通过。
- 全量冒烟测试：285项中273项通过、12项失败；12项均为本次之前已存在的其它芯片/攻击/视觉事项失败，与09C无关。
