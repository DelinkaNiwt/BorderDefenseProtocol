# 战斗体被动崩解禁用扫描 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 只让主动解除战斗体播放退出扫描，被动崩解和紧急脱离直接瞬时恢复。

**Architecture:** Content 扫描提供器通过 Core 现有只读表面读取当前战斗体阶段。`Exit + Collapsing` 在捕获前和生成 Mote 前均被拒绝；Core 生命周期广播、宿主恢复和崩解烟雾不变。

**Tech Stack:** C# 7.3、RimWorld 1.6、BDP Core 只读战斗体表面、PowerShell 冒烟测试、dotnet Release 构建。
