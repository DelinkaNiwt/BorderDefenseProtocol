## 1. 接通目标与顺序

目标是让玩家通过正常游戏途径接触 BDP，反复试用基础玩法，建立可持续的核心与普通装备生产，再逐步选用现有功能、组合和基地支援。

| 工作组 | 接通后的玩家体验 | 当前准备程度 |
|---|---|---|
| 外部入口与首用物品 | 皇室借住、追兵携带原型，击退后正式加入；玩家主动契约取得首个腺体，皇室携带核心材料 | 正式任务骨架、物品载体和契约已接通，构建与离线边界通过，完整游戏流程待实测；专用低性能芯片留后 |
| 睡眠恢复 | 无核心也能积累与恢复人物能量，休整后再次使用；有许可时睡眠更快 | 已接通原版实际睡眠判定与独立配置倍率，编译及隔离验证通过，用户确认游戏内验证通过 |
| 核心正式运转 | 材料分析引出研究建设，已加入皇室启动核心并能持续补充 | 高层连接已定，研究项目、献祭交互与绑定细则待专题定案 |
| 普通生产与配装 | 同一制造台生产普通触发体和芯片，装配后使用、补充，继续拓展功能 | 制造、装配许可和普通触发体临时配方、独立制造页已接通；用户确认本轮制造页与配方验证通过，研究关联待接入 |

建议开发顺序：

1. **先准备可独立核对的连接**：睡眠恢复、原型成品，以及制造和装配的许可接入。各项按自身已定行为和必要细节形成实现方案，不等待完整剧情或整棵研究树。
2. **接通正常首次接触**：承接定下的事件方案，让物品取得、首次培养与反复试用成立；同一事件中的皇室加入仍发生在任务达成并结束后。
3. **接通正式核心与自主生产**：在核心细则和必要研究关联明确后，完成材料分析、研究建设、首次启动、常态补充及自制配装。
4. **接上已有中期内容**：把现有功能、组合、操作员支援和紧急脱离映射到作者确定的研究内容，沿普通生产与原有使用条件投入游戏。

这是开发检查顺序。玩家的试用、研究和筹备可以交错；试用、皇室加入或基因组提取不另设为彼此的统一前置。调试验证用于核对接点，正常取得途径仍需接通后才能认为对应体验完成。

## 2. 外部入口与首用物品

### 2.1 首次接触与人物加入

- **已有基础**：腺体基因、检测仪、战斗体和触发器装备资格提示。
- **皇室身份基础（2026-10-05）**：已补皇室血脉超凡基因，按内源位置使用；原版禁止普通提取，仅放行本基因的自然遗传候选，复制体保留身份。编译、真实候选与原版候选概率、非皇室边界及定义语言检查通过；游戏内实测待做，人物任务和核心识别绑定未接入。
- **最小工作**：补首次胚芽、原型、核心材料的正常接触机会；补皇室基因及人物任务，按任务目标达成并结束后的时点正式加入。
- **已定边界**：胚芽与原型机会紧密衔接；核心材料可由追兵、皇室或双方携带，具体载体与交付未固定。剧情敌人尸体提取成胚芽、原型作为战利品仍是候选。首次袭击需能由原版手段应对。
- **完成表现**：玩家能选择已有殖民者检测、植入、使用原型；人物和物品按实际条件取得，不需要先有运行核心或 BDP 战斗能力。
- **待专题补齐**：具体任务行动与达成条件、尸体提取交互、物品分配。损失后人物与物品分别保留有代价的重获机会；材料重获不能只依赖“没有皇室成员”才出现的加入任务。

### 2.2 低性能原型成品

- **最小工作**：补近界原型触发体，主槽预载一项低性能近战，副槽预载一项低性能远程，复用已有真实芯片预装和战斗体机制。
- **已定控制方式**：固定预载，不开放玩家装卸换配，不显示芯片槽位管理面板；保留战斗体与两项功能所需的使用操作。
- **当前实现**：已新增[近界原型触发体定义](C:/NiwtDatas/Projects/RimworldModStudio/模组工程/BorderDefenseProtocol/1.6/Content/Defs/ThingDef/Equipment/NeighborPrototype.xml)，主副各一槽，无特殊槽；主槽预载现有弧月、副槽预载现有小行星，不改两项芯片的性能、能量或制造配置。固定预装、战斗体启动和攻击入口沿现有流程，专用低性能芯片留到以后。
- **完成表现**：取得资格、具备能量的成员能直接体验两项基础功能；正式起步的普通装备有明确替代价值。
- **后续细化**：专用低性能芯片及其参数以后安排；现阶段先验证固定双预载的基础试用。取得事件和正式配方不在本项接入。
- **验证状态**：定义、预载引用、槽位兼容、语言和贴图检查通过，既有固定预装定义与初始化检查通过；用户选择不等待本项游戏内实测，继续下一工作包。生成、装备、两项攻击及睡眠恢复联测保留为后续核对，未记作实测通过；正常取得仍由外部入口承接。

沿用原版基因植入与后续基因提取、胚芽制作；不另设重复培养机制或基因组获取任务。检测用于认识潜质，不新增强制植入门槛。

## 3. 睡眠恢复

- **已实现行为**：地图内玩家角色，无许可且清醒时停止恢复；仅有核心许可时保持基准恢复率；仅有实际睡眠时默认使用基准的 20%；二者同时存在时默认使用 120%。
- **实现依据**：读取原版当前任务执行器的真实睡眠标记，躺下或昏迷本身不算睡眠；内容层读取核心许可与睡眠配置，基础层只将基准恢复率乘以倍率。
- **可调整配置**：[独立睡眠恢复 XML 配置](C:/NiwtDatas/Projects/RimworldModStudio/模组工程/BorderDefenseProtocol/1.6/Content/Defs/TrionRecoverySettingsDef/Settings.xml) 的 `sleepWithoutCoreMultiplier` 与 `sleepWithCoreMultiplier` 分别控制无许可、有许可时的睡眠倍率。配置直接定义在内容层，由门控读取，不使用 XML 补丁或挂到基础恢复属性上；20% 与 120% 仅为当前配置，不硬编码到逻辑中。
- **保留边界**：战斗体既有恢复冻结继续独立生效；人物恢复不直接抽取核心储量。具体恢复量与倍率可重新平衡，不把当前初始量或速率写成标准。
- **既有例外**：无地图角色与非玩家派系继续保持原有基准恢复规则，本次不修改旅行恢复机制。
- **完成表现**：无运行核心时能完成必要的首次能量积累、试用、睡眠恢复和再次使用；许可开启后睡眠更快；许可停运后睡眠恢复仍可继续。
- **验证状态**：四种组合、配置调整、睡醒和核心切换、换图及既有许可生命周期隔离验证通过；真实编译组件的恢复增量、冻结阻断与容量封顶验证通过。用户已确认本项游戏内验证通过；与尚待接通的原型装备进行首次积累、重复使用联测，留到原型工作包。

## 4. 核心正式运转

### 4.1 材料分析与研究建设

- **最小工作**：核心材料可分析，取得所有正式 BDP 研究路线的共同准入；分析保留实物，之后按研究用于建设核心，资格独立保留。
- **完成表现**：不要求核心已经运行或原型已经试用，玩家即可分析并筹备研究建设；材料的两个用途顺序衔接。
- **待定边界**：分析交互的具体条件及必要研究项目由对应专题确定。整体研究树继续搁置，不用已撤回方案填空，也不将全部内容直接放开作为替代。

### 4.2 首次启动与持续补充

- **已有基础**：核心资源容器、资源增加接口、消耗结算与运行许可。
- **最小工作方向**：已加入的皇室殖民者作为献祭操作者和绑定者，从未运行、未绑定状态完成首次献祭启动，并能随后补充。
- **完成表现**：首次合法物品可由原版科技制成品独立提供，不等待核心许可产线；核心可持续使用，停运后通过既定补充操作恢复。
- **专题尚需定案**：合法物品与估值、交互方式、超额资源处理、绑定及解除或转交细则。这里只保留已定体验连接，不用旧讨论中的建议替用户定规格。皇室心情影响仍是轻微引导的待定设想，不列为本清单必做项。

### 5.2 制造与装配许可

- **已实现行为**：制造台、装配台按自身地图与派系接入已有核心运行许可。许可失效时，制造台不能开始或继续生产，装配台不能装卸、换配。普通触发体临时配方已经加入，同样受制造台许可约束。
- **制造入口**：重新实现原版账单的两项可用性接口，保留基类电力、燃料和故障判断。原版任务分配及任务进行中的检查均读取当前许可；账单编辑、备料筹备和开发模式批量完成入口保持原规则。
- **装配入口**：复用现有统一准入，覆盖右键、行走、打开前及已打开窗口的操作检查。许可失效时清除尚未提交的拖拽，不修改芯片库存、已有配装或事务回退逻辑。
- **已有正常操作**：芯片搬入与装配台有效连接的芯片仓；已有腺体的成员先装备可配置触发体，再使用装配台；启动仍按人物容量、能量等既有条件判断。
- **完成表现**：有许可能制造与配置；停运时相关操作停止可用；恢复许可后能够继续使用设施。许可不反向撤销研究或摧毁已有成品，不扩大到芯片仓独立存取、检测仪和原版基因设备。
- **中断与恢复依据**：原版制造任务每刻先检查工作台可用性，失去许可后中断；已有芯片配方沿原版半成品保存材料与剩余工作量，许可恢复后可由原版重新派工续做。不增加自制任务、许可缓存或原版补丁；预装用的芯片成品工厂不加建筑许可，保证原型可在核心建成前生成。
- **验证状态**：先验证无许可仍可使用的问题，再验证接入后的停运、运行、恢复、原版拒绝、地图和派系行为；编译、实际游戏程序集与编译产物的账单接口分派、制造原版流程、装配事务与交互、许可及睡眠生命周期检查通过。旧窗口测试在芯片详情标题断言失败，修改前版本同样失败且对应渲染文件未改，本轮不扩展修复。制造中途停运、半成品续做、窗口停运及存读档仍待游戏内核对。

### 5.3 普通人员自主扩充（2026-10-08核对）

- **正常路线**：皇室正式加入后，玩家主动缔约给予首名成员腺体；研究原版“异种遗传学”（前置电力），使用基因提取器取得含腺体的基因组；放入与基因装配器连接的基因库，选用该基因组制作胚芽，再按原版流程植入其他成员。同一基因组可重复用于制作。
- **提取依据**：真实原版`Building_GeneExtractor.Finish`（基因提取完成）从人物全部基因列表抽样，排除超凡基因、黑色素基因、重复选择和超出代谢范围的组合，不使用基因的随机生成权重与随机基因组开关。腺体超凡值为0、复杂度为2、代谢为-1，属于合法候选；不保证每次抽到腺体，保留原版提取后的再生与重复提取风险。
- **制作依据**：真实原版`Building_GeneAssembler.GetGenepacks / Finish`（读取基因组／完成制作）与`Xenogerm.Initialize`（胚芽初始化）直接使用连接基因库中的实际基因组，不重新随机生成基因。腺体复杂度2低于原版装配器基础上限6，单独制作不要求新增复杂度设施；抽到多基因组合时仍服从原版整体限制。
- **植入与使用**：真实原版`GeneUtility.ImplantXenogermItem`（植入胚芽）将基因加入外源列表，并通过`Pawn_GeneTracker.AddGene`（添加基因）调用现有腺体的加入处理。BDP资格只要求腺体存在且有效，不要求皇室身份或契约。正常已生成成员后天获得腺体后从零开始积累，恢复、装备与启动继续服从原有条件。
- **权限与遗传边界**：契约授予内源腺体，可按原版自然遗传；胚芽植入是外源腺体，不自然遗传。皇室超凡基因仍不能由普通提取器提取；胚芽只携带选中基因，不复制同生共死记录，普通腺体成员也不会取得契约者的核心操作权限。原版基因设备不另加核心许可。
- **验证状态**：当前游戏程序集的提取、基因组读取、胚芽生成与植入流程已核对；既有契约真实程序集检查及腺体加入／失活／移除检查通过。未改变C#逻辑、基因配置或原版研究；完整提取、制作、植入、恢复及装备操作仍需游戏内实测。

## 6. 核对与完成判断

实施时先做对应的编译、定义和语言键检查，再按实际风险核对游戏流程：

1. 正常首次接触能够提供资格和物品机会；袭击任务达成结束后皇室正式加入。
2. 无核心许可时，首次积累、原型使用、睡眠恢复和再次使用能够连续成立。
3. 材料分析保留实物与准入，之后完成研究建设；首次献祭不依赖核心许可产线。
4. 制造、入仓、装备、装配和实际使用能串起来；核心停运、恢复、存读档后许可和物品状态正确。
5. 原版基因提取与胚芽制作支持继续培养，遵循原版随机提取，不要求首次一定抽出腺体。
6. 新功能、组合与可选操作员支援能沿正常条件使用；紧急脱离消费后可沿普通生产补装。

可选战斗体外观编辑与现有跨阶段黑触发器继续沿既有入口使用。本清单的完成标准是正常体验连接成立；具体数量、消耗、恢复速度和强度以实际游戏体验再平衡。
