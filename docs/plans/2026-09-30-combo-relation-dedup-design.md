# 组合关系详情去重设计

## 目标

同一详情层级内，芯片以相同功能模板参与组合定义的第一、第二来源时，只显示一条组合名称和结果说明。

## 现状与原因

静态组合关系投影会分别保留 `first-source` 和 `second-source` 角色。自组合时，同一个 `ComboDef` 因而形成两个关系节点；详情渲染器当前逐节点生成展示行，所以名称、说明和展开入口重复。

## 方案

在 `ChipInformationDetailRenderer.BuildRelationLines` 的当前关系列表内，按 `reference_key`（组合 Def 名称）去重，保留第一次出现的有效关系行。根层级和各形态/姿态层级分别调用行构造，因此去重只发生在同一层级；不同组合定义仍单独显示。

不改关系投影或信息模型，保留两侧来源角色数据。当前读取入口只接收静态定义关系，运行时组合结果不受影响。展开/折叠使用保留行的关系键。

## 验证

构建 BDP.Content Release，检查最终 Git 差异和空白错误。不新增或运行测试，不替代游戏内视觉验收。
