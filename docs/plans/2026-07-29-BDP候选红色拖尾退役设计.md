# BDP 候选红色拖尾退役设计

## 背景

事项04已把“亮薄荷绿·长”和“亮薄荷绿·短”两个正式拖尾预设并入主模组。候选测试模组仍保留一个“炽红”预设，并有两个芯片引用它。

用户确认：候选测试模组里所有红色拖尾统一改为“亮薄荷绿·长”，之后不再保留红色拖尾预设。

## 处理边界

本次只处理拖尾配置：

1. 把候选测试模组中的两处 `BDP_TrailPreset_HotRed` 引用改为 `BDP_TrailPreset_BrightMintLong`。
2. 删除候选测试模组中只定义炽红拖尾的 `BeamTrailPresetDefs.xml`。
3. 不修改画点诊断等其它系统使用的红色，因为它们不是拖尾。
4. 不改变任何芯片的攻击、齐射、路径、伤害、射程或其它参数。

## 验收条件

1. 候选测试模组中不再出现 `BDP_TrailPreset_HotRed`。
2. 原来使用炽红拖尾的两个芯片都明确引用 `BDP_TrailPreset_BrightMintLong`。
3. 主模组继续提供“亮薄荷绿·长”和“亮薄荷绿·短”两个正式预设。
4. 拖尾专项检查、候选程序集构建和 XML 解析均通过。
