# 自动手枪武装构型设计

## 目标

新增“自动手枪”武装构型，使用原版自动手枪的武器参数和贴图，并让近界原型触发体预装的“小兵弹丸”按“小兵弹丸功能 + 自动手枪构型”组合解析。

## 已确认的现状

- `BDP_ChipFunction_SoldierBullet` 已配置原版自动手枪子弹、射程、精度、预热、冷却与音效。
- 固定装载工厂当前仅按功能模板创建组合记录，没有显式构型；射手远程功能因此落到隐藏的 `BDP_ArmamentForm_TrionCube`。
- Trion 立方体构型会覆盖单发数和手持视觉，所以小兵弹丸需要显式指定自动手枪构型。
- 原版自动手枪贴图路径为 `Things/Item/Equipment/WeaponRanged/Autopistol`；原版子弹基础伤害 10、停止力 0.5、速度 55。

## 设计

1. 在武装构型 Def 中新增“自动手枪”，使用原版自动手枪的射程 25.9、精度 0.80/0.70/0.40/0.30、预热 0.3 秒、单发、15 ticks 连发间隔、1.0 秒 BDP 动作冷却、原版枪声、尾音、传播半径和枪口闪光。
2. 新增自动手枪单持与双持视觉预设，继承小型枪械基准，使用原版自动手枪贴图；握持和枪口位置沿用左轮手枪视觉基准。
3. 给芯片功能模板增加可选的固定装载构型引用。仅在固定装载创建单功能成品时，把功能 Def 与该构型 Def 一起写入现有 `ChipCombinationRecord`，再调用现有 `ChipCombinationResolver`。此引用只表达该固定预装组合，不改变一般射手功能的隐式默认构型。
4. 小兵弹丸继续使用 `Bullet_Autopistol`，不增加投射物伤害或停止力倍率；每发 Trion 消耗 2、芯片占用 20 等现有设置不变。
5. 研究门槛、追加材料和工作量沿用左轮手枪构型。新增玩家可见文本放入简体中文语言包。

## 验证

检查 XML 可解析、组合记录包含小兵弹丸功能和自动手枪构型、Def 字段与语言键齐全，并构建 Content 程序集。按项目约束，不新增或运行测试；游戏内贴图、射击节奏和固定装载结果仍需启动游戏实测。
