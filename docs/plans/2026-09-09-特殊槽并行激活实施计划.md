# Special Slot Parallel Activation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复所有 Special 槽位共用一个侧级切换上下文的问题，使多个 Special 芯片可以同时激活并分别完成停用。

**Architecture:** 在 `TriggerService` 保持现有 Main/Sub 逻辑不变；仅把 Special 作为结构性独立槽位路由到 `SlotSwitchContext`。保留现有 `FindActivationBlockers`、激活条件、延迟和提交通知链。

**Tech Stack:** C#、RimWorld 1.6、PowerShell 源码烟测、MSBuild。
