# BDP Homing Module Refactor Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Rework the DevHarness homing module into a short-segment continuous curve pursuit system that can fly by, recover, and hand off impact cleanly while preserving save/load continuity, PathLatch isolation, and XML-configurable weak/strong variants.

**Architecture:** Keep the current `BdpProjectile` launch/arrival shell unchanged and move the behavior change into `HomingConfig`, `HomingModuleState`, `HomingPathPlanner`, and `HomingModule`. Use Arrival-stage short-segment continuation, sampled closest-approach evidence, and end-distance / fore-aft handoff rules to separate “命中” from “擦肩继续飞”.

**Tech Stack:** C#, RimWorld `Verse` / `RimWorld`, BDP ranged module runtime, XML module defs, PowerShell smoke tests.
