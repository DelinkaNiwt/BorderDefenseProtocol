# 毒蛇自动路径模式移植 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 DevHarness（伴生测试模组）的 `PathLatchModule（路线引导模块）` 中补回毒蛇自动路径模式：无手动锚点且目标不可直视时自动生成绕障锚点；成功后作为普通锚点路径飞行；失败时拒绝确认。

**Architecture:** 主模组保持中性，不出现毒蛇自动路径业务。DevHarness 新增 `PathLatchAutoRouteResolver（路线引导自动路径解析器）`，只在 Targeting/Preview/Confirm（目标选择/预览/确认）阶段提供锚点候选；ProjectileInit/Arrival（投射物初始化/到达）继续消费同一份锚点快照。

**Tech Stack:** C#、RimWorld `GenSight.LineOfSight（原版直线可视）`、PowerShell smoke tests（烟雾测试）、DevHarness Release 构建。项目要求直接在当前工程执行，不使用 worktree（工作树）。

### Task 3: 新增 PathLatchAutoRouteResolver

**Files:**
- Create: `模组工程/BorderDefenseProtocol.DevHarness/Source/BDP.DevHarness/RangedModules/Samples/PathLatchAutoRouteResolver.cs`
- Modify: `模组工程/BorderDefenseProtocol/Source/BDP.Tests/PathLatchAutoRouteModeSmokeTests.ps1`

**Step 1: Add result model**
- `PathLatchAutoRouteResult（自动路径结果）`
  - `Succeeded（是否成功）`
  - `Anchors（锚点列表）`
  - `RejectReason（拒绝原因）`

**Step 2: Add resolver input**
- 输入只收：
  - `Map（地图）`
  - `OriginCell（起点格）`
  - `TargetCell（终点格）`
  - `PathLatchConfig（路线引导配置）`

**Step 3: Implement minimum algorithm**
- 若起点或终点无效，失败。
- 若直线 `LOS（直线可视）` 已成立，返回成功但无锚点。
- 找射线上的第一个阻挡格。
- 用 `BFS（广度优先搜索）` 扩展障碍团，受 `AutoRouteMaxObstacleCells` 限制。
- 从障碍团外轮廓选可通行候选格。
- 按射线左右分组，分别挑最多 `AutoRouteAnchorsPerWall` 个锚点。
- 递归深度不超过 `AutoRouteMaxDepth`。
- 每条路线最终用逐段 `LOS（直线可视）` 复验。

**Step 4: Keep algorithm modest**
- 不做 `A*（A星全局寻路）`。
- 不用 pawn pathing（小人寻路）结果替代投射物 LOS。
- 不为了复杂迷宫引入新主模组设施。

**Step 1: Freeze source**
- `HandleFinalTargetConfirm（最终目标确认）` 中：
  - 有手动锚点：冻结手动锚点，`PathSource = Manual`。
  - 无手动锚点且直射可视：不写锚点，`PathSource = Direct`。
  - 无手动锚点且直射不可视：运行自动路径。

**Step 2: Freeze auto anchors**
- 自动路径成功时，把解析器输出锚点写入 `ConfirmedSnapshot.Anchors（确认快照锚点）`。
- 自动路径失败时 `TargetingAdvanceKind.Reject（目标选择拒绝）`。

**Step 3: Carry source into projectile snapshot**
- `PathLatchSegmentResolver.PopulatePathSnapshot()` 同步 `PathSource`。
- 不改变 `TryResolveFirstLegTarget()`、`BuildCurrentLegFlightPathSnapshot()` 和 `TryAdvanceLeg()` 的核心语义。

**Step 4: Verify final-target semantics**
- `OverrideLaunchTarget（发射导航目标）` 可以是首个自动锚点。
- `OverrideAimTarget（瞄准目标）` 和 `OverrideCurrentTarget（正式目标）` 仍是最终目标。
- 自动锚点不能污染最终命中语义。
