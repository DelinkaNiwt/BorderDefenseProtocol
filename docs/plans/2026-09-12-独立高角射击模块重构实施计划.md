# 独立高角射击模块重构实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将高角规则从投射物 DefModExtension（定义扩展）和 BdpProjectile 的 Def 读取逻辑中移除，改为由独立 `HighAngleShootingModule`（高角射击模块）按每发目标可视性决定是否使用高角投射物与高角绘制参数。

**Architecture:** 高角模块在 `ProjectileInit`（投射物初始化）阶段读取最终瞄准目标与射击者之间的可视性。不可视时，模块通过现有初始化贡献接口提交一个替代投射物 Def（其原版 `flyOverhead` 开启）和一份中性的视觉轨迹快照；可视时不提交任何覆盖，完整保留现有低角路径。Core（核心层）只增加通用的“投射物 Def 覆盖”和“视觉轨迹参数承载”能力，不认识高角模块、操作员控制台或追踪业务。

**Tech Stack:** C# 7.3、RimWorld 1.6 `Projectile`（投射物）/`flyOverhead` 原版逻辑、BDP 远程模块阶段协议、PowerShell（脚本）源码契约烟测。
