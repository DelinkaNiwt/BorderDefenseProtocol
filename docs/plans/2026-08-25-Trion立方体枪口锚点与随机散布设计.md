# Trion 立方体枪口锚点与随机散布设计

## 范围

只调整 `BDP_ArmamentForm_TrionCube` 及其单、双武器视觉预设配置。

不修改 `Core.dll`、组合技解析、组合技发射侧、四连发数量或任何 `ComboDef`。

## 配置

- `BDP_Visual_TrionCube`：声明远程枪口锚点，`MuzzleOffset=(0, 0, 0)`。
- `BDP_Visual_TrionCube_Dual`：显式声明同样的枪口锚点，避免继续使用基类的前向枪口偏移。
- `BDP_ArmamentForm_TrionCube`：声明真实发射点随机散布。

```xml
<originSpread>
  <LateralMin>-0.3</LateralMin>
  <LateralMax>0.3</LateralMax>
  <ForwardMin>0</ForwardMin>
  <ForwardMax>0.105</ForwardMax>
</originSpread>
```

## 验证

通过 `TrionCubeVisualSmokeTests.ps1`、`VisualMuzzleGraphicTransformSmokeTests.ps1`、`VisualPoseResolverBoundarySmokeTests.ps1`、`RangedRandomOriginSpreadSmokeTests.ps1` 与 `ComboArmamentFormPropagationSmokeTests.ps1`。
