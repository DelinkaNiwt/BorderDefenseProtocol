# 毒蛇锚点路径制导模块设计（第一版）

## 1. 文档范围

- 文档类型：业务模块设计文档
- 目标样本：毒蛇远程路径制导芯片
- 实现位置：`DevHarness（测试模组）`
- 归档位置：`BorderDefenseProtocol/docs/plans`
- 主模组约束：
  - 不新增毒蛇专用业务概念
  - 不在主模组实现锚点路径业务
  - 只依赖主模组现有正式设施与已补齐的中性输入事实层

## 2. 设计目标

- 提供一个毒蛇测试芯片。
- 玩家可在一次 `Targeting（瞄准阶段）` 内同时表达：
  - 最终目标
  - 可选路径锚点
- 玩家可直接攻击目标，不必先走完固定采集流程。
- 玩家可只设置部分锚点后立即选最终目标。
- 玩家可把地面格作为最终目标。
- 路径原文在 `Confirm（确认阶段）` 后冻结。
- 每个 `Cast（单枪次）` 独立重建运行态。
- 子弹沿路径逐段推进，末端效果只在最终锚点触发。
- 同一 `AttackSession（攻击会话）` 内多枪不串状态。

## 3. 非目标

- 不改主模组 `AttackExecution（攻击执行）` 正式边界。
- 不改主模组远程后半段执行职责分层。
- 不实现复杂路径编辑面板。
- 不实现自由曲线插值。
- 不实现跨枪继承旧游标。
- 不保留旧试作兼容层。

## 4. 命名

### 4.1 芯片

- DefName（定义名）：`BDP_TestChipViper`
- 显示名：`测试毒蛇芯片`

### 4.2 模块

- 模块类名：`AnchorPathGuidanceModule（锚点路径制导模块）`
- 模块 DefName（定义名）：`BDP_TestAnchorPathGuidanceModule`

## 5. 依赖的主模组能力

毒蛇模块依赖以下主模组正式能力：

- `AttackContext（攻击上下文）`
- `AttackContextSnapshot（攻击上下文快照）`
- `TargetingAdvanceKind（目标交互推进种类）`
- `TargetingInputFrame（目标输入帧）`
- `ITargetingSegmentLegalityService（Targeting 段合法性服务）`
- `ProjectileInitPlan.AttackContextSnapshot（子弹初始化计划攻击上下文快照）`
- `FlightStageContext.AttackContextSnapshot（飞行阶段攻击上下文快照）`

毒蛇模块额外依赖本轮已补齐的中性输入事实：

- `TargetingInputButton（目标输入按钮）`
- `TargetingInputModifiers（目标输入修饰键）`
- `TargetingSegmentLegalityRequest（Targeting 段合法性请求）`
- `TargetingSegmentLegalityResult（Targeting 段合法性结果）`

主模组只提供：

- 按下了哪个按钮
- 按住了哪些修饰键
- 当前一段是否合法的中性查询口

主模组不提供：

- 锚点
- 路径
- 终点
- 毒蛇

## 6. 交互目标

毒蛇交互必须满足以下玩家意图：

- 想直接打目标时，可直接选目标。
- 想直接打地面时，可直接选地面。
- 想先补几个关键锚点，再立即选最终目标时，可以做到。
- 想取消时，可以立即取消。

毒蛇交互不得要求玩家：

- 先完成整段锚点采集，才能选目标
- 先单独执行“结束采集”动作，才能进入下一步
- 被固定流程强行绑住

## 7. 正式交互模型

### 7.1 输入语义

在同一 `Targeting（瞄准阶段）` 内，输入语义固定为：

- `Shift（换挡键） + 左键`
  - 追加一个锚点
- 普通左键
  - 选择最终目标
- 右键 / `Esc（退出键）`
  - 取消本次输入

### 7.2 最终目标类型

普通左键选择的最终目标允许为：

- `Pawn（人物）`
- `Thing（物体）`
- `Cell（地面格）`

### 7.3 操作流程

```text
点击毒蛇按钮
    -> 进入毒蛇瞄准态

Shift + 左键点地面
    -> 追加锚点
    -> 保持留在当前瞄准态

普通左键点目标或地面
    -> 作为最终目标
    -> 完成本次输入
    -> 进入确认与执行

右键 / Esc
    -> 取消本次输入
```

### 7.4 交互性质

该交互模型的本质是：

- 最终目标始终是主线
- 锚点是可选插入式修饰
- 玩家随时可以从锚点修饰回到目标确认

## 8. 数据模型

### 8.1 `AnchorPathNode（锚点路径节点）`

用途：

- 保存路径原文
- 保存最终目标事实
- 挂载于模块私有上下文

字段：

- `Anchors（锚点列表） : List<IntVec3>`
- `HasTerminalTarget（是否已有最终目标） : bool`
- `TerminalTarget（最终目标） : LocalTargetInfo`
- `TerminalCellSnapshot（终点位置快照） : IntVec3`
- `IsComplete（是否完成输入） : bool`
- `VersionToken（版本令牌） : int`

约束：

- 只允许前半段交互链修改
- `Confirm（确认阶段）` 后只读

### 8.2 `AnchorPathCastCursor（锚点路径单枪游标）`

用途：

- 保存单枪路径运行态
- 保存当前路径消费进度

字段：

- `Anchors（锚点只读序列） : IReadOnlyList<IntVec3>`
- `TerminalTarget（最终目标） : LocalTargetInfo`
- `TerminalCellSnapshot（终点位置快照） : IntVec3`
- `CurrentAnchorIndex（当前锚点下标） : int`
- `CurrentSegmentIndex（当前路径段下标） : int`
- `IsFinished（是否完成） : bool`
- `SourceVersionToken（来源版本令牌） : int`
- `CastInstanceId（单枪实例标识） : string`

约束：

- 每个 `Cast（单枪次）` 独立创建
- 不允许跨枪复用
- 不允许写回 `AnchorPathNode（锚点路径节点）`

### 8.3 `AnchorPathGuidanceConfig（锚点路径制导配置）`

字段：

- `MinAnchorCount（最少锚点数）`
- `MaxAnchorCount（最多锚点数）`
- `AllowGroundTerminalTarget（允许地面终点）`
- `AnchorReachRadius（锚点到达半径）`
- `FinalExplosionRadius（末端爆炸半径）`
- `FinalDamageDef（末端伤害定义）`
- `FinalDamageAmount（末端伤害数值）`
- `FlightSpeedFactor（飞行速度倍率）`

## 9. 输入解释规则

### 9.1 `Shift（换挡键） + 左键`

解释规则：

- 当前点击必须解释为锚点输入
- 不解释为最终目标选择
- 成功追加锚点后，返回 `Continue（继续）`

### 9.2 普通左键

解释规则：

- 当前点击解释为最终目标选择
- 目标可以是人物、物体或地面格
- 成功设置最终目标后，返回 `Complete（完成）`

### 9.3 右键 / `Esc（退出键）`

解释规则：

- 当前输入解释为取消
- 返回 `Cancel（取消）`

## 10. Targeting 阶段设计

### 10.1 进入时

进入毒蛇瞄准态时：

- 初始化空路径原文
- 初始化空最终目标
- 清空完成标记

### 10.2 处理 `Shift（换挡键） + 左键`

处理步骤：

- 先构造：
  - `TargetingSegmentLegalityRequest（Targeting 段合法性请求）`
- 调用：
  - `SegmentLegality（段合法性查询面）`
- 校验“上一点 -> 当前点”这一段是否合法
- 非法：
  - 不追加锚点
  - 返回 `Reject（拒绝）`
- 合法：
  - 追加到 `Anchors（锚点列表）`
- 若达到 `MaxAnchorCount（最多锚点数）`：
  - 后续不再允许继续追加锚点
- 返回 `Continue（继续）`

### 10.3 处理普通左键

处理步骤：

- 先构造：
  - `TargetingSegmentLegalityRequest（Targeting 段合法性请求）`
- 调用：
  - `SegmentLegality（段合法性查询面）`
- 校验“最后一点 -> 最终目标”这一段是否合法
- 非法：
  - 不设置最终目标
  - 返回 `Reject（拒绝）`
- 合法：
  - 校验当前点击是否能作为最终目标
- 设置 `TerminalTarget（最终目标）`
- 设置 `TerminalCellSnapshot（终点位置快照）`
- 设置 `HasTerminalTarget（是否已有最终目标） = true`
- 设置 `IsComplete（是否完成输入） = true`
- 返回 `Complete（完成）`

### 10.4 处理取消

处理步骤：

- 放弃当前路径原文
- 放弃当前最终目标
- 返回 `Cancel（取消）`

## 11. Confirm 阶段设计

### 11.1 进入条件

只有在以下条件同时满足时允许进入：

- `HasTerminalTarget（是否已有最终目标） = true`
- `Anchors.Count >= MinAnchorCount（锚点数达到最小要求）` 或允许零锚点直达

### 11.2 零锚点直达

毒蛇设计必须允许：

- 没有任何锚点
- 直接普通左键指定最终目标

此时行为等价于：

- 一条只有终点、没有中间锚点的路径

### 11.3 冻结内容

`Confirm（确认阶段）` 冻结以下事实：

- `Anchors（锚点列表）`
- `TerminalTarget（最终目标）`
- `TerminalCellSnapshot（终点位置快照）`
- `VersionToken（版本令牌）`

## 12. 状态归属

### 12.1 原文状态

原文状态指：

- `AnchorPathNode（锚点路径节点）`

归属：

- `Targeting（瞄准阶段）`
- `Confirm（确认阶段）`

限制：

- `Prepare（准备阶段）` 之后只读

### 12.2 运行态

运行态指：

- `AnchorPathCastCursor（锚点路径单枪游标）`

归属：

- 单个 `Cast（单枪次）`

限制：

- 生命周期只覆盖当前枪次
- 不得跨枪共享

### 12.3 严禁事项

- 严禁整次 `AttackSession（攻击会话）` 共用一个可变路径游标
- 严禁 `Flight（飞行阶段）` 回写路径原文
- 严禁第二枪读取第一枪的游标进度
- 严禁齐射多发共享同一份可变消费下标

## 13. 各阶段职责

### 13.1 `ManualEntry（手动入口阶段）`

职责：

- 提供毒蛇入口按钮
- 进入毒蛇瞄准态

### 13.2 `Targeting（瞄准阶段）`

职责：

- 解释当前输入帧
- 查询当前路径段是否合法
- 追加锚点或设置最终目标
- 产生继续、完成、取消裁决

### 13.3 `Preview（预览阶段）`

职责：

- 显示锚点
- 显示锚点连线
- 显示最终目标预览

预览要求：

- 当尚未选定最终目标时，只显示当前锚点链
- 当已悬停潜在最终目标时，可显示从最后一个锚点到潜在终点的预览连线
- 当前悬停段合法时，显示正常预览线
- 当前悬停段非法时，显示拒绝态预览线

### 13.4 `Confirm（确认阶段）`

职责：

- 校验输入完整性
- 冻结路径原文与终点事实

### 13.5 `Prepare（准备阶段）`

职责：

- 读取冻结路径原文
- 为当前枪次准备路径输入

### 13.6 `Fire（射击阶段）`

职责：

- 为每个 `Cast（单枪次）` 重建 `AnchorPathCastCursor（锚点路径单枪游标）`

### 13.7 `ProjectileInit（子弹初始化阶段）`

职责：

- 绑定本枪路径信息
- 设置当前路径目标

### 13.8 `Flight（飞行阶段）`

职责：

- 沿锚点链推进
- 当锚点耗尽后，转向最终目标
- 当最终目标到达后完成路径

### 13.9 `Impact（命中阶段）`

职责：

- 在最终目标位置触发末端效果

规则：

- 最终目标为人物/物体时，在其位置结算
- 最终目标为地面格时，在该地面格结算

## 14. 路径推进规则

### 14.1 有锚点时

推进顺序：

```text
起点
    -> 锚点1
    -> 锚点2
    -> ...
    -> 锚点N
    -> 最终目标
```

### 14.2 无锚点时

推进顺序：

```text
起点
    -> 最终目标
```

### 14.3 终点规则

- 最终目标始终是路径最后一段的收束点
- 锚点只定义中间转向，不定义最终终结语义

## 15. 终点语义

### 15.1 地面终点

- 地面终点的正式语义是：
  - 固定地面格
- 冻结后以：
  - `TerminalCellSnapshot（终点位置快照）`
  - 作为唯一终点事实

### 15.2 对象终点

- 对象终点的正式语义是：
  - 目标对象
- 冻结后同时保留：
  - `TerminalTarget（最终目标）`
  - `TerminalCellSnapshot（终点位置快照）`

保留位置快照的目的：

- 用于预览、诊断与恢复时保留当时的终点事实

### 15.3 对象终点失效

对象终点在以下情况下视为失效：

- 目标被销毁
- 目标离图
- 目标已不再满足当前合法性复核

失效后的处理固定为：

- 当前枪次中止
- 不回落成旧位置强行结算
- 不把对象终点偷偷降级成地面终点

### 15.4 终点移动

- 对象终点：
  - 维持对象语义
  - 发射前复核与后段执行仍按对象目标处理
- 地面终点：
  - 维持地面格语义
  - 不转成对象追踪
## 16. 段合法性规则

### 16.1 需要检查的段

毒蛇模块必须检查以下段：

- 起点 -> 第一个锚点
- 最后一个锚点 -> 新锚点
- 最后一个锚点 -> 最终目标
- 零锚点时起点 -> 最终目标

### 16.2 查询方式

毒蛇模块不得自定义墙、门、掩体、命中规则。

毒蛇模块只允许：

- 构造 `TargetingSegmentLegalityRequest（Targeting 段合法性请求）`
- 调用 `ITargetingSegmentLegalityService（Targeting 段合法性服务）`
- 读取 `TargetingSegmentLegalityResult（Targeting 段合法性结果）`

### 16.3 非法段处理

非法段处理固定为：

- 不写入任何新状态
- 当前输入返回 `Reject（拒绝）`
- 保持留在当前 `Targeting（瞄准阶段）`
- 给玩家即时拒绝反馈

### 16.4 发射前复核

每个 `Cast（单枪次）` 开始前，必须按当前世界状态重新复核整条路径段。

复核失败时：

- 当前枪次中止
- 不允许沿用旧快照硬发射
- 记录明确诊断日志
## 17. 责任边界

### 17.1 毒蛇模块负责

- 定义输入解释
- 定义哪些段必须经过合法性检查
- 定义非法输入时的反馈
- 定义路径原文与运行态分层

### 17.2 主模组负责

- 提供中性输入事实
- 提供中性段合法性查询口
- 提供上下文、快照、执行传递链

### 17.3 原版 / 现有 BDP 负责

- 具体目标参数判定
- 具体命中与可视判定
- 具体碰撞与底层战斗规则

### 17.4 毒蛇模块不负责

- 不重写原版合法性算法
- 不重写原版碰撞系统
- 不重写原版多选规则
- 不发明第二套战斗真值

## 18. 多枪语义

### 18.1 逐射

- 每枪一份新游标
- 游标随枪次结束释放

### 18.2 齐射

- 同轮各发共享同一份冻结原文
- 同轮各发各自持有独立游标

### 18.3 多发

- 规则与齐射一致
- 不共享可变进度

## 19. 历史问题规避规则

需要规避的问题：

- 同一攻击会话内第一枪正常
- 第二枪开始直接在首锚点结束并爆炸

规避规则：

- `Confirm（确认阶段）` 后只冻结原文，不冻结可变游标
- 每个 `Cast（单枪次）` 强制重建游标
- 子弹飞行只消费本枪游标
- 任意阶段都不得把游标进度写回原文

## 20. 性能约束

允许：

- 确认后冻结一次路径原文
- 每个 `Cast（单枪次）` 重建一次轻量游标
- `Flight（飞行阶段）` 持续只读消费

禁止：

- 每个 `Tick（时刻）` 重建整条路径
- 每发子弹重复回溯整次会话
- 在飞行中反复生成新原文对象

## 21. 持久化要求

- `AnchorPathNode（锚点路径节点）` 必须随攻击上下文进入存读档链
- 确认后的路径原文和最终目标必须可恢复
- 运行态游标不要求跨存读档保留为同一实例，但恢复后必须能按冻结原文重新建立正确执行状态

## 22. 诊断日志

需要预埋以下诊断点：

- `targeting_anchor_add（瞄准阶段追加锚点）`
- `targeting_terminal_target_set（瞄准阶段设置最终目标）`
- `targeting_input_canceled（瞄准阶段取消输入）`
- `targeting_segment_rejected（瞄准阶段段合法性拒绝）`
- `confirm_path_snapshot_frozen（确认阶段路径快照冻结）`
- `cast_cursor_rebuild（单枪游标重建）`
- `cast_cursor_cross_cast_detected（检测到跨枪状态污染）`
- `cast_segment_recheck_failed（单枪发射前段复核失败）`
- `cast_terminal_target_invalid（单枪发射前终点失效）`
- `projectile_path_step_advance（子弹路径推进）`
- `projectile_terminal_target_enter（子弹进入最终目标段）`
- `projectile_path_finished（子弹路径完成）`
- `projectile_path_impact_final_anchor（最终目标命中）`

日志字段最少包含：

- `resultId（结果标识）`
- `versionToken（版本令牌）`
- `castInstanceId（单枪实例标识）`
- `currentAnchorIndex（当前锚点下标）`
- `anchorCount（锚点总数）`
- `terminalTargetType（最终目标类型）`
- `terminalTargetValidity（最终目标有效性）`

## 23. 验收标准

### 23.1 直接目标

- 不设锚点时，普通左键可直接选人物/物体/地面作为最终目标

### 23.2 部分锚点

- `Shift（换挡键） + 左键` 可连续设定若干锚点
- 设定部分锚点后，可随时普通左键选择最终目标

### 23.3 地面终点

- 普通左键点地面格，可作为最终目标完成输入

### 23.4 非法段反馈

- 非法锚点段不会被写入
- 非法终点段不会完成输入
- 玩家能看到拒绝态预览与拒绝反馈

### 23.5 对象终点失效

- 对象终点在发射前若已失效，当前枪次会中止
- 不会偷偷降级为地面终点

### 23.6 多枪稳定性

- 第一枪正常
- 第二枪正常
- 第三枪正常
- 不出现首锚点提前结束问题

### 23.7 齐射与多发

- 同轮多发互不污染游标
- 任一发完成不影响另一发路径推进

### 23.8 复核失败

- 前段合法的路径，在发射前若已失效，当前枪次会中止
- 不会硬发射

### 23.9 存读档

- 路径原文与最终目标不丢失
- 恢复后行为一致

## 24. 实施边界

- 实现目录限定为 `DevHarness（测试模组）`
- 主模组只作为依赖，不作为毒蛇业务实现位置
- 毒蛇样本完成前，不把毒蛇语义抽象为主模组通用业务设施

## 25. 最终裁定

- 主模组架构对毒蛇样本够用。
- 毒蛇样本按业务模块实现，不上升为新的主模组业务改造任务。
- 主模组本轮提供了两类中性补口：
  - `TargetingInputButton（目标输入按钮）`
  - `TargetingInputModifiers（目标输入修饰键）`
  - `ITargetingSegmentLegalityService（Targeting 段合法性服务）`
- 毒蛇正式交互固定为：
  - `Shift（换挡键） + 左键` 设锚点
  - 普通左键选最终目标
  - 右键 / `Esc（退出键）` 取消
- 毒蛇路径段必须经过合法性检查。
- 合法性检查调用主模组中性查询口，不自定义底层判定算法。
- 对象终点保持对象语义，失效时中止当前枪次，不回落成地面终点。
- 路径状态必须分为：
  - `AnchorPathNode（锚点路径节点，原文）`
  - `AnchorPathCastCursor（锚点路径单枪游标，运行态）`
- 单枪重建运行态是强制要求。
