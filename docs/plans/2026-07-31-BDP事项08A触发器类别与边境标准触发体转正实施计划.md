# BDP 事项08A触发器类别与玩家控制边界 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement the plan task-by-task.

**Goal:** 建立可扩展触发器类别Def，把候选测试触发体转为主模组的边境标准触发体，并为未来固定芯片触发体建立Core玩家控制边界。

**Architecture:** `BDP.Core`提供中性的类别Def、触发体类别引用、玩家信息显示和`PlayerConfigurable/DefinitionFixed`两态控制边界；主模组XML提供三种正式类别与边境标准触发体；候选库删除旧测试触发体，其他候选业务不动。

**Tech Stack:** RimWorld 1.6、C# 7.3、XML、PowerShell、MSBuild。
