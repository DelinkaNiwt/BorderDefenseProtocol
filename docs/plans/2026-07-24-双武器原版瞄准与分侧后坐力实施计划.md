# 双武器原版瞄准与分侧后坐力 Implementation Plan（实施计划）

> **For Claude（供执行代理使用）:** REQUIRED SUB-SKILL（必需子技能）: Use `superpowers:executing-plans`（实施计划执行技能）、`superpowers:test-driven-development`（测试驱动开发技能）和 `superpowers:verification-before-completion`（完成前验证技能） to implement this plan task-by-task（逐项执行本计划）。

**Goal（目标）:** 删除无效的瞄准镜像作者开关，并让双武器的每个视觉条目按实际开火来源分别使用 RimWorld（边缘世界）原版后坐力。

**Architecture（实现方式）:** `BdpVerb_Shoot.TryEmitPlan`（BDP 射击动作发射计划）在真正发射边界按 `plan.ResultId`（计划来源结果标识）同步来源正式 `Verb.LastShotTick`（攻击动作最近开火时间）；双武器绘制按 `entry.ResultId`（视觉条目结果标识）找到同一个来源 `Verb`，直接调用原版 `EquipmentUtility.Recoil`（装备后坐力计算）。后坐力只加到主贴图和附加层的绘制姿态，不写入枪口锚点、发射计划或投射物。

**Tech Stack（技术栈）:** RimWorld 1.6（边缘世界 1.6）、C#（C#语言）、Harmony（和谐补丁库）、PowerShell（微软命令行脚本）、Git（版本控制工具）。

**Workspace rule（工作区规则）:** 按项目约束直接在当前工程和当前分支执行，不创建 worktree（工作树）或新分支。仓库已有大量用户改动；每次提交前必须检查暂存区，只暂存本任务的精确文件，禁止吸收任何既有改动。

**Design reference（设计依据）:** `docs/plans/2026-07-24-双武器原版瞄准与分侧后坐力设计.md`

**Step 3：增加最小原版适配成员**

添加逐成员中文注释，并实现：

```csharp
/// <summary>
/// 按当前视觉条目的来源正式 Verb 应用原版装备后坐力。
/// 这里只改变主贴图与附加层绘制姿态，不改变枪口锚点和发射原点。
/// </summary>
private static void ApplyVanillaRecoil(
    Thing equipment,
    CompTriggerBody triggerBody,
    VisualResidentEntry entry,
    EquipmentPoseSample sample,
    ResolvedVisualPose pose)
{
    if (equipment?.def == null
        || triggerBody?.VerbHostManager == null
        || entry == null
        || sample == null
        || pose == null
        || !triggerBody.VerbHostManager.TryGetByResultId(
            entry.ResultId,
            out BdpFormalVerbBinding binding)
        || binding?.RangedVerb == null)
    {
        return;
    }

    EquipmentUtility.Recoil(
        equipment.def,
        binding.RangedVerb,
        out Vector3 drawOffset,
        out float angleOffset,
        sample.AimAngle);

    pose.DrawPosition += drawOffset;
    pose.DrawAngle += angleOffset;
    if (pose.OverlayPoses == null)
    {
        return;
    }

    for (int i = 0; i < pose.OverlayPoses.Count; i++)
    {
        ResolvedVisualOverlayPose overlay = pose.OverlayPoses[i];
```
