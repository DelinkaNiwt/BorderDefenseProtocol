# 皇室入口任务最小接通计划

Status: Implemented, game verification pending, initial balance provisional

2026-10-07 后续更新：用户批准参考皇权开场的首发安排，已按[原版首发安排计划](2026-10-07-皇室入口原版首发安排.md)接通第八天专门派发，不等待三人、不跳过极端生态。现有随机渠道从第八天开放，缺少皇室时仍可再次接触；临时身份保留原版小派系借住。下文关于仅通过随机候选出现的初版说明以此更新为准。

语言修复更新：开发目录与根目录的 `Keyed/RoyalArrival.xml`（键值语言文件）相对路径相同，原版优先加载开发目录后跳过正式文案。开发文件已改名为 `DevelopmentRoyalArrival.xml`，任务测试新增真实原版文件去重、键读取和译文查询回归，先复现缺失再确认修复；同步改名游戏副本，无程序集业务变更。重启后新生成任务才会重新读取中文，已经将语言键保存为标题／说明的旧任务不自动重写。

**目标：** 实现已确认的随机皇室临时借住、单波原型追兵、击退后正式加入；失败条件保持死亡或被敌人带走，倒地可救治。不补剧情背景、研究树或核心绑定。

**原版接法：** 使用原版任务节点、额外小派系、人物抵达、延迟、人物加入和任务结束部件。内容程序集只扩展追兵抵达部件，在落地图前激活真实战斗体；进攻部件仅替换原版队伍为已有专用追兵队伍。单组队伍的 `AllEnemiesDefeated`（全部敌人被击败）信号控制正式加入和成功；不扫描全地图敌人，不设保护到期胜利。

**原版身份事实：** 原版可操作借住者会临时设为玩家派系，`IsQuestLodger`（任务借住者判断）由额外所属派系区分正式成员。契约按钮、实际施放和目标资格必须排除原版借住者，才能兑现“正式加入后才可缔约”；不另建任务完成锁。无皇室检查同样排除借住者，同时检查未接受／进行中的同类任务，防重复。

## 执行与文件

1. 先在 `Source/BDP.Tests/RoyalContractTests.cs` 增加真实原版借住身份的资格验证，确认现有仅派系判定无法满足边界；修改 `Source/BDP.Content/Trion/Royalty/Contract/CompAbilityEffect_RoyalContract.cs` 的施放者、按钮与殖民者目标准入。保留全部已确认的契约机制。
2. 新增 `Source/BDP.Content/Royal/Quest/QuestNode_Root_RoyalArrival.cs`：原版任务生成准入、随机皇室和追兵、临时小派系、信号骨架。基因与装备引用、追兵数量和抵达间隔均放定义，不在逻辑里固定平衡数值。
3. 新增 `Source/BDP.Content/Royal/Quest/QuestPart_RoyalPursuersArrive.cs` 与 `QuestPart_AssaultRoyalPursuers.cs`：前者继承原版人物抵达流程，后者继承原版建立进攻队伍流程；保持原版保存、引用替换和信号监听，只补 BDP 必须的激活和专用队伍。
4. 新增任务定义与中文语言键，采用原版随机任务候选，不增加强制剧情或全局定时扫描。皇室携带一颗驱动核心的物品入口按此前描述承接；分析、研究和建筑使用另议，不在本轮引入新研究路线。
5. 增加开发任务生成入口，通过正常任务界面接受和测试；不直接把皇室生成成正式殖民者，不替玩家自动缔约。
6. 构建三个程序集，运行契约与追兵队伍回归、任务部件边界验证、定义和语言解析检查；准确记录游戏内尚待验证的借住、队伍结束、失败及存读档，不把编译等同于游戏验收。

## 当前待确认

追兵数量与抵达节奏已异步询问用户，尚未收到回复。本轮在说明假设后暂用一名追兵、接受后半天抵达接通测试；这是可调整的首版配置，未将其记为用户已批准的长期标准。此前用户已明确具体数值允许重新平衡。邀请有效期沿原版难民任务的4～8天范围，满足原版随机任务配置要求；不设置任务保护时限。

完整实测包括：缺少皇室时可取得任务；重复任务不出现；借住者可工作和战斗但不能缔约；追兵首次出现已处于真正战斗体、直接装备原型；崩解不胜利，原身继续进攻；真正击败该组才加入；皇室倒地不失败，死亡／被带走失败；任务结束后可再按缺失条件出现；任务与崩解期间存读档。

## 实现与验证结果（2026-10-07）

上述最小范围已经实现。正式加入只监听进行中的任务信号，避免任务已失败后击败余敌仍招募；队伍任务标记在生成时解析并保存，避免袭击前读档丢失胜利信号。驱动核心先作为皇室库存里的实体材料，使用原版灵能神经连接器贴图占位，未实现分析、研究或建筑用途。

核心、内容、开发三个程序集构建通过，核心程序集依赖隔离通过；实际契约借住权限、任务防重复及追兵队伍边界检查通过，新增定义和语言文件通过 XML（可扩展标记语言）格式检查。完整原版定义加载不能在缺少 Unity（游戏引擎）宿主的离线进程中验证；该尝试已移除，未保留无效验证设施，亦未将其记作游戏加载成功。

游戏验证入口：重启游戏后，开发操作中的“BDP：皇室加入任务测试 → 生成皇室求援任务”，再在正常任务界面接受。本入口遵守正式准入，不绕过已有皇室或同类任务限制。下一个主线步骤是完整入口实测，之后再讨论核心材料到核心建设的连接。
