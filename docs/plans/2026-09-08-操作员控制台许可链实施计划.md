# 操作员控制台许可链实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 BDP 中实现需要电力、玩家指派操作员和 Trion 中继核心上游许可的操作员控制台，并向本地图玩家派系芯片发布一个解耦的下游地图许可。

**Architecture:** Core 提供中性的地图许可读取/提供契约、地图索引和芯片功能许可接收上下文；Content 实现 Trion 上游提供器、操作员控制台建筑/工作/状态组件和具体芯片业务接收器；Development 只承载可移除的现场诊断。控制台的下游许可提供器只读取 `IsOperational`，运作状态内部才组合电力、操作员、上游许可和上帝模式覆盖。

**Tech Stack:** RimWorld 1.6、C# 7.3、.NET Framework 4.8、Verse `MapComponent`/`ThingComp`/`JobDriver`/`WorkGiverDef`、PowerShell 烟雾测试、MSBuild。

**Confirmed building presentation:** 逻辑占地 `3×2`，交互格相对南侧一格；复用 `Things/Building/Misc/CommsConsole` 的 `Graphic_Multi`，`drawSize=(5,4)`；基础功耗 `200 W`。`size` 负责逻辑格，`drawSize` 只负责视觉绘制边界，本次不新增 PNG。
