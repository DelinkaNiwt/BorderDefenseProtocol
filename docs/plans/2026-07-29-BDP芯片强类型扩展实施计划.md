# BDP 芯片强类型扩展实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把芯片 `Extensions（扩展）`从无人使用的三段自由文本改为 Core 中性的强类型静态扩展入口，并删除表达运行快照中的无消费者复制链。

**Architecture:** Core 提供抽象 `ChipExtensionConfig`父类型，`ChipDefinitionConfig`和内部契约只保存静态扩展引用；校验器拒绝空条目和同一具体类型重复声明。表达系统不携带任意业务扩展，具体 Content 业务以后直接读取自己的扩展，并在确有运行固化需求时建立专用快照。

**Tech Stack:** C# 7.3、RimWorld 1.6 `DefModExtension / Class` XML 反序列化、PowerShell 冒烟测试、MSBuild、现有 Core 单向依赖门禁。

**Step 3：改为静态引用浅复制**

`DefaultChipDefinitionContractResolver.TranslateExtensions`：

```csharp
private static IReadOnlyList<ChipExtensionConfig> TranslateExtensions(
    List<ChipExtensionConfig> configs)
{
    return configs != null
        ? new List<ChipExtensionConfig>(configs)
```

**Step 4：实现中性结构校验**

`ValidateExtensions`改为：

```csharp
private static void ValidateExtensions(
    IReadOnlyList<ChipExtensionConfig> extensions,
    List<ChipDefinitionValidationMessage> errors)
{
    if (extensions == null)
    {
        return;
    }

    HashSet<Type> declaredTypes = new HashSet<Type>();
    for (int i = 0; i < extensions.Count; i++)
    {
        ChipExtensionConfig extension = extensions[i];
        if (extension == null)
        {
            errors.Add(BuildMessage(
                "ChipExtensionEntryMissing",
                ChipDefinitionValidationSeverity.Error,
                ChipDefinitionDeclaredBlock.Extensions,
                "该芯片的扩展列表存在空条目。"));
            continue;
        }

        Type extensionType = extension.GetType();
        if (!declaredTypes.Add(extensionType))
        {
            errors.Add(BuildMessage(
                "ChipExtensionTypeDuplicated",
                ChipDefinitionValidationSeverity.Error,
                ChipDefinitionDeclaredBlock.Extensions,
                "该芯片重复声明了同一种具体扩展：" + extensionType.FullName));
        }
    }
}
```
