# 变色龙状态芯片实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 新增 `Chameleon`（变色龙）状态芯片，使小人在隐身期间可正常尝试攻击，并在任意成功攻击动作（包括武器和敌对/暴力 Ability）正式执行后立即关闭芯片。

**Architecture:** `Core.dll` 只提供中性的攻击动作成功通知，不包含变色龙业务；`Content.dll` 提供无 Royalty（皇权）依赖的原版隐身组件适配和变色龙关闭逻辑。芯片使用现有表达 Hediff、互斥组和 Trion 账本，容量占用仍由战斗体生成/解除生命周期锁定与释放。

**Tech Stack:** C#（C#语言）、Harmony（补丁框架）、RimWorld 1.6 Def/XML（定义配置）、PowerShell smoke tests（冒烟测试）、MSBuild（构建）。

- Content 关闭逻辑只响应当前小人的攻击，并且 Ability 仅把 hostile/violent（敌对/暴力）能力视为攻击。

**Verification:** 先运行新增测试，确认它们因目标 Def、事件和组件尚不存在而失败。

### Task 2: 实现 Core 攻击动作成功通知

**Files:**
- Create: `Source/BDP/Core/AttackExecution/AttackActionSuccess.cs`
- Create: `Source/BDP/Core/AttackExecution/AttackActionSuccessDispatcher.cs`
- Create or Modify: `Source/BDP/Patches/Patch_Ability_Activate_BdpAttackActionSuccess.cs`
- Modify: BDP 正式远程和近战成功执行点，以及原版武器攻击成功接入点

**Behavior:**
- Ability 在 `Ability.Activate()` 成功后广播一次能力攻击动作事件。
- 只有 `AbilityDef.hostile` 或 `VerbProperties.violent` 的能力被标记为攻击来源。
- 远程在成功发射攻击动作后广播，近战在攻击动作成功接受后广播。
- 事件只广播事实，不直接操作芯片、Hediff 或 Trion。

### Task 3: 实现 Content 隐身 Hediff 和即时关闭

**Files:**
- Create: `Source/BDP.Content/Chameleon/HediffCompProperties_BdpInvisibility.cs`
- Create: `Source/BDP.Content/Chameleon/HediffComp_BdpInvisibility.cs`
- Create: `Source/BDP.Content/Chameleon/ChameleonAttackShutdownService.cs`

**Behavior:**
- 复用 `Verse.HediffComp_Invisibility` 的隐身、强制显形和心理不可见判定。
- BDP 自己刷新攻击目标缓存，避免无 Royalty/Anomaly（皇权/异常）时触发 DLC 检查。
- Hediff 添加后订阅攻击动作事件，移除后取消订阅。
- 事件来源 Pawn 与 Hediff 所属 Pawn 相同且当前变色龙仍有效时，调用现有 Trigger 即时关闭入口。
- 关闭只停止表达和 5/s 持续消耗，不触碰战斗体容量锁定。

### Task 4: 添加 Def、互斥组和语言包

**Files:**
- Modify: `1.6/Content/Defs/ChipDef/Classification.xml`
- Modify: `1.6/Content/Defs/ChipActionPresetDef/Presets.xml`
- Create: `1.6/Content/Defs/HediffDef/Chameleon.xml`
- Modify or Create: `1.6/Languages/ChineseSimplified (简体中文)/Keyed/*.xml`
- Create or Modify: `1.6/Languages/ChineseSimplified (简体中文)/DefInjected/HediffDef/*.xml`

**Parameters:**
- Chip preset: `BDP_Preset_Chameleon`。
- Category: `BDP_ChipCategory_Status`。
- Loadout: `MainSub` + `Single`；激活 30 tick；停用 0 tick。
- Activation exclusion group: `BDP_ChipExclusionGroup_Stealth`。
- Chip Trion: `CapacityCost=100`、`ActivationCost=15`。
- Activation requirement: `TrionIntensityRequirement.Minimum=1`。
- Hediff expression: `BDP_Hediff_Chameleon`，`SustainCostBySourceCount` 单来源 `TotalPerSecond=5`。
- 不为变色龙重复声明攻击 `UseCost`。

### Task 5: 绿色验证与游戏边界验证

**Commands:**
- Run each new smoke test and the existing chip/exclusion/attack regression tests.
- Build Core、Content 的 Release 配置并检查程序集依赖。
- Verify in game with Royalty absent and present.

**Scenarios:**
- 变色龙与其它隐秘组芯片互斥切换。
- 主副槽可与武器/能力正常共存。
- 原版武器、BDP 远程、BDP 近战、敌对 Ability 成功执行后立即关闭。
- 跳跃、位移、治疗、增益 Ability 不关闭。
- 攻击落空但动作成功执行时仍关闭；预热失败时不关闭。
- 隐身期间容量仍由战斗体生命周期锁定，芯片关闭不提前释放容量。
- 战斗体解除后容量释放，持续 Trion 注册正确清理。
