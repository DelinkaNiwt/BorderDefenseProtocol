# BDP 简体中文本地化盘点报告

## 本轮结果

- 语言：只建立 `ChineseSimplified (简体中文)`，没有建立英文包。
- `Keyed`：266 个键，按命令、消息、状态报告、窗口、工作报告和通用玩法文字分类。
- `DefInjected`：63 个条目，按 RimWorld 的实际 Def 类型分类。
- 代码调用：主模组 Core 与 Content 中使用 `BDP_` 前缀翻译键；格式化文本使用 RimWorld 原生 `Translate(...)` 参数形式。
- 原始 Def 文本：保留，作为没有加载中文语言包时的默认回退；中文语言包加载后覆盖当前显示。

## 已提取的玩家可见范围

1. 战斗体启用、解除、崩解、冷却和 Trion 状态面板。
2. Trion 容量、释放力、技能门槛和角色条件提示。
3. Trion 天赋检测器的按钮、浮动菜单、工作状态和检测结果。
4. 触发器芯片面板、槽位状态、冲突切换、激活条件和操作提示。
5. 触发器装配台、芯片仓、装卸事务和装配窗口。
6. 紧急脱离信标、紧急脱离按钮和放置限制。
7. 已确认的正式类别、容量潜质档位、拖尾预设以及 Core 提供的通用工作/状态文本。

## 暂不提取的文字

以下文字经检查后确认不是普通玩家界面，本轮保留在代码中：

- `BdpDiagnostics`、`Log.Error` 和其他诊断日志；它们只用于排查游戏内实测问题。
- 芯片定义校验、表达结构校验、组合技校验和配置错误信息；它们面向开发者检查 Def，不作为正式玩家提示。
- 视觉姿态诊断、远程攻击投影诊断、拖尾运行时诊断等临时诊断数据。
- 尚未确认的具体芯片业务和双持示例（包括“双持远程”“双持近战”等候选入口）。
- Core 内部语义上下文、运行时作用域和内部状态标签；它们不直接绘制到玩家界面。

## 复查规则

以后新增正式玩家文字时：

1. 代码中使用 `BDP_` 前缀键，不直接写中文句子。
2. 普通按钮、提示、状态和窗口文字放入 `Keyed`；Def 的 `label`、`description`、`reportString` 放入对应 `DefInjected` 类型目录。
3. 运行 `Source/BDP.Tests/LocalizationChineseBoundarySmokeTests.ps1`，确认 XML 可解析、键不重复、代码调用都有简体中文值。
4. 只有在某个业务文本最终确认后，才把它从候选或诊断范围提升为正式本地化键。
