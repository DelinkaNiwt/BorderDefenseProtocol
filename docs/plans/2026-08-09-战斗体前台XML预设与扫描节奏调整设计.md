# 战斗体前台 XML 预设与扫描节奏调整设计

## 目标

把战斗体前台服装模式从注入式 Comp 的 C# 默认值归位到现有全局 XML 配置；临时启用预设服装模式供游戏观察，同时加快扫描并收紧头顶起点。

## 配置归位

`CombatBodyHostConfigDef` 继续作为战斗体宿主全局配置，新增：

- `frontMode`：`MirrorOriginal`（镜像原身）或 `Preset`（预设服装）；
- `frontPresetDefName`：预设模式使用的 `CombatBodyFrontPresetDef` 名称。

`PawnCombatBodyBridge` 在应用前台替换时读取该全局 Def。`CompProperties_CombatBodyHost` 不再承载前台模式，避免动态注入时把选择写死在 C#。安全回退仍为 `MirrorOriginal`。

## 临时预设

在 Content 定义目录增加 `BDP_TemporaryCombatBodyObservationPreset`，引用四件原版、无需 Stuff 参数即可创建的衣物：

- `Apparel_FlakPants`；
- `Apparel_FlakVest`；
- `Apparel_FlakJacket`；
- `Apparel_PowerArmorHelmet`。

这组预设只用于当前视觉观察，明确标注为临时项。XML 全局配置暂切到 `Preset` 并指向它。以后删除临时 Def 或切回 `MirrorOriginal`，不需要改桥接代码。

## 镜像边界

不修改 `ApplyMirrorOriginalFrontReplacement`、`CreateMirroredApparel`、快照容器、原衣恢复与镜像副本销毁语义。相关回归测试继续锁定这条路径存在。

## 扫描节奏

- 动画时长由 24 tick 调整为 16 tick，约从 0.4 秒降到 0.27 秒；
- 头部上边界由 `headOffset.z + headWidth * 0.5` 收紧为 `headOffset.z + headWidth * 0.38`；
- 身体下边界、扫描方向、裁切网格、光带厚度不变。

头部纹理在完整方形网格中带透明留白，0.38 系数用于让扫描中心更贴近肉眼可见的头顶，而不是改变头部或衣物真实绘制位置。

## 验证

- 新增 XML 配置边界测试，确认模式不再位于 `CompProperties`；
- 新增临时预设完整性测试，确认全部原版衣物引用存在于预设；
- 更新扫描测试锁定 16 tick 与 0.38 上边界；
- 运行镜像原身、前台恢复、扫描表现与双工程 Release 构建回归。
