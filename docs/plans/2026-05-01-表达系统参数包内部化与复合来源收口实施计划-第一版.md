# 表达系统参数包内部化与复合来源收口 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把 `ExpressionRuntimePayload（表达系统内部参数包）` 收回表达系统内部，只保留 `FormalExpressionResult（正式结果）` 作为下游正式出口，并用现有 `CompositeReferences（复合来源引用表）` 收口复合来源追踪。

**Architecture:** 本轮只改表达系统内部构建链、正式结果模型、正式宿主绑定状态，以及 `CombatBodyEmergencyEscape（紧急脱离）` 这一条已确认仍停留在旧单来源读法的链路。不新增胖上下文对象，不新增复合正式字段；内部只允许增加一个按单侧结果 `Id` 建好的来源材料索引，复合来源对下游一律优先复用 `TriggerCombatProjectionState（正式战斗投影状态）` 已公开的 `ResultIndex（结果索引）` 与 `CompositeReferenceIndex（复合引用索引）`。按项目约束直接在当前工程执行，不使用 `worktree（工作树）`。

**Tech Stack:** RimWorld 1.6 Mod、C#、PowerShell 烟测、`dotnet msbuild`

### Task 5: 用现有正式复合引用结构收口 `紧急脱离` 来源

**Files:**
- Modify: `Source/BDP/Core/CombatBody/Flow/CombatBodyEmergencyEscapeResolver.cs`
- Modify: `Source/BDP/Core/CombatBody/Flow/CombatBodyEmergencyEscapeResolution.cs`
- Modify: `Source/BDP/Core/CombatBody/Flow/CombatBodyEmergencyEscapeService.cs`
- Test: `Source/BDP.Tests/CombatBodyEmergencyEscapeResolverSmokeTests.ps1`
- Test: `Source/BDP.Tests/CombatBodyEmergencyEscapeExecutionSmokeTests.ps1`

**Step 1: 让解析层同时读取 Passive 结果和正式战斗投影**

在 `CombatBodyEmergencyEscapeResolver.Resolve(...)` 保留：

```csharp
reader.TryGetPassive(pawn, "EmergencyEscape", out result)
```

同时补：

```csharp
TriggerCombatProjectionState projection = reader.GetCombatProjection(pawn);
```

并只用 `projection.ResultIndex / projection.CompositeReferenceIndex` 解析复合来源。

**Step 2: 改成“单来源优先、复合来源回查”的解析顺序**

顺序固定为：

```text
1. 如果 result.SourceReference 非空，直接作为唯一来源
2. 否则按 result.Id 去 CompositeReferenceIndex 找 SourceResultIds
3. 再按 SourceResultIds 去 ResultIndex 找单侧结果
4. 取这些单侧结果的 SourceReference 列表
```

这里禁止：

- 回头扫描 Trigger 内部装载细节
- 重新构建表达快照
- 解析字符串拼来源

**Step 3: 把缓存结果改成来源列表**

把 `CombatBodyEmergencyEscapeResolution` 从：

```csharp
public ExpressionSourceReference SourceReference;
```

改成：

```csharp
public IReadOnlyList<ExpressionSourceReference> SourceReferences;
```

并同步更新存读档。

**Step 4: 执行层改成逐个消费来源**

把 `CombatBodyEmergencyEscapeService` 从单 `TryConsumeSourceChip(...)` 改成：

```text
循环 SourceReferences
  -> 对每条来源执行正式 Trigger 命令消费
```

单来源路径仍等价于现状。
