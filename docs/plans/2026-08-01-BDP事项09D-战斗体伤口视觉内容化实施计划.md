# BDP 事项09D：战斗体伤口视觉内容化实施计划

> **For Claude：** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task。

**目标：** 在不改变伤口严重度、Trion 泄漏、扣费、时序和存读档行为的前提下，把伤口喷溅视觉从 Core 拆到 Content。

**架构：** Core 保留伤口事实、伤口 Trion 运行时和一个中性的伤口表现扩展注册表，只向外部提供“伤口新增/移除/过期、运行时 Tick、读档重建”等生命周期通知。Content 注册喷溅视觉提供器，持有喷溅运行时、发射器、视觉随机量和 Fleck Def 引用。Core 不认识 Fleck、喷溅颜色或具体视觉业务。

**技术栈：** RimWorld 1.6、C# 7.3、Verse/RimWorld C# API、XML Def、PowerShell 冒烟测试、MSBuild。

### Task 2：实现 Core 中性伤口表现扩展口

**文件：**

- 新建：`Source/BDP/Core/CombatBody/Wounds/Presentation/ICombatBodyWoundPresentationProvider.cs`
- 新建：`Source/BDP/Core/CombatBody/Wounds/Presentation/CombatBodyWoundPresentationRegistry.cs`
- 修改：`Source/BDP/Core/CombatBody/Wounds/CombatBodyWoundRuntime.cs`

**接口生命周期：**

- `ExposeData()`：保存外部表现需要的轻量状态。
- `ClearAll()`：清除当前战斗体派生的表现运行时。
- `NotifyWoundAdded(Pawn, Hediff)`：伤口进入有效 Trion 流失生命周期。
- `NotifyWoundDrainExpired(int)`：伤口流失生命周期结束。
- `NotifyWoundRemoved(Pawn, Hediff)`：伤口从 Pawn 移除。
- `RebuildFromActiveDrains(Pawn, IEnumerable<int>)`：读档后按 Core 真实活跃伤口重建表现。
- `Tick(Pawn)`：推进表现运行时。

注册表要求：

- 对外公开 `Register` / `Unregister`，同一具体提供器类型只注册一次。
- 每个提供器调用单独捕获异常，避免视觉业务阻断伤口 Trion 主链。
- Core 主运行时只调用注册表，不再直接 `using ...Wounds.Visuals`。
