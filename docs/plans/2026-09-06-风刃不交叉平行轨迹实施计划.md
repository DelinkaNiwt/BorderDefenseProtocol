# 风刃不交叉平行轨迹 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让风刃齐射投射物使用有序横向车道，在发射后分叉、中段保持大致平行并在末端收束到同一目标。

**Architecture:** 保留毒蛇和共享 `OrderedSpreadSampler` 的现有行为。风刃 `DistanceRevectorModule` 在 `ProjectileInit` 阶段冻结每发车道、侧向基准和发射点偏移，在 `Arrival` 阶段按共同收束曲线生成路线；Core 只承载中性的“模块已解析发射点偏移”字段，Ability 宿主按该字段消费。

**Tech Stack:** C#、RimWorld Def/XML、Harmony-free existing ranged protocol、PowerShell smoke tests、.NET Release build。

### Task 3: 实现风刃专用有序车道

**Files:**
- Modify: `Source/BDP.Content/RangedModules/DistanceRevector/DistanceRevectorModule.cs`
- Modify: `1.6/Content/Defs/RangedModuleDef/Fujin.xml`
- Modify: `Source/BDP.Tests/FujinParallelLaneSpreadSmokeTests.ps1`

**Step 1: Implement lane sampling**

在风刃模块内部按 `EmitIndex` 和 `EmitCount` 生成归一化、稳定且保持顺序的横向车道；扰动限制在相邻车道间距以内。把车道值和固定侧向量写入 `DistanceRevectorTrack`，支持复制与读档。

**Step 2: Implement origin coordination**

读取现有每发 `OriginSpread` 数据，按同一车道值解析横向偏移，并使用整轮共享的稳定前后偏移，提交初始化计划的发射点偏移覆盖。风刃 XML 显式打开车道模式；默认关闭以保护其它潜在 DistanceRevector 使用者。

**Step 3: Implement checkpoint geometry**

继续使用当前实时目标格和检查点，不改目标绑定。将独立二维随机点替换为固定侧向车道偏移；在末端使用共同收束系数，让最终目标点的横向偏移为零。
