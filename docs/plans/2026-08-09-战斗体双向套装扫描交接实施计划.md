# 战斗体双向套装扫描交接 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让战斗体进入与解除时，退场套装和入场套装在扫描线两侧互补显示，消除入场预设整套瞬间出现的突兀感。

**Architecture:** Core.dll 只增加中性的变换完成通知，形成换装前后两个表现采样点。Content.dll 在两个采样点捕获服装，在短命 Mote 存活期间精确抑制已捕获入场衣物的原版身体/头部节点，再用同一套预建网格对退场与入场记录做相反方向裁切。

**Tech Stack:** C# 7.3、RimWorld 1.6 `PawnRenderTree`（人物渲染树）、Harmony（运行时补丁框架）、Unity `Graphics.DrawMesh`（网格绘制）、PowerShell 冒烟测试、MSBuild/dotnet Release（正式）构建。

**执行约束:** 遵循项目 `AGENTS.md`，直接在当前主线执行，不创建 worktree（工作树）或新分支；不改 `ApplyMirrorOriginalFrontReplacement` 及其镜像复制成员。

**Step 3: Write minimal implementation**

抑制注册表只存当前 Pawn 的令牌、截止 tick 和已捕获入场衣物编号。`Begin` 返回新令牌；`End` 只在令牌匹配时删除；`ShouldSuppress` 在 Mote 隐藏、状态过期、Pawn/衣物不匹配时返回 false。

两个 Harmony 后置补丁使用同一辅助方法：

```csharp
private static void ApplySuppression(
    PawnRenderNode node,
    PawnDrawParms parms,
    ref bool result)
{
    if (result
        && !parms.Portrait
        && node is PawnRenderNode_Apparel apparelNode
        && CombatBodyApparelRenderSuppression.ShouldSuppress(parms.pawn, apparelNode.apparel))
    {
        result = false;
    }
}
```

只补丁 `PawnRenderNodeWorker_Apparel_Body.CanDrawNow` 和 `PawnRenderNodeWorker_Apparel_Head.CanDrawNow`，不补丁基础渲染节点。
