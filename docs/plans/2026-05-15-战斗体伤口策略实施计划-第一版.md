# CombatBody Wound Policy Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 实现 `CombatBody Active`（战斗体激活态）期间的原版伤口有效规则：默认压制单伤口流血表现，默认不产生 Trion 伤口流失，并为未来按原版伤口 rawBleedRate（原始流血潜势）启用流失留下正确入口。同时只预留伤口视觉替换/特效渲染接口，不在本轮实现任何视觉替换行为。

**Architecture:** 原版 `Hediff_Injury / Hediff_MissingPart` 继续作为伤口事实基线；`BDP_CombatBodyActive` 继续承担全局健康保护；新增 `BDP.Core.CombatBody.Wounds` 小业务层，只在 Active 期间解释伤口的有效结果并可选维护 Trion drain（持续消耗）。实现必须最小接入 RimWorld 原版生命周期：Harmony 补丁只接单伤口 `BleedRate` 与伤口添加/移除/变化事件，Trion 仍通过现有 `CompTrion` 聚合账本结算。视觉需求只放入 `BDP.Core.CombatBody.Wounds.Visuals` 接口层，本轮不 patch `FleshTypeDef.ChooseWoundOverlay` 或 Pawn 渲染节点。

**Tech Stack:** RimWorld 1.6 mod、C# 7.3、Harmony、XML Def、PowerShell smoke tests、`dotnet build`。

`CombatBodyWoundPolicy.cs`:

```csharp
using BDP.Core.CombatBody;
using Verse;

namespace BDP.Core.CombatBody.Wounds
{
    /// <summary>
    /// 战斗体伤口策略判断层。
    /// 它只解释 Active 期间原版伤口的有效结果，不保存伤口真值。
    /// </summary>
    internal static class CombatBodyWoundPolicy
    {
        /// <summary>
        /// 默认策略 Def 名称。
        /// </summary>
        private const string DefaultPolicyDefName = "BDP_DefaultCombatBodyWoundPolicy";

        /// <summary>
        /// 读取当前默认策略。
        /// Def 缺失时返回代码内置安全默认值。
        /// </summary>
        internal static CombatBodyWoundPolicyDef Resolve()
        {
            return DefDatabase<CombatBodyWoundPolicyDef>.GetNamedSilentFail(DefaultPolicyDefName)
                ?? new CombatBodyWoundPolicyDef();
        }

        /// <summary>
        /// 判断 Pawn 当前是否处于战斗体 Active。
        /// CombatBody 相位是真值，激活态 Hediff 只是原版健康效果承载。
        /// </summary>
        internal static bool IsCombatBodyActive(Pawn pawn)
        {
            ICombatBodyReader reader = CombatBodySurfaceAccess.ResolveReader(pawn);
            return reader != null && reader.Phase == CombatBodyPhase.Active;
        }

        /// <summary>
        /// 判断当前伤口是否应压制单伤口流血表现。
        /// </summary>
        internal static bool ShouldSuppressIndividualBleeding(Hediff hediff)
        {
            if (hediff?.pawn == null || !IsSupportedWound(hediff))
            {
                return false;
            }

            CombatBodyWoundPolicyDef policy = Resolve();
            return policy.suppressIndividualBleeding && IsCombatBodyActive(hediff.pawn);
        }

        /// <summary>
        /// 判断当前 Hediff 是否属于第一版支持的原版伤口类型。
        /// </summary>
        internal static bool IsSupportedWound(Hediff hediff)
        {
            return hediff is Hediff_Injury || hediff is Hediff_MissingPart;
        }
    }
}
```

**Step 3: Add Trion binding**

`CombatBodyWoundTrionBinding` responsibilities:

- `UpdateWoundDrain(Pawn pawn, Hediff hediff)`
- `RemoveWoundDrain(Pawn pawn, Hediff hediff)`
- `ClearAll(Pawn pawn)`
- `Rebuild(Pawn pawn, IEnumerable<Hediff> wounds)`

Minimal behavior:

- If policy disabled or multiplier <= 0：unregister existing key and return。
- If wound is `Hediff_MissingPart` and `includeMissingPartBleedPotential=false`：unregister existing key and return。
- If no `ITrionCommands`：return。
- If no valid `loadID`：return。
- raw bleed <= 0：unregister key。
- else register `rawBleedRate * trionDrainPerRawBleedRate`。

Skeleton:

```csharp
using System;
using System.Collections.Generic;
using BDP.Core.Trion;
using RimWorld;
using Verse;

namespace BDP.Core.CombatBody.Wounds
{
    /// <summary>
    /// 战斗体伤口 Trion 持续消耗绑定。
    /// 它只负责把伤口策略结果发布到 Trion 账本，不参与资源结算。
    /// </summary>
    internal sealed class CombatBodyWoundTrionBinding
    {
        /// <summary>
        /// 当前运行期已经发布过的伤口 drain。
        /// </summary>
        private readonly Dictionary<int, TrionDrainKey> publishedKeysByHediffLoadId =
            new Dictionary<int, TrionDrainKey>();

        /// <summary>
        /// 重建当前 Pawn 所有伤口 drain。
        /// </summary>
        internal void Rebuild(Pawn pawn, IEnumerable<Hediff> wounds)
        {
            ClearAll(pawn);
            if (wounds == null)
            {
                return;
            }

            foreach (Hediff wound in wounds)
            {
                UpdateWoundDrain(pawn, wound);
            }
        }

        /// <summary>
        /// 按当前伤口状态注册、更新或注销 drain。
        /// </summary>
        internal void UpdateWoundDrain(Pawn pawn, Hediff hediff)
        {
            if (pawn == null || hediff == null || !CombatBodyWoundPolicy.IsSupportedWound(hediff))
            {
                return;
            }

            CombatBodyWoundPolicyDef policy = CombatBodyWoundPolicy.Resolve();
            if (!policy.trionDrainEnabled || policy.trionDrainPerRawBleedRate <= 0f)
            {
                RemoveWoundDrain(pawn, hediff);
                return;
            }

            if (hediff is Hediff_MissingPart && !policy.includeMissingPartBleedPotential)
            {
                RemoveWoundDrain(pawn, hediff);
                return;
            }

            float rawBleedRate = CombatBodyWoundRawMetrics.ReadRawBleedRate(hediff);
            float drainPerDay = Math.Max(0f, rawBleedRate * policy.trionDrainPerRawBleedRate);
            if (drainPerDay <= 0f)
            {
                RemoveWoundDrain(pawn, hediff);
                return;
            }

            ITrionCommands commands = TrionSurfaceAccess.ResolveCommands(pawn);
            if (commands == null || hediff.loadID <= 0)
            {
                return;
            }

            TrionDrainKey key = BuildDrainKey(hediff);
            commands.RegisterDrain(key, drainPerDay);
            publishedKeysByHediffLoadId[hediff.loadID] = key;
        }

        /// <summary>
        /// 注销指定伤口 drain。
        /// </summary>
        internal void RemoveWoundDrain(Pawn pawn, Hediff hediff)
        {
            if (pawn == null || hediff == null || hediff.loadID <= 0)
            {
                return;
            }

            if (!publishedKeysByHediffLoadId.TryGetValue(hediff.loadID, out TrionDrainKey key))
            {
                key = BuildDrainKey(hediff);
            }

            TrionSurfaceAccess.ResolveCommands(pawn)?.UnregisterDrain(key);
            publishedKeysByHediffLoadId.Remove(hediff.loadID);
        }

        /// <summary>
        /// 清理当前运行期所有战斗体伤口 drain。
        /// </summary>
        internal void ClearAll(Pawn pawn)
        {
            ITrionCommands commands = TrionSurfaceAccess.ResolveCommands(pawn);
            if (commands != null)
            {
                foreach (TrionDrainKey key in publishedKeysByHediffLoadId.Values)
                {
                    commands.UnregisterDrain(key);
                }
            }

            publishedKeysByHediffLoadId.Clear();
        }

        /// <summary>
        /// 为伤口实例生成稳定 drain 键。
        /// </summary>
        private static TrionDrainKey BuildDrainKey(Hediff hediff)
        {
            return new TrionDrainKey("CombatBody", "Wound", -1, hediff.GetUniqueLoadID());
        }
    }
}
```

## 验收标准

完成后应满足：

- 非战斗体 Active 状态下，原版伤口流血行为不变。
- 战斗体 Active 状态下，单伤口 `BleedRate/Bleeding` 有效为 0。
- `BDP_CombatBodyActive.totalBleedFactor=0` 继续负责总流血归零。
- 默认配置不产生 Trion 伤口流失。
- 未来启用流失时，流失计算基于原版 rawBleedRate，而不是被 BDP 压制后的有效流血率。
- Trion core 不引用伤口业务。
- CombatBody 相位是真值，伤口策略不反向依赖 `BDP_CombatBodyActive` Hediff 作为业务状态。
- 伤口视觉扩展接口存在，但本轮不替换原版伤口贴图、不追加特效、不 patch 原版伤口渲染。
- 退出 Active、读档恢复、伤口移除不会留下 `CombatBody/Wound` drain。
- `WoundInfection` 由激活态免疫承接，不在伤口策略层重复拦截感染。

## 风险与停点

遇到以下情况必须暂停反馈，不要继续扩大改动：

- Harmony 无法稳定 patch `BleedRate` getter。
- 需要修改 `CompTrion` 才能实现伤口 drain。
- 需要替换原版伤口 Hediff 类。
- 需要在本轮 patch `FleshTypeDef.ChooseWoundOverlay` 或 `PawnRenderNodeWorker_OverlayWounds` 才能完成视觉需求。
- 需要在本轮执行贴图替换、动态特效生成或直接绘制伤口 overlay。
- 需要把 DevHarness 或旧 BDP 内容引入主模组。
- 需要改动医疗 AI、治疗逻辑、自然愈合或感染组件内部实现。

这些都超出第一版最小设计边界。
