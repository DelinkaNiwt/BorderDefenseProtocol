# 霰弹枪岚参考视觉设计

## 目标

让霰弹枪枪壳在单武器和双武器状态下使用“测试图-岚”，其中双武器姿态与当前突击步枪双武器参考预设完全一致，以便在同一数据基准下比较不同武器贴图的实际表现。

## 设计

- 将现有 `BDP_Visual_Shotgun` 的贴图改为独立部署的岚参考贴图，不增加姿态、握持或枪口配置；因此单武器继续服从原版默认绘制。
- 新增 `BDP_Visual_Shotgun_Dual` 双武器预设。
- 新预设除 `defName`、`label` 和贴图路径外，完整复制 `BDP_Visual_RangedWeaponReference_Dual` 当前数据：
  - 南北握持目标 `(0.20, 0, 0.12)`；
  - 统一装饰角 `6` 度；
  - 非执行态手侧镜像；
  - 握持锚点 `(0, 0, -0.1953125)` 并作为姿态原点；
  - 远程枪口点 `(0, 0, 0.48828125)`。
- 在霰弹枪枪壳中保留单武器预设绑定，并新增 `compositeVisualPresetDefName` 指向该独立双武器预设。
- 不修改突击步枪预设、通用解析器或其它枪壳。

## 资源与验证

- 将 `参考资源/通用资源/占位贴图/测试图-岚.png` 原样部署到模组英文纹理路径，保持 `512×512` 和文件哈希一致。
- 新增独立烟雾测试，确认单武器无姿态配置、双武器数据与突击步枪参考双武器逐项一致、霰弹枪枪壳绑定正确、源目标贴图一致。
- 解析相关 XML，执行视觉回归与构建；最终效果由游戏内实测确认。
