# 毒蛇自动路径双侧分流修正 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修正毒蛇自动路径只保留一侧的问题，让条件允许时左右两侧自动路线都保留，并按 projectile 发射序号交替分配。

**Architecture:** 主模组不增加业务协议。DevHarness 的 `PathLatchAutoRouteResolver（路线引导自动路径解析器）` 输出左右候选，`PathLatchModule（路线引导模块）` 在确认快照中保存左右候选，并在 `ProjectileInit（投射物初始化）` 阶段为每发弹选择一条普通锚点路径。

**Tech Stack:** RimWorld 1.6、Verse、C#、PowerShell smoke tests。
