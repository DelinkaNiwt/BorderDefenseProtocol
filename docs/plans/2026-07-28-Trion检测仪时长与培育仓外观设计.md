# Trion 检测仪时长与培育仓外观设计

## 目标

固定 Trion 检测仪在研究速度与建筑研究系数均为 100% 时，将基准操作时间从 3 游戏小时缩短为 1 游戏小时；建筑外观和占地完全采用原版生物科技培育仓参数。

## 原版依据

原版 `GrowthVat`（培育仓）使用：

- 贴图路径：`Things/Building/Misc/GrowthVat/GrowthVat`
- 图形类：`Graphic_Multi`
- 定义尺寸与绘制尺寸：`(1,2)`
- 默认朝向：`East`

因此建筑默认放置时在地图上的观感为横向 2×1，同时保留原版多方向旋转一致性。

## 最小改动

- `Building_TrionDetector.WorkRequired` 从 `7500f` 改为 `2500f`。
- 检查信息中的“3 游戏小时”同步改为“1 游戏小时”。
- `ThingDefs_TrionDetector.xml` 仅替换尺寸、绘制尺寸、贴图路径并增加默认朝向。
- 不修改检测公式、研究速度影响、造价、耗电、入舱、结算和便携检测仪。

## 验证

先更新专项测试并确认旧参数失败，再修改代码与 XML；随后运行检测仪专项测试、XML 解析和 Release 编译。
