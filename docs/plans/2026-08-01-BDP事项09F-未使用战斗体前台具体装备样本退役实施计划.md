# BDP 事项 09F：未使用战斗体前台具体装备样本退役实施计划

> 时间：2026-08-01（Asia/Shanghai）
> 状态：已完成

## 一、目标

清除战斗体前台外观系统中没有实际调用的具体示例，同时保留通用机制，避免把临时样品误当成 Core（核心程序集）的正式业务。

## 二、保留内容

- `CombatBodyFrontMode`：支持“跟随原衣物”和“使用固定预设”两种模式。
- `CombatBodyFrontPresetDef`：供 BDP Content（内容程序集）或第三方模组注册固定外观清单。
- `PawnCombatBodyBridge`：负责按模式挂载、恢复战斗体前台衣物。
- `BDP_DefaultCombatBodySnapshotConfig`：战斗体快照的通用排除策略。

## 三、退役内容

- `BDP_DefaultCombatBodyFrontPreset`：没有生产运行时调用的临时默认预设。
- `BDP_CombatBodyArmor`：只被上述临时预设引用的示例护甲。
- Core 宿主配置中指向该临时预设的默认名称。

## 四、实施与验证

1. 先新增退役边界冒烟测试，并确认修改前因具体样品仍存在而失败。
2. 删除具体预设 Def 和示例护甲 Def；将默认预设名称改为空值。
3. 更新前台外观专项测试，改为验证通用机制保留、具体样品不存在。
4. 运行战斗体前台与快照专项测试、XML 解析、三程序集 Release 构建和 Core 依赖门禁。
5. 记录全量冒烟测试结果，确认没有新增本事项相关失败后提交。

## 五、行为影响

当前宿主默认仍为 `MirrorOriginal`（跟随原衣物），所以玩家实际游戏表现不改变。未来需要固定外观时，仍可由 Content 或第三方模组注册自己的 `CombatBodyFrontPresetDef`，并在宿主配置中填写名称。
