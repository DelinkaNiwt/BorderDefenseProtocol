# 远程目标许可门控设计

## 目标

让猎犬、黄蜂及其追踪配置的“可选空地”和“非直视目标”都受操作员控制台运作许可控制：

- 未获得许可：只允许选择 Thing（实体）目标，并要求射手到目标有直接视线。
- 获得许可：允许选择空地格子，并放宽射手到目标的直接视线要求。
- 直接可视目标继续沿用原版直射流程；不可视目标交给已经独立存在的高角射击模块切换高角投射物。

## 边界

- 高角射击模块不读取操作员控制台，也不读取追踪模块。
- 追踪模块不读取操作员控制台；它继续只负责追踪和落点附近目标搜寻。
- Core 只提供中性的“地面目标许可解析器”契约、注册表和访问入口。
- Content 的操作员控制台业务同时实现直视许可与地面目标许可。
- 目标选择阶段在模块和阶段扩展执行后做一次最终许可门控，避免追踪模块的默认空地能力绕过许可。
- 目标参数先复制再交给目标阶段，避免改动原版 Verb 共享的 `targetParams`。

## 时序

```text
原版 Verb.targetParams
        ↓ 复制
TargetingRecord.TargetingParameters
        ↓ 追踪模块/其它目标阶段扩展
控制台许可最终门控
        ↓
Targeter（原版目标选择器）
```

未声明控制台许可键的结果不接受这道门控，保留现有模块配置；只有显式声明该许可键的猎犬与黄蜂会被控制台许可覆盖。

## 验证

- 静态契约测试确认 Core、Content、目标阶段和猎犬/黄蜂 Def 的接线关系。
- Release 构建 Core 与 Content。
- 保留并复跑已有动态直视许可、追踪空地基线和高角模块测试。
- 实机仍需观察控制台运作/停机切换时 Targeter 的空地高亮、直视目标和墙后目标行为。
