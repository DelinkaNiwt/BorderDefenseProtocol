# 双武器静默自然下垂角设计

## 目标

在现有手侧镜像形成的朝南静默倒 V 基础上，让两个枪口适度靠近、枪尾自然分离，使两把枪仍然朝外，但整体更接近向下垂放的状态。

## 设计

- 只修改双武器远程参考预设的南北静默姿态。
- 保留 `ForceHandMirrorWhenInactive`，继续由贴图镜像保证两侧武器结构合理。
- 增加 `DefaultAngle = 6` 度。现有解析器会按最终网格镜像自动反转装饰角，因此两把武器对称内收，无需分别配置主副手角度。
- 保持握持目标 `(0.20, 0, 0.12)`、握持锚点和枪口锚点不变。
- 单武器、东西朝向与执行态不受影响。
- 用用户更新的 `512×512` 红色握把方向箭头版本覆盖模组内参考贴图。

## 验证

- 配置测试确认双武器装饰角为 `6` 度，并确认没有副手额外角度。
- 单武器回归测试继续确认基础预设没有南北姿态配置。
- 对比源贴图与部署贴图的尺寸和哈希值。
- 解析 XML，构建并部署 BDP.Core.dll；最终视觉效果由游戏内朝南静默截图确认。
