## 执行约束

- 直接在当前 `main（主线）`工作，不创建分支或 worktree。
- 先写失败测试，再做最小实现；每个任务使用独立提交。
- 不兼容旧字段、旧存档键、旧 DefName（定义名称）和旧内部类型名。
- Core 不得依赖 `BDP.Content.dll`、`BDP.DevHarness.dll`或未来任何其它本模组 DLL。
- `BDP.Content.dll`与 `BDP.DevHarness.dll`只允许单向引用 `BDP.Core.dll`。
- 不添加假的高门槛芯片，不提高现有具体芯片门槛，不给任何芯片虚构技能条件。
- 所有现有正式候选芯片只把旧最低功率 1 等义迁移为最低释放力 1；护盾等漏填旧字段的正式候选也补为 1。
- 不建立容量与释放力换算、相关随机、Trion 天赋总数值或多芯片释放力总预算。
- 激活条件失败必须发生在互斥关闭、启用延迟和激活费用之前。
- 玩家点击通过后的互斥等待与启用延迟不复查条件；正式启用后才进入 60 tick 低频持续复查。
- 持续失效只进入现有正常关闭流程，不建立立即强制撤下、自动恢复或自动重开。
- Content 不自行复制条件判断，只显示 Core 的只读结果。
- C# 至少逐成员中文注释，XML 至少逐条目中文注释，统一 UTF-8。

- 若实施发现必须扩大到计划外系统，立即暂停反馈。

## 正式配置

标准顺序：

```xml
<li Class="BDP.Core.Chips.ChipDefinitionConfig">
  <Profile>...</Profile>
  <Loadout>...</Loadout>

  <ActivationRequirements>
    <li Class="BDP.Core.Requirements.TrionIntensityRequirement">
      <Minimum>1</Minimum>
    </li>
  </ActivationRequirements>

  <Trion>
    <CapacityCost>100</CapacityCost>
    <ActivationCost>10</ActivationCost>
  </Trion>

  <Expression>...</Expression>
  <Extensions>...</Extensions>
</li>
```

技能条件由 Core 提供；当前旋空芯片已经采用格斗10级与射击6级两项具体配置：

```xml
<li Class="BDP.Core.Requirements.SkillLevelRequirement">
  <Skill>Melee</Skill>
  <MinimumLevel>10</MinimumLevel>
</li>
<li Class="BDP.Core.Requirements.SkillLevelRequirement">
  <Skill>Shooting</Skill>
  <MinimumLevel>6</MinimumLevel>
</li>
```

为了让 `0、负数、小数`都能由 BDP 校验器给出明确错误，`Minimum`和 `MinimumLevel`在作者配置对象中保留原始 `float（浮点数）`输入；通过校验后才转换成运行时整数。这样不会把 `4.5`静默截断成合法的 `4`。

## 正式只读结果

Core 对外只公开不可修改的条件快照：

```csharp
public sealed class PawnRequirementSnapshot
{
    public string Label { get; private set; }
    public string CurrentValueText { get; private set; }
    public string RequiredValueText { get; private set; }
    public bool IsSatisfied { get; private set; }
    public string FailureReason { get; private set; }
}
```

快照提供公开静态工厂，供未来 Content 自定义条件在不取得属性写权限的情况下返回规范结果；属性本身仍不可被外部事后修改。

统一检查结果：

```csharp
public sealed class ChipActivationRequirementCheckResult
{
    public bool Satisfied { get; private set; }
    public IReadOnlyList<PawnRequirementSnapshot> Requirements { get; private set; }
    public IReadOnlyList<PawnRequirementSnapshot> Failures { get; private set; }
}
```

静态详情使用同一种快照，但 `CurrentValueText`为空；角色面板和运行时检查使用完整当前值。
