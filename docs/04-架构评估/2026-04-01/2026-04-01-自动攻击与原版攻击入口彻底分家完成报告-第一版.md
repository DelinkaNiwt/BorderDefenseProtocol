# 自动攻击与原版攻击入口彻底分家完成报告

## 本次完成项

- 已撤销 `CompTriggerBody` 对原版 `IVerbOwner.VerbProperties` / `IVerbOwner.Tools` 的接管。
- 原版武器声明面已回归触发体本体基线，BDP formal host 不再进入原版 `PrimaryVerb` 候选链。
- 自动远程已改为读取表达系统 `PrimaryRanged`，存在合法结果时由 BDP 接管；不存在时完整回退原版。
- 自动近战已改为读取表达系统 `PrimaryMelee`，存在合法结果时由 BDP 独占接管；不存在时完整回退原版近战池。
- `TriggerBodyVerbHostManager` 已收缩为执行侧 formal host 解析层，formal host 壳改为 BDP 内部自持，不再依赖原版 `VerbTracker.AllVerbs`。

## 架构结果

整改后，三层边界已经重新分开：

1. 原版武器本体攻击面：只保留触发体本体自己的基线攻击表面。
2. BDP 表达系统默认主攻击裁定面：继续由 `DefaultPrimaryExpressionSelector` 产出 `PrimaryRanged` / `PrimaryMelee`。
3. BDP 自动攻击桥接执行面：由补丁读取表达系统默认主攻击，再桥接到既有 `AttackExecution`。

这意味着：

- 原版本体入口不需要由 BDP 补画。
- 自动攻击不再借原版武器候选链“误抓” BDP 芯片表达入口。
- 表达出的近战一旦存在，会独占自动近战，不再被原版近战池混合污染。

## 验证结果

已执行并通过：

- `Source/BDP.Tests/AutoAttackSeparationSmokeTests.ps1`
- `Source/BDP.Tests/TriggerSingleTruthSmokeTests.ps1`
- `Source/BDP.Tests/DefaultBurstParitySmokeTests.ps1`
- `Source/BDP.Tests/FormalHostVerbSmokeTests.ps1`
- `dotnet msbuild BDP.csproj -p:Configuration=Debug -t:Build -v:minimal`

## 结论

本次整改已满足“原版入口保留基线、BDP 自动攻击独立新增、表达系统成为唯一默认主攻击来源”的目标。

当前实现不是在结果层补丁掩盖，而是把错误混层拆开：

- 原版只看见触发体本体。
- BDP 自己决定默认主攻击。
- 自动攻击再使用 BDP 的默认主攻击。
- 没有对应表达时，按远程 / 近战两类分别回退原版。
