# 2026-03-23 逐步阅读推进（八）

## 这轮新确认

- 普通芯片表达的统一协议是 `IChipEffect`
- 普通表达来源于 `ChipMode.effectClasses`
- `CompTriggerChip.GetModeEffects()` 会懒加载并缓存每个形态的效果实例
- 当前普通芯片表达已明确投影到四类宿主通道：
  - `Verb`
  - `Ability`
  - `Hediff`
  - 被动外部检测
- 普通芯片表达统一在 `CompTriggerBody.Activation` 中激活 / 关闭
- 组合第三表达统一在普通表达更新后由 `UpdateComboEffects()` 处理
- 读档恢复时也会先恢复普通表达，再恢复组合第三表达
- 这说明旧 BDP 已经自然形成“表达 -> 宿主投影”的总体方向

## 这轮重要观察

- 普通表达和组合表达还不是同一个抽象协议
- 但它们在结构上已经非常接近：
  - 都有统一激活入口
  - 都允许投影到不同宿主通道
  - 都是运行时真实表达，不是临时 UI 数据
- 旧 BDP 这里真正更上位的概念，不该再叫“攻击系统”，而更接近“表达系统”
