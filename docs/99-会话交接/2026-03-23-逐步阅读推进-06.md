# 2026-03-23 逐步阅读推进（六）

## 这轮新确认

- `DualVerbCompositor` 是主攻击投影的规则形成层
- `CompTriggerBody` 是运行时缓存 owner 和对外默认投影查询口
- `GetPrimaryChipVerb()` / `GetPrimaryMeleeChipVerb()` 是旧 BDP 默认攻击投影的正式出口
- `Verb_BDPProxy` 只是原版自动远程桥，不是真业务 owner
- `SyncProxyVerb()` 会根据当前主远程攻击动态创建或清空 `ProxyVerb`
- `TickChipVerbs()` 是芯片 Verb 脱离 `VerbTracker.AllVerbs` 后必须补回的时序链
- `TickChipVerbs()` 不只 tick 主攻击，也 tick 副攻击和组合技
- `lastChipVerbTickedTick` 是防止 JobDriver 手动 tick 与 patch 自动 tick 同 tick 重复推进的关键保护

## 这轮重要观察

- 旧版已经有“规则形成层”和“运行时层”分离意识，但运行时职责仍大量汇聚在 `CompTriggerBody`
- `GetPrimaryChipVerb()` 里仍有右手优先兜底，这说明旧版规则层结果和运行时回退逻辑还没完全拆开
- `TriggerBodyQueries` 只是局部减重复工具，不是统一协议层
