# 2026-04-23 工作推进 卷 02

## 本轮完成

- 已定位远程射击点位校准可视化工具的颜色与含义：
  - 黄=`Pawn.DrawPos`
  - 青=`DrawLoc`
  - 绿=武器绘制位
  - 红 / 蓝=主 / 副枪口
  - 粉 / 薄荷=主 / 副理论中心
  - 橙 / 紫=主 / 副真实发射点
- 已确认紫点记录的是 `ActualLaunchOriginWorld（真实发射原点）`，不是子弹当前视觉中心。
- 已确认子弹白色拖尾落到紫点后方，根因是：
  - 紫点是发射瞬间原点；
  - 投射物贴图按当前 `ExactPosition（精确位置）` 居中绘制；
  - 测试弹使用原版 `Bullet_Small` 贴图；
  - 因此子弹刚出膛时，贴图后半截可能仍覆盖到紫点后方。
- 已确认齐射发射点散布当前不是“每发独立随机”，而是“按序号固定分布”的确定性序列散布：
  - 看起来均匀，是因为序号被映射成左右对称、均值归零的固定比例；
  - 看起来每枪固定，是因为每次齐射都按同样的序号顺序取偏移；
  - 当前随机性主要不在发射点散布，而在命中 / 打偏 / 落点扰动分支。

## 本轮结论

- 问题 1：更接近原版绘制方式与当前贴图锚点共同导致的正常视觉结果，不是这次定位到的新增 BUG。
- 问题 2：当前实现与“随机散布”的直觉不一致；现代码实际实现的是“稳定、对称、可复现”的序列散布。
