# 2026-03-23 逐步阅读推进（五）

## 这轮新确认

- 旧 BDP 自动攻击桥接不是靠大总线，而是精准 patch 三个 RimWorld 原版入口：
  - `Pawn.TryGetAttackVerb`
  - `Pawn_MeleeVerbs.TryMeleeAttack`
  - `VerbTracker.VerbsTick`
- 远程自动攻击通过 `CompTriggerBody.ProxyVerb` 接回原版自动战斗链
- 近战自动攻击通过 `GetPrimaryMeleeChipVerb()` 注入到原版 `verbToUse` 入口
- 芯片 Verb 不进 `VerbTracker.AllVerbs` 是刻意设计
- 因为脱离了 `AllVerbs`，旧版必须自己补回：
  - 自动攻击可选入口
  - `VerbTick()` 推进
  - burst 连射时序
- `TargetSearcher` 也说明旧版很多地方是局部务实工具，不是追求一个大而全的统一系统
