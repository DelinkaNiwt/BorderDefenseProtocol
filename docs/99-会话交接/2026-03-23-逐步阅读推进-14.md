# 2026-03-23 逐步阅读推进（十四）
## 这轮新确认
- `DualVerbCompositor` 已经把“左右表达如何合成为主攻击/双手攻击/混合攻击”这层规则写死
- 它决定的不是运行时发射，而是：
  - 哪些独立 Verb 要保留
  - 是否生成双手合成 Verb
  - 哪个 `isPrimary=true`
  - 单侧/混合/双侧齐射时 `burstShotCount` 如何修正
- `CompTriggerBody.CompGetEquippedGizmosExtra()` 说明玩家手动入口是独立投影层：
  - 左手
  - 右手
  - 双重攻击
  - 组合技
  - 副攻击（右键）
- 手动入口不是只显示主攻击，而是多表达并列投影
- `Patch_Pawn_TryGetAttackVerb` + `ProxyVerb` 构成自动远程入口桥
- `Patch_Pawn_MeleeVerbs_TryMeleeAttack` 构成自动近战入口桥
- `Patch_VerbTracker_VerbsTick` + `TickChipVerbs()` 则是“真实芯片 Verb 脱离 AllVerbs 之后”的时间推进补桥
- 到这一轮为止，Verb 主链已经基本闭环：
  - 表达来源
  - 合成规则
  - 真实 Verb 缓存
  - 主攻击查询口
  - 手动入口投影
  - 自动入口投影
  - Tick 驱动补桥

## 这轮最重要的认识
- 旧 BDP 的合理组织更像“分层投影链”，而不是一个大攻击内核
- 主攻击投影主要支配自动入口和默认表面，不等于全部手动表达
- 自动远程、自动近战、手动按钮，本来就是三条不同宿主口
- 真实表达脱离原版 AllVerbs 之后，必须成套补回入口和 Tick，不是只补一个 Proxy 就够
