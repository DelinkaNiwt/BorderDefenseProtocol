# 2026-03-23 逐步阅读推进（四）

## 这轮新确认

- `Bullet_BDP` 是旧 BDP 里已经比较成熟的宿主统一执行层
- projectile pipeline 的核心不是“模块自己做事”，而是：
  - 模块分阶段提供意图
  - 宿主统一调度和最终执行
- `ApplyFlightRedirect()` 是弹道层核心红线：
  - `origin`
  - `destination`
  - `ticksToImpact`
  - 只允许这里统一写
- `Bullet_BDP.TickInterval()` 的结构已经非常清楚：
  - PostLaunchInit
  - LifecycleCheck
  - FlightIntent
  - vanilla `base.TickInterval`
  - PositionModifier
  - VisualObserve
- `ImpactSomething()` 先做 ArrivalPolicy，再过 `VanillaAdapter`，再回 vanilla 命中链
- `Impact()` 先过 `IBDPImpactHandler`，未处理时才回 `base.Impact`
- `GuidedModule` 只负责折线路径推进
- `TrackingModule` 只负责追踪意图、生命周期请求、到达继续飞
- `ExplosionModule` 只负责命中爆炸效果
- `TrailModule` 只负责视觉拖尾
- `VanillaAdapter` 是单独的“原版兼容隔离层”，不是业务模块
- `Patch_Projectile_FireMode.cs` 说明 projectile 宿主层仍需要少量 RimWorld patch 做接线

## 这轮重要观察

- `TrackingModule` 注释仍写自己实现 `IBDPHitResolver`，但真实代码已经没有，这再次证明旧版注释不能直接当事实
- `VanillaAdapter.ExposeData()` 存在，但当前 `Bullet_BDP.ExposeData()` 没看到调用它
- 这至少说明“适配层跨存档状态恢复”后面值得专门再核一下
