# DevHarness 护盾芯片复现实施计划（Implementation Plan）

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不修改主 BDP 的前提下，于 DevHarness 中实现可装入主副槽、支持单枚与双枚聚合的旧版能量盾芯片。

**Architecture:** 芯片通过新 BDP 的 Hediff（状态）表达和 `countToSeverity`（按数量映射严重度）进入正式宿主同步链。DevHarness 自有 HediffComp（状态组件）承载伤害判定、Trion 扣费与表现，并用两个最小 Harmony（运行时补丁）接入 `Pawn.PreApplyDamage` 和 `Pawn.DrawAt`。

**Tech Stack:** RimWorld 1.6、C# 7.3、.NET Framework 4.8、Harmony、XML、PowerShell 冒烟测试。

**Step 2：实现可直接验证的最小判定策略**

`TestShieldBlockPolicy` 只收纳无状态、确定性的三项计算，并由正式组件直接调用：

```csharp
internal static bool IsWithinArc(
    float pawnAngle,
    float damageAngle,
    bool enableAngleCheck,
    float angleRange,
    float angleOffset)
{
    if (!enableAngleCheck)
    {
        return true;
    }

    float sourceAngle = (damageAngle + 180f) % 360f;
    float relativeAngle = Mathf.DeltaAngle(pawnAngle, sourceAngle);
    float minimum = angleOffset - (angleRange / 2f);
    float maximum = angleOffset + (angleRange / 2f);
    return relativeAngle >= minimum && relativeAngle <= maximum;
}

internal static float ResolveBlockChance(float severity, float singleChance, float stackedChance)
{
    return severity >= 2f ? stackedChance : singleChance;
}

internal static float CalculateTrionCost(float damageAmount, float multiplier)
{
    return damageAmount * multiplier;
}
```

**Step 3：实现核心组件**

`HediffComp_TestShield.TryBlockDamage` 严格保持以下顺序：

```csharp
public bool TryBlockDamage(ref DamageInfo damageInfo)
{
    if (!IsShieldActive || !Props.CanAbsorb(damageInfo.Def))
    {
        return false;
    }

    if (!CheckAngle(damageInfo.Angle) || !CheckBlockChance())
    {
        return false;
    }

    ITrionCommands commands = TrionSurfaceAccess.ResolveCommands(Pawn);
    float cost = damageInfo.Amount * Props.trionCostMultiplier;
    if (commands == null || !commands.TryConsume(cost))
    {
        return false;
    }

    damageInfo.SetAmount(0f);
    PlayBlockEffect(damageInfo);
    return true;
}
```

角度算法保持旧版事实：

```csharp
return TestShieldBlockPolicy.IsWithinArc(
    Pawn.Rotation.AsAngle,
    damageAngle,
    enableCheck,
    range,
    Props.blockAngleOffset);
```

Severity 2 使用叠加参数；概率判定使用 `Rand.Value < chance`，大于等于 1 时直接成功。

**Step 2：实现绘制后置补丁**

**Step 3：实现命中特效播放器**

1. 以 `DamageInfo.Angle + 180°` 计算攻击来源方向；

3. 叠加原版 `ExplosionFlash`；
4. 叠加原版 `Deflect_Metal_Bullet`；
