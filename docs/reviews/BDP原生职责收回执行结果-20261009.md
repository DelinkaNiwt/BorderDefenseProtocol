## 攻击与伤害能力盘点

正式内容当前有 8 个能力。检查按实际宿主与效果归类，而不是按风刃名称修补。

| 能力 | 实际内容 | 通知路径及结论 |
|---|---|---|
| 风刃远程斩击 | 共用射击能力宿主发射投射物，自行启动冷却 | 共用宿主未调用原版能力激活，原通知遗漏；已接入既有原版成功观察 |
| 旋空弧月 | 原版能力激活生成月牙剑气，后续实体造成伤害 | 原版激活成功通知保留，不在每次伤害结算时重复通知 |
| 弹射砍击 | 一次能力激活启动链式位移，沿途碰撞伤害 | 原版激活成功通知保留，不把每段落地或伤害结算作为重新施放 |
| 光魂推进 | 地面位移与对沿途敌人的钝伤、推挤和晕眩 | 原定义错误声明为非敌对，遗漏攻击分类；已更正敌对能力声明，复用原版激活通知 |
| 蚱蜢 | 纯链式位移 | 非攻击，不通知 |
| 战斗体短跳 | 纯跳跃位移 | 非攻击，不通知 |
| 变色龙 | 自施放隐身 | 非攻击，不通知 |
| 皇室契约 | 契约业务 | 非攻击，不因业务成本或状态变化发攻击通知 |

光魂推进只更正 `hostile`（敌对能力声明）；保留 `violent=false`（非暴力动作）、不要求人物具备暴力能力、手动使用和选格参数。举盾远程分类不读取敌对声明，因此仍允许推进。真实原版对此字段的读取只涉及能力激活记录战斗时刻、对人物预热时显示目标盾；推进只选格，没有新增目标盾展示问题。没有为了这个能力新增接口或特例补丁。
