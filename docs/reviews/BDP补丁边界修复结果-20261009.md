# BDP 补丁边界修复结果

日期：2026-10-09。修复对象是《BDP补丁范围审查-20261009》的 F01–F14。原报告和清单保留为审查基线快照；下表说明最终实现，不沿用已删除补丁的旧行号。

## 承伤记录的用途

它是一次明确请求的结果快照，区分护盾吸收、进入正常伤害处理、模块主动取消伤害，以及零伤害。BDP 的减益/附加效果和战斗日志据此处理；不能只凭“扣血为零”判断护盾是否挡住。结果由本次请求返回，不写入存档，也不保存长期人物受伤历史。普通无消费者的伤害不创建记录；独立嵌套伤害只在确有外层上下文时建立临时空边界。

## 验证与限制

- 四程序集按当前源代码正式编译：基础、正式内容、兼容、开发；基础层不依赖任何其他本模组程序集的检查通过。
- 本次新增行为夹具：DamageRequestBoundaryTests、CorePatchTemporaryStateTests（11 项）、ContentPatchBoundaryTests（6 项）、FloatingFlightShieldBoundaryBehaviorTests（9 项），均通过。
- 原有护盾耐久、攻击条件刷新、战斗体倒地/死亡保护、浮空原版指令兼容、浮空网格及动态武器信息冒烟检查通过。静态源码检查只用于结构约束，不代替实际行为证明。
- 交叉审查补丁准入、异常退出、对象寿命、真实原版指令锚点与日志时序；新增诊断文案进入简体中文语言包。未新增玩家功能或改变已确认的光魂破盾语义。

下一步应在游戏中验证：普通人物经过屋顶与死亡无 BDP 副作用；BDP 浮空遇建/拆屋顶正确换路；护盾忽略标志、破盾/恢复及近战/远程限制；跨刻爆炸颜色、护盾拦截后的附加效果和日志；第三方信息条目与芯片半成品恢复。离线夹具不等于游戏内多模组混装实测。
