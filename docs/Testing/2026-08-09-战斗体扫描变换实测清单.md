# 战斗体扫描变换游戏实测清单

## 预期效果

- 生成战斗体：扫描光从头到脚移动；扫描线前方暂时保留原衣物，越过后露出战斗体衣物。
- 解除战斗体：扫描光从脚到头移动；扫描线前方暂时保留战斗体衣物，越过后露出原衣物。
- 整段动画约 24 tick（游戏刻），即正常速度下约 0.4 秒。
- 光线由青绿色柔光和白色细核心组成；没有尘土、爆炸快闪、粒子群或大块矩形尾迹。
- 玩法换装和战斗体状态仍立即完成；短动画只负责表现，不延迟操作或结算。

## 主线检查

- [ ] 普通上衣：生成与解除方向正确，衣物沿扫描边界逐段替换。
- [ ] 裤装或多层身体衣物：各层没有明显错位、闪烁或反向裁切。
- [ ] 帽子：贴合头部位置，不落在身体中心。
- [ ] 腰带或背包：四个朝向下偏移、缩放与原版穿着位置基本一致。
- [ ] 北、东、南、西四朝向：西向贴图不镜像错误，其他方向材质正确。
- [ ] 主动生成与主动解除：每次只播放一套扫描效果，没有旧快闪或重复扫描。
- [ ] 被动崩解或紧急解除：解除扫描正常触发，玩法恢复不被动画延迟。
- [ ] 无衣物 Pawn（角色）：只显示扫描光，不报错。

## 降级与边界检查

- [ ] 倒地、爬行或其他非站立姿态：只显示扫描光，不重绘错位衣物。
- [ ] 带自定义渲染节点的特殊衣物：该衣物不参与裁切，扫描光仍正常。
- [ ] 镜头外发生变换：不生成不可见特效，回到该区域后状态已经正确。
- [ ] 动画期间暂停：扫描随游戏暂停，不按现实时间继续。
- [ ] 一倍、二倍、三倍速度：动画按游戏 tick 推进，方向和结束时间稳定。
- [ ] 动画中旋转 Pawn：不报错；若看到轻微朝向跳变，记录具体衣物和朝向。
- [ ] 多个 Pawn 同时变换：颜色、方向和衣物数据不互相串用。
- [ ] 近距离与远距离镜头缩放：光线覆盖头顶到脚底，不出现异常巨大矩形。
- [ ] 连续快速生成、解除：旧 Mote（特效实体）能够自行结束，不残留在地图上。
- [ ] 存档后读档：短命特效不进入存档，战斗体真实状态和衣物恢复正常。

## 性能观察

- [ ] 单个 Pawn 变换时无可感知卡顿。
- [ ] 10 个左右 Pawn 同时变换时无明显瞬时掉帧。
- [ ] 动画结束后地图上没有持续存在的扫描光或性能下降。

## 问题记录格式

发现问题时请记录：

1. 生成还是解除；
2. Pawn 朝向与姿态；
3. 衣物 DefName（定义名）或截图；
4. 是否仅视觉错误，战斗体状态和衣物实际数据是否正确；
5. 可稳定复现的操作顺序。
