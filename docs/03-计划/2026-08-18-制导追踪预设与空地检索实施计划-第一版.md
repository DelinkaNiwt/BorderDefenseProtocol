## 1. 关键实现基础（已逐行验证，避免计划落空）

1. **`InitialSegmentTriggerRatio` 语义**：`BdpProjectile.ResolveConfiguredInitialFlightPathSnapshot`（L1208-1225）把初始直线段 `Lerp` 缩短到全程 N% 处，到达缩短端点才触发 Arrival。clamp 0.1~1.0，`>=0.999` 视为不缩短。
2. **`MaxRelocks=0` 语义**：`HomingModule.cs` L844 `RelocksUsed < Mathf.Max(0, MaxRelocks)` 恒 false → 丢失直接 `IssueFlyAway`，永不重锁。
3. **配置继承链**：`RangedAttackModuleResolver.ResolveConfigSnapshot`（L81-91）= `mount.config` 优先，回退 `moduleDef.defaultConfig`。`Activator.CreateInstance(runtimeClass)` 创建实例 → 两个 Def 共享一个 runtimeClass 零感知差异。
4. **空地目标全链路已通**：原版 `TargetingParameters.CanTarget` 对空地（Thing==null）返回 `canTargetLocations`；BDP 毒蛇预设已实战 `canTargetLocations=true`；RoutePath 已有 `EnableGroundTargeting` 强制瞄地（私有，需上移）。
5. **落点寻敌原版工具**：`GenClosest.ClosestThing_Global(IntVec3 center, IEnumerable searchSet, float maxDistance, Predicate<Thing> validator, ...)`；候选集合 `map.attackTargetsCache.TargetsHostileToFaction(Faction)`（public，返回 HashSet<IAttackTarget>）。
6. **视线判定原版工具**：`GenSight.LineOfSight(IntVec3 start, IntVec3 end, Map map)`。
7. **空地"落地空放"天然成立**：Homing 追空地格到 `HitWindow` 内 → Hit 阶段 `LockedTarget.HasThing==false` 时 `acceptHit` 为 true，但 `HitRecord.IsValidHit = hitThing != null` 为 false → Impact 无有效命中物 → 落地无伤害。**无需额外代码实现"落地"。**
8. **弹体 Launcher 可取得**：`ArrivalStageContext.Launcher`（Pawn）、`ProjectileInitPlan.Launcher`、`BdpProjectile.Launch(Thing launcher, ...)` 参数均已存在 → 工具类 `hostileToFaction` 来源明确。
9. **Targeting 阶段接入点**：`ITargetingStageModule.Contribute(TargetingRecord)`，`TargetingRecord.TargetingParameters` 公开可写；`RangedAttackModuleSession.GetTargetingModules()` 已按 `Slots[i].Runtime as ITargetingStageModule` 自动收集。

### 阶段 B：公共工具类（新文件，纯新增，无行为变化）

**B1. 新建 `BdpRangedTargetAcquisitionUtility`**

- 文件：`Source/BDP/Core/AttackExecution/BdpRangedTargetAcquisitionUtility.cs`
- 命名空间：`BDP.Core.AttackExecution`
- 性质：`internal static`
- 两个方法（签名见设计文档附录 A）：

```csharp
internal static void EnsureGroundTargetingAllowed(TargetingParameters parameters)
{
    if (parameters == null) return;
    parameters.canTargetLocations = true;
}

internal static LocalTargetInfo FindNearestAcquirableTarget(
    Vector3 origin, Map map, Faction hostileToFaction, float radius,
    bool requireLineOfSight, Predicate<Thing> extraValidator)
```

`FindNearestAcquirableTarget` 实现要点（严格按已验证 API）：
1. `if (radius <= 0f || map == null) return LocalTargetInfo.Invalid;`
2. 候选：`HashSet<IAttackTarget> hostile = map.attackTargetsCache.TargetsHostileToFaction(hostileToFaction);`
3. 物化：`List<IAttackTarget> list = new List<IAttackTarget>(hostile);`（命中 `ClosestThing_Global` 的 `IList<IAttackTarget>` 快速分支，规避 HashSet 强转兜底）。
4. validator：
   ```csharp
   bool Validate(Thing t) =>
       t != null && !t.Destroyed
       && (t is not Pawn p || !p.Downed)
       && (extraValidator == null || extraValidator(t))
       && (!requireLineOfSight || GenSight.LineOfSight(origin.ToIntVec3(), t.Position, map));
   ```
5. `Thing hit = GenClosest.ClosestThing_Global(origin.ToIntVec3(), list, radius, Validate);`
6. `return hit != null ? new LocalTargetInfo(hit) : LocalTargetInfo.Invalid;`

> 说明：`Downed`（倒地）过滤 + `Destroyed`（已销毁）过滤是保守基线，是否加"是否可被追踪"类附加条件留到实测阶段用 `extraValidator` 扩展。

**验收 B**：纯新增文件，不改变任何现有行为；编译通过。

### 阶段 C：Homing 接入空地检索（核心改动）

**C1. `HomingConfig` 新增三字段 + 序列化 + 克隆**

- 文件：`Source/BDP.Content/RangedModules/Homing/HomingConfig.cs`
- 新增：
  ```csharp
  public bool AllowGroundTarget = false;      // 是否允许瞄空地
  public float AcquireRadius = 0f;            // 编码默认 0 = 未启用检索
  public bool AcquireRequireLineOfSight = true;
  ```
- `CloneTyped()` 补三字段；`ExposeData()` 补三条 `Scribe_Values.Look`（默认值分别为 false / 0f / true）。

**C2. `Homing.xml` 的 `BDP_HomingModule_Strong` 默认配置补空地检索默认值**

- 在 `defaultConfig` 里补（Def 默认 5）：
  ```xml
  <AllowGroundTarget>true</AllowGroundTarget>
  <AcquireRadius>5</AcquireRadius>
  <AcquireRequireLineOfSight>true</AcquireRequireLineOfSight>
  ```
- 弱追踪 Def `BDP_HomingModule_Weak` 同样补这三条并使用更小检索半径。

> 编码默认 0 与 Def 默认 5 的配合：无 Def 时 `new HomingConfig()` 得 0 → 关闭检索；Def 显式写 5 → 启用且半径 5。符合"编码默认无/0，Def 默认 5"决策。

**C3. `HomingState` 增加落点捕获标记**

- 文件：`Source/BDP.Content/RangedModules/Homing/HomingState.cs`
- 新增字段：
  ```csharp
  public bool GroundAcquireDone;   // 空地目标是否已完成落点检索（避免每段重复检索）
  ```
- `Clone()`、`ExposeData()` 补该字段（默认 false）。

**C4. `HomingModule` 实现 `ITargetingStageModule`（强制瞄地）**

- 类声明追加 `ITargetingStageModule`。
- 新增实现：
  ```csharp
  void ITargetingStageModule.Contribute(TargetingRecord record)
  {
      if (record == null) return;
      if (config != null && config.AllowGroundTarget)
          BdpRangedTargetAcquisitionUtility.EnsureGroundTargetingAllowed(record.TargetingParameters);
  }
  ```
- 依赖：`config` 在 `IRangedAttackModuleRuntime.Initialize` 已冻结（现有字段），Targeting 阶段在 Initialize 之后 → 可安全读取。

**C5. `HomingModule` ProjectileInit 阶段识别空地目标**

- 文件：`Source/BDP.Content/RangedModules/Homing/HomingModule.cs` `IProjectileInitStageModule.Contribute`
- 在锁定目标后判断空地：
  ```csharp
  bool groundAcquire = lockedTarget.IsValid && !lockedTarget.HasThing && config.AllowGroundTarget && config.AcquireRadius > 0f;
  state.GroundAcquireDone = !groundAcquire;  // 非空地模式直接视为"无需检索"
  ```
- 空地模式下，`ProjectileInit` 照常写 `OverrideCurrentTarget = lockedTarget`（空地格），弹体仍直飞落点；仅额外标记待检索。

**C6. `HomingModule` Arrival 阶段插入落点捕获分支**

- 文件：同 C5，`IArrivalStageModule.Contribute`
- 插入位置：在现有"目标解析失败 → FlyAway"之后、"距离/丢失判定"之前，新增：
  ```csharp
  // 空地目标落点捕获：只在尚未完成检索时执行一次
  if (config != null && config.AllowGroundTarget
      && state.LockedTarget.IsValid && !state.LockedTarget.HasThing
      && !state.GroundAcquireDone)
  {
      state.GroundAcquireDone = true;  // 无论成败，只检索一次
      float acquireRadius = config.AcquireRadius;
      if (acquireRadius > 0f)
      {
          LocalTargetInfo acquired = BdpRangedTargetAcquisitionUtility.FindNearestAcquirableTarget(
              projectilePos,                                  // 子弹自身位置
              context.Map,
              context.Launcher != null ? context.Launcher.Faction : null,
              acquireRadius,
              config.AcquireRequireLineOfSight,
              null);
          if (acquired.IsValid)
          {
              state.LockedTarget = acquired;   // 咬住最近合法目标
              // 后续继续走常规追踪（Pursuing 分支会用它重建追踪曲线）
          }
          // 检索失败：保持空地格目标，继续飞向落点，最终自然落地
      }
  }
  ```
- 注意：捕获成功后 `state.LockedTarget` 已切换为实体，后续 `TryResolveTargetPosition` / 距离判定 / 丢失判定全部自然作用于新目标，无需改现有追踪逻辑。
- 触发时机：`AcquireRadius`（默认 5）作为"到落点多近才开始检索"的阈值。是否要加"距离 <= AcquireRadius 才检索"的 gate 由实测定——当前先采用"Arrival 首次裁决即检索一次"的简单实现，避免复杂化。

**C7. Hit 阶段无需改动**

- 空地目标检索失败时：`LockedTarget.HasThing==false` → 现有 Hit 分支 `acceptHit = distance <= HitWindow` 为 true 但 `IsValidHit=false` → 落地空放（已验证天然成立）。
- 检索成功时：`LockedTarget.HasThing==true` → 现有 Hit 分支正常判定命中实体。

**验收 C**：
- 编译通过。
- 玩家可对空地开火（瞄准环允许点地面）。
- 弹体直飞落点，到落点附近咬住半径内最近敌人；无敌人则落地无伤害。
- 视线外空地：当前仍不可瞄（`DirectTargetLineOfSight` 未动）。

### 阶段 D：游戏实测清单

1. **预设 B（弱追踪）**：换 `BDP_HomingModule_Weak` 后，确认前 90% 直飞、追丢直接飘走不重锁。
2. **空地检索**：瞄敌人必经空地 → 弹到点咬最近敌人；瞄无人空地 → 落地空放。
3. **半径手感**：`AcquireRadius=5` 是否过大/过小，实测后回调 Def 值。
4. **视线开关**：`AcquireRequireLineOfSight` true/false 对比，确认挡墙后是否还能咬人。
5. **回归**：标准追踪（0.5/2）+ 猎犬原行为不变；毒蛇（RoutePath）不受影响。

## 4. 风险与注意事项

1. **`config` 在 Targeting 阶段是否已 Initialize**：`RangedAttackModuleResolver.ResolveSlots` 先 `runtime.Initialize(...)` 再入库 → Targeting 阶段调用时 `config` 已就绪。若实测发现 Targeting 早于 Initialize，需把 `config` 读取改到 `HomingState`（ProjectileInit 才冻结）——**风险点，实测首查**。
2. **Arrival 检索只做一次**：`GroundAcquireDone` 保证不每段重复检索、不抖动换目标。若后续想"每段重扫最近目标"再放开。
3. **`ClosestThing_Global` 的 HashSet 强转**：工具类已物化为 `List<IAttackTarget>` 规避，不依赖隐式强转。
4. **Downed 过滤**：倒地 Pawn 是否仍可被追踪命中有玩法争议，先用保守过滤，实测再定。
5. **存档兼容**：新增字段均有默认值（`Scribe_Values.Look` 带 default），旧存档反序列化不炸。
6. **模块独立性**：Homing 只引用 `BdpRangedTargetAcquisitionUtility`（公共工具），不引用 RoutePath/AreaExplosion。
