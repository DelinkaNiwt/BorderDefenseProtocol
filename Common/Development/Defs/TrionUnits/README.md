# 轻型试作兵01：生成、测试与移除

这是独立开发样本，复用正式基底，没有生产配方、派系投放或新能力。1.6、1.7共用定义，分别加载对应的开发程序集。

## 样本配置

| 项目 | 配置 |
|---|---|
| 外观与身体 | 原版搬运机贴图、轻型机械身体 |
| Trion | 容量1000、释放力10，无自然恢复 |
| 移动 | 每秒4.6格 |
| 内置能力 | 现成阿莱克托与自动盾，特殊槽同时激活 |
| 尸体产物 | 拆解后获得10钢，沿用原版轻型机械体默认值 |
| 玩家运行前置 | 独立测试许可、测试座归属、2点测试带宽 |
| 操控 | 原版征召；正式基底的自动战斗按钮，默认关闭 |
| 资源显示 | 玩家兵显示现成 Trion 状态条，停机仍可看生命余额 |
| 芯片资格 | 豁免芯片声明的角色激活资格，资源费用及装配规则各自照常 |

芯片初始化费用沿既有规则，因此初始余额可能略低于容量。补满工具只补资源，不修复伤势；敌方样本仍承受真实伤口泄露和原版机械体死亡规则。

永久战斗体健康标记通过原版阶段配置隐藏，材料效果保留。原版会在存档中记住已经显露的状态，因此旧试作样本先清除再重新生成；正常健康页不显示该标记，开发者“显示全部健康状态”仍可查看。

## 游戏内使用

1. 加载本版最新开发程序集，进入有生物科技扩展的地图并开启开发者模式。
2. 打开调试动作，在 BDP（模组）分类中找到“Trion兵基底验证”；菜单可搜索“试作兵”。
3. 选择“生成轻型试作兵01与测试座”，点击空地，右侧留一格给测试座。生成后自动选中玩家兵并建立许可和绑定。
4. 让游戏运行片刻完成初始化；可征召操作，也可开启“自动战斗”。用“生成敌方轻型试作兵01”提供敌情，敌方生成不会改掉当前玩家选择。
5. 同菜单提供许可、带宽、解绑／重绑、伤口、资源耗尽／补满和接入检查。检查输出在游戏日志中，标记为 `[BDP.TrionUnit]`。
6. “清除本图试作兵、尸体与测试座”删除当前地图上的这一专属样本，不删除普通机械体或正式兵种。

当前没有自动工作类型；具体战术沿正式基底的临时原版子树，测试数值不代表平衡结论。

征召移动沿原版命令队列：直接点击应立即接入走动作业，用原版排队键才顺次安排多段命令。未征召时隐藏战斗入口与盾卡，资源条和自动战斗开关仍可用；隐藏界面不会取消已启用护盾或自主作战。

## 死亡复活检查

使用已有“检查身体、装配与停机效果”，日志会列出内部触发体与主装备标识、已装芯片数以及各槽芯片标识／激活／禁用状态。先记录正常样本，再用原版开发工具杀死并复活，让游戏运行片刻完成激活，重新征召后检查按钮与攻击／护盾表现。重复两轮，并保存读档再检查。

死亡会销毁旧内部装配；复活后应有新标识的触发体和两枚预载芯片，两个特殊槽均激活。读档或普通转图应保留原装配标识，不重复制造芯片；已激活槽不会重复收费。停机复活时仍恢复槽位激活，但功能须等运行条件成立才发布。

另测资源耗尽死亡：先复活并在游戏继续运行前补回资源，检查不会被旧耗尽状态再次杀死。复活本身不补Trion；保持零余额时，下一次逐刻处理仍应死亡。可在耗尽前记录样本标识，复活后对照相同角色与新装配。

## 独立拔除

先清除存档里的样本并保存退出；当前图清除工具包含尸体，旅行队或容器内的样本先取回地图清除。随后移除下列路径，均相对于模组根目录：

- `Source/BDP.Development/Trion/Units/`（两份开发源码）。
- `Common/Development/Defs/TrionUnits/`（测试定义和本说明）。
- `Common/Development/Languages/ChineseSimplified (简体中文)/Keyed/TrionUnitDebug.xml`（菜单文案）。
- `Common/Development/Languages/ChineseSimplified (简体中文)/DefInjected/ThingDef/TrionUnitDebug.xml`（物品与种族文案）。
- `Common/Development/Languages/ChineseSimplified (简体中文)/DefInjected/PawnKindDef/TrionUnitDebug.xml`（款型文案）。

从主模组根目录分别重建开发程序集，旧编译类型才会真正移除：

```powershell
dotnet msbuild Source/BDP.Development/BDP.Development.csproj -restore -p:RimWorldVersion=1.6 -p:Configuration=Release
dotnet msbuild Source/BDP.Development/BDP.Development.csproj -restore -p:RimWorldVersion=1.7 -p:Configuration=Release
```

正式基础、兵组件和自动战斗功能保留；开发入口自动发现，不需要改正式启动代码。重新插回上述文件并分别重建开发程序集，即可恢复样本。
